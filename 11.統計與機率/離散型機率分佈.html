伯努利分佈 (Bernoulli Distribution)

$X \sim \text{Bernoulli}(p), \quad \Omega = \{0, 1\}$
SVG 資訊圖 1 · 伯努利二元狀態空間與成功轉移圖解 Binary State Machine & Probability Density
歷史由來 & 生活場景

以瑞士數學家雅各布·伯努利（Jacob Bernoulli）命名，他在 1713 年出版的《猜度術》中開創性推導出歷史上首個大數法則。生活實例包括單次投擲硬幣正面、棒球擊球員揮棒是否擊出安打、電子信件是否被判定為垃圾郵件。

半導體工業 / AOI 檢測：

自動光學檢測機台對單一 Die 晶粒表面掃描輸出二值分類結果（0: 良品合格，1: 發生金屬線路搭橋短路）。

PMF 與矩推導公式

$$P(X=k) = p^k (1-p)^{1-k}, \quad k \in \{0, 1\}$$

$$E[X] = 0\cdot(1-p) + 1\cdot p = p$$

$$Var(X) = E[X^2] - (E[X])^2 = p - p^2 = p(1-p)$$

當 $p=0.5$ 時方差最大 ($Var = 0.25$)，信息熵達到峰值；當 $p=0$ 或 $1$ 時系統具備完全確定性。

Chapter 02 · Sum of Independent Trials

二項分佈 (Binomial Distribution)

$X \sim B(n, p), \quad X = \sum_{i=1}^n X_i$
SVG 資訊圖 2 · 帕斯卡三角路徑分流與二項式組合數幾何圖解 Pascal Triangle Paths & Galton Board Flow
帕斯卡賭注與 AQL 品質工程

源自帕斯卡與費馬在 1654 年探討的賭金分配問題，二項分佈將所有可能路徑的組合數精準定型為 $\binom{n}{k} = \frac{n!}{k!(n-k)!}$。在半導體製造與電子裝配中，被廣泛用於 AQL (Acceptable Quality Limit) 抽樣檢驗規範，在批次抽檢 $n$ 件成品中決定合格與拒收判定界線。

PMF 與線性期望值矩推導

$$P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}, \quad k \in \{0, 1, \dots, n\}$$

$$E[X] = E\left[\sum_{i=1}^n X_i\right] = \sum_{i=1}^n E[X_i] = np$$

$$Var(X) = \sum_{i=1}^n Var(X_i) = np(1-p)$$

各試驗彼此獨立，$Cov(X_i, X_j) = 0$。當 $np \ge 5$ 且 $n(1-p) \ge 5$ 時，二項分佈可由常態分佈 $\mathcal{N}(np, np(1-p))$ 進行極佳近似。

泊松分佈 (Poisson Distribution)

$X \sim \text{Poisson}(\lambda), \quad E[X] = Var(X) = \lambda$
SVG 資訊圖 3 · 連續時間區間微元切分 (dt) 與稀有到達極限定理 Continuous Time Slicing & Poisson Point Process
普魯士馬踢致死與排隊論

法國數學家西梅翁·卜瓦松在 1837 年提出，1898 年博特基維茨研究普魯士騎兵團 20 年間士兵被馬踢致死數據完美印證。現代雲端微服務（Kubernetes HPA）之 API 每秒請求流量（RPS）、網路交換機封包到達均遵循泊松點過程。

PMF 與均值方差恆等性

$$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k \in \{0, 1, 2, \dots\}$$

$$E[X] = \lambda, \quad Var(X) = \lambda$$

$$\text{Additivity: } X_1 + X_2 \sim \text{Poisson}(\lambda_1 + \lambda_2)$$

$E[X] = Var(X) = \lambda$ 稱為等散佈（Equidispersion）。當數據樣本方差遠大於均值時即為超散佈，須轉用負二項分佈。

bernoulli_bce.py 
import scipy.stats as stats
import torch
import torch.nn as nn
from torch.distributions import Bernoulli

# 1. SciPy 統計計算
p = 0.65
dist = stats.bernoulli(p)
print(f"P(X=1): {dist.pmf(1):.4f}")
print(f"E[X]: {dist.mean():.4f}, Var: {dist.var():.4f}")

# 2. PyTorch 抽樣
p_tensor = torch.tensor([0.65])
bern = Bernoulli(probs=p_tensor)
sample = bern.sample((5,))
print("隨機樣本:", sample.squeeze().tolist())

# 3. BCE 損失驗證
logits = torch.tensor([0.619], requires_grad=True)
target = torch.tensor([1.0])
criterion = nn.BCEWithLogitsLoss()
loss = criterion(logits, target)
print(f"BCE Loss: {loss.item():.4f}")

poisson_traffic.py 
import scipy.stats as stats
import torch
from torch.distributions import Poisson

lam = 4.0

# 1. SciPy 稀有事件機率
dist = stats.poisson(mu=lam)
print(f"P(X=0) 零請求: {dist.pmf(0):.4f}")
print(f"P(X=4) 峰值機率: {dist.pmf(4):.4f}")
print(f"均值: {dist.mean():.2f}, 方差: {dist.var():.2f}")

# 2. PyTorch 伺服器流量模擬
rate = torch.tensor([lam])
torch_poi = Poisson(rate=rate)
samples = torch_poi.sample((1000,))
print(f"採樣均值: {samples.mean().item():.3f}")
print(f"採樣方差: {samples.var().item():.3f}")
