統計推論核心方法

假設檢定（Hypothesis Testing）

假設檢定是統計推論的核心方法之一，用來透過樣本數據去判斷關於母體參數的主張是否站得住腳。它的核心邏輯類似「法庭審判」：先假設被告無罪，再檢視證據是否強烈到足以推翻無罪假設。

虛無假設 H₀ Negative (維持現狀)
型一錯誤 (α) 偽陽性 (棄真)
型二錯誤 (β) 偽陰性 (存偽)
檢定力 (Power) 1 − β (正確檢出)

基本概念與核心名詞

建立嚴謹推論的必備名詞基石

虛無假設 (Null Hypothesis) H₀

通常代表「沒有差異」、「沒有效果」或「維持現狀」的起始假設，是我們企圖尋找充分證據去推翻的對象。

對立假設 (Alternative) H₁ / Hₐ

與虛無假設相反的敘述，通常是研究者真正想要證明的「有差異」或「有顯著效果」。

顯著水準 (Significance Level) α

容許犯下「型一錯誤」的最高機率界線，產業界與學界常用標準為 0.05 (5%) 或 0.01 (1%)。

p 值 (p-value) p

在虛無假設為真的前提下，觀察到目前樣本數據或比目前數據更極端的機率。越小代表越罕見。

檢定統計量 (Test Statistic) Z, t, χ², F

將樣本數據透過公式標準化或轉換後得到的數值（如標準常態 Z 值、學生 t 值、卡方值 χ²、變異數分析 F 值 等），用以評估樣本與 H₀ 的偏離程度。

四大關鍵檢定統計量深度剖析

標準常態 Z 值、學生 t 值、卡方值 χ²、變異數分析 F 值之定義、分佈與 AI 實務應用

IPAS AI 考題高頻考點
1

標準常態 Z 值 (Z-score)

N(0, 1)

定義：將樣本均值與假設的母體均值之間的差距，以標準誤（Standard Error）為尺度進行標準化轉換後的數值。它衡量樣本平均數距離虛無假設中心「相差幾個標準差」。

標準化公式：
Z = (X̄ − μ₀) / (σ / √n)
（需已知母體標準差 σ，或大樣本 n ≥ 30 符合中央極限定理）
理論分佈：完美的標準常態分佈，對稱且尾部固定（±1.96 涵蓋 95% 信心區間）。
AI / 工業應用：海量生產線推論延遲（n > 10,000）基準線比對、大數據集 A/B 轉換率雙比例 Z 檢定。
💡 口訣特徵：母體標準差已知，或樣本數大（n ≥ 30）時直上 Z 檢定！
2

學生 t 值 (Student's t)

t(df = n − 1)

定義：在母體變異數未知且只能使用「樣本標準差 S」來估計母體標準差時所用的檢定統計量。因額外估計了標準差，引發了額外的不確定性。

小樣本估計公式：
t = (X̄ − μ₀) / (S / √n)
自由度 df = n − 1；當 n → ∞ 時，t 分佈逼近 Z 分佈
理論分佈：鐘形對稱，但肥尾（Heavy-tailed）且較平緩，自由度越小尾部越厚，更容忍極端波動。
AI / 工業應用：成對比較新舊神經網路在 10-Fold 交叉驗證上的 F1 分數（Paired t-test）、邊緣設備少樣本耗能差異。
💡 口訣特徵：母體變異數未知、樣本小（n < 30），務必以樣本標準差 S 搭配自由度查 t 表！
3

卡方值 χ² (Chi-Square)

χ²(df)

定義：多個獨立標準常態變數平方和的分佈。在列聯表檢定中，用來衡量「實際觀察頻率 (O)」與「理論期望頻率 (E)」之間的累積偏離程度。

獨立性與適配度檢定公式：
χ² = ∑ [ (O − E)² / E ]
列聯表自由度 df = (列數 − 1) × (行數 − 1)
理論分佈：非對稱、右偏（Right-skewed）且數值恆正（≥ 0）。自由度愈大時逐漸接近對稱常態。
AI / 工業應用：類別特徵工程篩選（SelectKBest(chi2)）、NLP 詞彙與情感標籤獨立性檢定、混淆矩陣分佈適合度檢定。
💡 口訣特徵：平方和恆正、右偏分佈；專門處理類別變數關聯度與特徵重要性！
4

變異數分析 F 值 (ANOVA F-statistic)

F(df₁, df₂)

定義：兩個獨立卡方變數各自除以其自由度後的比值（變異比 Ratio of Variances）。在變異數分析（ANOVA）中，衡量「組間變異（信號）」相對於「組內變異（雜訊）」的相對倍數。

訊號雜訊比 (信噪比) 公式：
F = MS_between / MS_within = (SSB/df₁) / (SSW/df₂)
若組間變異遠大於隨機誤差，F 值便顯著大於 1
理論分佈：嚴格正值、右偏分佈，取決於分子自由度 df₁（組數 − 1）與分母自由度 df₂（總樣本數 − 組數）。
AI / 工業應用：三種以上深度學習架構/學習率配置的多組別效能比較（ANOVA）、多元線性迴歸整體的顯著性檢定（Regression Overall Test）。
💡 口訣特徵：組間變異比組內變異（信號 / 雜訊）；比較三組以上平均值是否相同時必用 F 檢定！

四大統計量快速選用決策樹

使用 Z 檢定？

母體變異數已知、或大樣本數（n ≥ 30），比較單一或兩組平均值。

使用 t 檢定？

母體變異數未知、樣本較小（n < 30），以樣本標準差 S 進行推論。

使用 χ² 檢定？

變數為類別型（非連續數值），檢測兩變數獨立性或次數分配配適度。

使用 F 檢定？

比較三組或以上實驗組的平均數差異（ANOVA），或檢定兩群體變異數是否同質。

型一錯誤 (Type I Error, α)：

實際上沒有差別，但你宣稱有差別（「偽陽性」）。例如：無辜者被判有罪；新舊模型無實質提升，卻被誤認為大幅進步。

型二錯誤 (Type II Error, β)：

實際上真的有差別，但你的樣本不足或沒測出來（「偽陰性」）。例如：罪犯證據不足獲釋；新特徵確實能提升模型表現卻被過濾遺漏。

生活化比喻：法庭無罪推定

直觀理解型一與型二錯誤

  • 預設立場: 被告預設是清白的（H₀：清白無辜者）。
  • 型一錯誤: 被告本無辜，卻被法官冤枉判刑有罪（冤獄 / 偽陽性 FP，機率 α）。
  • 型二錯誤: 被告明明有罪，卻因證據微弱被判無罪釋放（縱放 / 偽陰性 FN，機率 β）。
  • p-value: 假設嫌疑人真的是無辜的，現場採集到如此不利證據的機率有多極端罕見。
💡 核心考點： 事先嚴格設定顯著水準 α（通常為 0.05 或 0.01），就是在控制冤獄發生的最大容忍上限！

假設檢定的五大步驟

掌握標準推論邏輯流程，徹底根除誤判盲點

1

建立假設

明確寫出虛無假設 H₀ 與對立假設 H₁。

H₀: μ = μ₀
H₁: μ ≠ μ₀
2

設定顯著水準

決定 α 值（例如 α = 0.05 或 0.01）。

型一錯誤上限 α
3

計算檢定統計量

依資料類型與變異數已知與否，選用適用的檢定公式（單一樣本 Z 檢定、t 檢定、卡方檢定等）。

Z / t / χ² / F
4

算出 p 值或臨界值

算出 p 值或尋找臨界值，比較檢定統計量與拒絕域的關係。

P(Data | H₀)
5

做出決策

• 若 p ≤ α：拒絕虛無假設 (H₀)，接受對立假設，代表結果具「統計顯著性」。
• 若 p > α：不拒絕虛無假設 (H₀)，代表目前證據不足以推翻現狀（不等於證明 H₀ 一定正確）。

p ≤ α → 拒絕 H₀

實務工程開發

Python / SciPy 雙樣本獨立 t 檢定實作

# IPAS AI 實務標準流程：新舊深度學習模型推論延遲 (Latency ms) Welch's t-test
import numpy as np
from scipy import stats

def evaluate_model_improvement(baseline_latencies: np.ndarray, new_latencies: np.ndarray, alpha: float = 0.05):
    """
    使用 Welch's t 檢定驗證新模型推論耗時是否顯著優化 (不假設變異數相等)
    """
    n_base, n_new = len(baseline_latencies), len(new_latencies)
    mean_base, mean_new = np.mean(baseline_latencies), np.mean(new_latencies)
    
    # 核心重點函式：stats.ttest_ind (equal_var=False 即為 Welch's t-test)
    t_stat, p_value = stats.ttest_ind(
        new_latencies, 
        baseline_latencies, 
        equal_var=False, 
        alternative='two-sided'
    )
    
    print(f"[統計檢驗結果] t統計量 = {t_stat:.4f}, p值 = {p_value:.6f}")
    
    if p_value <= alpha:
        decision = "拒絕 H0 (統計顯著)：新模型與基準組延遲有顯著性差異！"
    else:
        decision = "不拒絕 H0 (無顯著差異)：現存樣本證據不足以證明改良效果。"
        
    return {"t_stat": t_stat, "p_val": p_value, "decision": decision}

if __name__ == "__main__":
    np.random.seed(42)
    # 模擬基準模型 (mu=45.0ms) 與優化模型 (mu=42.8ms) 各採樣 50 次推論耗時
    baseline_data = np.random.normal(loc=45.0, scale=3.2, size=50)
    optimized_data = np.random.normal(loc=42.8, scale=3.0, size=50)
    
    result = evaluate_model_improvement(baseline_data, optimized_data, alpha=0.05)
    print("決策判定:", result["decision"])
stats.ttest_ind 雙樣本獨立 t 檢定必用核心函式。
equal_var=False 啟用 Welch's 修正，避免變異數不齊性引發之誤判。
p_value <= alpha 程式化判定門檻，嚴格遵循預先定義之顯著水準。
