「你看得見外部表象，看不見內在真實狀態」

隱馬可夫模型 (Hidden Markov Model, HMM) 是一種專門處理時序序列 (Sequential Data)的統計機率圖形模型。它假設背後運行著一個不可直視的隱藏狀態鏈 (Hidden State Sequence)，外部唯一能測量到的，只是隱藏狀態隨機發射出來的表面觀測值 (Observation Sequence)。

假設一：一階馬可夫假設

目前時刻的隱藏狀態 $S_t$ 僅受前一時刻 $S_{t-1}$ 影響，與更早的歷史完全條件獨立（無長程記憶）： $$P(S_t \mid S_{t-1}, S_{t-2}, \dots, S_1) = P(S_t \mid S_{t-1})$$

假設二：觀測獨立性假設

任何時刻產生的觀測值 $O_t$ 僅由當前隱藏狀態 $S_t$ 決定，與其他時刻的狀態或觀測值皆獨立： $$P(O_t \mid S_t, S_{t-1}, O_{t-1}, \dots) = P(O_t \mid S_t)$$

HMM 歷史發展里程碑
1906 · Andrey Markov

提出馬可夫鏈 (Markov Chain)，分析俄語詩歌母音與子音轉移，奠定無後效性隨機過程基礎。

1960s-1970s · Leonard Baum

發展出隱含隨機狀態統計理論，並發明著名的 Baum-Welch 演算法（即 EM 期望最大化演算法在 HMM 中的經典形式）。

1989 · Lawrence Rabiner

發表歷史級經典論文《A Tutorial on Hidden Markov Models》，統一規範了 HMM 三大問題與現代語音辨識、生物資訊架構。

HMM 三大經典問題與演算法全解析 核心命題熱點

所有的 HMM 應用與理論，皆圍繞這三個本質問題展開：評估、解碼、學習。

模型三元組：$\lambda = (A, B, \pi)$
問題一 · 評估 Evaluation

評估問題 (Evaluation Problem)

計算生成機率：$P(O \mid \lambda)$

【輸入條件】給定模型參數 $\lambda = (A, B, \pi)$ 與觀測序列 $O = (O_1, \dots, O_T)$。

【目標任務】計算該特定觀測序列發生的總機率 $P(O \mid \lambda)$。

標準解法演算法：
前向演算法 (Forward) / 後向演算法 (Backward)
暴力窮舉時間複雜度為 $\mathcal{O}(N^T)$（不可行）；透過動態規劃將重複子問題記憶化，大幅壓縮至 $\mathcal{O}(N^2 T)$！
🎯 典型場景：語音辨識中比對哪個單詞模型的生成機率最高。
問題二 · 解碼 Decoding

解碼問題 (Decoding Problem)

推論最優路徑：$\arg\max_S P(S \mid O, \lambda)$

【輸入條件】給定模型參數 $\lambda$ 與觀測序列 $O$。

【目標任務】在所有可能的隱藏狀態序列中，找出機率最大的最優路徑 $S^* = (s_1^*, s_2^*, \dots, s_T^*)$。

標準解法演算法：
維特比演算法 (Viterbi Algorithm, 動態規劃 DP)
記錄到達時刻 $t$ 各狀態的最大路徑機率 $V_t(j)$ 與最佳前驅節點 $\psi_t(j)$，時間複雜度同樣為 $\mathcal{O}(N^2 T)$。
🎯 典型場景：看室友配件猜天氣、NLP 詞性標註、工廠機台磨損階段推論。
問題三 · 學習 Learning / Training

學習問題 (Learning Problem)

參數最佳化：$\max_\lambda P(O \mid \lambda)$

【輸入條件】僅給定大量表面觀測序列 $O$（無隱藏狀態標註，非監督式學習）。

【目標任務】自動調整估計模型參數 $\lambda = (A, B, \pi)$，使得觀測似然度最大化。

標準解法演算法：
鮑姆-韋爾奇演算法 (Baum-Welch Algorithm, 即 EM 演算法)
交替執行 E-Step（計算隱含狀態後驗期望機率）與 M-Step（極大化重新更新矩陣參數），保證單調收斂至局部最優解。
🎯 典型場景：在沒有人工標籤的情況下，從感測器歷史大數據自學設備模型。

HMM 模型三元組參數 $\lambda = (A, B, \pi)$ 的嚴謹定義

矩陣 A：狀態轉移機率矩陣
$$a_{ij} = P(S_{t+1} = s_j \mid S_t = s_i)$$

維度為 $N \times N$，每列機率和必須滿足 $\sum_{j=1}^N a_{ij} = 1$。描述底層隱藏世界自身變遷規律。

矩陣 B：觀測發射/混淆矩陣
$$b_j(k) = P(O_t = v_k \mid S_t = s_j)$$

維度為 $N \times M$，每列機率和滿足 $\sum_{k=1}^M b_j(k) = 1$。描述各隱藏狀態隨機發射出特定觀測值的機率。

向量 $\pi$：初始狀態機率分佈
$$\pi_i = P(S_1 = s_i)$$

維度為 $N \times 1$，總和滿足 $\sum_{i=1}^N \pi_i = 1$。系統在時間 $t=1$ 開始時各隱藏狀態的先驗分佈。

前向演算法 (Forward Algorithm)

定義前向變數 $\alpha_t(i)$ 為時刻 $t$ 觀測到 $O_1, \dots, O_t$ 且狀態為 $s_i$ 的聯合機率：

1. 初值化 ($t=1$)：
$$\alpha_1(i) = \pi_i \cdot b_i(O_1)$$
2. 遞推式 ($t=1 \to T-1$)：
$$\alpha_{t+1}(j) = \left[ \sum_{i=1}^N \alpha_t(i) a_{ij} \right] \cdot b_j(O_{t+1})$$
3. 終結求和：
$$P(O \mid \lambda) = \sum_{i=1}^N \alpha_T(i)$$
維特比演算法 (Viterbi Algorithm)

定義 $V_t(j)$ 為到達時刻 $t$ 狀態為 $s_j$ 的最大路徑機率；$\psi_t(j)$ 記錄回溯最佳前驅：

1. 初值化 ($t=1$)：
$$V_1(i) = \pi_i \cdot b_i(O_1), \quad \psi_1(i) = 0$$
2. 動態規劃遞推：
$$V_t(j) = \max_{1 \le i \le N} [V_{t-1}(i) a_{ij}] \cdot b_j(O_t)$$
$$\psi_t(j) = \arg\max_{1 \le i \le N} [V_{t-1}(i) a_{ij}]$$
3. 終結與回溯：
$$S_T^* = \arg\max_i V_T(i), \quad S_t^* = \psi_{t+1}(S_{t+1}^*)$$
鮑姆-韋爾奇 (Baum-Welch EM)

透過前向後向變數計算隱含狀態後驗期望機率 $\gamma_t(i)$ 與狀態轉移期望機率 $\xi_t(i,j)$：

E-Step (期望步)：
$$\gamma_t(i) = P(S_t = s_i \mid O, \lambda)$$
$$\xi_t(i,j) = P(S_t = s_i, S_{t+1} = s_j \mid O, \lambda)$$
M-Step (極大化更新)：
$$\bar{a}_{ij} = \frac{\sum_{t=1}^{T-1} \xi_t(i,j)}{\sum_{t=1}^{T-1} \gamma_t(i)}, \quad \bar{\pi}_i = \gamma_1(i)$$

工業與 AI 應用：為什麼 HMM 不可或缺？

當關鍵特徵隱藏於物理內部或底層結構時的經典落地場景

智慧製造：預測性維護 (PHM)

觀測: 振動頻譜、溫度感測
隱藏: [良好➔微磨損➔危險]

工廠刀具與馬達軸承無法隨時拆機。工程師透過外貼加速規的振動訊號，利用 HMM 維特比演算法推論內部磨損階段與剩餘可用壽命 (RUL)。

語音辨識：經典聲學模型 (ASR)

觀測: 梅爾倒頻譜係數 (MFCC)
隱藏: 音素 (Phoneme) 狀態序列

說話語速有快有慢，時間長度不固定。GMM-HMM 透過轉移機率矩陣吸收語速彈性，精確將連續波形特徵對齊到文字音素。

自然語言處理：詞性標註 (POS)

觀測: 句子中的文字單詞
隱藏: 詞性標籤 (名詞/動詞/形容詞)

「研究」可以是動詞或名詞。HMM 根據前一個詞的詞性轉移到下一詞性的文法規律，精確解碼消解語義歧義。

生物資訊：DNA 基因外顯子定位

觀測: 鹼基序列 (A, T, C, G)
隱藏: 基因區域 (外顯子/內含子)

DNA 鏈由數十億個字母構成。HMM 能在未標註的鹼基鏈中，自主劃分並解碼出真正負責合成蛋白質的編碼區段 (Exon)。

Python + hmmlearn 實作範例

hmm_weather_roommate.py
Python 3.9+ / hmmlearn 
# 安裝套件指令: pip install hmmlearn numpy
import numpy as np
from hmmlearn import hmm

# 1. 定義狀態與觀測維度
states = ["Sunny (晴天)", "Rainy (雨天)"]
n_states = len(states)

observations = ["Umbrella (雨傘)", "Sunglasses (墨鏡)"]
n_observations = len(observations)

# 2. 建立 Categorical HMM 模型 (處理離散觀測值)
model = hmm.CategoricalHMM(n_components=n_states, algorithm="viterbi")

# 3. 設定模型參數 lambda = (pi, A, B)
# 初始機率分佈 pi: 晴天 0.6, 雨天 0.4
model.startprob_ = np.array([0.6, 0.4])

# 狀態轉移矩陣 A (Transition Matrix)
model.transmat_ = np.array([
    [0.7, 0.3],  # Sunny -> [Sunny, Rainy]
    [0.4, 0.6]   # Rainy -> [Sunny, Rainy]
])

# 觀測發射矩陣 B (Emission Matrix)
model.emissionprob_ = np.array([
    [0.1, 0.9],  # 晴天 -> [雨傘 0.1, 墨鏡 0.9]
    [0.8, 0.2]   # 雨天 -> [雨傘 0.8, 墨鏡 0.2]
])

# 4. 室友帶出門的配件觀測序列: [雨傘(0), 雨傘(0), 墨鏡(1)]
obs_seq = np.array([[0], [0], [1]])

# 5. 解碼問題 (Decoding) - 執行維特比演算法
log_prob, hidden_states = model.decode(obs_seq, algorithm="viterbi")

print("=== 維特比演算法解碼結果 ===")
print(f"對數聯合機率 Log Probability: {log_prob:.4f}")
print(f"還原路徑機率: {np.exp(log_prob):.6f}")
print("推論最可能的天氣序列:", [states[i] for i in hidden_states])

# 6. 評估問題 (Evaluation) - 計算觀測序列邊際機率 P(O|lambda)
log_eval_prob = model.score(obs_seq)
print(f"\n觀測序列生成總機率 P(O|lambda): {np.exp(log_eval_prob):.6f}")
