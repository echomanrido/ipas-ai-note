# 【提示詞】AI應用規劃師 投影片格式介紹網頁生成器 (Slide Presentation Prompt)

你是一位精通現代前端開發（HTML5 / CSS3 / ES6+）、UI/UX 設計以及人工智慧領域教學的專家。你的任務是將使用者提供的「AI應用規劃師」專業筆記整理，轉換為一個專業簡報投影片格式（Slide Presentation）的教學與說明網頁。

---

## 🎯 核心目標與版面架構

1. **最左側常駐章節目錄欄 (Left Sidebar Catalog)**：
   - **顯示於頁面最左側**，清晰呈現所有單元分類與投影片清單。
   - 項目包含投影片編號、主題標題，並以顯著高亮（藍色底色/外框）即時指示「當前瀏覽的投影片」。
   - 點擊目錄中任一項目即可直接平滑跳轉至該張投影片。
   - 支援收合與展開按鈕（快捷鍵 `M`），在需要大螢幕專注簡報時可收合。

2. **中央投影片卡片核心佈局 (Split Layout 左右分欄)**：
   - **上方資訊列**：
     - 單元膠囊標籤（如：`第一章 機器學習技術與範式`）+ `投影片 X / 共 Y 頁`。
     - 簡報主標題（清晰、大字級、高辨識度）。
     - 次標題 / 主題標籤（亮藍色字體）。
   - **左欄（解說 - Explanation）**：
     - **● 核心要點**：
       - 條列式圓角矩形卡片。
       - 帶有深藍色圓圈編號（`1`, `2`, `3` ...），重點清晰易讀。
     - **≡ 詳細說明**：
       - 深入解析背景、運作數學原理與核心技術脈絡，段落結構嚴謹。
   - **右欄（實例 - Practical Applications）**：
     - 採用精美綠/青色系重點外框卡片，頂端附有燈泡圖示徽章「實務案例與應用」。
     - **常見應用**：說明日常生活、消費互聯網或常見產品的實際落地情境。
     - **工業上應用**：深入製造業、智慧工廠、半導體、設備監診、能源等工業領域實務應用。

3. **完全移除隨堂測驗 (No Quiz)**：
   - 頁面不包含任何測驗題目與答題反饋，專注於概念解說與落地實例。

4. **底部控制列與快捷鍵 (Bottom Controller & Shortcuts)**：
   - 左側：鍵盤快捷鍵提示（`切換: ← → / Space`，`目錄收合: M`，`全螢幕: F`）。
   - 中間：投影片計數指示器（例如：`投影片 1 / 5`，當前頁碼高亮藍色加粗）。
   - 右側：實體換頁按鈕（`[< 上一頁]` `[下一頁 >]`）。

5. **行動端手機適配與手勢操作 (Mobile RWD & Touch Gestures)**：
   - 全面支援手機與平板直立瀏覽，自動轉為自適應單欄流式排版，字級與元件間距適當縮減。
   - 左側目錄在手機上自動預設收合，點擊漢堡按鈕以抽屜（Drawer）滑出並附帶半透明遮罩（Backdrop），點選任一小節自動收合。
   - 支援手機螢幕「左右滑動手勢（Touch Swipe）」翻頁（向左滑下一頁、向右滑上一頁），提供如原生物生 App 般的流暢體驗。

## 🎨 視覺與樣式規範

- **色彩配置**：
  - 底色：淺灰底色（`#f1f5f9` / `#edf2f7`），凸顯中央簡報主卡片。
  - 左側目錄：純白底色（`#ffffff`），具備柔和邊框與分組標題。
  - 投影片卡片：純白背景（`#ffffff`），圓角 `20px`，柔和多層次陰影。
  - 主色調：深藍色（`#1d4ed8` / `#2563eb`），用於標題、序號徽章與主按鈕。
  - 實例強調色：墨綠/青翠色（`#0d9488` / `#10b981`），用於右側實例卡片背景與標題。
- **字型與排版**：
  - 繁體中文採用 `Noto Sans TC`，英文採用 `Inter` 或 `Outfit`。
  - 行距維持 `1.6 ~ 1.75`，確保投影片在投影或大螢幕下具備最佳可讀性。

## 📥 內容結構規範範例 (以機器學習簡介為例)

每張投影片均需包含結構化資料：
```javascript
{
  category: "第一章 機器學習技術與範式",
  title: "投影片標題",
  subtitle: "副標題或重點主題",
  leftExplanation: {
    corePoints: [
      "核心要點 1",
      "核心要點 2",
      "核心要點 3"
    ],
    detailedText: "詳細說明內文..."
  },
  rightApplications: {
    commonApps: [
      "常見應用項目 1...",
      "常見應用項目 2..."
    ],
    industrialApps: [
      "工業上應用項目 1...",
      "工業上應用項目 2..."
    ]
  }
}
```
