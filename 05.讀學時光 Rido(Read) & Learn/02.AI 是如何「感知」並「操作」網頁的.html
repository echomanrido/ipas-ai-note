AI 是如何「感知」並「操作」網頁的？

AI 看網頁不是單一模式，而是根據任務深度在成本、動態互動與無視防爬之間取捨。下方模擬器可手動體驗或啟動「一鍵自動模擬」，即時洞悉三大模式的資料 Payload 與 CDP 操作指令。

1. 純文字與清理後的 HTML 最常見 ‧ 成本最低

透過演算法剔除 script、style 與廣告追蹤代碼，只萃取乾淨的語意 HTML 或 Markdown，Token 暴跌 90%，是搜尋摘要與 RAG 的首選。

2. 渲染後的 DOM 樹 處理動態網頁 / SPA

HTML 是靜態字串，DOM 才是執行 JS 後的活體物件。無頭瀏覽器執行 SPA 後提取動態 DOM 與 a11y 樹，才能取得點擊後狀態與動態按鈕。

3. 多模態視覺截圖 Vision-based 視覺

直接對視窗截圖並標註元素邊框與座標（Set-of-Marks），讓模型用人類肉眼直覺理解排版，無視前端程式碼混淆、Shadow DOM 與防爬蟲。

          體系化解析
          

            HTML 與 DOM 到底差在哪？3 大核心感知範式
          

          

            理解「靜態原始碼 HTML」與「運行時記憶體 DOM」的本質差異，是打造自主瀏覽 Agent 的核心基本功。
          

        


        

          
          
          

            

              

                

                  01
                

                靜態文本 ‧ 成本最低
              

              
純文字與清理後的 HTML

              

                本質是「伺服器回傳的靜態文字字串」。不啟動瀏覽器引擎，直接由 Python/Go 發出 HTTP 請求後剔除 JS/CSS。
              

              

                

                  ✓極度輕量，單頁 Token 消耗僅數百，延遲小於 30ms
                

                

                  ✕致命缺點：若網頁是 React/Vue 單頁應用（SPA），抓回來的 HTML 只有一個空殼 <div id="root"></div>，內容全是空白！
                

              

            

            
典型代表：Jina Reader, Perplexity 聯網檢索

          


          
          

            

              

                

                  02
                

                動態執行 ‧ 互動核心
              

              
渲染後的 DOM 樹 (Rendered DOM)

              

                本質是「瀏覽器記憶體裡的動態物件樹」。必須啟動無頭瀏覽器（Chromium）跑完前端 JS、打完 API 之後，從記憶體抓出的即時狀態。
              

              

                

                  ✓解決 SPA 盲區：即使是客戶端動態渲染，也能拿到執行後真實的商品、價格與購物車按鈕
                

                

                  ✓能即時掌握動態狀態（例如 input 內使用者輸入的文字、選單是否展開）
                

              

            

            
典型代表：Browser-Use, Playwright Agent, MultiOn

          


          
          

            

              

                

                  03
                

                多模態 ‧ 視覺直覺
              

              
多模態視覺截圖 (Vision-based)

              

                以無頭瀏覽器將畫面完整渲染為視窗截圖，並在互動元件上自動疊加數字標籤（Set-of-Marks）或像素座標，送交多模態模型（VLM）以肉眼方式閱讀。
              

              

                

                  ✓完全無視 Shadow DOM、Canvas 畫布渲染與前端反爬蟲混淆代碼
                

                

                  ✓精準理解相對視覺排版、圖表趨勢、驗證碼與遮罩彈窗
                

                

                  ⚠圖像 Token 計費較高，且受視窗滾動範圍限制（無法單次看整頁）
                

              

            

            
典型代表：Claude 3.7 Computer Use, GPT-4o Vision
