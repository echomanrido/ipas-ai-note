01. 一句話簡介 & 02. 核心原理

什麼是 Stable Diffusion（潛在擴散模型，LDM）？

一句話簡介： Stable Diffusion 是一種潛在擴散模型 (Latent Diffusion Model)，利用 VAE 將高維像素壓縮至低維潛在空間，並藉由 CLIP 將文字提示轉為語意引導向量，最後透過 UNet 執行多步逆向去噪，以極高的計算效率實現「以文生圖 (Text-to-Image)」。

Stable Diffusion (LDM) 端到端完整架構流程圖（含 VAE Encoder 與 Decoder）

雙向轉換: 像素 [512×512×3] $\rightleftharpoons$ VAE $\rightleftharpoons$ 潛在空間 [64×64×4]
VAE Encoder ($\mathcal{E}$)：將 $512\times 512$ 像素壓縮為 $64\times 64$ 潛在特徵 $z_0$
文字流 (CLIP)：提取高階語意為 Cross-Attention 的 Key、Value 引導
潛在流 (UNet)：在 64×64 壓縮空間執行多步噪聲預測與反向去噪
VAE Decoder ($\mathcal{D}$)：將去噪完成之 $z_0$ 放大 8 倍還原回真實 RGB 影像

三大核心組件協同工作原理

編碼 $\mathcal{E}$ 與解碼 $\mathcal{D}$

1. VAE (變分自編碼器)

職責：空間壓縮（Encoder $\mathcal{E}$）與像素重構（Decoder $\mathcal{D}$）。
• VAE Encoder：在模型訓練及圖生圖 (img2img) 任務中，負責將高維影像（$512 \times 512 \times 3$）壓縮成 $64 \times 64 \times 4$ 潛在特徵張量 $z_0 = \mathcal{E}(x)$，實現 48 倍資訊降維；
• VAE Decoder：去噪循環完畢後，Decoder $\mathcal{D}$ 將潛在特徵 $z_0$ 放大 8 倍升採樣，還原成高畫質 RGB 影像。

跨模態引導

2. CLIP (文字編碼器)

職責：語意特徵提取。
使用對比學習訓練出的 CLIP Text Encoder（ViT-L/14），將人類輸入的 Prompt（文字提示詞）轉換為高維文字嵌入向量（$77 \times 768$），作為後續去噪時 Cross-Attention 的 Key 和 Value 引導訊號。

核心去噪引擎

3. UNet + Cross-Attention

職責：噪聲預測與條件引導。
包含下採樣、中間瓶頸層與上採樣架構，並包含跳躍連接 (Skip Connections)。其內部嵌入了交叉注意力機制 (Cross-Attention)，在每個去噪步階 $t$ 預測當前潛在張量中的噪聲 $\epsilon_\theta$。

04. 實務特徵 (Key Characteristics)

工程落地三大關鍵

  • 消費級 GPU 普及：因為去噪在 $64\times 64$ 潛在空間進行，僅需 4GB~8GB VRAM 即可推論生成 512px 或 1024px 影像。
  • 無引導擴散分類器 (CFG)：透過調節 Classifier-Free Guidance Scale，平衡多樣性（Creativity）與符合提示詞（Prompt Fidelity）。
  • 生態模組化擴展：支持 LoRA 微調、ControlNet 邊緣/骨架控制、IP-Adapter 圖像提示等周邊技術。
05. 由來 (History & Origins)

學術到開源的爆炸演變

源自非平衡熱力學原理（Sohl-Dickstein et al., 2015），由 DDPM（Ho et al., 2020）確立去噪架構。

2021~2022 年慕尼黑大學 (LMU Munich) 的 Robin Rombach 與 Patrick Esser 發表了 High-Resolution Image Synthesis with Latent Diffusion Models。隨後由 Stability AI、Runway 與 LAION 社群資助開源釋出權重，徹底打破 OpenAI DALL-E 的閉源壟斷。

08. 理論簡介 & 09. 數學推導（互動式探討）

潛在擴散模型 (LDM) 數學核心推導

擴散模型本質是馬可夫鏈 (Markov Chain)，由兩大過程構成：前向加噪過程 (Forward Process $q$) 與 逆向去噪過程 (Reverse Process $p_\theta$)。

1. 前向加噪閉式解 (Forward Diffusion Trick)

令潛在變數 $z_0 = \mathcal{E}(x)$，每一步加噪：$q(z_t | z_{t-1}) = \mathcal{N}(z_t; \sqrt{1 - \beta_t} z_{t-1}, \beta_t \mathbf{I})$。令 $\alpha_t = 1 - \beta_t$，且 $\bar{\alpha}_t = \prod_{i=1}^t \alpha_i$。透過高斯分佈可加性重參數化技巧，可直接從 $z_0$ 一步採樣任意時刻 $t$ 的 $z_t$：

$$z_t = \sqrt{\bar{\alpha}_t} z_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, \mathbf{I})$$

當 $t \to T$（如 $t=1000$）時，$\bar{\alpha}_T \approx 0$，$z_T$ 幾乎退化為標準純高斯白噪聲 $\mathcal{N}(0, \mathbf{I})$。

2. UNet 訓練目標函數 (Simplified Variational Bound Loss)

UNet 不直接預測乾淨圖像 $z_0$，而是學習預測當前步階所加入的標準高斯噪聲 $\epsilon$。其文字條件訓練損失為均方誤差 (MSE)：

$$\mathcal{L}_{\text{LDM}} = \mathbb{E}_{\mathcal{E}(x),\, y,\, \epsilon \sim \mathcal{N}(0,\mathbf{I}),\, t} \left[ \left\| \epsilon - \epsilon_\theta(z_t, t, \tau_\theta(y)) \right\|^2 \right]$$

其中 $\tau_\theta(y)$ 為 CLIP 文字編碼器對文字 $y$ 提取的特徵矩陣，藉由 Cross-Attention $Q=W_Q z_t$, $K=W_K \tau_\theta(y)$, $V=W_V \tau_\theta(y)$ 注入特徵：$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$。

3. 無分類器引導 (Classifier-Free Guidance, CFG)

推論時，UNet 會同時執行兩次預測：包含文字引導的預測 $\epsilon_\theta(z_t, t, c)$ 與無條件 (空字串) 的預測 $\epsilon_\theta(z_t, t, \emptyset)$。最終引導噪聲為：

$$\tilde{\epsilon}_\theta(z_t, t, c) = \epsilon_\theta(z_t, t, \emptyset) + s \cdot \Big( \epsilon_\theta(z_t, t, c) - \epsilon_\theta(z_t, t, \emptyset) \Big)$$

$s \ge 1$ 為 CFG Scale。當 $s$ 越大，模型越嚴格遵守文字提示詞，但過高可能導致色彩過飽和 (Saturation Artifacts)。

11. Python / PyTorch 核心演算法實作代碼

使用 Diffusers 與 PyTorch 實現底層去噪循環邏輯

這段代碼完整揭示了 CLIP 嵌入、隨機潛在噪聲生成、UNet 逐步去噪與 CFG 運算，最後透過 VAE Decode 產出圖片：

色彩圖例： 核心關鍵函式 (Key Core Methods) 一般輔助/張量操作函式 類別與模型架構 語法關鍵字 (Keywords) 字串與提示詞
代碼已成功複製至剪貼簿！ 
import torch
from transformers import CLIPTextModel, CLIPTokenizer
from diffusers import AutoencoderKL, UNet2DConditionModel, PNDMScheduler
from PIL import Image

# 1. 載入三大關鍵模組 (CLIP, UNet, VAE)
device = "cuda" if torch.cuda.is_available() else "cpu"
model_id = "runwayml/stable-diffusion-v1-5"

tokenizer = CLIPTokenizer.from_pretrained(model_id, subfolder="tokenizer")
text_encoder = CLIPTextModel.from_pretrained(model_id, subfolder="text_encoder").to(device)
vae = AutoencoderKL.from_pretrained(model_id, subfolder="vae").to(device)
unet = UNet2DConditionModel.from_pretrained(model_id, subfolder="unet").to(device)
scheduler = PNDMScheduler.from_pretrained(model_id, subfolder="scheduler")

# 2. 準備文字 Prompt 並經由 CLIP Text Encoder 提取引導向量
prompt = ["A futuristic cyberpunk skyline with neon rain"]
negative_prompt = [""]  # 無條件 (CFG 基準)

# 編碼正面與負面提示詞 (CLIP 語意編碼)
tokens = tokenizer(prompt, padding="max_length", max_length=tokenizer.model_max_length, return_tensors="pt").input_ids.to(device)
cond_embeddings = text_encoder(tokens)[0]

uncond_tokens = tokenizer(negative_prompt, padding="max_length", max_length=tokenizer.model_max_length, return_tensors="pt").input_ids.to(device)
uncond_embeddings = text_encoder(uncond_tokens)[0]

# 拼接文字特徵供 CFG 批次計算 [2, 77, 768]
text_embeddings = torch.cat([uncond_embeddings, cond_embeddings])

# 3. 初始化潛在空間純高斯白噪聲 z_T (64x64x4)
batch_size = 1
height, width = 512, 512
latents = torch.randn((batch_size, unet.config.in_channels, height // 8, width // 8), device=device)
latents = latents * scheduler.init_noise_sigma

# 4. 逆向擴散去噪循環 (Sampling Loop)
scheduler.set_timesteps(num_inference_steps=20)
cfg_scale = 7.5

for t in scheduler.timesteps:
    # 複製 latents 供 CFG 平行計算條件與無條件輸出
    latent_model_input = torch.cat([latents] * 2)
    latent_model_input = scheduler.scale_model_input(latent_model_input, t)

    # UNet 核心前向推論預測噪聲 (Cross-Attention 語意注入)
    with torch.no_grad():
        noise_pred = unet(latent_model_input, t, encoder_hidden_states=text_embeddings).sample

    # 執行 Classifier-Free Guidance (CFG) 數學引導合成
    noise_pred_uncond, noise_pred_text = noise_pred.chunk(2)
    noise_pred = noise_pred_uncond + cfg_scale * (noise_pred_text - noise_pred_uncond)

    # 調度器 (Scheduler) 依當前噪聲計算前一時刻潛在向量 z_{t-1}
    latents = scheduler.step(noise_pred, t, latents).prev_sample

# 5. VAE Decoder 將 64x64x4 潛在向量解碼回 512x512x3 像素空間 (Pixel Space)
latents = 1 / 0.18215 * latents
with torch.no_grad():
    image = vae.decode(latents).sample

# 後處理為標準 RGB 影像
image = (image / 2 + 0.5).clamp(0, 1)
image = image.cpu().permute(0, 2, 3, 1).float().numpy()[0]
image = (image * 255).round().astype("uint8")
pil_img = Image.fromarray(image)
pil_img.save("generated_cyberpunk.png")
print("Stable Diffusion 生成完成！")
