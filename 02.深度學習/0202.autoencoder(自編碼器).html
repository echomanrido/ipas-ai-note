自編碼器：從 資訊瓶頸 到 異常檢測與生成

深入解析自編碼器架構的對稱之美，掌握無監督學習的「壓縮—還原」本質，從 IPAS 認證關鍵考點、工業 AOI 缺陷判定，到 PyTorch 端到端實作與五步即時動態模擬。

SECTION 01

一句話簡介

自編碼器（Autoencoder） 是一種非監督式學習（或自監督學習）的人工神經網路，主要用來學習資料的壓縮表示，並從中重建原始數據。你可以把它想像成一個「先壓縮、再還原」的資料處理模型。

SECTION 02

核心原理

透過強迫神經網路穿越維度大幅縮減的瓶頸層 (Bottleneck / Code)，剝離無關雜訊與冗餘維度，僅留下資料最核心的潛在表徵（Latent Representations），以最小化自身重構誤差達成自主學習。

SECTION 04

實務特徵

  • 非線性降維：利用非線性活化函數捕捉流形幾何結構。
  • 無監督學習：無需標籤資料（Label-free），大幅降低資料標註成本。
  • 異常檢測靈敏性：僅對訓練集的正常模式具備重建能力。
  • 抗噪學習：具備抑制白雜訊、重建原始清晰信號的泛化潛能。

核心架構：主要由三個部分組成

自編碼器透過「編碼 ➔ 瓶頸 ➔ 解碼」的經典對稱沙漏管線運作：

PART 1

編碼器（Encoder）

把高維度的輸入資料壓縮成低維度的隱藏特徵（稱為瓶頸層或 Code），過濾冗餘細節並萃取高層次抽象特徵。

PART 2

瓶頸層（Bottleneck）

儲存最小表示空間的關鍵特徵，強迫模型去除雜訊、保留最重要的資訊，杜絕模型退化為單純的恆等拷貝。

PART 3

解碼器（Decoder）

從低維度的壓縮特徵中，盡可能還原出原始的輸入資料，透過最小化重構誤差指導全網路權重最佳化。

主要用途 (Major Applications)
降維（Dimensionality Reduction）

類似主成分分析（PCA），但自編碼器具備非線性活化函數，能捕捉更複雜細膩的非線性流形特徵。

異常偵測（Anomaly Detection）

模型只學習正常資料的重建方式；當異常資料輸入時，重建誤差會劇增，藉此準確抓出異常瑕疵。

去噪（Denoising）

去除圖片或音訊中的隨機高斯雜訊或脈衝雜訊，自主還原乾淨高保真的原本版本。

常見核心變體 (Common Variants)
去噪自編碼器（DAE, Denoising Autoencoder） 抗噪表徵

輸入資料會被刻意加入雜訊 $\tilde{x}$，訓練模型學會消除干擾，並還原出無雜訊的原始純淨資料 $x$。

變分自編碼器（VAE, Variational Autoencoder） 生成模型

將潛在空間約束為連續平滑的機率分佈（常態分佈 $\mu, \sigma$），突破離散點限制，具備無窮生成全新逼真樣本的能力。

從傳統「特徵提取器」演進為具備採樣生成能力的現代「生成式架構」。

115年第1次 · 初級第一科（人工智慧基礎概論）第 10 題 初級試題

產品概念圖與風格草圖生成

題目：某設計公司導入生成式 AI（Generative AI）工具，用於自動產生產品概念圖與風格草圖。為了讓系統能依據既有圖像資料產生具有變化且風格一致的新圖像，模型必須具備學習資料特性並生成新樣本的能力。下列哪一種模型技術或方法最符合上述需求？

(A) 隱變量自編碼器（Variational Autoencoder, VAE）
(B) 隨機森林（Random Forest）
(C) K-近鄰演算法（K-Nearest Neighbors, KNN）
(D) 貝氏網路（Bayesian Network）
正確答案：(A) ｜ 深度題解剖析

核心解析：隨機森林與 KNN 皆為典型傳統判別/分類模型，不具備自主產生圖像新樣本的「生成模型（Generative Model）」能力；而貝氏網路主要處理概率圖因果推論。變分自編碼器（VAE）將高維圖像映射至連續的潛在機率分佈 $\mathcal{N}(\mu, \sigma^2)$，透過採樣能平滑生成「風格連貫且具備多樣細節變化」的嶄新草圖圖像。

115年第1次 · 初級第一科（人工智慧基礎概論）第 22 題 初級試題

無標註數據下之異常預警

題目：某製造業工廠規劃導入 AI 監控系統，持續分析設備感測數據（如溫度、震動與壓力）。系統需能在缺乏完整異常標註資料的情況下，辨識與一般運作型態顯著不同的狀態，並發出預警。在此需求下，下列何種技術較為適合？

(A) 使用支援向量機（SVM）建立異常分類模型
(B) 以決策樹（Decision Tree）學習異常類型的判斷規則
(C) 採用變分自編碼器（Variational Autoencoder, VAE）學習正常資料分佈
(D) 使用生成對抗網路（GAN）直接預測異常標籤
正確答案：(C) ｜ 深度題解剖析

核心解析：題目關鍵詞為「缺乏完整異常標註資料（無監督/單類別情境）」。SVM 與決策樹需要大量且平衡的異常標籤進行監督式分類；GAN 是生成架構，一般不直接作為異常標籤預測器。VAE 可只輸入大量「正常運作狀態」資料，學習其多維機率分佈，當未知故障或偏差數據輸入時，潛在機率對數似然度暴跌或重構誤差劇增，即可精準發出異常預警。

115年第2次 · 初級第一科（人工智慧基礎概論）第 27 題 初級試題

自編碼器最適應用場景

題目：某製造業評估在不同場景導入 AI，包含：（甲）依據設備感測器數值判斷是否出現異常；（乙）依據客服對話內容判斷客戶情緒；（丙）依據產品影像輪廓直接進行瑕疵分類。下列哪一種情境最適合以自編碼器（Autoencoder）作為主要模型架構？

(A) 甲
(B) 乙
(C) 丙
(D) 甲與丙
正確答案：(A) ｜ 深度題解剖析

核心解析： • 情境（甲）：感測器數值多為正常連續訊號，瑕疵極罕見，最適合 Autoencoder 學習正常重構，以 Reconstruction Loss 超標判定異常。
• 情境（乙）：文本情緒分析屬於標準 NLP 分類任務，適合 BERT / RNN 等架構。
• 情境（丙）：「直接瑕疵分類」需要輸出具體瑕疵類別標籤（如刮傷、凹陷），屬於監督式 CNN/Vision Transformer 分類模型，非 AE 之首要定位。故最適合者唯有 (A) 甲。

114年第2梯次 · 中級第一科（技術應用與規劃）第 40 題 中級試題

VAE、GAN 與擴散模型之根本差異

題目：下列哪一項最正確地描述了 VAE（Variational Autoencoder）、GAN（Generative Adversarial Network）與擴散模型（Diffusion Model）在多模態潛在空間對齊（Latent Alignment）與生成策略上的根本差異？

(A) VAE 透過顯式潛在變數建模實現跨模態對齊，適合捕捉整體語意結構但生成解析度有限；GAN 透過對抗損失在不同模態間學習分佈映射，生成品質高但穩定性差；擴散模型則以條件化噪聲反推方式實現高保真跨模態生成，兼具穩定性與多樣性
(B) VAE 與 Diffusion Model 均屬隱式生成架構，GAN 屬顯式密度模型...
(C) VAE 與 GAN 均使用馬爾可夫鏈（Markov Chain）進行跨模態轉換...
(D) 三者在多模態應用中皆依賴同一潛在表徵空間...
正確答案：(A) ｜ 深度題解剖析

核心解析： 1. VAE：採用變分推斷顯式建模潛在分佈 $q_\phi(z|x)$，結構平滑但生成易產生模糊、高頻解析度受限；
2. GAN：藉由鑑別器與生成器的極小極大博弈（Minimax Game）無顯式潛在先驗，生成銳利但面臨模式崩潰（Mode Collapse）與訓練震盪；
3. Diffusion：透過多步馬爾可夫前向加噪與逆向條件去噪（Score Matching），兼得超高解析度與分佈覆蓋度。選項 (A) 精準剖析三大架構本質。

114年第2梯次 · 中級第一科（技術應用與規劃）第 42 題 中級試題

以 VAE 監控潛在空間分佈與資料偏移

題目：若部署一個深度學習模型至金融風控系統，該模型採用鑑別式架構（如 Transformer Classifier）。然而上線後，模型對新樣本的分類錯誤率顯著上升，經檢查發現，輸入資料分佈已與原訓練集明顯不同。針對此情形，下列哪一種應對策略最為適合？

(A) 改用生成對抗網路（GAN）生成新樣本並混入訓練集
(B) 改用邏輯迴歸模型（Logistic Regression）以提升穩定性
(C) 增加模型容量（Model Capacity），以學習更多樣本差異
(D) 使用變分自編碼器（VAE）監控潛在空間分佈，偵測輸入資料偏移
正確答案：(D) ｜ 深度題解剖析

核心解析：線上金融風控模型表現衰退的主因為資料漂移（Data Drift / Distribution Shift）。VAE 具備統計先驗約束（例如約束在標準高斯空間），透過計算新樣本在潛在空間中的 KL 散度或重建似然度，可作為絕佳的漂移預警哨兵（Drift Detector），及時通知系統觸發重新訓練。而盲目擴增模型容量 (C) 反而會加劇過擬合。

114年第2梯次 · 中級第一科（技術應用與規劃）第 43 題 中級試題

生成式路徑（VAE）與鑑別式路徑（BERT）低資源實驗設計

題目：某金融科技公司欲導入 AI 模型協助客服郵件自動分類（投訴、詢問、表揚）。團隊同時考慮兩種模型設計：方案 A（生成式路徑）：採用 VAE 建構潛在語意空間，再結合下游分類器進行標籤預測；方案 B（鑑別式路徑）：採用 BERT Classifier 直接根據輸入文本進行監督式分類。現有標註資料約 2,000 筆，資料分佈均勻但擴充成本高。若團隊希望公平比較兩種模型的資料利用效率與泛化能力，下列哪一種實驗設計最能突顯兩者的本質差異？

(A) 在完整資料集上分別訓練兩者，並比較其分類準率與推論時間
(B) 在低資源情境（Low-resource Setting）下，逐步減少標註比例（100%、50%、10%），比較其 F1-score
(C) 使用 GAN 自動生成文本樣本補足資料...
(D) 在相同訓練資料上固定輸入維度...
正確答案：(B) ｜ 深度題解剖析

核心解析：「生成式路徑（VAE 半監督學習）」的一大優勢在於：即使在極少標註（Low-resource Setting）時，VAE 仍能利用大量未標註文本自我重構學習紮實的潛在分佈；而純監督式鑑別路徑（BERT Classifier）在標註樣本縮水至 10% 時往往性能急遽跌落。故設計遞減標籤比例（100% $\to$ 50% $\to$ 10%）的對比實驗，最能突顯 VAE 半監督表徵學習的資料利用效率。

114年第2梯次 · 中級第一科（技術應用與規劃）第 44 題 中級試題

兼顧預測與虛擬樣本生成

題目：某電信公司希望建立一個模型來預測顧客是否即將流失，並進一步模擬不同促銷或服務策略下顧客的行為變化，以生成多樣化的虛擬樣本資料進行 A/B 測試與行銷策略評估。若要同時兼顧預測與資料生成的需求，最適合採用下列哪一種方法？

(A) 使用傳統隨機森林（Random Forest）
(B) 使用邏輯迴歸（Logistic Regression）模型
(C) 使用變分自編碼器（Variational Autoencoder, VAE）或生成對抗網路（GAN）
(D) 使用強化學習代理（Reinforcement Learning Agent）
正確答案：(C) ｜ 深度題解剖析

核心解析：傳統隨機森林 (A) 或邏輯迴歸 (B) 僅能輸出流失機率預測值，完全不具備「生成全新顧客樣貌資料」的能力。變分自編碼器 (VAE) 或 GAN 能學習顧客特徵的聯合機率分佈，不僅能結合分類頭預測流失，更可透過潛在向量插值（Latent Vector Interpolation）生成極具可信度的「虛擬高價值顧客」特徵，以供 A/B 模擬測試。

05. 由來 (History)

從自動關聯到深度學習復興

1986 年由 Rumelhart、Hinton 等人在 PDP 連接主義架構中提出「Auto-association（自聯想）」。2006 年，Geoffrey Hinton 在 Science 期刊發表里程碑論文，利用受限玻爾茲曼機 (RBM) 逐層貪婪預訓練 (Greedy Layer-wise Pre-training) 深度 Autoencoder，成功證明深層神經網路的有效訓練，一舉引爆近代深度學習革命。

速記記者的極簡提綱筆記

想像一位法庭速記員：

SECTION 08

自編碼器理論家族譜系 (AE Taxonomy)

為了克服單純複製（Identity Mapping）並學習更具泛化力的表徵，衍生出多種強大架構：

Vanilla / Undercomplete AE

潛在維度 $d \ll D$。強迫模型捨棄次要雜訊，抓取主成分流形。若維度不足會模糊，若維度過大易過擬合。

Denoising AE (DAE)

人為向輸入添加雜訊 $\tilde{x} \sim q(\tilde{x}|x)$，但要求解碼器還原無雜訊的原始 $x$。強迫模型學習將受擾動數據投影回收斂流形的能力。

Sparse / Contractive AE

引入稀疏性約束（如 KL 散度）或雅可比矩陣懲罰項（Frobenius Norm of Jacobian），限制潛在神經元僅在關鍵特徵出現時微量活化。

Variational AE (VAE)

邁向生成模型！將瓶頸編碼為機率分佈 $\mu, \sigma^2$，透過重參數化技巧（Reparameterization Trick）生成連續且可插值的潛在空間。

SECTION 09

數學推導與理論證明

嚴密數學表述：從目標泛函、反向傳播更新，到「線性 AE 與 PCA 等價性證明」

給定高維無標籤數據集 $\mathcal{D} = \{x^{(1)}, x^{(2)}, \dots, x^{(N)}\}$，其中 $x \in \mathbb{R}^D$。自編碼器由兩部分構成：

【編碼器 Encoder】 將輸入空間映射至低維潛在空間 $\mathbb{R}^d$ ($d \ll D$)：
$$z = f_\theta(x) = \sigma(W_e x + b_e)$$
其中 $W_e \in \mathbb{R}^{d \times D}, b_e \in \mathbb{R}^d$，$\sigma$ 為活化函數。
【解碼器 Decoder】 將低維瓶頸映射回原始高維空間 $\mathbb{R}^D$：
$$\hat{x} = g_\phi(z) = \sigma'(W_d z + b_d)$$
其中 $W_d \in \mathbb{R}^{D \times d}, b_d \in \mathbb{R}^D$。若採用權重綁定（Tied Weights），則令 $W_d = W_e^T$。
【損失函數 Loss Function】 針對連續型數值特徵，通常採用均方誤差（Mean Squared Error, MSE）：
$$\mathcal{L}(x, \hat{x}) = \frac{1}{2} \| x - \hat{x} \|_2^2 = \frac{1}{2} \sum_{j=1}^D (x_j - \hat{x}_j)^2$$
針對歸一化在 $[0, 1]$ 區間的影像像素，亦常採用二元交叉熵（Binary Cross-Entropy, BCE）：
$$\mathcal{L}_{\text{BCE}}(x, \hat{x}) = - \sum_{j=1}^D \left[ x_j \ln \hat{x}_j + (1 - x_j) \ln (1 - \hat{x}_j) \right]$$

透過鏈式法則（Chain Rule）計算損失對解碼器與編碼器權重的偏導數：

1. 解碼器梯度推導：

設解碼器輸出前之淨輸入為 $a_d = W_d z + b_d$，故 $\hat{x} = \sigma'(a_d)$。 $$\delta_d = \frac{\partial \mathcal{L}}{\partial a_d} = (\hat{x} - x) \odot \sigma'(a_d)$$ 對於解碼器權重矩陣之梯度為： $$\frac{\partial \mathcal{L}}{\partial W_d} = \delta_d \cdot z^T \in \mathbb{R}^{D \times d}, \quad \frac{\partial \mathcal{L}}{\partial b_d} = \delta_d \in \mathbb{R}^D$$

2. 編碼器梯度推導：

誤差信號反向穿越潛在空間 $z$ 傳遞至編碼器： $$\delta_e = \frac{\partial \mathcal{L}}{\partial a_e} = \left( W_d^T \delta_d \right) \odot \sigma(a_e)$$ 對編碼器權重矩陣之更新梯度為： $$\frac{\partial \mathcal{L}}{\partial W_e} = \delta_e \cdot x^T \in \mathbb{R}^{d \times D}, \quad \frac{\partial \mathcal{L}}{\partial b_e} = \delta_e \in \mathbb{R}^d$$
【定理：線性 Autoencoder 等價於 PCA】

若所有活化函數為線性即 $\sigma(u)=u, \sigma'(u)=u$，且中心化輸入滿足 $\mathbb{E}[x] = 0$。則優化問題轉化為：

$$\min_{W_e, W_d} \mathbb{E}\left[ \| x - W_d W_e x \|_2^2 \right]$$

令投影矩陣 $P = W_d W_e \in \mathbb{R}^{D \times D}$。因為 $W_e \in \mathbb{R}^{d \times D}, W_d \in \mathbb{R}^{D \times d}$，故 $P$ 的秩（Rank）最多為 $d$。

由 Eckart-Young-Mirsky 低秩逼近定理，最佳的秩-$d$ 正交投影矩陣必然由協方差矩陣 $\Sigma = \mathbb{E}[x x^T]$ 的前 $d$ 個最大特徵值所對應的特徵向量張成！

結論： 線性 AE 所學到的瓶頸特徵向量空間，與 PCA 主成分所張成的超平面完全重合。而非線性 AE 則是將這種線性超平面推廣至任意彎曲的非線性流形（Nonlinear Manifold）。

import torch
import torch.nn as nn
import torch.optim as optim

class DeepAutoencoder(nn.Module):
    def __init__(self, input_dim=64, latent_dim=4):
        super(DeepAutoencoder, self).__init__()
        
        # 1. 編碼器 (Encoder)：高維特徵壓縮
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 32),
            nn.GELU(),
            nn.Linear(32, 16),
            nn.GELU(),
            nn.Linear(16, latent_dim)   # 壓縮至 Bottleneck 維度
        )
        
        # 2. 解碼器 (Decoder)：低維表徵高保真還原
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 16),
            nn.GELU(),
            nn.Linear(16, 32),
            nn.GELU(),
            nn.Linear(32, input_dim)   # 還原至輸入維度
        )

    def forward(self, x):
        latent_z = self.encoder(x)       # 進入潛在空間 (Bottleneck)
        reconstructed_x = self.decoder(latent_z)
        return reconstructed_x, latent_z

# 實例化模型、定義損失函數與最佳化器
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = DeepAutoencoder(input_dim=64, latent_dim=4).to(device)

# 重點函式顏色標註：MSE 均方重構損失與 AdamW 權重優化
criterion = nn.MSELoss()
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)

# 3. 訓練循環 (Training Step)
def train_step(model, batch_normal_data):
    model.train()
    optimizer.zero_grad()                  # 清空歷史累積梯度
    
    outputs, _ = model(batch_normal_data)  # 前向傳播
    loss = criterion(outputs, batch_normal_data) # 自我監督重建損失
    
    loss.backward()                        # 反向傳播計算梯度
    optimizer.step()                       # 參數更新
    return loss.item()

# 4. 工業異常判定函式 (Inference & Anomaly Detection)
def detect_anomaly(model, test_sample, threshold=0.05):
    model.eval()
    with torch.no_grad():
        reconstructed, _ = model(test_sample)
        # 計算樣本級重建誤差 (Sample-wise Reconstruction Error)
        error = torch.mean((test_sample - reconstructed) ** 2, dim=-1).item()
        
    is_anomaly = (error > threshold)
    return {"reconstruction_error": error, "is_anomaly": is_anomaly}
