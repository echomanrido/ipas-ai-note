核心原理 (Core Principles)

1. 小卷積核堆疊：使用兩個 $3\times3$ 卷積獲得相當於 $5\times5$ 的感受野；三個 $3\times3$ 獲得 $7\times7$ 感受野。
2. 更多非線性映射：每層後面皆銜接 ReLU 激勵函數，增加網路判斷複雜函數的能力。
3. 通道倍增規律：空間降維（MaxPool）時，通道擴展 2 倍，保證資訊承載容量（Channel Capacity）。

06-附錄. 辦公秘密武器 (Office Secret Weapons)

鑑定總部的兩大神隊友：ReLU 與 Max-pooling

光是基層看圖、中階主管整合還不夠！如果每個細節與負面廢話都往上報，高層腦袋一定會當機。這時就需要兩大「辦公神器」出場！

高效率傳遞機制
VGG 網路架構中 ReLU 與 Max-pooling 的具體位置與作用全貌

在 VGG 網路架構中，ReLU 屬於啟用函數（Activation Function）層，緊跟在每個卷積層之後；而 Max-pooling 則是池化層（Pooling Layer），位於特定卷積組合之間。這兩個部分在 VGG 中的具體位置與作用如下：

1. ReLU (Rectified Linear Unit) 的位置與作用 啟用函數層
  • • 所在位置：緊跟在每一個卷積層（Convolutional Layer）的後面。
  • • 主要作用：引入非線性特徵。卷積運算本身是線性的，ReLU（公式為 $f(x) = \max(0, x)$）可以將負值歸零、保留正值，讓網路能夠學習複雜的非線性模式，同時有效緩解梯度消失問題。
  • • 結構範例：在 VGG 中，你會看到 Conv -> ReLU -> Conv -> ReLU 這樣的連續組合。
數學式：$f(x) = \max(0, x)$ 非線性擬合核心
2. Max-pooling 的位置與作用 池化降維層
  • • 所在位置：位於幾組卷積層（通常是 2 到 3 個卷積層）的尾端。
  • • 主要作用：進行空間降維（Subsampling）。VGG 使用 $2 \times 2$、步長（stride）為 2 的 Max-pooling，將特徵圖（Feature Map）的長寬各縮小一半，藉此減少計算量、擴大後續層的感受野（Receptive Field），並提供一定程度的平移不變性。
  • • 結構範例：整個 VGG 的主體骨架可以看作是五個大區塊（5 Blocks），每個區塊的結尾都是一個 Max-pooling。
規律：2×2, Stride=2 (長寬減半) 5 次降維至 7×7

1. ReLU 激活函數

去蕪存菁的「正能量篩選器」

08 & 09. 理論簡介與互動數學推導

為什麼 2 個 3×3 可以替代 1 個 5×5？為什麼能省參數？

探討感受野（Receptive Field, RF）遞推公式與參數量（Parameter Count）比率

經典論證：參數量減少 28% ~ 45%

1. 感受野計算公式 (Receptive Field)

設輸入為單步步長（$s=1$）的連續卷積。第 $l$ 層感受野 $RF_l$ 之關係式為：

$$RF_l = RF_{l-1} + (k_l - 1) \times S_{in}$$

其中 $k_l$ 為卷積核大小，$S_{in}$ 為前幾層累積之步長（在無步幅縮放時 $S_{in} = 1$）：

  • • 第 1 層 ($3\times3$): $RF_1 = 1 + (3 - 1) = 3$
  • • 第 2 層 ($3\times3$): $RF_2 = 3 + (3 - 1) = 5$ (等效單個 5×5)
  • • 第 3 層 ($3\times3$): $RF_3 = 5 + (3 - 1) = 7$ (等效單個 7×7)

2. 參數量 (Parameter Savings) 比較推導

假設輸入與輸出通道皆為 $C$：

單個 7×7 卷積核參數: 1 × (7 × 7 × C × C) = 49 C²
三個 3×3 卷積核參數: 3 × (3 × 3 × C × C) = 27 C²
參數節省比率 (Reduction): $$\frac{49 - 27}{49} \approx 44.9\%$$

不僅參數節省近一半，還多插入了 2 次 ReLU 激活，使決策函數更具辨識能力！

標準模組化 VGG16 網路架構代碼

重點核心函式以顏色高亮標記，並附詳細註解與參數量驗證

import torch
import torch.nn as nn

# VGG16 配置清單：數字代表卷積輸出通道數，'M' 代表 MaxPool2d
cfgs = {
    'vgg16': [64, 64, 'M', 128, 128, 'M', 256, 256, 256, 'M', 512, 512, 512, 'M', 512, 512, 512, 'M']
}

class VGG16(nn.Module):
    def __init__(self, num_classes=1000):
        super(VGG16, self).__init__()
        # 構建 13 層卷積特徵提取主幹
        self.features = self._make_layers(cfgs['vgg16'])
        
        # 自適應池化至 7x7 (相容各種尺寸輸入)
        self.avgpool = nn.AdaptiveAvgPool2d((7, 7))
        
        # 構建 3 層全連接分類頭（參數量巨大處）
        self.classifier = nn.Sequential(
            nn.Linear(512 * 7 * 7, 4096),  # 第 14 權重層 (約 102M 參數)
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.5),
            nn.Linear(4096, 4096),        # 第 15 權重層 (約 16.7M 參數)
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.5),
            nn.Linear(4096, num_classes)  # 第 16 權重層 (輸出 1000 類)
        )

    def _make_layers(self, cfg):
        layers = []
        in_channels = 3
        for v in cfg:
            if v == 'M':
                layers += [nn.MaxPool2d(kernel_size=2, stride=2)]
            else:
                # 核心重點：固定 3x3 卷積、padding=1 維持尺寸
                conv2d = nn.Conv2d(in_channels, v, kernel_size=3, padding=1)
                layers += [conv2d, nn.ReLU(inplace=True)]
                in_channels = v
        return nn.Sequential(*layers)

    def forward(self, x):
        x = self.features(x)
        x = self.avgpool(x)
        x = torch.flatten(x, 1)          # 展平成一維特徵向量 (Batch, 25088)
        x = self.classifier(x)
        return x

# 測試運行與驗證參數量
if __name__ == '__main__':
    model = VGG16(num_classes=1000)
    dummy_x = torch.randn(1, 3, 224, 224)
    out = model(dummy_x)
    total_params = sum(p.numel() for p in model.parameters())
    print(f"Output Shape: {out.shape}")          # [1, 1000]
    print(f"總參數量: {total_params / 1e6:.2f}M")   # 約 138.36M
1. 固定 Padding=1 卷積運算尺寸公式為 $\frac{W - K + 2P}{S} + 1$。當 $K=3, P=1, S=1$ 時，尺寸完美保持不變，只在 MaxPool 減半。
2. Flatten 銜接尺寸 經過 5 次池化，尺寸變為 $224 / 2^5 = 7$。因此展開維度為 $512 \times 7 \times 7 = 25,088$。
3. Inplace ReLU 啟用 inplace=True 避免開闢新記憶體空間保存中介張量，對早期 VGG 訓練記憶體優化極為關鍵。
