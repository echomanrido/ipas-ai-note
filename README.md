# AI 應用規劃師 證照筆記與投影片簡報平台

本專案收錄經濟部 iPAS「AI 應用規劃師」專業筆記整理，並以投影片簡報格式（Slide Presentation）提供線上互動式閱讀與解說。

🌐 **線上瀏覽網址 (GitHub Pages)**:  
👉 **[https://echomanrido.github.io/ipas-ai-note/](https://echomanrido.github.io/ipas-ai-note/)**

---

## 📖 專案特色

- **左側常駐章節目錄 (Left Sidebar Catalog)**：
  - 收錄各單元投影片，即時高亮當前瀏覽章節，點擊快速跳轉。
  - 支援鍵盤快速鍵 `M` 或點擊按鈕一鍵收合/展開目錄。
- **投影片 1:1 左右分欄排版**：
  - **左邊（解說）**：
    - `● 核心要點`：清晰列出 1~3 項核心概念與運作機制。
    - `≡ 詳細說明`：深入論述觀念原理與背景脈絡。
  - **右邊（實例）**：
    - `常見應用`：生活與大眾消費落地情境。
    - `工業上應用`：半導體 AOI、產線設備預知保養 (PdM)、無人搬運車 (AGV) 等工業實務案例。
- **流暢簡報體驗**：
  - 支援鍵盤翻頁：`←` `→` 或 `Space` 鍵。
  - 支援全螢幕展示：按下 `F` 鍵即可進入投影展示模式。

## 🚀 本地執行

無需安裝任何伺服器或依賴套件，直接在瀏覽器中開啟 `index.html` 即可：
- Windows: 雙擊 `index.html` 或在終端機輸入 `start index.html`
- macOS / Linux: `open index.html`
