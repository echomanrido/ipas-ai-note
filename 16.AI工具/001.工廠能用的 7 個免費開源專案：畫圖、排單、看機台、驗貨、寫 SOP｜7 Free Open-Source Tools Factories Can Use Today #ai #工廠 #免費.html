工具 1｜階段一：開圖設計・新手級

FreeCAD（免費 2D/3D 繪圖與 DXF 量測）

[00:00:18]

🎯 現場痛點與避坑提醒

客戶直接傳來 .DXF 工程圖檔，但工廠現場電腦沒有安裝昂貴的商業 CAD 繪圖軟體，連確認尺寸都無法開啟。

⚙️ 核心功能與應用場景

支援平面 2D 與立體 3D 參數化建模。將客戶的 DXF 圖檔匯入打開後即可直接量測關鍵尺寸（例如影片中實測鋼板圖面：板高 60 mm 與各組安裝孔位座標）。

✅ 免費與商用授權優勢

LGPLv2+ 開源授權，完全免費下載、無席次限制，中小型加工廠可合法安裝於所有業務與生管電腦看圖報價。

🛠️ 導入門檻與技術前提

入門難度最低（新手級）：不需架設伺服器或寫程式，今天下載安裝就能立刻開圖量尺寸。

工具 2｜階段一：開圖設計・進階級

Text-to-CAD（文字描述自動生成 3D 模型）

[00:00:38]

🎯 現場痛點與避坑提醒

有時候客戶連圖面都沒有，只透過電話或通訊軟體口頭描述零件需求，業務與繪圖人員反覆溝通修改耗時費力。

⚙️ 核心功能與應用場景

實現「打字變圖面」：只要用自然語言描述零件形狀、長寬高與孔徑規格，AI 助理就會自動生成 3D 實體模型，並可匯出 STEP / DXF 等標準加工圖檔。

✅ 免費與開源生態優勢

開源 Text-to-CAD 介面與串接工具可免費取得，能與 FreeCAD 等開源繪圖工作流無縫銜接進行二次細修。

🛠️ 導入門檻與費用前提

進階級：需要搭配具備 CAD 生成能力的 AI 助理（API / 雲端模型）一起運作，AI 助理本身依用量可能需要付費。

工具 3｜階段二：接單排程・進階架設級

Odoo 社群版（ERP 接單、製造單與庫存算料）

[00:00:55]

🎯 現場痛點與避坑提醒

訂單分散在業務手機 LINE 裡、BOM 用料記在 Excel 表格裡、生產進度寫在現場白板上，倉庫原料夠不夠還得打電話一個一個問。

⚙️ 核心功能與物料淨需求公式

將銷售接單、製造工單（MO）、BOM 用料與倉儲庫存整合進同一套系統。開立製造單時，系統自動依下列公式計算缺料量：

$$\text{缺料量 } Q_{\text{short}} = \max\left(0,\; \sum_{i=1}^{n} (D_i \times u_i) - I_{\text{on-hand}} + I_{\text{safety}}\right)$$

✅ 免費與商用授權優勢

Odoo Community（社群版）採用 LGPLv3 授權，內建完整繁體中文介面，且完全免費、可合法商業營運使用。

🛠️ 導入門檻與技術前提

進階架設級：主要門檻在於初期環境安裝（Linux / Docker 伺服器），只要請工程師或顧問幫忙架設一次，之後日常操作的生管與倉管人員完全不需寫程式。

工具 4｜階段三：機台監控・進階架設級

Node-RED + Grafana（低代碼機台連線與戰情看板）

[00:01:29]

🎯 現場痛點與避坑提醒

機台開始自動加工後，廠長或組長想知道哪一台異常停機或閒置，還得親自走進吵雜的產線一台一台巡檢。

⚙️ 核心功能與時間稼動率指標

Node-RED 讓你在瀏覽器內用滑鼠「拖拉節點連線」把 PLC/機台數據接出來；Grafana 則將即時數據繪製成視覺化戰情看板，計算機台稼動率 $A$：

$$A = \frac{T_{\text{run}}}{T_{\text{planned}}} \times 100\%$$

✅ 免費與商用授權優勢

兩者皆為業界標準開源專案（Apache 2.0 / AGPLv3），無點數授權費，可自由擴充監控數十台甚至上百台加工機。

🛠️ 導入門檻與硬體前提

進階架設級：需要請專人協助部署與設定通訊協定（如 Modbus / OPC-UA），且老舊機台能否直接連線需視機台型號與控制器介面而定（必要時需加裝三色燈感測器）。

工具 5｜階段四：品管驗貨・工程師級

anomalib（AI 視覺異常檢測與自動化驗貨）

[00:01:50]

🎯 現場痛點與避坑提醒

零件加工完成後要出貨驗貨，全靠品管人員一片一片用肉眼檢查刮傷、毛邊或凹陷，長時間盯看極易視覺疲勞導致漏檢。

⚙️ 核心功能與非監督式異常判定

Intel 開源的異常檢測（Anomaly Detection）深度學習庫。不需收集各種瑕疵照片，只要提供「正常良品」照片學習特徵分佈，當特徵距離超過閾值 $\tau$ 即判定瑕疵：

$$S(x) = \| f(x) - \mu_{\text{normal}} \|_2 > \tau \implies \text{瑕疵品 (Defect)}$$

✅ 免費與開源授權優勢

Apache 2.0 寬鬆開源授權，內建 PatchCore、PaDiM 等頂尖工業視覺演算法，省下數十萬元商業 AOI 軟體授權費。

🛠️ 導入門檻與技術前提

門檻最高（工程師級）：需要具備 Python 程式撰寫、工業相機打光取像與模型訓練能力，通常需由自動化工程師或外部團隊協助建置。

工具 6｜階段五：知識交接・新手/進階級

Whisper / 聯發科 ASR 語音辨識（師傅經驗轉文字）

[00:02:06]

🎯 現場痛點與避坑提醒

最後要交付技術文件時，資深師傅在機台邊口頭交代的調機眉角與加工做法常常沒人寫下來，老師傅一退休經驗就斷層。

⚙️ 核心功能與應用場景

結合 OpenAI Whisper 與聯發科旗下研究團隊（MediaTek Research）針對台灣繁體中文優化的開源語音辨識（ASR）模型，將現場錄音高準確率轉為逐字稿（影片製作團隊本身也用它來檢查旁白聽寫）。

✅ 免費與開源授權優勢

開源權重模型免費下載使用，可搭配免費圖形介面工具在單機運行，不用按分鐘支付雲端語音轉寫費。

🛠️ 導入門檻與技術前提

新手至進階級：使用打包好的桌面版工具即可直接拖入錄音檔轉文字；若要自建批量轉錄服務則需基礎環境設定。

工具 7｜階段五：知識交接 SOP・進階級（資料不出廠核心）

Ollama（本地端離線 AI 整理 SOP 與外國客戶信件翻譯）

[00:02:25]

🎯 現場痛點與機密外洩風險

有了語音轉出的零散文字後，還需要整理成條理分明的標準作業程序（SOP），但工廠製程參數、報價單與客戶規格屬於商業機密，絕對不想上傳到外部公有雲 AI。

⚙️ 核心功能與應用場景

讓大型語言模型（如 Llama、Gemma、Qwen 等）直接在工廠自己的電腦上離線運行！可一鍵將師傅口述紀錄結構化為標準 SOP 步驟表，也能安全翻譯外國客戶的詢價與技術信件。

✅ 免費與資訊安全優勢

MIT 開源授權免費使用，拔掉網路線也能運作，100% 確保工廠機密資料不出廠，無月費訂閱壓力。

🛠️ 導入門檻與硬體前提

進階級：需要請人幫忙下載安裝適合繁體中文的模型權重，並需視電腦硬體等級而定（建議具備獨立顯示卡 GPU VRAM 8GB 以上或大容量記憶體，推論速度才夠流暢）。
