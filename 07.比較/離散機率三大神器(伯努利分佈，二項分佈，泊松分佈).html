⚠️ 1. 過離散 (Overdispersion)

泊松分佈要求 $E[X] = \text{Var}(X) = \lambda$（等離散性）。若實務資料的變異數顯著大於平均數（$\text{Var}(X) > E[X]$），稱為過離散，不可強用泊松迴歸，應改用負二項分佈 (Negative Binomial)。

📐 2. 二項近似泊松黃金條件

當二項分佈滿足 $n \ge 20$ 且 $p \le 0.05$（稀有事件）時，可直接令 $\lambda = np$，以泊松分佈近似計算機率，大幅簡化階乘組合運算並避免數值溢位。

🧠 3. 二元分類交叉熵損失

Logistic Regression 與神經網路二元分類假設 $Y \mid \mathbf{x} \sim \text{Bernoulli}(\hat{p})$。對其進行最大概似估計 (MLE) 並取負對數，推導出的目標函數正是 Binary Cross-Entropy (Log Loss)。

逐步數學推導｜從二項分佈極限導出泊松分佈

為什麼當 $n \to \infty$ 且 $p \to 0$ 時，二項分佈會變成泊松分佈？

步驟 1：寫出二項分佈 PMF 並代入平均發生率 $\lambda = np$（即 $p = \frac{\lambda}{n}$）
$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k} = \frac{n!}{k!(n-k)!} \left(\frac{\lambda}{n}\right)^k \left(1 - \frac{\lambda}{n}\right)^{n-k}$$
步驟 2：展開組合數分子並依 $n$ 的極限拆分為三個部分
$$\lim_{n \to \infty} P(X = k) = \frac{\lambda^k}{k!} \cdot \underbrace{\lim_{n \to \infty} \frac{n(n-1)\cdots(n-k+1)}{n^k}}_{\text{項 A：趨近於 } 1} \cdot \underbrace{\lim_{n \to \infty} \left(1 - \frac{\lambda}{n}\right)^n}_{\text{項 B：自然常數極限 } e^{-\lambda}} \cdot \underbrace{\lim_{n \to \infty} \left(1 - \frac{\lambda}{n}\right)^{-k}}_{\text{項 C：趨近於 } 1}$$
步驟 3：合併極限結果，獲得泊松分佈機率質量函數 (PMF)
$$P(X = k) = \frac{\lambda^k}{k!} \cdot 1 \cdot e^{-\lambda} \cdot 1 = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0, 1, 2, \dots$$

💡 期望值與變異數連動驗證：當 $n \to \infty, p \to 0$ 且 $np = \lambda$ 保持不變時，二項分佈的變異數 $\text{Var}(X) = np(1-p) = \lambda(1 - \frac{\lambda}{n}) \to \lambda$，這正是泊松分佈「期望值等於變異數」的數學根源！

1. 伯努利分佈推導

利用 $X^2 = X$ 性質

$$E[X] = 0(1-p) + 1(p) = p$$ $$\text{Var}(X) = E[X^2] - (E[X])^2 = p - p^2 = p(1-p)$$
2. 二項分佈推導

獨立同分佈 (i.i.d.) 線性可加

$$X = \sum_{i=1}^n X_i \implies E[X] = \sum_{i=1}^n p = np$$ $$\text{Var}(X) = \sum_{i=1}^n \text{Var}(X_i) = np(1-p)$$
3. 泊松分佈歷史由來

1. Python 統計分析 (scipy.stats) 
from scipy.stats import bernoulli, binom, poisson

# 1. 伯努利分佈：單次簡訊點擊機率 p = 0.25
p = 0.25
p_click = bernoulli.pmf(k=1, p=p)      # 0.25

# 2. 二項分佈：發送 n = 1000 封簡訊，p = 0.005
n, p_sms = 1000, 0.005
p_exact_5 = binom.pmf(k=5, n=n, p=p_sms)  # 0.17591

# 3. 泊松近似驗證 (n>=20 且 p<=0.05 黃金條件成立)
lam = n * p_sms  # lambda = 5.0
p_pois_5 = poisson.pmf(k=5, mu=lam)     # 0.17547 (高度一致!)
print(f"二項精確: {p_exact_5:.5f} | 泊松近似: {p_pois_5:.5f}")
2. PyTorch 深度學習損失函數 (nn & distributions) 
import torch
import torch.nn as nn
from torch.distributions import Bernoulli, Binomial, Poisson

# 1. 二元分類 BCEWithLogitsLoss 等價於伯努利負對數概似
y_true = torch.tensor([1.0, 0.0])
logits = torch.tensor([1.7346, -2.1972])
y_prob = torch.sigmoid(logits)

loss_bce = nn.BCEWithLogitsLoss()(logits, y_true)
loss_nll = -Bernoulli(probs=y_prob).log_prob(y_true).mean()
# loss_bce 與 loss_nll 數值完全相同！

# 2. 計數預測任務（如每小時來電數預測）
pois_loss = nn.PoissonNLLLoss(log_input=False)
val = pois_loss(torch.tensor([4.8]), torch.tensor([5.0]))
