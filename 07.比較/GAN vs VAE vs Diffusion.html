重點整理 (Key Takeaways)
  • 三大生成範式之本質差異：
    • GAN（隱式密度）：生成器與判別器零和博弈，單步前向採樣極速、紋理銳利，但訓練易不穩定且易發生模式崩潰（Mode Collapse）。
    • VAE（顯式下界）：最大化 ELBO 證據下界，潛在空間具備良好連續性與可插值性，訓練穩定快速，但生成樣本傾向局部模糊。
    • Diffusion（多步加去噪）：透過分數匹配反向去噪，樣本多樣性最強、無模式崩潰、畫質逼真天花板，但推論需多步迭代採樣速度受限。
  • 生成學習三難困境 (Trilemma)：現代生成模型存在核心權衡：高品質生成 (Quality)、快速採樣 (Sampling Speed)、模式多樣性 (Diversity)。GAN 偏向品質與速度；VAE 偏向速度與覆蓋；Diffusion 偏向品質與覆蓋。
  • 架構融合大趨勢 (潛在擴散 LDM)：工業界最優解為技術整合——利用 VAE 進行感知降維，在低維潛在空間執行 Diffusion 生成，解碼時引入 PatchGAN 鑑別器損失保留紋理細節，全面克服三難困境。
核心機制與原理說明

三大生成模型的根本差異在於「機率空間映射與優化路徑的數理哲學不同」。
GAN 捨棄顯式似然計算，利用可微判別器作為動態損失函數，將隨機雜訊映射至數據流形邊界，雖然生成邊緣銳利，但判別器過強時易造成生成器梯度消失。
VAE 將生成轉化為統計推斷，藉由 KL 散度強制潛在空間符合高斯分佈，然而其 MSE 重建損失在面對多峰分佈時傾向計算像素期望值平均，導致視覺模糊。
Diffusion (擴散模型) 則顛覆單步映射思維，將生成拆解為可控的微步平滑擴散過程：前向注入高斯雜訊逐步湮滅數據結構，逆向學習局部分態（Score Matching）預測噪聲並步步剔除。由於每一步學習目標清晰且聚焦局部特徵，擴散模型能夠穩健覆蓋數據空間中所有稀有模式，徹底根除模式崩潰，成為當前生成式 AI（影像、影片、3D 資產）的主流霸主。

應用在何處 (產業與落地實務)
  • 半導體與高階製造業：
    • GAN：產線 Edge 端超低延遲瑕疵修復、金相微結構合成（推論僅需數毫秒）。
    • VAE：晶圓缺陷 Bin Map 全自動無監督異常偵測、機台傳感器健康度監控。
    • Diffusion：半導體極罕見致命缺陷（Killer Defects）高擬真合成擴增、晶圓電子顯微鏡（SEM）超解析度重建。
  • 智慧醫療與生醫科學：
    • GAN：CT 快速轉 MRI 跨模態影像合成（CycleGAN/Pix2Pix）、手術內視鏡即時超清晰化。
    • VAE：靶向抗癌小分子化學結構連續特徵優化、病患生命徵象時序表徵建模。
    • Diffusion：蛋白質 3D 折疊逆向生成（如 RFdiffusion）、罕見病理切片無偏差合成。
  • 商業設計與元宇宙數位娛樂：
    • GAN：虛擬主播實時動態表情遷移、自駕車夜間轉白天即時渲染。

隱式密度 (Implicit) 2014 Goodfellow

GAN (對抗生成網路)

01. 造假集團與防偽警探的極限博弈，在納許均衡中逼真還原數據分佈。

⚡ 對抗機制資訊流 Minimax Zero-Sum
02. 核心原理：由「生成器 (Generator)」與「鑑別器 (Discriminator)」互相對抗競賽。生成器負責產生命片以假亂真，鑑別器負責辨別真假，兩者在訓練中不斷同步進化。
優點：產出的影像非常銳利、逼真，細節極佳，特別適合用在風格轉換 (CycleGAN) 與特定圖像生成 (StyleGAN)。
缺點：訓練過程不穩定、極易發生「模式崩塌 (Mode Collapse，即產出樣式過於單一、喪失多樣性)」。
05. 由來起源：Ian Goodfellow 於 2014 年構思，為了解決馬可夫隨機場難以解析配分函數的瓶頸。
06. 生活化例子：藝術偽畫師不斷臨摹名畫，鑑定師努力抓漏洞，技術在對抗中雙雙登頂。
08. 理論範疇：隱式密度估計 (Implicit Density)，透過對抗目標近似 Jensen-Shannon 散度。
核心特徵：生成極其銳利 | 罩門：模式崩塌 (Mode Collapse) 與梯度不穩
顯式近似 (Explicit) 2013 Kingma & Welling

VAE (變分自編碼器)

01. 將高維資料壓縮為常態分佈雲，在結構化潛在空間中平滑漫遊與重建。

🧬 編解碼與潛空間沙漏 Bottleneck + Reparam
02. 核心原理：基於編碼器 (Encoder) 與解碼器 (Decoder) 架構。編碼器將圖片壓縮成低維度的「潛空間 (Latent Space)」並加入隨機性，解碼器再從中還原成圖片。
優點：訓練過程非常穩定（凸優化下界），且潛在空間的插值 (Interpolation) 極為平滑連續。
缺點：受 MSE 像素均方差均值化影響，生成的影像通常比較模糊、高頻細節不足。
實務關鍵應用：現代擴散模型（如 Stable Diffusion）廣泛結合 VAE，先由 VAE 壓縮影像至潛空間再擴散，大幅降低運算資源。
06. 生活化例子：圖書館依分類標籤整理書籍，並留出連續貨架，使相近座標都能組裝出合理新書。
核心特徵：平滑潛空間插值 | 罩門：高頻細節偏模糊 (現多擔任潛空間壓縮器)
非平衡熱力學 (Score-Based) 2020 Ho et al. (DDPM)

Diffusion (擴散模型)

01. 向清水中滴墨水令其徹底混沌，再藉由類神經倒帶雕刻出清晰世界的奇蹟。

🔄 兩階段加噪與去噪 Forward & Reverse
02. 核心原理：模仿熱力學「擴散」現象，分為兩階段：
  • 前向過程 (Forward Process)：逐步為清晰圖片加上高斯雜訊，直到完全退化為純白雜訊。
  • 逆向過程 (Reverse Process)：訓練神經網絡一步步「去雜訊 (Denoising)」，從純雜訊還原出高品質圖像。
優點：生成品質極高、多樣性完備，且文字條件控制 (Text-conditional Prompt) 極為穩定（如 DALL-E 3、Stable Diffusion、Midjourney）。
缺點：反覆多步去雜訊迭代需要花費大量計算時間與硬體資源，推理延遲較高。
06. 生活化例子：將雕塑一層層敲成細砂，再訓練一個神工巧匠依每一步的砂礫方向雕刻還原。
核心特徵：逼真度與可控性 SOTA | 罩門：多步去雜訊推論開銷巨大
💡

現代工業界代表作：潛在擴散模型 (Latent Diffusion / Stable Diffusion) 的「VAE + Diffusion」合體奧秘

若直接在像素空間 ($512 \times 512 \times 3$) 進行數百步擴散去雜訊，硬體計算量與記憶體消耗將呈天文數字。因此現代架構先利用 預訓練 VAE Encoder 將像素圖片壓縮成低維的潛空間特徵（例如縮小 8 倍至 $64 \times 64 \times 4$），再於該平滑潛空間中執行 Diffusion 的去雜訊運算，最後由 VAE Decoder 一次性解碼還原成超高解析度畫質。這巧妙結合了 VAE 的降維穩定性與 Diffusion 的頂級去噪生成能力！

1. GAN 對抗對稱架構與反向梯度流向

Minimax Flow
核心特點：無須定義真實機率密度，判別器將對抗損失反向傳導回饋給生成器以推動分佈遷移。

2. VAE 重參數化與潛空間編解碼流程

ELBO Flow
核心特點：將噪聲 $\epsilon$ 移為獨立輸入（重參數化），確保採樣過程可解析求導，反向傳遞梯度更新編碼器。

3. Diffusion 馬可夫加噪 vs 類神經逆向去噪

DDPM Process
核心特點：前向加噪為確定性的非可學習馬可夫過程；逆向去噪由神經網絡（如 U-Net）逐步估計所加噪聲並予以剔除。

4. 現代工業標準：Latent Diffusion (SD) 融合架構

SD Pipeline
核心特點：VAE 負責空間降維與升維解碼；Diffusion 專注在低維特徵流形上做條件引導去噪，將運算複雜度降低超過 64 倍！

Q1 (GAN 訓練異常診斷)

在訓練標準 GAN 時，判別器損失迅速降至 0，而生成器損失飆高且無法更新權重，生成品質不再改善。請問造成此現象的主因與最佳解法為何？

正確答案：(B)
詳解：傳統 GAN 目標等價於 JS 散度。當兩分佈無重疊時，$D_{JS}$ 恆為常數，判別器過強會令梯度趨近於 0。WGAN 透過推土機距離賦予平滑連續梯度，克服梯度飽和。
Q2 (VAE 重參數化機制)

在變分自編碼器 (VAE) 中，為何不能直接從編碼器輸出的高斯分佈 $\mathcal{N}(\mu, \sigma^2)$ 進行隨機採樣 $z$，而必須使用重參數化技巧？

正確答案：(A)
詳解：隨機採樣無法計算對網路參數的偏微分。重參數化透過將隨機性剝離為獨立噪聲 $\epsilon \sim \mathcal{N}(0, \mathbf{I})$，使 $z = \mu + \sigma \odot \epsilon$ 成為確定性可微式。
Q3 (Diffusion 推理延遲與加速)

標準擴散模型生成圖片通常需數十至數百步反向去噪迭代，難以直接應用於即時邊緣裝置。當前工業界加速擴散推論的主要策略不包括下列何者？

正確答案：(C)
詳解：增加加噪步數只會使整體反向迭代更冗長。工業加速包含 DDIM 跳步取樣 (20~50 步)、ODE 專用求解器 (DPM-Solver) 與一致性蒸餾 (LCM/SDXL-Turbo 可降至 1~4 步)。
09. 數學推導核心

機率圖模型與損失函數嚴謹推導

GAN：極小極大與 JS 散度

生成器 $G$ 與判別器 $D$ 的 Minimax 零和博弈目標函數：

$$\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

固定 $G$ 求導數為 0，得到全局最優判別器 $D^*(x)$：

$$D^*(x) = \frac{p_{data}(x)}{p_{data}(x) + p_g(x)}$$

代回目標函數，即轉化為兩分佈之 Jensen-Shannon 散度：

$$V(D^*, G) = -\log(4) + 2 \cdot D_{JS}(p_{data} \parallel p_g)$$

VAE：證據下界 (ELBO) 與重參數化

藉由變分近似 $q_\phi(z|x)$ 最大化邊際似然，展開為 ELBO：

$$\log p_\theta(x) \ge \mathbb{E}_{q_\phi}[\log p_\theta(x|z)] - D_{KL}(q_\phi(z|x) \parallel p(z))$$

第 1 項為重建損失，第 2 項為迫使後驗貼近標準高斯先驗之 KL 懲罰。

重參數化技巧 (消除隨機取樣阻斷)：

$$\epsilon \sim \mathcal{N}(0, \mathbf{I}), \quad z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon$$

使得 $\nabla_\phi z$ 可解析求導，反向傳播得以順利穿透至編碼器。

Diffusion：前向閉合解與分數匹配

馬可夫前向加噪 $q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t}x_{t-1}, \beta_t \mathbf{I})$，任意步閉合解：

$$x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1 - \bar{\alpha}_t} \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, \mathbf{I})$$

神經網絡 $\epsilon_\theta(x_t, t)$ 預測所加高斯噪聲，簡化損失函數：

$$\mathcal{L}_{simple}(\theta) = \mathbb{E}_{t, x_0, \epsilon}\left[ \| \epsilon - \epsilon_\theta(x_t, t) \|^2 \right]$$

等價於估計數據分佈之對數梯度分數 $\nabla_{x_t}\log p(x_t)$。

11. Python / PyTorch 實作

三大生成模型最小可行性實作（核心函式色彩高亮）

重點標註說明：函式宣告、核心損失 Loss、關鍵技巧 Trick。

GAN 對抗訓練步驟 PyTorch 
import torch
import torch.nn as nn

criterion = nn.BCELoss()

def train_gan_step(real_imgs, G, D, opt_G, opt_D, z_dim=100):
    bs = real_imgs.size(0)
    real_lbl = torch.ones(bs, 1)
    fake_lbl = torch.zeros(bs, 1)

    # 1. 訓練判別器 D
    opt_D.zero_grad()
    loss_r = criterion(D(real_imgs), real_lbl)
    z = torch.randn(bs, z_dim)
    fake_imgs = G(z)
    # 關鍵: detach 阻斷回傳至 G
    loss_f = criterion(D(fake_imgs.detach()), fake_lbl)
    loss_D = loss_r + loss_f
    loss_D.backward()
    opt_D.step()

    # 2. 訓練生成器 G
    opt_G.zero_grad()
    loss_G = criterion(D(fake_imgs), real_lbl)
    loss_G.backward()
    opt_G.step()
    return loss_D.item(), loss_G.item()
重要細節：`fake_imgs.detach()` 可避免在更新判別器時冗餘反向傳播至生成器。
VAE 重參數化與 ELBO PyTorch 
import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    # 重參數化: z = μ + ε * σ
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

def loss_function(recon_x, x, mu, logvar):
    BCE = F.binary_cross_entropy(recon_x, x, reduction='sum')
    # 封閉解析解 KL 散度
    KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return BCE + KLD
重要細節：利用 `logvar` 取代 `std` 進行回歸可確保數值恆正且數值穩定性更佳。

import torch
import torch.nn as nn

class DiffusionEngine:
    def __init__(self, alphas_cumprod):
        self.alphas_cumprod = alphas_cumprod

    # 閉合加噪採樣: x_t = √ᾱ*x_0 + √(1-ᾱ)*ε
    def q_sample(self, x_0, t, noise):
        s_alpha = torch.sqrt(self.alphas_cumprod[t])
        s_one_minus = torch.sqrt(1.0 - self.alphas_cumprod[t])
        return s_alpha * x_0 + s_one_minus * noise

    def train_loss(self, unet, x_0):
        t = torch.randint(0, len(self.alphas_cumprod), (x_0.size(0),))
        noise = torch.randn_like(x_0)
        x_t = self.q_sample(x_0, t, noise)
        pred_noise = unet(x_t, t)
        return nn.functional.mse_loss(noise, pred_noise)
重要細節：UNet 輸入包含時間步編碼 (Timestep Positional Embedding)，使其感知當前噪聲能級。
