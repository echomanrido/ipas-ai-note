重點整理 (Key Takeaways)
  • 調和平均短板懲罰效應：\(F_1 = 2 \cdot \frac{P \cdot R}{P + R} = \frac{2}{\frac{1}{P} + \frac{1}{R}}\)；其本質對極端小值極端敏感，只要 Precision 或 Recall 任一維度塌陷，F1 即刻大幅暴跌，絕不容許單邊膨脹。
  • 破解類別不平衡虛假高分：在異常比率極低（如 0.1%）的場景，Accuracy 會被海量負樣本 \(TN\) 灌水；F1 完全排除 \(TN\) 稀釋，只衡量模型對少數目標的真確辨識力。
  • \(F_\beta\) 權衡天平：若漏抓代價遠高於誤報（如機台爆炸、惡性腫瘤），選 \(\beta=2\)（\(F_2\) 強化召回率）；若誤報成本極高（如高檔名牌推薦），選 \(\beta=0.5\)（強化精確率）。
機制說明 (Mechanism & Math)
  • 集合幾何映射 (Dice 係數)：代數展開後 \(F_1 = \frac{2TP}{2TP + FP + FN}\)，本質是預測正類集合與真實正類集合交集比例的兩倍，為影像分割與重疊度評估的黃金指標。
  • 多類別平均策略三式： · Macro-F1：不考慮樣本數各類平權，能嚴格暴露邊緣少數類短板。
    · Weighted-F1：依類別樣本數加權，反應實際整體商業效益。
    · Micro-F1：全局合計總體 \(TP, FP, FN\)，等同於全局 Accuracy。
  • 門檻動態最佳化 (Threshold Tuning)：透過 precision_recall_curve() 動態搜尋使 \(F_1\) 達到全域極大值的最佳分類機率切點 \(\theta^*\)。
應用在何處 (Industrial Scenarios)
  • 半導體晶圓自動光學檢查 (AOI)：先進製程良率高達 99.8%，缺陷顆粒極罕見；以 F1-Score 衡量檢測模型，保證零漏網之魚（高 Recall）且不過度誤殺報廢良品（高 Precision）。
  • 金融信用卡盜刷與 AML 反洗錢風控：在數千萬筆每日刷卡交易中捕捉微量盜刷事件，依 F1-Score 最適化攔截門檻，平衡詐欺損失與尊榮客戶投訴。
  • 設備預測性維護 (PdM 振動異常示警)：關鍵高壓泵浦與發電機軸承故障前兆捕捉，採用高 \(F_2\)-Score 模型進行實時預警，避免千萬停工損害。
MODULE 01 & 02

一句話簡介與核心原理

兼顧「不抓錯」與「不漏抓」的黃金調和度量

一句話核心定位 日常決策與機器學習的關鍵交集

在日常生活中，F1-Score（F1 分數）最常用在「當你想同時兼顧『不抓錯』與『不漏抓』，且這兩者缺一不可」的決策場景。

在機器學習中，F1-Score 是精準率（Precision，抓對的比例）和召回率（Recall，抓完整的比例）的調和平均數（Harmonic Mean）。當其中一個表現很差時，F1-Score 就會被大幅拉低。

1

F1 分數（F1-Score）核心定義

F1 分數（F1-Score）是精確率（Precision）與召回率（Recall）的調和平均數（Harmonic Mean）。

$$F_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2}{\frac{1}{\text{Precision}} + \frac{1}{\text{Recall}}}$$
2

為什麼不用算術平均？

對低值更敏感：調和平均有一個特性，只要其中一邊（精確率或召回率）數值偏低，F1 分數就會被明顯拉低。 [1]

範例說明（Precision = 0.8，Recall = 0.6）：
若採算術平均數：
$\frac{0.8 + 0.6}{2} = \mathbf{0.7000}$
無法反映 Recall 明顯較低的短板缺陷
調和平均計算後的 F1：
$2 \times \frac{0.8 \times 0.6}{0.8 + 0.6} = \frac{0.96}{1.4} \approx \mathbf{0.6857}$
數值偏向較小者，約為 0.6857（而非 0.7）

極值崩塌效應：如果有一方趨近於 0，F1 分數也會接近 0。這代表模型必須「兩者兼顧」才能得到高分。 [1] [2]

3

常見使用情境

類別不平衡（Imbalanced Dataset）

當正負樣本比例懸殊時（例如垃圾郵件偵測或罕見疾病診斷），只看準確率（Accuracy）容易被多數類掩蓋，此時看 F1 分數會更具參考價值。

📧 垃圾郵件偵測：正常信 99% vs 垃圾信 1%，全猜正常信 Accuracy 高達 99%，但 Recall 卻是 0；F1 能夠立刻刺破此假象。
🏥 罕見疾病診斷：陽性罕病患者 < 0.1%，若模型將所有患者誤診為陰性，Accuracy 仍高達 99.9%，唯有 F1 能嚴厲揭露漏抓重病患者的致命漏洞。
💡 核心總結

當我們說一個模型的 F1-Score 很高，用生活白話文來說就是：

「這傢伙做事很靠譜，既不會冒冒失失地亂指（不冤枉好人），也不會粗心大意地漏掉（不放過壞人），達到了完美的平衡。」

F1-Score 意義：既精準擊中你的偏好，又能把深藏的熱愛好物完整挖出展現眼前。
VECTOR ARCHITECTURE #2

調和平均數 vs 算術平均數：木桶短板懲罰幾何 SVG 解構

視覺化呈現為何算術平均會偽裝高分，而調和平均能狠狠懲罰「瘸腿模型」

木桶理論（短板效應）的數學體現

在算術平均中，優異的一端（0.90）可以輕易替爛的一端（0.10）掩飾，產生看似尚可及格的「0.50」假象。

極端短板案例 (Precision 0.9 vs Recall 0.1)：
算術平均：$(0.90 + 0.10) / 2 = 0.50$ (虛假安全感)
調和平均：$\frac{2 \times 0.9 \times 0.1}{0.9 + 0.1} = \frac{0.18}{1.0} = 0.18$ (暴跌懲罰)
常見溫和案例 (Precision 0.8 vs Recall 0.6)：
算術平均：$(0.8 + 0.6) / 2 = 0.7000$
調和平均 F1：$2 \times \frac{0.8 \times 0.6}{0.8 + 0.6} \approx 0.6857$ (拉低至 0.6857，而非 0.7)

調和平均永遠偏向較小者，且如果有一方趨近於 0，F1 分數也會接近 0。這代表模型必須「兩者兼顧」才能獲得高分。

VECTOR ARCHITECTURE #3

$F_\beta$ 天平與權衡向量圖（Trade-off Balance SVG）

直觀理解 $\beta=0.5$（偏重精準率）、$\beta=1$（平衡）、$\beta=2$（偏重召回率）之天平傾斜法則

β = 0.5 (偏重 Precision)
寧缺勿濫：容忍漏放，絕不可冤枉好人。
例如：垃圾郵件過濾、法院判刑。
β = 1.0 (標準 F1 平衡)
等重權衡：P 與 R 同等重要。
例如：通用分類、問答重疊 Token 評測。
β = 2.0 (偏重 Recall)
寧可殺錯不可放過：漏抓代價極其致命。
例如：癌症快篩、地震警報、晶圓缺陷檢測。
公式定義：$F_\beta = (1 + \beta^2) \frac{P \cdot R}{\beta^2 P + R}$，當 $\beta$ 代表的是 Recall 相較於 Precision 的重要倍數。

經濟部 IPAS AI 應用工程師能力鑑定 — 必考經典題實戰

經濟部官方能力鑑定「機器學習與深度學習」常考題型與速算解析

IPAS 試題 #1：指標數值速算 難易度：★★☆☆☆

某製造廠以 AI 模型進行半導體晶圓瑕疵篩檢。在 1000 顆晶圓中，實際上僅有 50 顆為瑕疵品（Positive）。模型預測為瑕疵品的共有 60 顆，其中有 40 顆為真正的瑕疵品。試問此模型的 Precision、Recall 與 F1-score 分別為何？

點擊展開題解步驟與速算密技 ▼

【解題步驟】

• 提煉計數：$TP = 40$，$FP = 60 - 40 = 20$，$FN = 50 - 40 = 10$。

• $\text{Precision} = \frac{TP}{TP + FP} = \frac{40}{60} \approx 66.67\%$。

• $\text{Recall} = \frac{TP}{TP + FN} = \frac{40}{50} = 80.0\%$。

【IPAS 速算口訣】代入 $F_1 = \frac{2TP}{2TP + FP + FN} = \frac{80}{80 + 20 + 10} = \frac{80}{110} \approx 72.73\%$ 最快！

IPAS 試題 #2：情境指標決策 難易度：★★★☆☆

在醫院推行「惡性腫瘤早期電腦斷層快篩」專案時，若發生漏診（把癌症誤判為健康），病患將錯失黃金治療期而喪命。工程師欲評估多個深度學習模型，應優先採用何種指標？若使用 $F_\beta$ 應如何設定？

點擊展開題解步驟與分析 ▼

正確決策：應優先關注 Recall（召回率），並採用 $F_2$-score ($\beta=2$)。

【決策解析】

• 漏診對應混淆矩陣中的 FN（偽負例）。當 FN 增加時，Recall 顯著下降。

• 誤報（FP）僅需醫師人工複檢，但漏報（FN）會致命。故召回率的重要性高於精準率，應挑選 $\beta > 1$ 的 $F_2$-score 作為驗收門檻。

04. 實務特徵

模型工程師必須警惕的特性

  • 完全忽視 TN： 公式中不含 TN，對百萬筆正確負例鈍化，絕不受龐大背景干擾。
  • PR-AUC vs ROC-AUC： 極端不平衡（如 99.9% 負例）下，ROC 會盲目樂觀虛高，PR-AUC 與 F1 才能反映真實力。
  • 門檻敏感： 0.5 幾乎永遠不是 F1 最佳切分點，實務必須掃描閥值。
05. 歷史由來

資訊檢索學派之起源

1979 年，計算機科學家 C. J. van Rijsbergen 在《Information Retrieval》中提出 E-measure 衡量檢索有效性。1992 年 MUC-4 評測正式確立 $F = 1 - E$ 形式。當精準率與召回率權重相同時，即誕生聞名世界的 F1-Score。

MODULE 08 & 09

理論簡介與代數逐步推導

從調和平均定義出發，一步步通分約分推導至混淆矩陣經典公式

1. 多分類聚合：Macro, Micro, Weighted F1

面對多元分類時，常見三種彙總方式：

Macro-F1 (類別平等) 各自計算每個類別的 F1，再取算術平均。對小樣本稀有類別最嚴格。
Micro-F1 (全域樣本平等) 將所有類別的 TP, FP, FN 累加後計算單一 F1，在單標籤下數值等同於 Accuracy。
Weighted-F1 (加權平均) 依據每個類別的真實樣本數量（Support）進行權重分配。

2. 步步推導證明（點擊展開各推導環節）

Step 1: 定義式 $$F_1 = \frac{2}{\frac{1}{P} + \frac{1}{R}} = \frac{2 \cdot P \cdot R}{P + R}$$
Step 2: 代入 $P = \frac{TP}{TP+FP}$ 與 $R = \frac{TP}{TP+FN}$

分子項：$2 \cdot P \cdot R = 2 \cdot \frac{TP}{TP+FP} \cdot \frac{TP}{TP+FN} = \frac{2 \cdot TP^2}{(TP+FP)(TP+FN)}$

分母項：$P + R = \frac{TP(TP+FN) + TP(TP+FP)}{(TP+FP)(TP+FN)} = \frac{TP(2TP + FP + FN)}{(TP+FP)(TP+FN)}$

Step 3: 上下約分抵消相同分母 $(TP+FP)(TP+FN)$ 及一個 $TP$：
$$F_1 = \frac{2 \cdot TP}{2 \cdot TP + FP + FN}$$
這就是混淆矩陣中最經典且不含 TN 的 F1-Score 算式！

訓練階段：PyTorch 可微 Soft-F1 損失函式

soft_f1_loss.py 
import torch
import torch.nn as nn

class SoftF1Loss(nn.Module):
    """利用 Sigmoid 連續機率點乘構建平滑混淆矩陣，支援梯度反向傳播"""
    def __init__(self, eps=1e-7):
        super().__init__()
        self.eps = eps

    def forward(self, logits, targets):
        # 1. 通過 Sigmoid 轉換為平滑連續機率
        probs = torch.sigmoid(logits)
        
        # 2. 計算連續可導的軟性交集 (Soft Counts)
        tp = torch.sum(probs * targets)
        fp = torch.sum(probs * (1.0 - targets))
        fn = torch.sum((1.0 - probs) * targets)
        
        # 3. Soft-F1 平滑度量
        soft_f1 = (2.0 * tp + self.eps) / (2.0 * tp + fp + fn + self.eps)
        
        # 損失函數為 1 - F1 (最小化 Loss 相當於最大化 F1)
        return 1.0 - soft_f1
