Accuracy 與 F1-score 深度對比指南

從數學原理、生活範例、IPAS 考古題到機器學習、深度學習、強化學習與 LLM 的實際應用，帶你徹底掌握評估指標的精髓。

【Accuracy 與 F1-score 深度對比】核心精華與產業實務應用

Key Takeaways · Mechanism Overview · Industrial Applications

重點精華 · 實務落地
重點整理 (Key Takeaways)
  • Accuracy (準確率) 的不平衡陷阱：當正負樣本比例極端懸殊（如 99% vs 1%），無腦全猜多數類即可獲得 99% Accuracy，但模型對關鍵少數異常類的檢測能力為 0，具嚴重誤導性。
  • F1-score 調和平均特性：\(F_1 = 2 \cdot rac{ ext{Precision} \cdot ext{Recall}}{ ext{Precision} + ext{Recall}}\)。調和平均本質對極端低值極為敏感，任一指標崩塌均會拉低 F1，唯有兩者兼優才能拿高分。
  • IPAS 應考黃金法則：題目只要出現「樣本極不平衡」、「重視少數關鍵事件」、「降低漏報成本」，一律無條件優先考慮 F1-score、Recall 或 PR-AUC，不可採用 Accuracy。
機制說明 (Mechanism & Math)
  • 混淆矩陣映射：\( ext{Accuracy} = rac{TP + TN}{TP + TN + FP + FN}\)，其分母與分子均被巨量 True Negative (\(TN\)) 淹沒；而 \(F_1\) 排除 \(TN\)，聚焦於少數正類的 \(TP, FP, FN\)。
  • 門檻值動態調整 (Threshold Tuning)：分類機率門檻預設為 0.5；調低門檻可提升 Recall（抓更多但也抓錯多），調高門檻可提升 Precision；F1 曲線的頂峰即為兩者最平衡之黃金切點。
  • 多類別擴展評估：多分類場景下支援 Macro-F1（不考慮樣本數，各類別平等）與 Weighted-F1（依各類樣本數加權），極度不平衡時 Macro-F1 最能暴露少數類弱點。
應用在何處 (Industrial Scenarios)
  • 半導體晶圓瑕疵篩檢 (Wafer Defect)：先進製程良率高達 99%，每片晶圓缺陷圖樣極其稀有。以 F1-score 作為製程異常偵測模型驗收標準，徹底杜絕漏檢瑕疵品出貨給客戶的毀滅性風險。
  • 智慧金融與信用卡反洗錢/防盜刷：在千萬筆交易中僅有數十筆為偽冒。以 F1-score 作為平衡「攔截盜刷成功率」與「誤擋一般正常客戶抱怨」的最佳風控判定指標。
  • 醫療影像病灶自動初篩：如胸部 X 光結節與乳房攝影微鈣化篩檢，病灶發生率低，以高 Recall 與高 F1-score 守護患者早期發現與黃金治療契機。
01

一句話簡介

  • Accuracy： 衡量模型在所有預測中，答對的比例（適合資料分佈均勻的場景）。
  • F1-score： 結合 Precision（精確率） 與 Recall（召回率） 的調和平均數，專門用來應對類別不平衡（Imbalanced Data）。
02

核心原理與混淆矩陣

透過混淆矩陣（Confusion Matrix）定義：TP, TN, FP, FN。

Accuracy = (TP + TN) / (TP + TN + FP + FN)

Precision = TP / (TP + FP)

Recall = TP / (TP + FN)

F1-score = 2 * (Precision * Recall) / (Precision + Recall)

03

IPAS AI 考題精選

【IPAS 經濟部產業人才能力鑑定試題範例】

在一個罕見疾病診斷的資料集中，正樣本（確診者）僅佔全體的 1%，負樣本佔 99%。若有一個笨蛋模型（Dummy Model）盲目將所有人都預測為「健康（陰性）」，其 Accuracy 高達 99%。此時若想評估該模型的真正實用價值，下列哪一個指標最不適合，而哪一個指標最能看出其缺陷？

(A) Accuracy 最不適合；F1-score 能正確反映其效能 (✓ 正確答案)

(B) F1-score 最不適合；Accuracy 能正確反映其效能

(C) Precision 最不適合；Recall 能正確反映其效能

(D) 兩者皆適合

解析： 在極度不平衡資料中，Accuracy 會被多數類別（Negative）嚴重灌水。此時由於 TP = 0，Precision 與 Recall 皆為 0，導致 F1-score 歸零，從而暴露出模型無法檢出任何患者的重大缺陷。

05

指標由來與理論簡介

Accuracy：源自傳統統計學的命中率與總體正確率，直覺易懂。

F1-score：由 Van Rijsbergen 於 1979 年提出，採用「調和平均數（Harmonic Mean）」具備懲罰極端值的特性，只要 Precision 或 Recall 其中一者趨近 0，F1-score 就會直接歸零。

06

生活化例子與分工解析

核心總結：

Accuracy 看的是「大局整體的答對率」，而 F1-Score 看的是「極端或重要任務中，抓得準不準、有沒有漏掉」。

📧

1. 垃圾郵件過濾器

（錯殺 vs. 漏放）

  • Accuracy（準確率）： 你的信箱今天收到了 100 封信，其中 99 封是正常信，1 封是垃圾信。如果系統「偷懶」把所有信都判定為正常信，它的 Accuracy 高達 99%。
  • 缺點： 看起來很完美，但唯一那封重要的垃圾詐騙信還是溜進來了。
  • F1-Score： 嚴格檢視那封「垃圾信」的處理狀況。如果為了追求高 Accuracy 而漏掉垃圾信，或者把重要工作信當成垃圾信刪掉，F1-Score 就會慘不忍睹。
🩺

2. 醫學檢查 / 驗孕棒

（偽陽性 vs. 偽陰性）

  • Accuracy（準確率）： 某種罕見疾病的盛行率只有 1%。試劑永遠只猜「健康」，Accuracy 也有 99%。但在醫學上這是災難，病人完全沒被找出來。
  • F1-Score： 在「不容許漏診」的關鍵時刻必須看 F1。
  • • Precision： 驗出陽性中真的生病的比例（不想嚇到健康的人）。
    • Recall： 所有病人中成功被驗出的比例（一隻漏網之魚都不能有）。
  • 平衡： F1 高代表既無亂報（偽陽性低）也無漏報（偽陰性低）。
🚨

3. 火災警報器

（放羊的孩子 vs. 睡著）

  • Accuracy： 一年 365 天，360 天沒火災。警報器壞掉永遠不響，Accuracy 高達 98.6%（因沒火災的日子都猜對了）。但火災來一次，家就沒了。
  • F1-Score：
  • • 太敏感（煮飯冒煙就大叫 $\rightarrow$ Precision 低），你會想拔掉它。
    • 太遲鈍（失火不響 $\rightarrow$ Recall 低），失去作用。
  • 結果： F1 高的警報器只在真正危急、有火災煙霧時精準作響。

整合對照總結表格

指標 什麼時候看它？ 生活白話文
Accuracy 資料很平衡、猜錯代價差不多時。
例如：猜明天會不會下雨、猜是非題。		 「反正整體算下來，我對的次數比較多。」

07

工業上應用

半導體晶圓瑕疵檢測：良品率高達 99.9%，若用 Accuracy，把全部晶圓判良品的模型 Accuracy 也是 99.9%，但會漏掉所有瑕疵品。工業上必須依賴 F1-score 或 Precision-Recall 把關。

網路資安入侵偵測：攻擊封包往往只佔日常流量微小比例，使用 F1-score 才能確保安全防護系統不會產生過多誤報或漏報。

08 & 09

數學推導與計算範例

假設混淆矩陣：TP=80, FP=20, FN=10, TN=890（總數 1000）

Accuracy = (80 + 890) / 1000 = 97.00%

Precision = 80 / (80 + 20) = 80.00%

Recall = 80 / (80 + 10) = 88.89%

F1-score = 2 * (0.80 * 0.8889) / (0.80 + 0.8889) = 84.21%

11

Python / PyTorch 實作程式碼

重點函式已標明顏色（使用 Scikit-Learn 與 TorchMetrics）：

import torch

import torchmetrics

from sklearn.metrics import accuracy_score, f1_score


# 模擬真實標籤與模型預測值

y_true = torch.tensor([0, 1, 1, 0, 1, 0, 0, 0, 1, 0])

y_pred = torch.tensor([0, 1, 0, 0, 1, 0, 1, 0, 1, 0])


# 1. Scikit-Learn 計算

sk_acc = accuracy_score(y_true.numpy(), y_pred.numpy())

sk_f1 = f1_score(y_true.numpy(), y_pred.numpy(), average='binary')


# 2. PyTorchMetrics 計算（深度學習常用）

metric_acc = torchmetrics.Accuracy(task="binary")

metric_f1 = torchmetrics.F1Score(task="binary")


print(f"[Scikit-Learn] Accuracy: {sk_acc:.4f}")

print(f"[Scikit-Learn] F1-score: {sk_f1:.4f}")
