特徵工程 01 / 03

為什麼必須萃取 9 維特徵？

原始的 2,000 點時域波形若直接送入機器學習模型會導致維度過高且缺乏物理直覺。透過時域（RMS、Peak、Crest Factor）與頻域 FFT（主頻、最大振幅、低/中/高頻帶能量與頻譜質心），我們將 2,000 個數值濃縮成最具機械病徵代表性的 9 個指標。

🛒 生活實例：超市購物車與發票摘要

你去超市買了一車 50 件商品（原始 2000 點波形），收銀員不會逐一跟你討論每顆蘋果的重量，而是直接列印「總金額、最貴商品、類別比例」（9 維特徵），讓你一眼看出這筆消費是否異常。

資料預處理 02 / 03

StandardScaler 的必要性與公式

主頻率數值動輒 30 ~ 400 赫茲，而高頻能量數值僅約 0.01 ~ 0.5。若不經由 z = (x - μ) / σ 標準化，數值大的特徵將在機器學習距離計算中完全主導模型，導致小數值特徵的微小異常被忽略。

⚖️ 生活實例：身高與體重的評分陷阱

評選健康分數時，若身高用公分（170cm）而體重用公斤（60kg），直接相加會讓身高完全決定結果。Z-Score 標準化就像把兩者轉換成「距離平均值幾個標準差」，讓每個指標獲得公平的發言權。

無監督學習 03 / 03

Isolation Forest 的運作奧秘：隨機切蛋糕

隔離樹不計算點與點之間的歐式距離，而是利用隨機超平面不斷切割特徵空間。正常運轉的資料點被包圍在密集的常態叢集中，需要極多刀才能切開；而故障異常點（如軸承高頻衝擊或不平衡低頻暴增）孤立在邊緣，只需少數幾刀就能切分出來。

🍰 生活實例：切蛋糕與人群疏散

廣場上有一大群學生緊密聚在一起（正常點），角落孤零零站著一個外國人（異常點）。隨機拉幾條封鎖線，角落那個人一下子就被隔開了（路徑短），而要分開人群得切十幾刀（路徑長）。

1. 用 5W1H 框架全面深度解析 11 個欄位及其機器學習應用（點擊卡片可即時連動圖解）

1. rms (均方根) 時域特徵

【5W1H 深度解析】
• What: 訊號能量的統計均方根值。
• Why: 機械故障（如不平衡）會使整體振動加劇。
• How (ML 應用): StandardScaler 標準化後，Isolation Forest 抓出能量過高者。

2. peak (峰值) 時域特徵

【5W1H 深度解析】
• What: 時域波形中的最大絕對振幅。
• Why: 反映軸承滾珠撞擊缺陷時的瞬間高脈衝。
• How (ML 應用): 捕捉突發性尖銳衝擊。

3. crest_factor (波峰因數) 時域特徵

【5W1H 深度解析】
• What: 峰值與 RMS 的比值 (Peak / RMS)。
• Why: 早期軸承磨損時整體能量尚不大，但 Peak 已飆升。
• How (ML 應用): 提高對早期微小受損的敏感度。

4. dominant_freq (主頻率) 頻域特徵

【5W1H 深度解析】
• What: 頻譜中能量最強的頻率 (Hz)。
• Why: 正常運轉約 30 Hz，軸承故障可能激發至 260+ Hz。
• How (ML 應用): 協助辨識頻率結構的異常偏移。

5. max_fft_amp (最大FFT振幅) 頻域特徵

【5W1H 深度解析】
• What: 主頻對應的 FFT 頻譜振幅大小。
• Why: 量化特定頻率成分的強烈程度。
• How (ML 應用): 正常時數值穩定，故障時大幅放大。

6. band_low_energy (低頻帶能量) 頻帶能量

【5W1H 深度解析】
• What: 0 ~ 100 Hz 頻帶的能量總和。
• Why: 涵蓋轉速基頻與 1X~3X 諧波。
• How (ML 應用): 轉子不平衡時此數值暴增。

7. band_mid_energy (中頻帶能量) 頻帶能量

【5W1H 深度解析】
• What: 100 ~ 350 Hz 頻帶的能量總和。
• Why: 捕捉機械結構共振。
• How (ML 應用): 提供中頻段結構鬆動指標。

8. band_high_energy (高頻帶能量) 頻帶能量

【5W1H 深度解析】
• What: 350 ~ 1000 Hz 頻帶的能量總和。
• Why: 軸承滾珠磨損的高頻共振。
• How (ML 應用): 軸承故障時數值大幅飆升。

9. spectral_centroid (頻譜質心) 頻譜統計

【5W1H 深度解析】
• What: 反映頻譜能量重心的頻率位置。
• Why: 高頻雜訊或軸承異音增加時，質心會往高頻偏移。
• How (ML 應用): 輔助判斷頻譜整體分佈重心。

10. condition (健康狀態) 文字標籤

【5W1H 深度解析】
• What: normal、unbalance、bearing_fault。
• Why: 供人工稽核與視覺化分色。
• How (ML 應用): 用於散佈圖視覺化與驗收對照。

11. label (二元標籤) ML 答案

【5W1H 深度解析】
• What: 0 = 正常，1 = 異常。
• Why: 測試集驗收與計算 Recall。
• How (ML 應用): 評估 Isolation Forest 預測準確度的標準答案。
