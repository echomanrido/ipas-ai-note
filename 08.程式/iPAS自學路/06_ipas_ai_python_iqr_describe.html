IQR 異常值偵測與 describe 報表解讀

章節 01

由來與統計學大師 John Tukey

在傳統高斯統計中，常以平均數 $\mu$ 與標準差 $\sigma$ 的 $3\sigma$ 原則篩選極端值。然而統計巨擘約翰·圖基（John Tukey）在 1977 年創立探索性資料分析（EDA）時指出：「離群值本身就會嚴重扭曲平均數與標準差！」因此他發明了無需假設常態分佈的箱形圖（Box Plot）與四分位距（IQR）。

為什麼圖基選定 1.5 倍？

在標準常態分佈下，$1 \text{ IQR} \approx 1.349 \sigma$。因此 $1.5 \times \text{IQR} \approx 2.698 \sigma$。 箱形圖的上下界線正好涵蓋了約 99.3% 的常態分佈資料，既能精準捕捉異常雜訊，又不會過度過濾正常邊際數據。

💡 穩健統計量（Robust Statistic）：中位數與 IQR 不受極值拉扯，是資料前處理最可靠的基石。

章節 03

工業實務應用：CNC 工具機震動與感測器異常檢測

在智慧製造與工業物聯網（IIoT）情境中，高頻感測器常因雜訊干擾回傳突波，IQR 扮演著第一線特徵過濾守門員：

熱電偶溫度感測器突波

產線熱處理感測器偶發短路回傳 9999°C。若直接輸入神經網路會導致損失函數梯度爆炸，需經由 IQR 上限自適應濾除。

CNC 主軸切削震動特徵

工件上下料碰撞產生短暫衝擊脈衝，透過箱形圖下鬚與上鬚門檻界定，能保留穩態切削振動基線，精準預測刀具磨耗。

AOI 晶圓光學瑕疵面積辨識

無塵室晶圓鏡片反光產生超大異常光斑。利用 IQR 能自動標記反光噪聲，防止機器視覺分類模型將反光誤判為破片。

章節 07

Python / Pandas 實作程式碼

# 載入 Pandas 與 NumPy 函式庫
import pandas as pd
import numpy as np

# 1. 建立門市銷售額範例資料
data = {'sales': [120, 200, 380, 450, 480, 510, 620, 650, 999]}
df = pd.DataFrame(data)

# 2. 產出 8 大摘要指標報表
summary = df['sales'].describe()
print("=== Pandas describe() 報表 ===")
print(summary)

# 3. 提取 Q1, Q3 與計算 IQR
q1 = df['sales'].quantile(0.25)   # 亦可由 summary['25%'] 取得
q3 = df['sales'].quantile(0.75)   # 亦可由 summary['75%'] 取得
iqr = q3 - q1

# 4. 依據 Tukey 1.5 倍法則建立安全閥邊界
lower_bound = q1 - 1.5 * iqr
upper_bound = q3 + 1.5 * iqr

# 5. 篩檢出極端離群值 (Outliers)
outliers = df[(df['sales'] < lower_bound) | (df['sales'] > upper_bound)]
print(f"\nIQR: {iqr}, 正常安全閥區間: [{lower_bound}, {upper_bound}]")
print("抓出的離群異常值清單:\n", outliers)
