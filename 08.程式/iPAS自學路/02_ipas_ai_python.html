容器一：列表 List 與索引雙向座標

列表最大的特點就是「有序」，每項元素都擁有精確、獨一無二的座標位置。

觀念核心｜有序陣列的存取邏輯

列表以中括號 [ ] 包覆。Python 支援正向（從左至右）與反向（從右至左）兩套座標系統，永遠記住兩條鐵律：

⚠️ 鐵律 1：正向索引從 0 開始 考場重災區

第 1 個項目的地址是 data[0]，而不是 data[1]！ 緊張時極易將「第幾個」跟「索引值」混為一談。

⚡ 鐵律 2：負數索引秒殺倒數元素 效率心法

取最後一個元素不必計算長度 len(data)-1，直接使用 data[-1] 秒殺；倒數第二個就是 data[-2]。

⚙️ range() 執行次數心算法

range(start, stop) 與切片相同，絕對遵守「含頭不含尾」！
若寫 range(1, 5)，只會產生 1, 2, 3, 4，絕不會有 5！
👉 次數公式：stop - start（例如 5 - 1 = 跑 4 次）。

🔍 列表推導式的閱讀順序

考題常把數行迴圈壓縮成一行：
[x * 2 for x in data if x > 0] 閱讀心法：先看後面的 for 知道資料來源，再回頭看最前面的 x * 2 做了什麼計算！

🛑 break 與 continue：千萬不能搞混的戰術指令

break 毀滅整個任務

直接炸掉並終止整個迴圈。一旦觸發，後續的所有輪次都不會再執行，程式立即跳出迴圈區塊！

continue 掠過當前目標

態度溫和。僅跳過這一次迭代剩下的程式碼，立即回到迴圈最上方，繼續跑下一個輪次。

魔王關：切片 Slicing 手術刀與「含頭不含尾」

最高頻陷阱
🎙️ 語音逐字稿： 「接下來我們要進入魔王關了：切片 slicing！你可以把它想像成一把手術刀，讓你非常非常精準地從列表裡面切下一段你要的部分。它的語法長這樣：[開始 : 結束 : 步長]。我們直接來看一道經典的陷阱，這題真的讓無數考生直接陣亡！好，假設現在有一個列表 data = [10, 20, 30, 40, 50]，那問你：data[1:3] 切出來的結果會是什麼？憑直覺想好像很簡單啊，不就是從索引 1 到索引 3 嗎？那答案應該是 [20, 30, 40] 對不對？如果你是這麼想的，恭喜你，完美地掉進陷阱了！這是錯的！記住，真正的規則只有五個字：『含頭不含尾』！什麼意思？它是說它會從開始的位置，也就是 index 1 一路拿到結束位置的前一個就停了！所以在 [1:3] 這個指令裡，它只會拿到 index 1 和 index 2，所以正確答案是 [20, 30]！好，我直接給你一個心法：以後看到切片，看到冒號右邊那個數字，你心裡自動把它減一！那個才是真正的終點，這樣絕對不會錯！再來還有幾個進階的考點，其實都是固定套路，你背起來就好：[:3] 就是從頭開始拿 3 個；[::2] 這個 2 是步長，意思就是每隔一個拿一個、跳著拿；再來最重要的一個：[::-1]，這個看到要馬上反應過來，它的意思就是把整個列表全部反轉，這是倒序輸出的標準寫法，一定要記！OK，第一個容器搞定！」
💡 右邊減一心法 若考卷出現 data[1:3]：
看右邊數字 3 - 1 = 2 ➔ 只取到索引 2，得 [20, 30]。
⚡ 考場三大固定套路
[:3] ➔ 取前 3 個元素 (0, 1, 2)
[::2] ➔ 步長為 2，間隔跳躍取出
[::-1] ➔ 整份列表完美反轉倒序
❌ 切勿把 stop 當包含 考試 10 個人有 6 個會手滑把 index 3 的值加進去，務必克制！

📦 記憶體本體與標籤真相 (Reference vs Deepcopy)

在 Python 中，串列（List）屬於可變物件（Mutable Object）。
B = A 僅是讓變數 B 引用與 A 相同的記憶體地址（Reference），因此更動 B[0] 會直接影響 A[0]！

👉 真正獨立副本必用深拷貝：import copy; B = copy.deepcopy(A)
