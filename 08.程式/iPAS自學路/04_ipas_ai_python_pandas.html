MODULE 02

資料讀取的三大致命陷阱（pd.read_csv）

🔴 致命陷阱 01 DecodeError

編碼地獄 (Encoding)

Pandas 預設採 utf-8。台灣政府開放資料與 Windows 匯出檔多為繁體 Big5 / CP950，讀取直接噴錯崩潰。

🟢 實戰 SOP 破解： encoding='cp950' 或 'big5'
🔴 致命陷阱 02 Header Consumed

吃掉首列數據 (Header)

預設 header=0 會將第一行當作欄域名稱。若原始檔本無表頭，第一筆真實資料會被吃掉且無法被當作資料分析！

🟢 實戰 SOP 破解： header=None
🔴 致命陷阱 03 Auto Index

多餘流水號 (Index Col)

預設會在最左側自動生成 0, 1, 2... 流水號。若要將已有的日期或 ID 欄位指定為列索引主鍵，需主動設定。

🟢 實戰 SOP 破解： index_col='date' 或 index_col=0

MODULE 03

屬性 (Attribute) vs 方法 (Method) 必勝判讀

🔵 核心名詞 🚫 不加小括號 ()

屬性 Attribute（靜態特徵/形狀）

描述 DataFrame 既有的靜態特徵（如維度、欄位清單、資料型態）。只需提取現成屬性，不進行運算或資料變更。

df.shape → (列數, 欄數) tuple
df.columns → 回傳所有欄域名稱 Index
df.dtypes → 檢視各欄位資料型態
🔴 致命錯誤： df.shape() ➔ TypeError: 'tuple' object is not callable
🟢 實戰動作 ✅ 必須加小括號 ()

方法 Method（動態行為/操作）

對資料進行運算、過濾、聚合或動態切片提取。這是一個執行動作，可以傳遞參數來微調運作行為。

df.head(5) → 提取前 n 筆資料 (預設 5)
df.tail(3) → 提取末端 n 筆資料 (預設 5)
df.info() → 執行全身健檢印出報表
🟡 漏寫括號提醒： df.head ➔ 僅印出函數指針 <bound method DataFrame.head...>
🔴

業界震撼彈：為何資料載入後第一件事務必 df.tail()？

實務上從 ERP 或會計系統匯出的報表，其最後一行常偷偷附帶「總計 / 報表製作者 / 系統版權宣告」等純文字行。 只要該文字混在整欄數值下方，Pandas 為了安全相容，就會將整欄強行降級為 object (字串)！ 導致所有數值加總直接爆掉。載入後務必用 df.tail() 快速檢查尾端。
