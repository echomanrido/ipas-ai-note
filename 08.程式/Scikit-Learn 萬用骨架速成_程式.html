只要掌握 4 個動作，秒解 90% 考題

看到骨架直接直覺翻譯：用什麼工具、學什麼資料、對誰預測或轉換。

萬用句型 (考題 90% 長這樣)
from sklearn.某個地方 import 某個工具
引進法寶：需要什麼演算法
model = 某個工具(參數)
實例物件：把參數設定好
model.fit(X_train, y_train)
閉關修煉：從訓練集學規律
結果 = model.predict(X_test) 或 model.transform(X_test)
驗收出關：下結論 / 轉資料
核心記憶心法： 看到題目考這幾行，不要死背細節。第一步看工具是誰，第二步看用誰 fit（學習），第三步看對誰 predict 或 transform（拿結果）。

什麼時候用 predict？什麼時候用 transform？

一秒判斷法則：問自己「我的目標是得到未知的答案（預測標籤/數值），還是「把資料改變形狀/換個單位給下一步使用」？

.predict()

預測器 (Predictor)

回答「這是什麼？」或「數值是多少？」

監督式學習

當你想讓模型扮演占卜師 / 判官時使用。模型已經學會了 X → y 的規則，你餵給它新的題目 X_test，它輸出答案 y_pred。

什麼時候輪到它？
  • 二元/多元分類：預測病患是否得病（0 或 1）、判斷手寫數字（0~9）。
  • 數值迴歸：預測下個月房屋售價、明日最高氣溫。
  • 常見工具：RandomForest, LinearRegression, LogisticRegression, SVC, XGBoost
# 範例：預測未知房子的價格 (迴歸)
model = LinearRegression()
model.fit(X_train, y_price_train)
predicted_prices = model.predict(X_test)
.transform()

轉換器 (Transformer)

回答「把特徵整理成什麼規格？」

特徵預處理

當你想讓工具扮演加工廠 / 翻譯機時使用。輸入是資料 X，輸出還是資料 X_new（維度或尺度改變），但不是預測解答。

什麼時候輪到它？
  • 特徵縮放：把「年齡(0~100)」與「薪水(3萬~20萬)」標準化到同一尺度。
  • 文字或類別編碼：將文字標籤轉為向量（如 OneHotEncoder）。
  • 降維壓縮：將 100 個特徵降為最核心的 5 個主成分（PCA）。
  • 常見工具：StandardScaler, MinMaxScaler, OneHotEncoder, PCA
# 範例：將測試資料依訓練集的平均值與標準差縮放
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
# 考點注意：測試集不可再 fit，只能 transform！
X_test_scaled = scaler.transform(X_test)
一句話秒懂：predict 是用來拿「最終答案 (y)」；transform 是用來把「特徵 (X)」重新排版縮放以餵給下個模型！
輸入 X → 產出 y (predict) vs 產出 X' (transform)
