深入解析：資料如何轉化為機器學習可理解的「數值矩陣」？

電腦無法直接讀懂字串、圖片或自然語言，前處理函式庫的終極任務即是「向量化」

X_train, y_train ➔ Model
表格 ➔ 數值特徵矩陣

透過 OneHotEncoder 轉換文字類別，以 StandardScaler 統一量綱，將非數值轉換為 N×D 的 NumPy 矩陣。

圖像 ➔ 像素強度陣列

藉由 OpenCV / Pillow 縮放解析度至統一尺寸，再將 0~255 RGB 像素除以 255 縮放為浮點數向量。

文本 ➔ TF-IDF 稀疏矩陣

透過 jieba 斷詞切分獨立 Token，再由 TfidfVectorizer 計算統計詞頻權重轉化為數值矩陣。

步驟 4：模型評估結果視覺化常用 API (matplotlib / seaborn)

將模型預測表現、特徵重要性與混淆矩陣繪製成直觀圖表

sns.heatmap(data, annot=True) Seaborn

繪製特徵相關性矩陣或分類混淆矩陣 (Confusion Matrix) 的彩色熱力圖。

plt.scatter(x, y, c=y_pred) Matplotlib

散佈圖繪製，可將降維後（如 PCA）的特徵點依據群集標籤著色，檢驗分群邊界。

RocCurveDisplay.from_estimator() sklearn.metrics

直接計算二元分類模型的真陽性率 (TPR) 與假陽性率 (FPR)，一鍵繪製 ROC 曲線與 AUC 分數。

evaluate_visualization.py 視覺化評估示範 
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.metrics import confusion_matrix

# 計算測試集預測的混淆矩陣
cm = confusion_matrix(y_test, y_pred)

# 透過 Seaborn 繪製混淆矩陣熱力圖
plt.figure(figsize=(6, 4))
sns.heatmap(cm, annot=True, fmt="d", cmap="Blues",
            xticklabels=["負向", "正向"],
            yticklabels=["負向", "正向"])
plt.xlabel("預測類別 (Predicted)")
plt.ylabel("實際類別 (True)")
plt.title("模型分類混淆矩陣 (Confusion Matrix)")
plt.tight_layout()
plt.show()

重點函式庫快速對照表

掌握 Python 資料科學與機器學習生態系的核心套件定位

階段分類 函式庫名稱 主要功能說明 在機器學習流程的角色
表格 / 數值 NumPy / pandas 高維陣列運算、表格資料載入、遺失值填補、特徵挑選 將非結構或混雜的原始表格整理成純數值特徵矩陣
影像前處理 OpenCV / Pillow 影像縮放、色彩空間轉換 (RGB to Gray)、裁切、濾波增強 將像素矩陣標準化為固定尺寸與數值區間 (0~1 或 -1~1)
自然語言處理 mecab / NLTK / jieba 文本斷詞 (Tokenization)、去除停用詞、詞性標註、詞袋模型 將人類自然語言句子轉換為電腦理解的詞向量 (TF-IDF / Word2Vec)
核心演算法 scikit-learn 提供隨機森林、SVM、KNN、K-Means、線性迴歸等廣泛演算法 執行模型擬合 (fit)、驗證 (predict) 及交叉驗證評估
結果可視化 matplotlib / seaborn 折線圖、散佈圖、熱力圖 (Heatmap)、ROC曲線等圖表生成 直觀呈現資料特徵分佈與模型分類預測表現
