Scikit-Learn 四行通解

考試或作業 90% 的題型，本質上就是「引工具、建模型、學資料、做預測」。不需要管神經元的權重梯度與批次。

  • 1. import：從 sklearn.ensemble, linear_model 等模組引入演算法。
  • 2. fit：吃進 (X_train, y_train) 一口氣擬合完成。
  • 3. predict / transform：特徵轉換用 transform，結果預測用 predict。
sklearn_skeleton.py 
from sklearn.某個地方 import 某個工具

# 1. 建立模型 (用什麼工具、設什麼參數)
model = 某個工具(參數)

# 2. 學習資料 (特徵矩陣 X, 目標向量 y)
model.fit(X_train, y_train)

# 3. 產出結果 (預測類別/數值 或 進行特徵尺度縮放)
結果 = model.predict(X_test)  # 或 model.transform(X_test)

Keras / TensorFlow 萬用公式

Keras 最貼近 sklearn 的體驗，但中間多了一個關鍵的「compile（編譯）」步驟，用來指定損失函數和優化策略。

記憶口訣：四部曲
1. Sequential 鋪管路（加圖層）
2. Compile 定規矩（選 Loss & Optimizer）
3. Fit 反覆練（分批次、設 Epochs）
4. Predict 驗收成果
keras_skeleton.py 
from tensorflow.keras import models, layers

# 步驟 1: 疊加網路層 (Model Architecture)
model = models.Sequential([
    layers.Dense(128, activation='relu', input_shape=(特徵數,)),
    layers.Dense(64, activation='relu'),
    layers.Dense(類別數, activation='softmax')
])

# 步驟 2: 編譯規則 (指定最佳化器、損失函數、監控指標)
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# 步驟 3: 訓練迴圈 (指定次數 Epochs 與批次大小 Batch Size)
model.fit(X_train, y_train, epochs=10, batch_size=32, validation_data=(X_val, y_val))

# 步驟 4: 預測評估
結果 = model.predict(X_test)

PyTorch「經典五步迴圈」

PyTorch 沒有現成的 model.fit()，所有考題都在考你有沒有背熟這 5 步訓練心法。缺一不可，順序絕對不能錯！

1
optimizer.zero_grad() 梯度歸零（清除上輪累積）
2
outputs = model(inputs) 前向傳播（計算當前猜測）
3
loss = criterion(outputs, labels) 計算誤差（比對真實答案）
4
loss.backward() 反向傳播（求每個參數的微分梯度）
5
optimizer.step() 參數更新（朝谷底微調一步）
pytorch_skeleton.py 
import torch
import torch.nn as nn
import torch.optim as optim

# 準備三要素：模型、損失函式、優化器
model = MyNeuralNet()
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 進入訓練模式
model.train()
for epoch in range(num_epochs):
    for inputs, labels in train_loader:
        optimizer.zero_grad()               # 1. 梯度歸零
        outputs = model(inputs)                 # 2. 前向傳播 (Forward)
        loss = criterion(outputs, labels)    # 3. 計算 Loss
        loss.backward()                     # 4. 反向傳播 (Backward)
        optimizer.step()                    # 5. 更新權重權重

# 推論測試萬用句型 (關閉梯度以加速並節省記憶體)
model.eval()
with torch.no_grad():
    predictions = model(test_inputs)

從影像分類 CNN、資料處理 DataLoader 到常見的陷阱對比

範例 1

電腦視覺：CNN 影像分類骨架 (TensorFlow / Keras)

考題中最常出現的典型影像分類模板：透過 Conv2D 提取特徵、MaxPooling2D 降維，最後透過 Flatten 攤平接全連接層。骨架完全符合「定義 $\to$ 編譯 $\to$ 擬合」。 

from tensorflow.keras import layers, models

# 1. 骨架：捲積層 (Conv2D) -> 池化 (MaxPooling) -> 展平 (Flatten) -> 全連接 (Dense)
model = models.Sequential([
    layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.Flatten(),
    layers.Dense(64, activation='relu'),
    layers.Dense(10, activation='softmax') # 10 個類別預測機率
])

# 2. 編譯規則：分類常客 sparse_categorical_crossentropy
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])

# 3. 訓練並驗證
history = model.fit(X_train, y_train, epochs=5, batch_size=64, validation_split=0.2)
範例 2

PyTorch 資料管線萬用骨架：自訂 Dataset & DataLoader

PyTorch 必考的資料讀取「三大法寶」：自訂 Dataset 必須覆寫 __init__、__len__ 與 __getitem__，最後交給 DataLoader 進行批次洗牌。 

from torch.utils.data import Dataset, DataLoader
import torch

# 1. 深度學習自訂資料集必須繼承 Dataset 並實現這 3 個魔術方法
class CustomDataset(Dataset):
    def __init__(self, features, labels):
        self.x = torch.tensor(features, dtype=torch.float32)
        self.y = torch.tensor(labels, dtype=torch.long)

    def __len__(self):
        return len(self.x) # 資料集總筆數

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx] # 抽出一筆 (特徵, 標籤)

# 2. 用 DataLoader 進行打包分批 (Batching) 與隨機洗牌 (Shuffle)
dataset = CustomDataset(X_train, y_train)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

面試與考試「必踩地雷」萬用檢查清單

漏掉 zero_grad()

在 PyTorch 裡梯度是累加的（+=），如果迴圈沒寫 zero_grad()，上一輪計算的梯度會留著，導致模型越練越爛。

推論忘了 with torch.no_grad()

預測不需要計算微分，如果不關閉梯度，GPU 記憶體會暴增直接跳 OOM (Out Of Memory)。

model.eval() 與 model.train()

Dropout 和 BatchNorm 層在訓練和測試時行為完全不同，評估時務必呼叫 model.eval() 凍結它們！
