模型層 (Model Architecture)：空間、時序與特徵複用

00:02:25 - 00:08:40

CNN 為何擊潰全連接層？

全連接層將 2D 圖片強制拉直成 1D 向量，摧毀相鄰像素間的幾何空間結構，且權重參數量爆炸。CNN 透過局部感知野 (Local Receptive Field) 與參數共享 (Weight Sharing)，就像拿著手電筒掃描圖片提取邊緣輪廓。

RNN 瓶頸 vs Transformer 上帝視角

傳統 RNN 像單線傳遞紙條，長序列必定遺忘前端；LSTM 藉由遺忘門/輸入門穩定記憶；而 Transformer 以多頭自注意力 (Multi-Head Attention) 站在上帝視角一覽全文字詞關聯，支援高度並行化。

遷移學習 (Transfer Learning) 凍結

小樣本情境下從零訓練必死無疑。底層卷積層學的是通用輪廓紋理，直接將底層權重凍結 (Freeze, 梯度設為 0)，僅訓練替換後的頂部分類器，保證特徵泛化能力。

00:08:49 - 00:13:50
準確率 (Accuracy) - 陷阱
$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$
精確率 (Precision) vs 召回率 (Recall)
$$\text{Prec} = \frac{TP}{TP + FP}, \quad \text{Rec} = \frac{TP}{TP + FN}$$
F1-Score 調和平均數 (Harmonic Mean)
$$F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

回歸任務診斷：殘差分析 (Residual Analysis) 與 $R^2$

評估回歸模型時，除了看決定係數 $R^2$（目標總變異被模型解釋的比例）外，必做殘差圖檢定：

  • 健康隨機分佈 (Good Fit)：殘差點以 $y=0$ 水平線為中心均勻無規則散布，代表誤差均為純隨機白雜訊。
  • 系統性缺陷 (Curved Pattern)：在特定區間出現顯著拋物線或漏斗狀，表示模型忽視了非線性關係或存在異質變異。

TOP 03

資料層 (Data Layer)：標準化、PCA 降維與 SMOTE 合成過採樣

00:14:06 - 00:18:25
為何 KNN / SVM 必須標準化？

基於歐氏距離 (Euclidean Distance) 計算的模型，若特徵 A 範圍為 0~100,000 (如年薪)，特徵 B 為 0~5 (如年資)，年薪將完全主導幾何距離，導致年資形同虛設。標準化將尺度消除。

PCA 主成分分析與特徵選取

PCA 是特徵萃取 (Feature Extraction)，透過正交旋轉找到變異量最大的新主成分軸；而決策樹利用資訊增益 (Information Gain) 篩除低貢獻變數，屬於特徵選擇 (Feature Selection)。

$$\frac{\lambda_1 + \lambda_2}{\sum \lambda} = \frac{6+3}{10} = 90\% \text{ 變異保留}$$
SMOTE 絕非單純複製樣本

直接單純複製少數樣本，只會加劇決策邊界在原有點周圍的極度過擬合 (Overfitting)。SMOTE 是在少數樣本的 k 個最近鄰近點間，以線性內插法 (Linear Interpolation) 隨機產生全新的人造合成樣本！

TOP 04

優化層 (Optimization Layer)：正則化幾何約束與 Early Stopping

00:18:35 - 00:22:10

L1 正則化 (Lasso Regression)

稀疏解 / 特徵篩選
$$\mathcal{L}_{L1} = \mathcal{L}_0 + \lambda \sum_{i=1}^n |w_i|$$

幾何形狀為菱形 (Diamond)。等高線極易與菱形頂點 (角點) 相交，使得部分不重要權重精確被壓制為 0，產生稀疏模型 (Sparse Model)。

L2 正則化 (Ridge Regression)

平滑收縮 / 權重衰減
$$\mathcal{L}_{L2} = \mathcal{L}_0 + \lambda \sum_{i=1}^n w_i^2$$

幾何形狀為圓球形 (Circle)。約束邊界平滑，使得權重向 0 縮小但不會精確等於 0，有效抑制過擬合並保留全部特徵維度。

正則化幾何邊界互動：菱形頂點 (L1=0) vs 圓形切線 (L2)

拖動損失等高線大小，觀察等高線最先接觸 L1 菱形軸上頂點（令 w1 或 w2 為 0）與 L2 圓形弧面的幾何直覺。

等高線半徑：
L1 菱形約束 (|w1| + |w2| ≤ C)
★ 切點落在軸上，使得 w2 = 0 (達成特徵篩選)
L2 圓形約束 (w1² + w2² ≤ C)
★ 切點落在弧面上，w1, w2 同步縮小且均非 0

TOP 05

規劃師實戰心法：領域偏移 (Domain Shift) 與偏見治理

領域偏移 (Domain Shift) 的突襲

在固定的驗證集上跑出 98% 的 F1-Score 只能證明模型適合過去切片的歷史分佈。當系統移轉至真實環境（例如：原先以標準英文語料訓練的情感分析器，直接丟進西語地區或論壇俚語環境），資料分佈偏移將導致成效大崩盤。因此持續監控 (Continuous Monitoring) 與漂移檢測是規劃師不可或缺的職責。

演算法優化放大偏見 (Bias Amplification)

過採樣（如 SMOTE）與梯度優化固然強大，但若原始資料集存在偏見（例如：因過往升遷紀錄產生的性別或學歷失衡），演算法在內插少數類與強化邊界時，會毫無批判地將歷史社會偏見放大並制度化。評估時不能僅盯著 F1 指標，更須落實倫理審查與反事實公平檢驗。

高準確率的落地陷阱：工廠瑕疵召回災難

⚠️ 落地致命陷阱

工廠瑕疵檢測等資料極度不平衡的場景下，假設 99% 為正常品、1% 為瑕疵品，AI 模型即便完全不做任何學習，直接將所有產品通通預測為正常，帳面上也能輕易取得 99% Accuracy。但在現實產線中，這會導致所有瑕疵品全面流出到終端消費者手上，造成天價的召回成本與商譽損失。

規劃師核心思維：面對極端不平衡資料，評估指標絕不能只看 Accuracy，必須引入注重少數類的精確率 (Precision)、召回率 (Recall) 與 F1-Score。

AI 專案五大層次：立體破局架構

📘 系統性方法論

解構 AI 專案千萬不能單純調包或死背參數，應依序劃分為五個關鍵支柱： 模型層（幾何/時序架構適配）、 評估層（業務目標與指標綁定）、 資料層（前處理與特徵提煉）、 訓練層（權重更新與收斂穩定）、 優化層（泛化約束與過擬合控制）。

CNN 卷積神經網絡：空間局部性與池化降維

💡 核心演算法直覺

全連接層的致命傷：若將 1000x1000 的彩色影像展平為 300 萬維度的一維向量，相鄰像素的幾何相對位置被徹底破壞，且第一層權重就高達數百億，根本無法訓練。
CNN 的兩大殺手鐧： 1. 局部感知野 (Local Receptive Field)：如同拿手電筒一小塊一小塊掃描，捕捉局部的邊緣、輪廓與紋理； 2. 參數共享 (Weight Sharing)：同一個濾波器（卷積核）掃過全圖，大幅壓低參數量。 最後透過最大池化 (Max Pooling) 保留顯著特徵並達成平移不變性。

LSTM 長短期記憶：以水閘門控打破記憶遺忘瓶頸

⚙️ 時序門控設計

傳統 RNN 像單線紙條傳話，長度一拉長，梯度的連續矩陣相乘便導致梯度消失 (Vanishing Gradient)，後段單詞完全喪失對開頭上下文的記憶。
LSTM 的解法：建立了加法直通的 Cell State 高速公路，配合三個水閘（遺忘門過濾過時記憶、輸入門寫入新資訊、輸出門產出當前輸出），讓時序相依性得以長跨度穩定保留。

Transformer 架構：拋棄遞歸鏈，登上上帝視角

⚡ 革命性架構

Transformer 全面摒棄了 RNN/LSTM 的循序逐步遞推機制，改採自注意力機制 (Self-Attention)。就像站在上帝視角一眼縱覽整篇文章，任何兩個單詞之間的關聯性皆由 Query 與 Key 進行點積直接計算出來（時間複雜度跨度降至 $O(1)$），不僅解決了遠距依賴，更能全面解放現代 GPU 進行巨量並行訓練。

遷移學習 (Transfer Learning) 與微調：站在巨人肩膀上

🛠️ 小資料集實戰解方

面對工業界常見的幾百張罕見瑕疵小資料集，從頭訓練大型深度神經網路必將嚴重過擬合。
凍結機制 (Freezing)：利用在大資料集 (如 ImageNet) 訓練好的模型（如 ResNet/VGG），其底層卷積提取的是通用的幾何特徵，將這些層的權重凍結（梯度反向傳播截斷為 0），只訓練最後替換的分類層；後續若資料足夠再以極小學習率微調 (Fine-tune) 上層卷積層。

F1-Score 為何採用調和平均數？數學原理剖析

📐 數學直覺必考

算術平均數在面對偏科時會產生虛偽安全感（例如 Precision 100%、Recall 0% 時算術平均仍有 50%）。
調和平均數 (Harmonic Mean) 的數學特性：其對極小值具有極度強烈敏感性。一旦 Precision 或 Recall 其中任一者趨近於 0，F1-Score 就會迅速被拉向 0，嚴厲懲罰任何企圖靠犧牲某一方來偷吃步的模型！

$$F_1 = \frac{2}{\frac{1}{\text{Precision}} + \frac{1}{\text{Recall}}} = 2 \cdot \frac{P \cdot R}{P + R}$$

回歸評估指標：決定係數 $R^2$ 與殘差分析 (Residual Analysis)

🚨 考題混淆警示

千萬不可將分類指標用在回歸任務！回歸看的是 $MSE, RMSE, MAE$ 與 $R^2$（決定係數，代表目標總變異被模型解釋的百分比）。
更關鍵的是殘差圖檢查：健康模型的殘差點應在 0 軸上下呈均勻隨機的白雜訊分布；若殘差圖呈現明顯的 U 型拋物線或規律弧線，代表模型存在系統性偏差，未能捕捉高階非線性關聯。

領域偏移 (Domain Shift)：驗證集高分的殘酷現實

⚠️ 部署落地風險

模型在離線驗證集上跑出 98% 絕非大功告成，這僅僅證明模型學會了歷史特定資料分佈。當部署至真實世界，資料往往會發生動態飄移（例如將以維基百科英文訓練的情感模型應用至社群論壇西語俚語）。規劃師必須設計概念漂移監控 (Concept Drift Detection) 與持續學習重訓流程。

特徵標準化：防止大尺度變數「霸凌」幾何距離

✅ 必備前處理

對於依賴幾何空間距離的模型（如 KNN、SVM、K-Means），若輸入特徵 A 的範圍為 0～1,000,000（年收入），特徵 B 為 0～10（工作年資），在歐氏距離公式中，年收入的微小波動便會達到數千，徹底主導了距離計算，使得年資變數毫無話語權。透過標準化 (Z-score: 均值為 0、標準差為 1)，才能拉回同一起跑線。

PCA 主成分分析 vs 特徵選擇：降維本質差異

💡 觀念嚴格釐清

特徵選擇 (Feature Selection)：從現有欄位中直接保留或刪除特定變數（如以決策樹資訊增益篩除無關特徵）；
特徵萃取 (Feature Extraction - PCA)：保留所有原始特徵資訊，透過線性代數的正交旋轉，投影出變異量最大的全新主成分軸線。考題常問：若前兩個主成分特徵值分別為 6 與 3，總變異量為 10，則其解釋力為 $(6+3)/10 = 90\%$。

SMOTE 合成過採樣：為何嚴禁單純複製樣本？

✅ 數據平衡首選

直接將罕見瑕疵照片 Duplicate 複製 100 次，只是讓模型重複背誦那幾個特定點，會誘發極嚴重的決策邊界過擬合。
SMOTE 的智慧機制：找出少數類樣本點周邊的 k 個鄰近同類點，在這些點之間的連線上以內插法隨機合成全新、合理且從未出現過的虛擬樣本，拓展決策空間的泛化韌性。

L1 (Lasso) vs L2 (Ridge) 正則化：幾何形狀決定稀疏性

📐 核心考點對比

在損失函數中加入對權重複雜度的懲罰項 $\lambda$：
L1 (絕對值和)：幾何約束邊界為尖銳的菱形 (Diamond)。損失函數等高線極容易在菱形的頂點（即坐標軸上）相切，導致不重要特徵的權重被精確壓制為 0，產生稀疏矩陣，兼具特徵挑選效果。
L2 (平方和)：幾何約束邊界為平滑的圓形 (Circle)。切點幾乎都在圓弧非零處，因此權重會向 0 縮小衰減，但不會精確等於 0，能平滑抑制過擬合並保留全部特徵。

提早停止 (Early Stopping)：鎖定驗證損失最低點

🛡️ 過擬合熔斷機制

訓練過程中 Training Loss 往往會單調持續下降，但 Validation Loss 在經過特定 Epoch 後會開始向上反彈，這代表模型開始背誦雜訊（過擬合發動）。透過設置耐受輪數 (Patience)，在驗證損失連續數輪未再創新低時主動中斷訓練，並自動回滾儲存歷史泛化能力最佳的權重 Checkpoint。

考前快問快答重點拆解 (DBSCAN / SVM / XGBoost)

🎯 必得分秒殺考點
1. DBSCAN 雜訊點判定：點周遭半徑內點數小於 MinPts，且不在其他核心點勢力範圍內，即標為 Noise Point。
2. KNN / SVM 預處理：因幾何歐氏距離對尺度極端敏感，必做 Standardization。
3. XGBoost 泛化保證：在目標函數中顯式加入正則化項（限制葉節點數與權重平方和），防止單一決策樹無止境分裂。

結語與 AI 倫理反思：當演算法放大社會偏見

⚖️ 規劃師責任與治理

AI 應用規劃師的最高境界不僅是跑出頂尖的 F1-Score，而是具備審視資料本質與社會影響的批判眼光。如果歷史徵才資料存在性別歧視，無論過採樣技術多麼精妙，演算法都只會將偏見合理化並進一步放大。合格的規劃師必須在導入階段實施公平性檢測與倫理護欄，確保 AI 真正帶來正向價值。
