Query、Key、Value 是什麼？AI 如何判斷文字之間的關聯？ #一分鐘學人工智慧 #資訊科技 #AI #人工智慧

在大型語言模型（LLM）與 Transformer 的 Self-Attention（自我注意力機制）中，AI 透過 Query（查詢）、Key（索引） 與 Value（內容） 三個核心角色協作，就像在資料庫中精準搜尋資訊一樣，計算句子裡每個詞彙之間的關聯強度並整合上下文語意。

CORE CONCEPTS · 圖文並茂核心解說

認識 Attention 的三個核心角色與語句整合實例

以日常生活「搜尋資料」的過程來理解 Query、Key、Value 如何分工合作。

Q · Query（查詢）

現在想尋找什麼資訊？

Query（查詢）代表當前正在處理的文字（例如代名詞「它」）想要尋找什麼線索，主動向句子中的其他詞彙提出「我應該參考誰的資訊？」的請求。

K · Key（索引）

判斷資料是否符合查詢需求

Key（索引）就像每筆資料的目錄標籤或關鍵字，用來讓系統比對並判斷每個詞彙的特徵是否符合當前 Query 的查詢需求。

V · Value（內容）

這筆資料真正提供的資訊

Value（內容）是該詞彙實際攜帶的語意內涵。當某個詞的 Key 與 Query 高度匹配時，它的 Value 就會被大量提取並融入最終理解中。

Self-Attention · 實戰整合

「我昨天買了一台新的電腦，它真的很好」

AI 讀到「它」時，透過 Q 與各詞的 K 比對，發現「電腦」獲得最高注意力，因此「電腦」的 Value 對理解「它」產生最大影響！

WORKFLOW & MATH · 運作流程與數學原理

一圖看懂 Attention 運作四步驟與縮放點積公式

點擊下方四格分鏡切換步驟重點，並對照無亂碼的標準數學公式與矩陣維度流動圖。

步驟 ① 輸入分詞與向量投影：AI 先把句子拆解成一個個 Token（詞元），並透過權重矩陣為每個 Token 分別產生 Query（查詢向量）、Key（索引向量）與 Value（內容向量）。
1. 線性投影產生 Q、K、V（Linear Projections） 角色誕生
Q = X · WQ ,   K = X · WK ,   V = X · WV
白話比喻：同一個字戴上三副不同眼鏡（WQ, WK, WV），瞬間分身出「發問身份」、「被搜尋標籤」與「真實內涵」。

輸入詞向量 X 分別乘上三個可學習的權重矩陣，讓模型學會在不同任務下該怎麼發問、怎麼被索引，以及該傳遞什麼資訊。

2. 縮放點積注意力（Scaled Dot-Product Attention） 全句總公式
Attention(Q, K, V) = softmax ( Q · KT √dk ) V
白話比喻：一句公式串起四部曲：「先算兩兩配對分數 → 除以 √dk 降溫穩定 → 轉成百分比聚光燈 → 按比例提取 V」。

這是 Transformer 最核心的矩陣運算公式，能一次性平行計算句子裡所有詞彙之間的注意力關聯並整合上下文。

3. 單一查詢與鍵的縮放相似度分數 方向雷達
score(q, ki) = q · ki √dk
白話比喻：內積 q · ki 就像「方向一致度雷達」，兩個向量越指向同一個語意方向分數越高；除以 √dk 則像把過大音量調回正常範圍。

維度 dk 越大時點積數值容易變極端，除以 √dk 可讓分數維持在穩定區間，避免後續 Softmax 失去辨別細節的能力。

4. Softmax 注意力權重與加權總和 贏家放大器
αi = exp(score(q, ki)) ∑j exp(score(q, kj)) ,   Output = ∑i αi Vi
白話比喻：指數函數 ex 會把高分者的優勢大幅拉開（聚光燈效果），最後再按百分比把各字的 Value 調成一杯專屬「它」的新語意特調。

所有注意力權重 αi 必為正數且總和等於 1（100%），確保加權相加後的輸出向量尺度穩定且語意聚焦。
