藍色模組：監督式學習架構

  • • 特徵空間 (Feature Space)：將每筆輸入轉換為高維空間中的幾何座標點。

綠色模組：分群評估指標精華

內部指標（無真值標籤時使用）

輪廓係數 (Silhouette)：範圍 [-1, 1]。群內越緊密、群間越遠，越接近 1。
Davies-Bouldin 指數 (DBI)：群內離散度 / 群間距離。數值越小越好！

外部指標（後續取得抽樣標籤時使用）

ARI (調整蘭德指數) / AMI：衡量分組結構與真實標籤的一致度。 ⚠️ 陷阱：分群結果編號（Cluster 0, 1）與人工標籤（Label A, B）無對應關係，絕不可直接算 Accuracy！

互動 SVG ④：輪廓係數幾何意涵 a(i) 與 b(i) 即時模擬

點擊點 $i$ 或拖曳切換觀察點，理解群內聚度 $a(i)$ 與最近鄰群分離度 $b(i)$。

$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$
群內平均距離 a(i) 28.4 越小代表群內越凝聚
相鄰群平均距離 b(i) 225.1 越大代表各群越分明
輪廓係數 s(i) +0.87 極佳分群 (+1最佳)

琥珀色模組：強化學習 (Reinforcement Learning) 決策機制

馬可夫決策過程 (MDP)
MDP 核心架構

代理人 (Agent)、環境 (Env)、狀態 (S)、動作 (A)、獎勵 (R)、策略 ($\pi$)、價值函數 (V, Q)。

策略梯度 vs Q-learning

Policy Gradient 直接學習輸出動作機率；Q-learning 學習動作價值矩陣後選極大值。

經驗回放 (Experience Replay)

將歷程存入 Buffer 並打破時序相關性，避免神經網路災難性遺忘。

獎勵塑造 (Reward Shaping)

修正獎勵漏洞，引導代理人以符合人類初衷的正確方式達成目標。

紫色模組：機率推論 (Probabilistic Inference) 與隨機模擬

公式無法解析時的最佳利器
貝氏推論 (Bayesian Inference)

$$P(\theta|X) = \frac{P(X|\theta)P(\theta)}{P(X)}$$ 核心哲學：「根據觀測到的新證據，動態更新先驗信念成為後驗機率」。

馬可夫鏈 (Markov Chain)

無記憶性：未來的狀態只由當前狀態決定，與過去的歷史路徑無關。透過轉移機率矩陣運算。

蒙地卡羅方法 (Monte Carlo)

當維度過高或系統太複雜無公式解析解時，透過數萬次隨機抽樣求得近似解（如 VaR 風險估計）。

iPAS 科目三【四大出題大坑與秒殺祕笈】

❌ 陷阱 1：只有正常品樣本，強行用監督式二元分類

監督分類必須同時具備雙方標籤。工廠僅有正常運轉馬達震動資料時，必須使用非監督/半監督異常偵測 (One-Class SVM / Isolation Forest)！

❌ 陷阱 2：分群演算法驗證直接計算準確率 (Accuracy)

K-means 分出的「第 0 群」不等於人工標籤的「低消費群」，不可做 Confusion Matrix！必須使用調整蘭德指數 (ARI) 或 調整互資訊 (AMI)。

❌ 陷阱 3：強化學習原地打轉刷分，以為是學習率 (LR) 設錯

這屬於獎勵函數規範錯誤 (Reward Hacking)，調整神經網路超參數或學習率完全無效，必須重新執行獎勵塑造 (Reward Shaping)。

❌ 陷阱 4：分不清蒙地卡羅與馬可夫鏈

考題若強調「狀態轉移機率矩陣」選馬可夫鏈；強調「隨機產生數萬筆模擬估計分佈分位數」選蒙地卡羅。

# ==========================================
# 1. 強化學習：經驗回放緩衝區 (Experience Replay Buffer)
# 核心價值：打破時間序列自相關性，防止災難性遺忘
# ==========================================
import random
from collections import deque
import numpy as np

class ReplayBuffer:
    def __init__(self, capacity: int = 10000):
        # 固定容量的雙向佇列
        self.buffer = deque(maxlen=capacity)

    def push(self, state, action, reward, next_state, done):
        # 儲存 (S, A, R, S', Done) 五元組
        self.buffer.append((state, action, reward, next_state, done))

    def sample(self, batch_size: int):
        # 【iPAS關鍵考點】：隨機均勻抽樣，打散時間相關性
        batch = random.sample(self.buffer, batch_size)
        states, actions, rewards, next_states, dones = zip(*batch)
        return (np.array(states), np.array(actions), 
                np.array(rewards, dtype=np.float32), 
                np.array(next_states), np.array(dones, dtype=np.uint8))

# ==========================================
# 2. 獎勵塑造 (Reward Shaping) 範例
# ==========================================
def calculate_shaped_reward(is_picked: bool, placed_in_bin: bool) -> float:
    # 錯誤做法：if is_picked: return 1.0 (導致原地抓放洗分)
    # 正確塑造做法：
    if placed_in_bin:
        return 10.0  # 完整送達才給予主要回饋
    elif is_picked:
        return 0.05  # 僅給予微量引導，不給刷分空間
    return -0.01    # 時間懲罰，避免無意義遊蕩
# ==========================================
# 蒙地卡羅 (Monte Carlo) 95% 風險值 (VaR) 估算
# ==========================================
import numpy as np

def monte_carlo_var_simulation(portfolio_val=1_000_000, days=1, 
                               mu=0.0005, sigma=0.02, simulations=10000, 
                               alpha=0.95):
    """
    使用幾何布朗運動 (GBM) 進行大量隨機情境抽樣
    """
    # 隨機產生常態分佈震撼因子
    epsilon = np.random.normal(0, 1, simulations)
    
    # 計算未來資產價格分佈
    simulated_returns = (mu - 0.5 * sigma**2) * days + sigma * np.sqrt(days) * epsilon
    simulated_values = portfolio_val * np.exp(simulated_returns)
    
    # 計算各情境損益 (PnL)
    pnl = simulated_values - portfolio_val
    
    # 【iPAS關鍵考點】：取第 100*(1 - alpha)% 最壞分位數即為 VaR
    percentile = (1.0 - alpha) * 100
    var_threshold = -np.percentile(pnl, percentile)
    
    return {
        "mean_pnl": np.mean(pnl),
        "var_95": var_threshold,
        "worst_loss": -np.min(pnl)
    }

# 非監督式分群評估：內部指標 vs 外部指標
# ==========================================
from sklearn.metrics import (
    silhouette_score,       # 內部指標 (無標籤，越近1越佳)
    davies_bouldin_score,   # 內部指標 (無標籤，越小越佳)
    adjusted_rand_score,    # 外部指標 (ARI，有標籤驗證，介於-1到1)
    adjusted_mutual_info_score # 外部指標 (AMI)
)

def evaluate_clustering(X, cluster_labels, ground_truth=None):
    # 1. 內部指標：完全無標準答案時
    sil_score = silhouette_score(X, cluster_labels)
    db_index = davies_bouldin_score(X, cluster_labels)
    print(f"內部指標 => 輪廓係數: {sil_score:.3f}, DB Index: {db_index:.3f}")

    # 2. 外部指標：抽樣取得人工標籤時 (嚴禁直接算 Accuracy)
    if ground_truth is not None:
        ari = adjusted_rand_score(ground_truth, cluster_labels)
        ami = adjusted_mutual_info_score(ground_truth, cluster_labels)
        print(f"外部指標 => 調整蘭德指數 (ARI): {ari:.3f}, AMI: {ami:.3f}")

兩大延伸學習型態：半監督與自監督

半監督式學習 (Semi-supervised)

少量有標籤資料 + 大量無標籤資料共同訓練。例如：2,000 篇產品評論中，僅 100 篇有人工標籤。

自監督式學習 (Self-supervised)

直接從資料本身製造題目與答案。例如：文字克漏字遮蔽或預測下一個字，大型語言模型 (LLM) 預訓練的關鍵基礎！

非監督式指標：內部指標 vs 外部指標 (00:05:20)

內部指標（無真值標籤）

• 輪廓係數 (Silhouette)：介於 -1 到 1，越接近 1 越好。
• Davies-Bouldin 指數 (DBI)：群內分散程度比群間距離，越小越好！
• 重建誤差：降維壓縮再還原後的差異。

外部指標（後續取得部分人工標籤）

• 調整蘭德指數 (ARI) 與 調整互資訊 (AMI)：評估分組與真實標籤的一致性。
⚠️ 絕不能直接計算 Accuracy！因為群集編號與標籤無對應名稱。

00:06:19

重點三：強化學習 (RL) 核心機制與馬可夫決策過程 (MDP)

【逐字精要】：RL 核心包含代理人 (Agent)、環境 (Env)、狀態 (S)、動作 (A)、獎勵 (R)、策略 ($\pi$)、價值函數 (V, Q)。馬可夫性質意指：「下一步狀態只與當前狀態和動作有關」。

策略梯度 vs Q-learning (00:07:09)

Policy Gradient 直接學動作機率；Q-learning 學每個動作在該狀態的價值。

經驗回放 (00:07:42)

打破時間序列相關性，隨機抽樣避免神經網路災難性遺忘。

獎勵塑造 (00:08:05)

重新設計獎勵目標，消除漏洞，引導代理人以符合人類初衷的方式達成目標。

00:08:43

開場問題正式解答：機械手臂洗分破解

【逐字精要】：手臂反覆抓放的原因是「獎勵設計出現漏洞」。解決方式是採取獎勵塑造 (Reward Shaping)，將規則修改為「成功將物品放進指定集貨箱」才結算分數，徹底消除代理人鑽漏洞洗分的問題。

00:09:16

重點四：機率推論三大流派（貝氏、蒙地卡羅、馬可夫鏈）

① 貝氏推論 (00:09:16)

看到新證據就更新想法，將先驗機率更新為後驗機率。

② 蒙地卡羅方法 (00:09:24)

當公式太複雜無法求得解析解時，透過數萬次隨機抽樣逼近真實分佈。

③ 馬可夫鏈 (00:09:32)

利用狀態轉移矩陣描述系統動態變化，下一步只取決於當前狀態。

00:10:46

考題實戰 ③：複雜金融資產風險值 (VaR) 估算

【逐字精要】：含衍生性商品的複雜投資組合無法用解析解計算風險值，工程師隨機模擬一萬種市場情境估計損失分佈，答案為蒙地卡羅方法。

00:11:35

考題實戰 ④：電商購買率條件機率推估

【逐字精要】：根據顧客歷史瀏覽記錄與停留時間，計算顧客在特定行為條件下的購買機率，採用的原理為貝氏定理（條件機率推估）。

00:12:45

總結：iPAS 必背解題三句話口訣

1. 判斷學習類型：問資料有沒有標籤？有沒有獎勵懲罰？

2. 代理人刷分漏洞：模型只追求分數最大化，獎勵有漏洞時以「獎勵塑造」修改評分標準。

3. 無解析解求值：公式難以推導時，利用「蒙地卡羅方法」進行大量隨機模擬。
