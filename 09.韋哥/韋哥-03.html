線性變換之死角：為什麼多層網路必須加入非線性激活？

幾何可折疊性驗證
🔹 純線性疊加的坍塌定理
連續線性變換：$y_2 = W_2(W_1 x + b_1) + b_2 = (W_2 W_1) x + (W_2 b_1 + b_2)$。
令 $W_{new} = W_2 W_1$，$b_{new} = W_2 b_1 + b_2$，疊加 100 層依舊退化為單層線性模型！
🌿 解決方案：引進非線性（如 ReLU）
加入 $\text{ReLU}(z) = \max(0, z)$ 後，空間在原點處產生摺痕（Folding），使決策邊界能夠扭曲轉彎，完美劃分異或門（XOR）！
目前為純線性模式：決策邊界只能是一條直線，無法切分對角分佈的資料點。

四大分解與降維技術決策樹（EVD vs SVD vs NMF vs LDA）

歷屆題型對號入座
⚠️ 考題關鍵字秒殺對照
1. 特徵值分解 (EVD)：限制「必須是方陣 (Square Matrix)」且多為對稱協方差矩陣。
2. 奇異值分解 (SVD)：萬用！適用於「任意 $M \times N$ 矩陣」，推薦系統稀疏評分補全首選。
3. 非負矩陣分解 (NMF)：所有元素 $\ge 0$，特點為「純加法疊加（Additive Parts）」、主題模型。
4. 線性判別分析 (LDA)：有監督降維，目標是「最大化類間距離、最小化類內變異」。
奇異值分解 Singular Value Decomposition (SVD)
適用於任意形狀 M × N 矩陣
A = U · Σ · V^T （其中 U 為左奇異向量、Σ 為奇異值對角陣、V 為右奇異向量）

SVD 是線性代數的皇冠寶石！不要求矩陣為方陣，在推薦系統中能將高維稀疏矩陣分解為代表「使用者偏好」與「電影風格」的低秩特徵空間。

重點一：向量三大運算（點積、長度與遮罩相乘）

「在機器學習中，所有資料（文字 Embedding、圖片特徵）都是向量。第一個最核心的運算是『點積（Dot Product）』。把對應維度的數字相乘後通通加起來，最後得到一個單一的純量數字。這個純量直接代表兩個向量在方向上的相似程度！如果在計算前把各自的長度除掉，就是鼎鼎大名的『餘弦相似度（Cosine Similarity）』。」

🔹 幾何本質 點積為 $\vec{u} \cdot \vec{v} = \|\vec{u}\| \|\vec{v}\| \cos\theta$。當兩向量夾角為 0 度時值最大，垂直 90 度時點積為 0（完全獨立不相關）。
🌿 現代 AI 應用 Transformer 注意力機制 $Attention(Q, K, V) = \text{softmax}(\frac{Q K^T}{\sqrt{d_k}}) V$，分子正是 Query 與 Key 的批次點積相似度！

L2 範數與逐元素相乘（Dropout 遮罩）

「第二個運算是向量長度，數學上叫 L2 範數（$\|\vec{w}\|_2$），各元素平方和開根號。模型訓練時的 L2 正則化（Weight Decay）就是懲罰過大的向量長度。而第三個運算是『逐元素相乘（Hadamard Product）』，這跟點積完全不同！它不加總，輸出依然是向量。最常見的工業應用就是 Dropout 隨機關閉神經元，將特徵乘上由 0 與 1 組成的遮罩向量。」

⚠️ 避坑提醒： 點積輸出為「純量數值（Scalar）」；逐元素相乘輸出為「同維度向量（Array）」。在 NumPy 中，`np.dot(a, b)` 是點積，`a * b` 則是逐元素相乘，考題曾多次考語法區別！

NumPy 矩陣運算三大常考函式（114 年 40 題）

「請大家特別注意 114 年第 40 題考的 NumPy 函式對照： 1. np.linalg.inv(A) 求反矩陣，只有當矩陣是方陣且『行列式不為 0』時才存在！ 2. np.linalg.det(A) 計算方陣的行列式。 3. np.linalg.eig(A) 計算方陣的特徵值與特徵向量。若行列式為 0，代表特徵之間存在完全線性相依，呼叫 inv 會引發 LinAlgError！」

重點三：線性變換的幾何本質（四種基本動作）

「矩陣乘以向量，幾何本質就是對空間進行『線性變換』。線性變換只能做四件事： 1. 縮放（Scaling）：把空間拉長或壓短； 2. 旋轉（Rotation）：轉動座標方向； 3. 剪切（Shearing）：傾斜滑移空間； 4. 投影（Projection）：壓扁至低維空間。 無論怎麼變換，原點絕對固定不動，且原本的網格直線變換後依然是平行均勻的直線！」

🔹 核心幾何意義 神經網路的全連接層 $y = Wx + b$ 本質就是：先用 $W$ 對特徵空間進行旋轉與縮放，再用偏差向量 $b$ 平移原點。

為什麼神經網路一定要非線性激活函數？

「這題在歷屆選擇題幾乎必考：『如果把所有層的激活函數都拿掉會怎樣？』答案是：連續進行兩次線性變換 $W_2(W_1 x + b_1) + b_2$，乘開來等於 $(W_2 W_1)x + (W_2 b_1 + b_2)$。矩陣連乘依然只是一個矩陣！所以如果不加非線性激活（如 ReLU），網路疊 100 層跟單層線性回歸毫無區別，永遠學不會異或門（XOR）或任何曲線分界！」

重點四：三大矩陣分解法（EVD, SVD, NMF）

「矩陣分解是中級考科的分水嶺，請牢記三者的適用條件： 1. 特徵值分解（EVD）：限定『必須是方陣』，如協方差矩陣； 2. 奇異值分解（SVD）：萬能神技！適用於『任意形狀 $M \times N$ 矩陣』； 3. 非負矩陣分解（NMF）：所有元素必須 $\ge 0$，特點為可加疊性，適合主題模型與局部零件解析。」

重點五：PCA 主成分分析五大標準流程

「PCA 是無監督降維之王，目標是找出『資料分散程度（變異量 Variance）最大的方向』。完整步驟請大家按順序記熟： 1. 資料中心化（Centering）：每個特徵減去平均值，讓資料中心回到原點； 2. 計算協方差矩陣（Covariance Matrix）； 3. 對協方差矩陣進行特徵值分解（EVD）； 4. 依特徵值由大到小排序，特徵向量就是主成分軸； 5. 將原始資料投影到選定的前 $k$ 個主成分軸上。」

🔹 幾何對應意義 • 特徵向量（Eigenvector） = 空間投影的旋轉方向（主成分軸）
• 特徵值（Eigenvalue $\lambda$） = 資料在該方向上的變異量大小（代表保留了多少資訊）

PCA 影像降噪原理與 scikit-learn 參數致命陷阱

「為什麼 PCA 可以幫影像降噪？因為真實訊號通常是強烈的大特徵值（排在前面的主成分），而隨機雜訊散佈在能量極微弱的尾端小特徵值上！我們把前 $k$ 個主成分保留，把後面的雜訊截斷拋棄，再還原回來，雜訊就被洗掉了！但注意：寫 Python 呼叫 PCA() 時，若括號內不傳任何參數，預設會保留 100% 的所有維度！這樣做降噪完全無效，雜訊會被原封不動還原回來！」

重點六：最小平方法（OLS）幾何投影與離群值破壞

「最小平方法（OLS）是線性回歸的基石。幾何上它是把目標向量 $y$ 垂直投影到特徵所張成的子空間上，推導出的正規方程式為 $\hat{\beta} = (X^T X)^{-1} X^T y$。但 OLS 有一個致命死穴：它追求的是『誤差平方和最小』。因此只要資料裡有一兩個極端『離群值（Outliers）』，誤差平方後會產生天文數字的懲罰，硬生生把整條原本貼合多數資料的回歸線給扯歪！」

⚠️ 考試防坑解法： 題目若問『如何挽救受離群值嚴重破壞的線性回歸？』增加特徵數量、增加網路層數都是錯的！正確答案是：使用 IQR 箱形圖濾除極端值，或改採對離群值不敏感的穩健回歸（Huber Loss、RANSAC）。
