單元 1

L1 (Lasso) vs L2 (Ridge) 正規化完整對比

原始簡報高清還原 · 重點一
目標損失函數 (Objective Loss) Loss = MSE + Penalty
$$\text{Loss} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2 + \lambda \cdot \Omega(w)$$
L1 懲罰項 (Lasso)： $$\Omega_{\text{L1}}(w) = \sum_{j=1}^{p} |w_j|$$

絕對值總和：斜率為常數 $\pm 1$，能將不重要權重完全推向 0。

L2 懲罰項 (Ridge / Weight Decay)： $$\Omega_{\text{L2}}(w) = \sum_{j=1}^{p} w_j^2$$

平方總和：權重愈小梯度愈小，全體係數等比壓縮但絕不歸零。

幾何約束空間互動模擬 (Geometric Contours)

點擊切換約束型態，觀察等高線與約束邊界的最優交點

L1 菱形約束特性：菱形具有尖銳的稜角頂點。等高線向外膨脹時最容易最先碰觸軸上的頂點，因此該維度權重直接變為 0，具備特徵選擇功能。

L1 Lasso (斷捨離)

稀疏化 Sparse
  • 自動特徵篩選：不重要維度直接歸零，降低模型雜訊。
  • 優勢：高解釋性、大幅節省推論特徵工程算力。
  • 劣勢：面對高度共線性群組時隨機挑選 1 個，訓練結果較不穩定。

L2 Ridge (全面打折)

權重衰減 Weight Decay
  • 保留全部特徵：等比縮減係數，但微小至小數點後多位仍不為零。
  • 優勢：完美抵抗多重共線性，保留所有特徵變異解釋力。
  • 劣勢：模型複雜度無法透過特徵剔除減少。
單元 2

進階防治：Elastic Net、Dropout 與早停

原始簡報高清還原 · 重點二
E

Elastic Net 彈性網路

同時混合 L1 與 L2 懲罰項： $$\lambda_1 \sum |w_j| + \lambda_2 \sum w_j^2$$ 兼具 L1 特徵挑選 與 L2 群組穩定性，解決高相關變數隨機抽樣跳動的缺陷。

D

Dropout 隨機丟棄

訓練期間隨機讓神經元以機率 $p$ 失活，打破節點共適應（Co-adaptation）。

⚠️ 考點必防：測試評估時必須關閉 Dropout（PyTorch 務必執行 model.eval()），否則推論具隨機性。
S

Early Stopping 早停機制

持續監測驗證集損失 (Val Loss)，當驗證集指標不再進步甚至反向惡化達預設耐心值 (Patience)，立即終止訓練以防止死記雜訊。

原始簡報高清還原 · 重點三

考題最高頻誘答陷阱解密

正則化的本質是「約束模型自由度」以降低過擬合。題目最常出現的混淆選項是「擴增輸入特徵 (Feature Expansion)」，這會讓特徵空間維度暴增，反而賦予模型更多死背雜訊的空間；而「增加訓練輪數 (Epochs)」只會加劇過擬合；「調整學習率 (Learning Rate)」僅僅控制參數更新的單步距離，並未對權重空間設置邊界，這些通通不屬於正規化。

單元 4

不平衡資料重取樣與評估指標

原始簡報高清還原 · 重點四
策略 1

過採樣 (Oversampling)

SMOTE：相鄰少數類樣本點之間以線性插值生成全新虛擬點，解決簡單複製帶來的過擬合問題。

策略 2

欠採樣 (Undersampling)

縮減多數類樣本規模以達成數量均衡。缺點是可能直接丟失包含決策邊界的多數類關鍵特徵。

策略 3

類別權重 (Class Weights)

不更改原始資料分佈，直接在 Loss function 中對少數類的誤判賦予 5~10 倍的懲罰加權。

策略 4

異常偵測 (Anomaly)

使用 One-Class SVM 或 Isolation Forest，只建立多數正常樣本邊界，適合極端比例。

🚨 評估指標禁忌：嚴禁使用「準確率 (Accuracy)」！

當正負樣本比例為 99:1 時，模型只要完全無腦猜負類即可獲得高達 99% 的表面準確率，但真正需要被捕捉的 1% 正類將全數漏抓。評估必須改採 Recall（召回率 / 敏感度）、F1-Score 或 PR-AUC。

00:51 重點一：L1 與 L2 正規化核心機制比較
▼

【影音逐字口述】「正規化的根本機制，就是在原本的損失函數（例如均方誤差 MSE）後方加上一個懲罰項：$\text{Loss} = \text{預測誤差} + \lambda \times \text{懲罰項}$。利用超參數 $\lambda$ 去限制模型權重的大小，避免模型去硬背訓練集裡的雜訊。」

「其中 L1 正則化（Lasso）懲罰的是權重的絕對值總和（$\sum |w|$），就像『斷捨離』，會將非關鍵特徵的權重直接壓縮為 0，具備自動特徵選擇與稀疏化效果；而 L2 正則化（Ridge）懲罰的是權重的平方和（$\sum w^2$），就像『全體打折』，會將所有權重等比例縮小，但通常不歸零，能保留所有的特徵解釋力。」

🎯 本段核心考點：L1 懲罰絕對值（產生稀疏解/特徵選擇）；L2 懲罰平方和（等比縮小不歸零）。
02:06 數學原理探究：為什麼 L1 會歸零而 L2 不會？
▼

【影音逐字口述】「許多同學在考題中常會死記這個結論，但我們用梯度下降的導函數來看就很直覺。L2 是平方項 $w^2$，它的導函數是 $2w$。這意味著當權重已經很小（比如 $0.001$）的時候，懲罰帶來的梯度更新量微乎其微，它會停留在一個無限接近 0 但始終大於 0 的極小值，因此不會歸零。」

「但 L1 是絕對值 $|w|$，它的導數在正數區間恆為 $+1$、在負數區間恆為 $-1$。無論權重縮得再小，它向 0 靠攏時所受到的減法懲罰都是固定等額的，因此每一步都會強力把權重推進並鎖定在 0 點。」

02:40 面對高度共線性（Multicollinearity）的表現差異
▼

【影音逐字口述】「考題常出情境：當資料中存在高度共線性（例如月收入與年收入這兩根特徵相關係數高達 0.99）。此時若採用 L1，Lasso 會在兩者之中隨機保留一個，並將另一個直接壓到 0。當換一批資料或重新隨機分割訓練時，保留的特徵清單常會跳動，造成模型解釋上的不穩定。」

「相反地，L2 Ridge 面對這類高度共線性特徵時，會把相關的權重一起等比例壓縮保留下來，維持權重分配的平穩性。」

03:06 超參數 $\lambda$ 與深度學習別名（Weight Decay 權重衰減）
▼

【影音逐字口述】「超參數 $\lambda$（在部分套件中稱為 $\alpha$）控制約束強度。若 $\lambda = 0$，模型就退化成無約束的普通最小平方法；若 $\lambda$ 設得太大，模型權重全被壓成極小甚至為零，會導致嚴重的欠擬合（Underfitting）。實務上必須透過交叉驗證（Cross-Validation）尋找最佳值。」

「此外在深度學習神經網路中，L2 正則化在反向傳播的權重更新式中表現為每次扣除一個與權重成比例的量，因此在 PyTorch/TensorFlow 中直接被稱為 Weight Decay（權重衰減）。看到 Weight Decay 就要立刻聯想到 L2。」

03:59 實務情境考古題解析：電信流失、信貸評分與開場題揭曉
▼

【情境 1】電信客戶流失特徵篩選：「收集了幾百個特徵，管理層要求挑選最重要的 20 個特徵建構簡明模型。題目問要用哪種正規化？看到『篩選重要特徵』、『自動特徵選擇』，答案秒選 L1 (Lasso)。」

【情境 2】信貸審查模型係數漂移：「銀行團隊發現模型每次重新訓練，保留的特徵清單都大幅變動，主管質疑不穩定。問該如何改善？這是因為使用了 L1 面對高度共線性造成的，應改用 L2 (Ridge) 或 Elastic Net。」

【開場題解答】：「回到 150 個特徵且共線性，題目明確說『保留所有 150 個特徵的預測解釋能力、絕不讓任何係數歸零』，因此唯一解答就是 Ridge (L2)！」

05:38 重點二：Elastic Net、Dropout 與 Early Stopping 早停機制
▼

【影音逐字口述】「如果我們既想要 L1 的特徵選擇，又想要 L2 抵抗共線性的群組效應怎麼辦？這就是 Elastic Net（彈性網路）。它把 L1 絕對值和 L2 平方和同時放進損失函數，高度相關的特徵會整批被選中或一起被縮小。」

「在深度學習裡，Dropout 是極具代表性的手法。訓練時隨機讓神經元失活（斷開連結），避免特定節點互相產生過度依賴（共適應 Co-adaptation）。」

「而 Early Stopping（早停） 則是緊盯驗證集誤差（Validation Loss）。只要驗證集誤差開始反彈回升，就立即強制中斷訓練，防止模型繼續死記硬背訓練資料中的雜訊。」

06:17 考題深水區：Dropout 程式實作細節與 Inverted Dropout
▼

【影音逐字口述】「中級科目三偶爾會考出程式底層邏輯題：神經網路在做 Dropout 時，如果保留節點的機率是 $p$（例如 0.8），為了讓推論階段與訓練階段的期望值保持一致，通常會在訓練時將存活節點的輸出除以 $p$（稱為 Inverted Dropout 反向丟棄）。」

「另外要注意各框架的參數定義：在 Keras 裡面 `Dropout(0.2)` 的 0.2 代表的是『丟棄的比例（Drop rate）』，剩下的保留機率是 0.8；但在部分學術公式中 $p$ 定義為保留機率，審題時務必看清題目指涉的是丟棄比率還是保留比率。」

06:53 進階題型：基因分析選 Elastic Net、PyTorch 預測浮動忘記 model.eval()
▼

【情境 1】基因微陣列特徵篩選：「特徵數上萬且同組基因高度協同表達（強共線性），若要挑出病因基因群組，Lasso 會隨機砍掉有效基因，此時最佳解是 Elastic Net。」

【情境 2】測試集預測結果每次都在浮動：「某工程師部署模型後，發現同一張圖片輸入模型兩次，得到的預測機率居然不一致。題目問最可能的原因？答案是：推論評估時忘記關閉 Dropout（PyTorch 忘記呼叫 model.eval()）！」

07:38 重點三：辨別什麼「不屬於」正規化？（考題高頻反向陷阱）
▼

【影音逐字口述】「題目常問：『下列何者不是正規化手段？』掌握一個根本原則：正規化必須是限制模型容量、降低模型複雜度、約束參數自由度的手法。」

「常見的誘答選項包括：『擴增輸入特徵（Feature Expansion）』（這反而增加了擬合自由度與複雜度）、『增加網路層數或神經元寬度』、『增加訓練迭代輪數（Epochs）』、『調大學習率（Learning Rate）』。這些通通都不屬於正規化！」

08:42 重點四：不平衡資料重取樣（SMOTE、欠採樣、類別權重）
▼

【影音逐字口述】「面對正負樣本極度不均衡的資料（例如詐欺交易僅 0.1%），模型容易投機全猜多數類。常見解決策略有四種：」

  • 過採樣（Oversampling）：直接複製少數類容易導致過擬合，因此首選 SMOTE 演算法——在相鄰的少數類樣本點之間做線性插值生成全新虛擬樣本。
  • 欠採樣（Undersampling）：隨機刪除多數類，省運算時間但容易遺失重要多數類邊界。
  • 類別權重（Class Weights）：不改變原始資料，直接在損失函數中將少數類的猜錯代價調高 5 到 10 倍。
  • 單類別異常檢測（One-Class SVM / Isolation Forest）：若極端懸殊到幾萬筆只有幾筆，直接轉換問題定義為異常檢測。
09:54 不平衡資料評估指標禁忌：嚴禁使用 Accuracy（準確率）
▼

【影音逐字口述】「這題在歷屆考古題中出現頻率極高！題目若說資料集正負樣本為 98:2，某工程師訓練出一個準確率 98% 的模型，詢問成效如何？答案一定是『無效、有偏差』。」

「因為模型只要全猜陰性就有 98% 準確率，但少數類的陽性病患完全抓不到。不平衡資料的評估，絕對不能看 Accuracy，必須採用 Recall（召回率 / 敏感度）、Precision、F1-Score 或 PR-AUC。」
