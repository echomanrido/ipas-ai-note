Topic 01

自編碼器（Autoencoder）與異常偵測核心

降維 · 去雜訊 · 異常偵測
核心架構三要素：編碼器 (Encoder) ➔ 瓶頸層 (Bottleneck) ➔ 解碼器 (Decoder)
  • 編碼器（Encoder）：將高維度的原始資料（如 $28 \times 28 = 784$ 維像素）逐層壓縮至低維度。
  • 瓶頸層（Bottleneck / Latent Space）：神經網路中最窄的一層，迫使模型丟棄非核心細節，僅保存核心精華特徵（如 32 維向量）。
  • 解碼器（Decoder）：接收瓶頸層的向量，逐層還原成原始維度，以達成最小化「重建誤差（Reconstruction Error）」。
  • 比喻：猶如將一萬字長文提煉為 200 字重點摘要筆記，再從摘要重新寫出全文。摘要抓得越準，全文還原度越高。

互動沙盒：自編碼器重建與異常偵測模擬

切換樣本種類，觀察瓶頸層萃取與解碼後的重建誤差變化

【模型行為觀察】：模型在訓練時只見過正常晶圓，因此其瓶頸層精華與解碼權重完全適應正常電路特徵。面對正常產品時，重建圖與原圖幾乎無異，重建誤差僅 0.04（遠低於閾值），成功通過檢驗。

重點一 · 自編碼器（Autoencoder）架構、三用途與弱點 必考核心

編碼器 ➔ 瓶頸層（潛在空間）➔ 解碼器 ➔ 重建誤差

🔍 點擊檢視高解析大圖
EP11_02.png
💡 自編碼器四大組件與三大實務用途
  • • 四要素架構：輸入 ➔ 編碼器（Encoder 壓縮） ➔ 瓶頸層（Bottleneck / 潛在空間） ➔ 解碼器（Decoder 還原） ➔ 重建誤差（Reconstruction Error）。
  • • 三大常見用途：
    1. 資料降維：瓶頸層的低維向量就是精華特徵（非線性 PCA）。
    2. 去雜訊（Denoising AE）：輸入雜訊圖片，要求還原成乾淨圖片。
    3. 異常偵測（工廠最愛）：只用「正常品」訓練模型！輸入異常品時還原度極差，重建誤差爆表即為瑕疵。
  • • 致命弱點：不能任意生成「全新多樣」樣本，潛在空間分佈不連續時亂採樣只會產出怪異雜訊。
影片對應時間點：00:44 ~ 02:44

🛠️ 自編碼器三大核心實務用途

  1. 特徵降維：提取瓶頸層低維向量作為下游分類模型的新輸入特徵。
  2. 影像去雜訊（Denoising）：輸入加噪圖片，監督其輸出還原成潔淨無雜訊圖片。
  3. 非監督異常偵測：無須標註任何異常樣本，專注辨別高重建誤差。

⚠️ 為什麼不擅長憑空生成新圖片？

主要弱點在於潛在空間（Latent Space）缺乏規則幾何結構。瓶頸層數字分佈非連續均勻，若隨機抽樣一組向量灌入解碼器，常會還原出無法辨識的模糊破碎圖樣（後續發展之 VAE 變分自編碼器才透過機率分佈約束修復此問題）。

Topic 02

GAN（生成對抗網絡）博弈動態與實務落地

生成器 vs 判別器 · 納許均衡 · 模式崩潰
零和博弈經典比喻：偽鈔製造者 (Generator) vs 查緝警察 (Discriminator)
👤 生成器（Generator，偽鈔犯）：

輸入一串「隨機雜訊向量」，目標是製造出能騙過判別器的逼真合成影像。若被判別器識破，就調整權重改進製程。

👮 判別器（Discriminator，警察）：

輸入包含真實資料與生成假資料，輸出為二元機率（1=真, 0=假），目標是明察秋毫抓出所有贗品。

重點二 · GAN 的兩個角色（偽鈔犯 vs 警察）與博弈平衡 生成模型核心

隨機雜訊輸入 ➔ 生成器 vs 判別器 ➔ 納許均衡 ➔ 模式崩潰

🔍 點擊檢視高解析大圖
EP11_03.png
🎭 雙模型動態博弈與常考四大弱點
  • • 生成器（Generator）：像偽鈔犯，吃進隨機雜訊向量 $z$，千方百計製造出能瞞天過海的逼真假資料。
  • • 判別器（Discriminator）：像警察，同時接收真實照片與假照片，負責判別「真 (1) 或 假 (0)」。
  • • 納許均衡（Nash Equilibrium）：雙方達到勢均力敵，警察準確率降到 50%（相當於隨機猜硬幣），生成器產出極其逼真。
  • • GAN 四大致命弱點（考題最愛）：
    1. 訓練極難穩定：兩者能力不能落差太大，否則梯度消失。
    2. 模式崩潰（Mode Collapse）：生成器偷懶只產少數幾種特定假圖。
    3. 缺少客觀指標：無法用單一數值 Loss 判斷好壞。
    4. 硬體成本高昂：訓練時間長且極耗 GPU 算力。

互動競技場：訓練演進與納許均衡（Nash Equilibrium）

步進模擬兩者互相競爭的收斂過程，或觸發模式崩潰陷阱

💡 博弈進程觀察：初始時生成器無規律吐出雜訊，警察（判別器）輕易以 95% 準確率抓出假貨。點擊「進行一輪對抗訓練」見證生成器如何逐步改進，或點擊「納許均衡」體驗警察也只剩 50% 機率瞎猜的理想終局！
1. 模式崩潰 (Mode Collapse)

偽鈔犯發現印某種特定樣式最容易騙過警察，從此只產出少數幾種單調樣本，完全喪失多樣性。

2. 訓練不穩定

生成器與判別器若實力相差過大（通常是警察太強，梯度消失），對抗系統會直接癱瘓練不起來。

3. 超參數極度敏感

學習率（Learning Rate）、優化器挑選或網路層數深度微調稍有不慎，訓練損失即刻劇烈震盪發散。

4. 品質量化困難 (FID / IS)

生出來的圖無法像監督學習對答案算 Accuracy。實務標準採用 FID（越低越逼真）與 Inception Score 間接評估特徵分佈。

🏭 工業 AOI 落地實務：瑕疵品僅 1% 的極端不平衡應對錦囊
1. GAN 瑕疵增強（Data Augmentation）

用現有少數真實瑕疵照片訓練條件式 GAN，生成多樣態的逼真瑕疵圖加回訓練集。

2. 類別加權（Class Weights）

在損失函數中加大少數瑕疵類別的懲罰權重（例如錯判瑕疵扣分乘上 50 倍）。

3. SMOTE 演算法合成

在特徵空間透過近鄰樣本內插合成少數類樣本，改善分類決策邊界。

📌 觀念深拷：計算圖機制

● 靜態計算圖（Static Graph）： 先編譯定義整張圖結構才塞資料執行。優勢是編譯器可做全域優化提高速度，缺點是除錯與條件分支非常晦澀。

⚔️ 模式崩潰 (Mode Collapse) vs 過擬合 (Overfitting)
● 模式崩潰（Mode Collapse - GAN 特有）：

生成器偷懶，只掌握製造 1~2 種能騙過警察的特定樣式（例如偽鈔犯不管什麼狀況都只印百元鈔），喪失多樣性。

● 過擬合（Overfitting - 一般通用）：

模型對「訓練資料」死記硬背包含雜訊在內的細節，導致在訓練集表現滿分，但在「未見測試集」泛化能力奇差無比。

⚔️ 自編碼器 (AE) vs 生成對抗網絡 (GAN)
● 自編碼器（Autoencoder）：

任務是「複製/重建輸入」。學習原封不動壓縮並還原自身，核心指標是 Reconstruction Loss。適合特徵抽取與異常偵測。

● 生成對抗網絡（GAN）：

任務是「憑空生成全新逼真數據」。輸入為隨機雜訊，不比對任何特定單張原圖像素，而是比對整個資料分佈相似度。

⏱ 00:44 - 02:13

重點一：自編碼器（Autoencoder）架構、三用途與弱點

非監督異常偵測核心
架構提煉：高維資料(784) ➔ 編碼器壓縮 ➔ 瓶頸層(32) 儲存精華特徵 ➔ 解碼器還原。異常資料因無法精準還原，將引發高額重建誤差。

[00:00:44] 重點一：自編碼器（Autoencoder）。

[00:00:46] 它分三個部分：編碼器把高維的輸入壓成低維的向量，最窄的那一層叫瓶頸層（Bottleneck），存的是資料的精華；解碼器再從精華還原回原本的樣子。

[00:00:57] 訓練是讓重建誤差最小，重建誤差就是原圖和還原圖的差距。比喻是把一篇文章濃縮成重點筆記，再從筆記寫回文章，筆記越精準，寫回來越像。

[00:01:10] 例如一張 28 乘 28 的圖有 784 個數字，編碼器把它壓成 32 個數字，解碼器再從這 32 個數字畫回 784 個數字的圖。瓶頸層塞不下全部細節，模型被逼只留下最重要的特徵，所以存的是精華。

[00:01:27] 自編碼器為什麼能做異常偵測？ 它只用正常資料訓練，只學會怎麼還原正常的樣子；遇到異常資料時，還原不好，重建誤差特別大，就能標出來。

自編碼器有三種主要用途：
  1. 降維和特徵學習：取瓶頸層的向量當新特徵。
  2. 去雜訊（Denoising）：輸入加了雜訊的圖，訓練它還原乾淨的圖。
  3. 異常偵測（Anomaly Detection）：重建誤差大的判為異常。

[00:01:53] 它的弱點是：主要用來重建，不擅長憑空生成多樣的新樣本。原因在潛在空間（Latent Space）缺乏結構。

[00:02:01] 潛在空間是瓶頸層那些數字所在的空間，一般自編碼器的這些數字分佈沒有規則，隨便挑一組數字丟進解碼器，常常還原出一團看不懂的東西，所以拿來生新圖不好用。

開場問題答案揭曉與選項剖析

答題邏輯確立

[00:02:14] 回到開場那一題，答案是第二個：用正常照片訓練自編碼器，上線時重建誤差特別大的判為可疑品。

[00:02:23] 這招只需要正常照片，不需要標註，剛好符合手上的資料。

[00:02:28] 監督式分類要先有大量標好正常、瑕疵的照片，這裡瑕疵品很少又沒標註，練不起來。

[00:02:34] GAN 的判別器重點二會細講，先記住它學的是分辨真照片和生成器做的假照片，判斷的是真假，和產品正不正常無關。

⏱ 02:44 - 04:05

重點二：GAN（生成對抗網絡）、納許均衡與四大弱點

零和博弈
博弈天平：生成器(偽鈔犯)與判別器(警察)互不相讓，納許均衡時判別器猜中機率剛好落於 50% 隨機猜測狀態。

[00:02:44] 重點二：GAN（生成對抗網絡）。

[00:02:46] 它有兩個角色：生成器的輸入是隨機雜訊，目標是生成以假亂真的樣本，騙過判別器，像偽鈔犯。隨機雜訊是一串隨機抽出的數字，當生成器的原料，每次抽不同的數字就生出不同的樣本。

[00:03:01] 判別器的輸入是真樣本加假樣本，目標是分辨真假，像警察。兩邊輪流訓練、互相進步，警察越會抓，偽鈔就得印得更像。

[00:03:11] 理想終點是納許均衡（Nash Equilibrium），判別器完全分不出真假。納許均衡是雙方都已經找不到能讓自己更好的改法，誰也不想再改，這時判別器面對任何一張圖猜對的機率都只剩一半（50%）。

GAN 的四大弱點（必考）：
  • 模式崩潰（Mode Collapse）：生成器偷懶只做少數幾種樣本，就像偽鈔犯只會印一種面額。
  • 訓練不穩定：兩邊實力差距太大（如判別器太強）就會直接癱瘓練不起來。
  • 超參數敏感：學習率、架構稍微不對就失敗震盪。
  • 品質難量化：沒有標準答案，常用 FID 與 Inception Score 間接評估特徵分佈距離。

[00:03:58] GAN 的用途有：影像生成、資料增強、風格轉換、超解析度（把模糊變清楚大圖），以及黑白影像上色。

⏱ 04:06 - 04:47

工業實務情境：AOI 瑕疵影像僅 1% 的工程解法

資料不平衡解法

[00:04:06] 來看一個場景：自動光學檢測（AOI）團隊的瑕疵影像只有 1%，模型學不到瑕疵長怎樣，該怎麼辦？先想一下。

[00:04:16] 做法是這樣：瑕疵照片太少，模型看的不夠多種瑕疵就學不會，所以先想辦法多弄一些瑕疵樣本。

[00:04:23] 用 GAN 拿現有的少數瑕疵照片訓練，生成更多擬真的瑕疵影像加進訓練資料，這就是資料增強（Data Augmentation）。

[00:04:30] 再搭配類別權重（Class Weights）或 SMOTE：類別權重是讓模型漏抓少數類時扣比較重，SMOTE 則是合成少數類特徵樣本。

[00:04:39] 要注意：GAN 生成的樣本如果出現模式崩潰都長得很像，等於只多了同一種瑕疵，增強效果將非常有限。

⏱ 04:48 - 07:38

重點三：深度學習框架全解析與三大團隊選型

iPAS 認證必考
九字口訣：TF 好部署、Keras 好上手、PyTorch 好除錯。

[00:04:48] 重點三：深度學習框架。

  • TensorFlow：Google 開發，部署生態完整。
  • Keras：已經整合進 TensorFlow，是高階包裝得很完整，用最少程式碼疊出模型，適合快速原型。
  • PyTorch：Meta 開發，動態計算圖，邊執行邊建圖，寫起來像一般 Python，內建自動微分。
  • JAX：Google 的，語法和 Python 做矩陣計算的 NumPy 幾乎一樣，加上自動微分和 GPU/TPU 加速。JAX 是函數式風格，程式寫成一個給輸入回傳輸出、不偷改外面變數的函數。
  • MXNet：Apache/AWS 主要支持，多語言支援，MXNet 是混合式程式設計，同一份程式可以先用動態方式寫來除錯，再切換成靜態圖跑得更快。
📢 有兩件事考試請照官方學習指引作答：

1. 官方學習指引寫「Keras 已完全整合進 TensorFlow」，考試照這個說法；不過實務上 Keras 3 起也能跑在 JAX、PyTorch 上。
2. MXNet 已經在 2023 年退役，官方學習指引仍然列入，考試照指引作答。

[00:05:54] TF 是 TensorFlow 的簡稱，口訣是：TF 好部署、Keras 好上手、PyTorch 好除錯。

[00:06:01] 計算圖是把模型資料先乘權重、再加偏差、過激活函數，這一連串步驟畫成的流程圖，框架照著這張圖算前向、算梯度。
- 靜態計算圖：先畫好整張流程圖再執行，優化空間大，但除錯難。
- 動態計算圖：邊執行邊建圖，像一般程式一樣可以逐行除錯。TensorFlow 早期是靜態計算圖，TF 2.x 改成即時執行（Eager Execution），寫一行就跑一行，用起來就接近 PyTorch。

[00:06:29] 部署是把練好的模型放到真正要用的地方，例如手機 App、網頁、伺服器： TFLite 跑在手機、TFJS 跑在瀏覽器、TF Serving 把模型架成伺服器讓別的程式呼叫、TFX 管整條從資料到上線的流程。

[00:06:45] 自動微分是框架自動幫你算出每個權重的梯度，PyTorch 這個功能叫 Autograd。PyTorch 的生態裡有 Hugging Face，這是一個集中分享大量預訓練模型的平台，很多模型下載後直接用 PyTorch 跑。

[00:07:04] 三個工程團隊框架選型結論：

1. 研究團隊要逐行除錯 ➔ 選 PyTorch（動態計算圖）。
2. 產品要同時上手機 App 和網頁 ➔ 選 TensorFlow（TFLite + TF.js 生態）。
3. 新手想用最少程式碼疊出第一個模型 ➔ 選 Keras（高階一行加一層）。

⏱ 07:39 - 08:20

總結：最容易搞混的觀念與本集帶走三句話

考前速記

[00:07:39] 最後分辨這集最容易搞混的觀念：

  • 自編碼器：重建輸入，擅長壓縮、去雜訊、異常偵測。
  • GAN：對抗生成，擅長生成逼真的新樣本。
  • TensorFlow：部署生態強。
  • PyTorch：動態圖，研究常用。
  • 模式崩潰 vs 過擬合：模式崩潰是 GAN 生成器偷懶只生成少數幾種樣本；而過擬合是模型死背了訓練資料的雜訊細節。
[00:08:01] 本集帶走三句話：
  1. 自編碼器先壓縮再還原，還原不好的就是異常。
  2. 偽鈔犯與警察互相進步。
  3. TF 好部署，Keras 好上手，PyTorch 好除錯。
