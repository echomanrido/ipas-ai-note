開場思維挑戰題 114年第48題同型

一段程式先把每一欄減掉自己那欄的平均，再除以自己那欄的標準差：

X_train -= np.mean(X_train, axis=0)
X_train /= np.std(X_train, axis=0)

請問以下哪些敘述是正確的？（多選思考）

正確解答：僅 ① 與 ④ 正確！

  • ① 正確： $x - \mu$ 使得轉換後的新平均值變為 0。
  • ② 錯誤： 除以標準差 $\sigma$ 後，新標準差會縮小為 1，並非 0。
  • ③ 錯誤： 壓縮至 $[0, 1]$ 是 Min-Max 正規化；標準化後的值可為負數或大於 1。
  • ④ 正確（官方標竿正解）： 輸入維度尺度一致，避免特定欄位數值巨大讓梯度暴衝或神經元飽和，使反向傳播更穩定。
  • ⑤ 錯誤： 屬於特徵縮放（Feature Scaling），並沒有丟棄任何特徵欄位。

考卷最愛挖的五大高頻陷阱

  • 全資料預處理：標準化或 PCA 在切分前 `fit` 全部資料（偷窺驗證集）。
  • 增強破壞語意：手寫英文字母或數字不能水平翻轉（如 'b' 翻轉成 'd'）。
  • 指標不配任務：多分類問題（如 10 類）直接寫 `scoring='f1'` 必定報錯或失真。
  • 凍結範圍寫錯：遷移學習只想凍結卷積層特徵提取器，卻凍結了全網路。
  • 超參數未指定：`PCA()` 未傳參數，預設保留所有主成分，根本沒達成降維！

經典題型解構：亂數模擬與條件機率估計（114年第41題同型） Monte Carlo Simulation

# 固定種子並擲骰子 10 萬次 (產生 1~6，注意 7 不包含)

np.random.seed(42)

rolls = np.random.randint(1, 7, size=100000)

# 條件 A：點數為偶數；條件 B：點數大於 3

cond_A = (rolls % 2 == 0) # 得到 True/False 陣列

cond_B = (rolls > 3)

# 條件機率 P(A|B)：在 B 發生的條件下，A 也發生的機率

prob = np.sum(cond_A & cond_B) / np.sum(cond_B)

理論解析與公式對照

條件機率公式為： $$P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{N(A \cap B)}{N(B)}$$

  • • 分母放什麼？ 條件是 $B$，所以分母放 $B$ 發生的次數 np.sum(cond_B)。
  • • 分子放什麼？ 兩者同時成立的交集次數 np.sum(cond_A & cond_B)。
  • • 理論值驗算： 骰子大於 3 的點數集合為 $\{4, 5, 6\}$，共 3 種可能；其中為偶數的有 $\{4, 6\}$，共 2 種可能。因此理論機率精確為： $$\frac{2}{3} \approx 0.6667$$

pandas 切片與 scikit-learn 核心五大方法

表格數據切片、學規則與套用規則之區隔

pandas 表格轉純數值陣列與特徵切片

# 讀取 CSV 並轉為純浮點數陣列
df = pd.read_csv('data.csv')
data = df.values.astype(float)
# 切分特徵 X 與目標標籤 y
X = data[:, 0:9] # 列全選；欄取 0~8 (共 9 欄)
y = data[:, 9] # 列全選；欄取索引 9 (第 10 欄)
中括號切片語法拆解：[列, 欄]

單獨一個冒號 : 代表「該維度全部選取」。

Python 切片左閉右開原則：

0:9 包含索引 0、1、2... 直到 8，不包含 9。欄位索引從 0 起算，故 [:, 9] 取的是第 10 個欄位！

scikit-learn 核心五大方法比喻法

.fit()
「量身尺寸」

從資料中學習規則（如平均值、主成分投影矩陣、權重）。

.transform()
「照寸裁布」

套用已學會的規則，對資料進行變換（如標準化、降維投影）。

.fit_transform()
「量完直接裁」

邊學規則邊變換當前資料，僅能在 Training Data 上使用！

.predict()
「給出產出」

讓已訓練完成的 Estimator 對未知資料預測目標類別或數值。

.inverse_transform()
「還原原狀」

將轉換後的降維或標準化數據，逆轉映射回原本維度。

視覺化解構：資料洩漏（Data Leakage）與 Pipeline 防護

切分驗證集前 fit 全資料 vs Pipeline 嚴格折內隔離

洩漏分析：在交叉驗證外對全體資料做 fit

如果在做 cross_val_score 前，就先執行了 lda.fit_transform(X, y)，LDA 便會提前利用了驗證折（Validation Fold）的標籤學到投影權重。這等於考前偷看考卷答案，產生的模型驗證分數嚴重虛高，上線必死！

scoring 評估指標配置規範（高頻考點）

任務類型 可使用的 scoring 名稱 致命錯誤 / 禁止使用 觀念理由
二元分類 (Binary) accuracy, f1, roc_auc 無特殊限制 具有單一明確的正類（Positive Class），`f1` 預設直接計算該類別。
多類別分類 (Multiclass) accuracy, f1_macro, f1_weighted scoring='f1' 超過 2 類（如 10 類手寫字）沒有單一正類，直接寫 `f1` 會因缺乏平均策略而噴錯或無效！
數值回歸 (Regression) neg_mean_squared_error, r2 'mse' 或 'accuracy' scikit-learn 慣例：效能指標越高越好，但 MSE 越小越好，故內建指標冠上負號（Negative）。

PCA 降噪原理解構：保留主要變異 vs 濾除微小雜訊

115 年第 46 題核心盲點：為什麼不設 n_components 雜訊完全沒濾掉？

0.05 (過度平滑) 0.50 (最佳降噪) 1.0 (未降維/雜訊重現)
PCA 降噪三部曲

1. pca.fit(X_noisy) 尋找資料變異量最大的正交主軸。
2. 有效信號（數字結構）集中在前幾個大變異主成分；隨機雜訊分散在尾部微小主成分。
3. 丟棄尾端成分後進行 pca.inverse_transform(X_pca) 還原，雜訊就被截斷清除了！

考古

官方考古試題精選實戰（114～115年真題同型）

考前必刷五大經典程式陷阱題，檢驗觀念盲區

noisy = digits.data + np.random.normal(0, 4, digits.data.shape)
pca = PCA() # <-- 關鍵行！
pca.fit(noisy)
components = pca.transform(noisy)
filtered = pca.inverse_transform(components)

【問題剖析】執行完 filtered 後，發現影像中的雜訊完全沒有消失，原因是？

【考點解析與正解】：
PCA() 在初始化時若沒有指定主成分個數，預設會保留全部 64 個主成分（變異量 100%）。將所有正交基底投影後再做 inverse_transform，相當於原封不動地重建，所有的隨機雜訊也全數被還原！
正確解法： 應明確指定保留部分成分，如 PCA(n_components=0.5)（保留 50% 變異量）或指定主成分數，截斷後端高頻雜訊。
程式碼 A：
cv = StratifiedKFold(n_splits=5)
cross_val_score(knn, X, y, cv=cv, scoring='accuracy')
程式碼 B：
cv = StratifiedKFold(n_splits=5)
cross_val_score(knn, X, y, cv=cv, scoring='f1')
程式碼 C：
cross_val_score(knn, X, y, cv=5, scoring='accuracy')
程式碼 D：
cross_val_score(knn, X, y, cv=5, scoring='f1')
【考點解析與正解】：只有 A 與 C 能正確輸出！
1. 核心陷阱： 手寫數字辨識共有 0 到 9 十個類別（多分類任務）。scoring='f1' 只適用於有明確單一正類的二元分類，若用於多分類會拋出 ValueError。多類別必須寫為 f1_macro 或 f1_weighted，故 B、D 直接排除！
2. CV 設置： 分類問題傳入 cv=5 時，scikit-learn 會自動預設採用分層切分（Stratified K-Fold），與直接建立 StratifiedKFold(5) 行為完全一致，因此 A 與 C 均正確無誤。
line 1: lda = LinearDiscriminantAnalysis(n_components=2)
line 2: X_lda = lda.fit_transform(X, y) # <-- 抓到了！
line 3: knn = KNeighborsClassifier(n_neighbors=3)
line 4: scores = cross_val_score(knn, X_lda, y, cv=5)
【考點解析與正解】：問題在第 2 行（Data Leakage 資料外洩）！
LDA 是監督式降維技術，需要依賴標籤 $y$ 來最大化類間分散度。第 2 行直接對「全部資料 X, y」進行 fit_transform，導致後面第 4 行進行交叉驗證時，每一個驗證折的資料與標籤早就在第 2 行被看光光，分數虛高無效！
正確修改： 必須使用 Pipeline([('lda', lda), ('knn', knn)]) 再放進 cross_val_score，確保每折各自獨立 Fit。
A: KFold(n_splits=5, shuffle=True)
B: StratifiedKFold(n_splits=5, shuffle=True)
C: cv=5 (用於分類器 cross_val_score)
D: RepeatedStratifiedKFold(n_splits=5, n_repeats=2)
【考點解析與正解】：只有 B、C、D 能保持類別比例！
• A 錯誤： KFold 僅是隨機打亂後均分，不會去計算各類別分佈，極易造成某些折特定類別樣本過少。
• B 與 D 正確： 凡名稱帶有 Stratified（分層）者，皆會嚴格依照母體標籤比例切分各折。
• C 正確： 當傳入的 Estimator 為分類器（Classifier）時，直接給整數 cv=5，scikit-learn 底層預設自動調用分層切分！
