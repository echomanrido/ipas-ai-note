【iPAS AI應用規劃師_中級科目三 系列 EP17】ROC 與迴歸指標

帶你看懂 ROC、AUC、macro 與 micro 和迴歸指標。完整圖解、手算公式與逐字稿

🎯 開場思考題：模型跨語言衰退分析
❓ 思考情境

情感模型判斷一段評論是「正面」還是「負面」。在英文資料上 Micro F1 為 0.91，部署到西班牙文資料後掉到 0.58，哪個說法最合理？

1. 模型在西班牙文上過擬合 (Overfitting)
2. 應該改用 Macro F1 評估
3. 語言轉移造成召回率下降
4. 應該改用 MSE 來評估
💡 解析揭曉：答案是 (3) 語言轉移造成召回率下降

• 模型沒在西班牙文上訓練：談不上在西班牙文上過擬合。
• 召回率崩跌：換了語言，模型認不出關鍵情緒特徵，容易偏向看成同一類，造成另一類的情緒被大量漏抓（召回率下降），進而將整體 F1-score 拉低。
• 干擾選項排除：改用 Micro F1 只是換算法，不能解決問題；MSE 是迴歸指標，根本不能用於分類任務！

📑 第十六章：評估指標（後半）架構圖
📈 重點四：ROC 曲線與 AUC 指標

ROC 曲線把門檻（Threshold）從高調到低，畫出每個門檻下的表現。

橫軸：假正率 (FPR / 冤枉好人比例)

分母是全部好人，分子是被冤枉抓錯的人：

FPR = FP FP + TN = 被誤判為壞人的好人 全部好人
縱軸：真正率 (TPR / 抓到壞人比例 / 召回率)

分母是全部壞人，分子是成功抓到的人：

TPR = Recall = TP TP + FN = 成功抓到的壞人 全部壞人
滑動調節門檻 (Threshold)：
門檻: 0.65 FPR: 0.12 TPR: 0.86
📌 AUC 白話意義： 隨機挑一個壞人、一個好人，模型給壞人的分數比給好人高的機率。0.5 表示跟擲銅板盲猜一樣；ROC 的好處在於不綁定特定門檻，能綜觀整體的區分能力。
⚖️ 多類別指標聚合策略：Macro vs. Micro
🟣 Macro Average (宏觀平均)

「每類一樣重要，小類別表現差會被看見」

  • 算法：各類別分開算一次指標再平均。
  • 例：三類 F1 為 0.9、0.9、0.3，Macro F1 = 0.70（小類別拉低平均）。
  • 比喻：各班分開算再平均，小班表現差會被看見。
🟢 Micro Average (微觀平均)

「全部樣本一起算，大類別主導」

  • 算法：所有類別的 TP、FP、FN 各自加總後再算一次。
  • 例：大類別樣本數多、貢獻最多 TP/FP，由大類說了算。
  • 比喻：全校學生打散一起算，大班說了算。
⚠️ iPAS 程式題細節：Scikit-learn cross_validate

多類別分類寫 scoring='f1' 跑不出有效結果！因為 F1 預設只算二元分類（需指定正類），多類別任務務必明確寫出平均方式：scoring='f1_macro' 或 scoring='f1_micro'。（Accuracy 算全體答對率，不用分正負類，所以不受影響）。

📐 重點五：迴歸四大指標總覽
指標名稱 數學公式 (清晰原生排版) 特性與適用情境
MAE
(平均絕對誤差)		 MAE = 1n ∑ |yi - ŷi| 單位與原數據相同，抗離群值（極端值干擾少），最容易向非技術主管直觀說明「平均誤差幾分鐘/元」。
MSE
(均方誤差)		 MSE = 1n ∑ (yi - ŷi)2 單位為原單位的平方。會呈二次方「放大較大誤差」，適合大錯絕對不能發生的情境。
RMSE
(均方根誤差)		 RMSE = √MSE 開根號後回歸原單位，同時保留了放大極端大誤差的懲罰性質。
R²
(判定係數)
R2 = 1 − RSS TSS = 1 − ∑(y − ŷ)2 ∑(y − ȳ)2
代表模型能解釋多少比例的目標變異。
• 1.0：完美預測
• 0.0：等同於盲猜平均值
• <0：比直接盲猜平均值還要差！

誤差為：[-2, +2, -3]。TSS = (-10)2 + 02 + 102 = 200，RSS = 4 + 4 + 9 = 17。

🏢 特殊情境指標
  • 醫療診斷：自訂誤判成本矩陣（如漏診扣 100 分、誤報扣 5 分），選總代價最低者。
  • 推薦/搜尋排序：採用 NDCG，越相關的項目排越前面分數越高（滿分 1）。
  • 商業決策：直接看收益，預測結果換算為賺賠金額進行比較。

ROC 曲線原理

重點四：ROC、AUC、macro 與 micro。
ROC 曲線把門檻從高調到低，畫出每個門檻下的表現。橫軸是假正率，好人被冤枉的比例，假正率是 FP / (FP + TN)，分母是全部好人；縱軸是真正率，壞人被抓到的比例，也就是召回率。
門檻很高時，幾乎誰都不抓，點在左下角；門檻一路調低，抓到的壞人和冤枉的好人都變多，點往右上走，最後到右上角。好模型會先往上衝，壞人抓很多、好人冤枉很少，曲線貼近左上角，下面的面積就大。

00:01:23
AUC 白話意涵

AUC 是曲線下面積，0.5 表示分辨能力和亂猜一樣，越接近 1 越好。
AUC 的白話是：隨機挑一個壞人、一個好人，模型給壞人的分數比給好人高的機率。0.5 就是對半，跟丟銅板一樣，所以分辨能力等於亂猜。ROC 的用途是不綁特定門檻，看整體的區分能力。

00:01:43
Macro vs Micro

多類別時指標要怎麼平均？
Macro 是每個類別各算一次 F1 再平均，每類一樣重要，小類別表現差會被看見。例如三類的 F1 分別是 0.9、0.9、0.3，Macro F1 是三個加起來除以 3 等於 0.7；第三類很差，平均就被明顯拉下來。
Micro 是全部樣本一起算，大類別主導。做法是先把所有類別的 TP、FP、FN 各自加總，再用加總後的數字算一次。樣本多的類別貢獻的 TP、FP 多，所以大類別說了算。
學校版的比喻是：各班分開算再平均是 Macro，小班表現差會被看見；全校學生一起算是在 Micro，大班說了算。

00:02:26
考試考點：Scikit-learn

考過一題程式細節：Scikit-learn 是程式題常用的套件，做交叉驗證時用 scoring 指定哪個指標打分。多類別分類用 scoring='f1' 跑不出有效結果，因為 F1 預設只算二元分類，要指定哪一類是正類；多類別沒有唯一的正類，要寫 f1_macro 這類指定平均方式的寫法。Accuracy 是準確率，只數對比，不用分正負類，所以沒問題。

00:02:53
解答開場題

回到開場那一題：模型沒在西班牙文上訓練，談不上在西班牙文上過擬合；換了語言，模型認不出關鍵情緒，容易偏向看成同一類，另一類的情緒大量被漏掉，召回率就下降。召回率下降會把 F1 拉低，所以答案是第三個「語言轉移造成召回率下降」。改 micro F1 只是換個算法，不會解決問題；MSE 是迴歸指標，不能用在分類。

00:03:20
迴歸指標概述

重點五：迴歸指標。
MSE 是誤差平方的平均，會放大誤差，用在大錯特別不能接受的時候。
RMSE 是 MSE 開根號，單位和目標相同、好解讀，適合報告給人看。
MAE 是誤差絕對值的平均，比較不怕極端值，適合有離群值的資料。
R平方看模型解釋了幾成變異。
MSE 為什麼放大誤差？誤差 10 平方後變 100，誤差 2 平方後只有 4，大誤差在 MSE 裡被放大好幾倍。MAE 只取絕對值，誤差 10 就算 10，一個離群值不會把分數拉爆。

00:03:58
R平方算法

R 平方的算法要用到兩個數：RSS 是模型預測的誤差平方和，TSS 是直接猜平均的誤差平方和。R² = 1 - (RSS / TSS)。
RSS / TSS 是模型還剩多少錯佔猜平均會錯的比例，1 減掉它就是模型解釋掉的比例。
R² = 0.85 的意思是 85% 的變異可以被模型解釋，不能說成準確率 85%。R² 通常在 0 到 1，最高 1；等於 0 表示跟猜平均一樣；小於 0 表示比猜平均還差。

00:04:34
手算推導演練

來算一次：實際值 10、20、30，預測值 12、18、33。誤差是 -2、+2、-3。
• MAE 是 2、2、3 加起來除以 3，大約 2.33。
• MSE 是 4、4、9 加起來除以 3，大約 5.67。
• RMSE 是 5.67 開根號，大約 2.38。
• R 平方要先算 TSS：實際值平均是 20，直接猜 20 的誤差是 -10、0、+10，平方和是 100 + 0 + 100 = 200。模型的 RSS 是 4 + 4 + 9 = 17。R² = 1 - (17 / 200) ≈ 0.915。

00:05:13
會考分數比喻

學校版的比喻是預測會考分數：MSE 的單位是分的平方，開根號成 RMSE 才回到「分」這個單位。RMSE 等於 8 分不等於平均差 8 分，它會放大差很多的那幾個人；要說平均差幾分，用 MAE。R² = 0.85 是成績差異有 85% 被模型解釋。

00:05:37
114年考題剖析

114 年那回的第 38 題：給一段程式要你認出是 MSE。講義整理了三種長相：誤差的平方加總再除以筆數是 MSE；上面再開根號是 RMSE；誤差取絕對值再平均是 MAE。

00:05:54
業務導向指標

講義另外列了業務導向的指標：
• 醫療用自訂的誤判成本矩陣／漏診成本矩陣，是替每一種錯訂一個代價。例如漏診一次扣 100 分，誤報一次扣 5 分，再看哪個模型總代價最低。
• 推薦搜尋排序用 NDCG，這是給排序結果打分的指標，越相關的項目排得越前面分數越高，滿分 1。
• 商業決策用收益，直接把預測結果換算成賺多少錢、賠多少錢來比較模型。

00:06:24
外送平台送達時間

來看一個場景：外送平台預測送達時間，主管問了三個問題：平均差幾分鐘？遲到很久的情況多不多？模型到底有沒有比亂猜好？這三個問題各看哪個指標？先想一下。
平均差幾分鐘看 MAE（單位是分鐘；RMSE 單位也是分鐘，但會放大差很多的那幾筆，不能直接說成平均差幾分鐘）；遲到很久的情況多不多看 RMSE 或 MSE（大誤差會被放大）；有沒有比猜平均好看 R 平方（大於 0 才比猜平均好）。

00:07:01
易混淆大對照

最後分辨這集最容易搞混的：
• MSE 的單位是平方，RMSE 開根號回到原單位。
• Macro 是每類平均，Micro 是全部樣本一起。
• R² 是解釋變異的比例，準確率是分類猜對的比例。
• ROC 曲線橫軸假正率、縱軸真正率；PR 曲線橫軸召回率、縱軸精確率，在不平衡資料更敏感。

00:07:25
核心結語

這集帶走兩句話：ROC 和 AUC 看整體區分能力，Macro 看每一類；迴歸指標看誤差平方、絕對值、解釋比例。下一集進入第 17 章：超參數與優化器調整。
