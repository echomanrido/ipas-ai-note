Key Takeaways · Mechanism Overview · Industrial Applications

重點精華 · 實務落地
重點整理 (Key Takeaways)
  • 多觀點思想碰撞：從統計物理學的自由能最小化、資訊幾何學的流形貼合，到認知科學的預測編碼（Predictive Coding）理論，全方位解構 AI 的預測機制。
  • 幻覺 (Hallucination) 的本質溯源：語言模型的預測目標是「統計上最可能出現的下一個詞」，而非「物理世界中客觀存在的真理」，機率預測必然伴隨統計幻覺風險。
  • 模型校準度 (Model Calibration)：一個良好的預測模型不僅要準確，預測置信度更應真實反映正確機率（例如預測 80% 置信度的樣本，真實命中率應為 80%）。
  • 檢索增強生成 (RAG) 對抗預測盲區：將參數化隱性記憶（Parametric Memory）與外接向量知識庫非參數記憶（Non-parametric Memory）結合，確保關鍵預測有據可查。
核心機制與原理說明

本筆記剖析現代 AI 系統如何進行不確定性預測。模型推論輸出的是一個機率向量 $\mathbf{p} = \operatorname{softmax}(\mathbf{z} / T)$。當遇到訓練分佈外（OOD）的全新邊界案例時，純神經網路往往輸出過度自信（Overconfident）的錯誤機率。為解決此問題，現代工程架構引入蒙地卡羅 Dropout（MC-Dropout）或深度集成（Deep Ensembles），透過多次隨機推論的方差量化「認識不確定性 (Epistemic Uncertainty)」，當不確定性超過警戒閾值時，主動放棄自動裁決並移交人工專家審查。

應用在何處 (產業與落地實務)
  • 金融證券非結構化財報分析：以 RAG 結合語言模型預測企業獲利能力與破產違約概率，並強制輸出引用條文來源防止模型編造數據。
  • 自主移動機器人 (AMR) 碰撞風險評估：根據光達掃描點雲的預測不確定性動態調速，在視線死角或高不確定性走廊主動減速鳴笛。
  • 智慧專利侵害檢索與分析：比對數百萬專利請求項與待上市產品規格，預測專利訴訟侵權機率並標記高風險權利要求。

Paradigm Shift

傳統寫程式 vs. 機器學習：思維大翻轉

如果叫你寫程式判斷一張照片有沒有貓？你會怎麼做？

傳統程式設計 (Rule-Based) 人類手寫規則

手刻所有規則：世界太複雜了！

「如果有兩個尖尖的耳朵就是貓，有鬍鬚是貓，毛茸茸的是貓...」
但折耳貓呢？正面看無耳朵呢？逆光看不清毛呢？你永遠寫不完世上所有的 IF-ELSE。

[資料 Data] + [規則 Rules] ➔ [答案 Answer]
if (ears == 2 && whiskers && is_furry) {
  return "Cat"; // 遇到沒想到的邊界條件立刻翻車
}
缺點：規則窮舉不盡，對現實的高維多變世界完全無力。
機器學習 (Machine Learning) 讓機器逆推規律

整件事情反過來：尋找函數 $Y = f(X)$

你丟給他幾萬張照片（資料 $X$），再給他標記這是貓還是狗（答案 $Y$）。
不教它怎麼看，而是讓模型自己調校內部參數，自動找出那套神秘映射函數 $f$。

[資料 Data (X)] + [答案 Answer (Y)] ➔ [自適應規則 f(X)]
# 核心本質：
Y = f(X, θ)
# 透過最佳化演算法自動逼近真實規律
本質核心：所有機器學習，說到底就是在找那個神奇函數！
Knobs & Parameters

模型就是一台「混音器」

模型上的每一個旋鈕叫做「參數 (Parameters)」。小模型可能只有 2 個旋鈕，GPT 則有上千億個！
機器學習就是在不斷旋轉這些旋鈕，直到預測值與正確答案完全契合。

Three Big Paradigms

依照手上資料，分為「三大門派」

機器學習都在調旋鈕，但該往哪裡調？取決於你手上擁有什麼形式的資料。

1
Supervised Learning

監督式學習

就像「附詳解的考古題」。每一道題都有標準答案（標籤 Label）。模型做一題、對一下答案，錯了就調一下旋鈕。

A. 分類 (Classification)
答案是類別：是貓還是狗？是不是垃圾郵件？自駕車框框內是不是行人？
B. 回歸 (Regression)
答案是連續數字：這間房子賣多少？明天氣溫幾度？行人離自駕車還有幾公尺？
業界最普及但最痛：標籤得靠人工作業，人工標註極度昂貴！
2
Unsupervised Learning

非監督式學習

想像媽媽把一整堆衣服倒在床上叫你整理，卻沒說怎麼分。
你會自己把褲子放一堆、T恤放一堆、襪子放一堆。沒有人給標籤，單純發現「它們長得很像」。

核心任務：分群 (Clustering)
只給資料、不給答案。讓模型自主挖掘幾何拓撲結構與群聚模式。
現實案例：自駕車光達 (LiDAR)
每秒打出幾十萬無標籤的點，演算法透過分群把相近點圈成團，辨識出獨立物體。
優勢：免人工標記；但難在評估群聚好壞缺乏客觀標準。
3
Reinforcement Learning

強化學習

不是看歷史資料學，而是「做了才知道」！
就像訓練小狗握手：你不會拿握手書給牠看，而是等牠亂動抬起手時立刻給零食（獎勵），多次後牠就摸索出行為與回饋的關聯。

機制：環境反饋機制 (Agent & Env)
模型在環境中探索動作，做對加分（Reward）、做錯扣分（Penalty）。
著名代表：AlphaGo 與賽車
圍棋大局博弈、機器人學走路、自駕賽車摸索最佳過彎切線。
致命傷：極度需要試錯！現實中不能撞車百萬次，需仰賴高精度模擬器。
Core Optimization

最硬核但也最精華：損失函數與濃霧下山

既然學習就是轉旋鈕，你怎麼知道現在轉得好不好？
第一步是「衡量自己有多爛」(Loss Function)；第二步是用「坡度」(Gradient) 指引你下山。

STEP 01 • 衡量模型多爛的尺規

損失函數 (Loss Function, $L$) 與均方誤差 (MSE)

例如模型猜房價 800 萬，但實際上是 1000 萬，差了 200 萬。為什麼誤差要平方之後再取平均？

  • 消除正負抵消：猜高跟猜低都是犯錯，平方後全變正數。
  • 大幅放大巨大錯誤：差 10 萬平方是 100，差 100 萬平方是 10000！模型會特別害怕犯大錯。
$MSE = \frac{1}{N}\sum (y_{pred} - y_{true})^2$  ➔  目標：讓 Loss 降到最小！
STEP 02 • 身處濃霧怎麼下山？

梯度下降 (Gradient Descent)

山頂起濃霧完全看不到山谷時：用腳感受腳下的坡度 (梯度 Gradient, 即微分)，朝著下坡方向跨出一步。

• 山的高度 = 目前的 Loss

• 你的位置 = 目前的旋鈕參數 $\theta$

• 腳下坡度 = 偏微分 $\nabla L$（微分一次，一次告訴所有旋鈕該往哪轉、轉多少！）

$\theta_{new} = \theta_{old} - \eta \cdot \nabla L$ （減號代表朝上坡的反方向走）

濃霧下山互動實驗室 Canvas 物理模擬

調整學習率 $\eta$ (Learning Rate)，觀察球體如何在損失山谷中下滑、震盪或卡在局部最小值！

Generalization

Loss 降到 0 就完美了？大錯特錯！

想像一個班上有三個學生在準備期末考。真實世界的資料充滿雜訊，機器學習真正的目標，是在沒看過的資料上也預測正確。

😴 Underfitting

學生 A：欠擬合 (Underfitting)

完全沒讀書，連考古題都寫不好，期末考自然直接爆掉。

考古題 (Train)：40 分 (爛)
期末考 (Test)：35 分 (爛)

本質原因：模型太簡單了（例如用一條死板的直線硬套波浪資料），旋鈕太少，連訓練資料的規律都學不會。

解決方案：增加模型複雜度、增加特徵。
🤓 Overfitting

學生 B：過擬合 (Overfitting)

把考古題全死背下來！第三題選C、第七題42。換個數字直接零分。

考古題 (Train)：100 分 (滿分)
期末考 (Test)：20 分 (慘死)

本質原因：旋鈕太多太靈活，模型把訓練集裡的雜訊、標錯、巧合全當成規律死記！貫穿了每個點，但完全失去預測能力。

解決方案：正規化 (Regularization)、簡化旋鈕、Dropout。
🎓 Generalization

學生 C：泛化能力 (理想目標)

徹底理解題目的底層觀念，抓住大趨勢而非死記個案特徵。

考古題 (Train)：90 分 (優秀)
期末考 (Test)：88 分 (穩健)

這才是真正的 AI：能夠過濾掉真實世界感測器、標註員帶來的雜訊，在未知的新資料上依然維持高準確度。

黃金法則：永遠以測試集/未見資料的表現為準！

Dataset Splitting & Pitfalls

資料切分的三份原則與兩大暗礁

你不能拿學生複習過的考古題當期末考，否則你永遠不知道他在裝懂還是真懂！

PART 01 (約 60% ~ 70%)
訓練集 (Training Set)
【考前考古題】

專門用來轉動旋鈕（更新參數）的資料。模型對答案、算梯度、調權重全都發生在這裡。

PART 02 (約 15% ~ 20%)
驗證集 (Validation Set)
【學校模擬考】

用來決定超參數（例如：學習率該設多大？模型該用幾層神經網路？）。檢測模型有沒有在死記考古題。

🔒
PART 03 (約 15% ~ 20%)
測試集 (Test Set)
【鎖在保險箱的期末考】

整批專案研發的最最後一刻才能打開一次！純粹衡量模型在完全陌生世界中的真實實力。

新人常犯致命傷 01

資料洩漏 (Data Leakage)

期末考的題目，不小心混進了考古題裡！

真實慘案：
自駕車辨識影片切資料時，同一個行人的連續畫面：前一秒切在訓練集，後一秒切在測試集。 模型在實驗室評測拿到 99.9% 的夢幻分數，但車子一開上真實馬路立刻撞車翻覆！
更具深度的產業盲點 02

分佈偏移 (Distribution Shift)

就算切得很乾淨、測試集 100 分，上線還是可能翻車！

真實慘案：
自駕車所有訓練與測試資料都在陽光明媚的「亞利桑那州 (Arizona)」收集；結果車子運到「下暴雪的匹茲堡 (Pittsburgh)」立刻失靈！因為模型世界觀中從未見過雪花。真實世界永遠比資料集更廣大。
