[01:02] 我們先做一個小實驗：假設我叫你寫一個程式，判斷這張照片裡面有沒有貓，你可能會這樣寫：如果「有兩個尖尖的耳朵」就會是貓、「有鬍鬚」是貓、「毛茸茸的」是貓……

2. 核心本質：找函數 $f(X) = Y$ 與「混音器旋鈕」比喻

The Core Essence of ML
f(X) = Y

X (輸入)：照片、坪數、感測點雲
Y (目標)：是否為貓、房價、障礙距離

θ₁ (w)
θ₂ (w)
θ₀ (b)
混音器旋鈕 = 模型參數
小模型：2~10 個旋鈕
大語言模型：上千億個參數

[01:38] 那規則到底長什麼樣子？這就是這一集最重要的一句話，請你記下來：「所有的機器學習說到底都是在找那個函數 $f(X) = Y$」。

[01:46] $X$ 是輸入：可能是一張照片、一間房子的坪數、一台車的感測器資料；那 $Y$ 是你想要的答案：是不是貓、房價、前面有沒有行人。

[02:00] 那機器要怎麼樣去找這個函數？你可以想像一台混音器，模型就是這一台混音器，上面每一個旋鈕叫做「參數」。

[02:08] 一開始旋鈕亂轉，輸出當然會亂七八糟的。學習這件事情就是不斷地調旋鈕，直到輸出跟正確答案越來越接近。小模型可能只有兩個旋鈕，GPT 這類大型的語言模型則會有上千億個，但不管大小，本質都是一樣的小旋鈕。

[02:29] 而後面的 33 集演算法差別就在於：混音器是長什麼樣子，以及用什麼方法去調旋鈕。

02:37 - 05:33

3. 機器學習三大門派：監督式、非監督式、強化學習

📝
門派 1

監督式學習

比喻：附詳解的考古題，有標準標籤 (Label)。

分流：
• 分類 (貓/狗、垃圾信)
• 迴歸 (預測房價、車距公尺)

⚠️ 缺點：標籤要大量人工人工手動標註
🧺
門派 2

非監督式學習

比喻：倒一堆衣服在床上整理，褲子一堆、襪子一堆。

應用：
• 分群 (Clustering)
• 自駕車光達 (LiDAR) 點雲聚類

✨ 優勢：無需標籤，自發發現內在結構
🐕
門派 3

強化學習

比喻：教小狗握手給零食；做對獎勵、做錯扣分。

應用：
• AlphaGo 圍棋對弈
• 賽車過彎自學、機器人走動

⚠️ 缺點：試錯數百萬次，需仰賴模擬器

[02:37] 好，機器學習是在調旋鈕，但怎麼知道要往哪一個方向調？取決於你手上有什麼資料。依照資料的不同，機器學習分為三大門派：

門派一：監督式學習（Supervised Learning）

[02:49] 門派一就是監督式學習（Supervised Learning）。監督式學習就像是附詳解的考古題，每一題都有它的標準答案，我們叫它標籤（Label）。模型寫一題、對一下答案，錯了就調一下旋鈕。

[03:04] 它又分成兩種類型：

  • 分類（Classification）：它的答案是類別，是貓還是狗？是不是垃圾郵件？
  • 迴歸（Regression）：它的答案是一個數字，這間房子賣多少？明天的氣溫幾度？

[03:20] 拿自駕車來說：「這個框框裡面是不是行人？」是分類；「那這個行人離我幾公尺？」就是迴歸。

[03:27] 這是業界用的最多的一個門派，因為效果最好。但它有一個很痛的缺點：標準答案要有人一個一個標。自駕車公司每年花了大量的錢，請人坐在電腦前面一張一張塗行人。對，AI 背後其實是有很多人工的。

門派二：非監督式學習（Unsupervised Learning）

[03:47] 那門派二就是非監督式學習（Unsupervised Learning）。如果沒有標準答案呢？想像你媽把一整堆衣服倒在你的床上叫你整理一下，但沒說怎麼分。你自己會把褲子放一堆、T-shirt 放一堆、然後襪子放一堆。沒人告訴你這個叫做褲子，你只是發現它們長得很像。

[04:07] 那這個就是非監督式學習：只給資料、不給答案，然後讓模型自己找出資料裡面的結構。最常見的是分群，也就是把相似的東西放在一起。自駕車的光達（LiDAR）每秒會打出幾十萬個點，這些點本身是沒有標籤的，但你可以用分群把靠近的點圈成一團一團，每一團大概就是一個物體。這個我們後面集數會實際做。

門派三：強化學習（Reinforcement Learning）

[04:37] 門派三：強化學習（Reinforcement Learning）。第三個門派最有趣，它不是看資料學，而是「做了才知道」。

[04:47] 你怎麼訓練狗握手？你不會拿一本握手教學給牠看，你是等牠亂動，剛好抬手的時候給牠一塊零食。那抬了很多次之後，牠就懂了「抬手就等於有吃的」。強化學習就是這樣子：模型在一個環境裡面做動作，做對了有獎勵、做錯了被扣分，然後自己摸索出什麼情況該做什麼。

[05:12] AlphaGo 下圍棋、機器人學走路、或者讓一台賽車自己學怎麼樣過彎最快，都是這個門派。但缺點就是它非常需要試！狗可能試了 50 次就學會了，模型常常要試幾百萬次。你也不能真的讓一台車去撞幾百萬次，所以通常要先在模擬器裡面練。

05:33 - 06:45

4. 第一步：損失函數（Loss Function）——定義模型有多爛

// 均方誤差 (Mean Squared Error)
MSE = 1/n ∑ (y_true - y_pred)²
差距平方取平均：房價預測 800 萬 vs 真實 1000 萬 ➔ 差 200 萬平方
① 避免正負抵消

猜高與猜低都是犯錯，平方皆轉為正數。

② 重罰巨大失誤

差 10 變 100；差 100 變 10,000，重罰大錯！

[05:33] 好，接下來是這一集最硬、但也最重要的部分！懂了這段，後面一半以上的演算法你都會覺得「啊，又是這個」。

[05:40] 那剛剛說學習就是調旋鈕，問題來了：你怎麼知道現在調得好不好？

[05:48] 第一步就是先定義「錯誤」。你需要一個分數來衡量這個模型到底有多爛，這個分數叫做 Loss 損失函數。

[05:58] 比如說模型猜房價是 800 萬，但實際上是 1000 萬，差了 200 萬。那把每一間房子的誤差都算出來，平方之後取平均——這是一個很常見的 Loss 叫做「均方誤差」（MSE, Mean Squared Error）。

[06:13] 那為什麼要平方？兩個原因：

  1. 猜高跟猜低都算錯：平方之後都變正數，就不會互相抵消。
  2. 平方會放大錯誤：差 10 萬只算 100，差 100 萬就是 1 萬，所以模型會特別怕犯大錯。

[06:36] 重點是：Loss 越低，模型越好。所以學習這件事情就變成一個數學題：找一組旋鈕設定，讓 Loss 最小！

06:45 - 09:21

5. 第二步：梯度下降（Gradient Descent）與學習率

梯度下降直覺圖解：濃霧下山法
⚠️ 學習率 η 太小：

如步履蹣跚一公分一公分移，天亮都還在山腰，極其耗費算力。

💥 學習率 η 太大：

一步跨越山谷左右亂跳，甚至震盪暴增，Loss 直接發散爆炸。

🎯 剛剛好 (Optimal η)：

穩定下坡收斂至谷底，找到最佳旋鈕參數組。

[06:45] 第二步：怎麼找到 Loss 最小的地方？最笨的方法就是一個一個試，把所有的旋鈕組合都試過一遍。如果只有兩個旋鈕，每一個試 100 個位置，就是 1 萬種組合，還行；但如果有 100 萬個旋鈕呢？組合數會是一個後面有 200 萬個零的數字，宇宙毀滅了你都還沒試完！

[07:08] 所以我們需要一個更聰明的方法，叫做梯度下降（Gradient Descent）。

[07:13] 想一下你在微風起濃霧的山上，完全看不到山腳在哪裡，你的目標是走到最低點，你會怎麼做？你會用腳感覺一下腳下的坡度，哪一個方向是往下的你就往那邊走一步，然後再感覺一次、再走一步，這樣一直重複，直到周圍都不再往下為止。

[07:37] 對應回來：山的高度就是 Loss，你的位置就是目前旋鈕的設定，腳下的坡度就是梯度（Gradient），也就是微積分裡面的微分。

[07:47] 梯度最厲害的地方是：就算你有 100 萬個旋鈕，微分一次就能告訴你每一個旋鈕該往哪邊轉、轉多少，不用一個一個試！這就是為什麼現代 AI 可以訓練這麼大的模型。這個公式看起來很嚇人，但它就是剛剛那句話：新位置等於舊位置減掉步伐的大小乘以坡度。減號是因為坡度指向上坡，而我們要往反方向（下坡）走。

[08:18] 第三步就是步伐要多大：公式裡的那個 $\eta$（Eta）叫做學習率（Learning Rate），也就是你每一步跨多大。這是整個機器學習裡面最讓人抓狂的設定之一：

  • 太小：一步一公分地下山，方向是對的，但是走到天亮都還沒到。
  • 太大：一步就跨過了整個山谷跳到對面的山上，然後再跨回來左右亂跳，嚴重的話還會越跳越高，Loss 直接爆炸！
  • 剛剛好：才能穩穩地走到谷底。

[08:50] 而且還有一個陷阱：山上可能不只一個山谷，所以你可能走到半山腰的一個小坑，周圍都是上坡，你以為就已經到了，這個叫做局部最小值（Local Minimum）。很多演算法的改良就是在想辦法不要卡在這種小坑裡面。好，那這一段先講到這裡就好，下一集線性迴歸，我們會真的拿紙筆把整座山的微分一步一步地算出來！

09:21 - 11:27

6. Loss 降到 0 就完美了嗎？欠擬合、過擬合與泛化能力

經典三態曲線圖解（資料點 vs 擬合線）
學生 A：欠擬合 (Underfitting)

模型太死板，連訓練資料趨勢都抓不住

學生 C：泛化良好 (Generalization)

理解核心規律，對未見過的資料預測精準

學生 B：過擬合 (Overfitting)

死記硬背所有雜訊，Loss 為 0 但遇新題必爆

[09:21] 好，假設你的梯度下降走得很順，Loss 一路降到幾乎是 0，模型就完美了嗎？不一定！這可能是一個非常危險的訊號。

[09:30] 想像一個班上有三個學生在準備期末考： 學生 A 完全沒讀，考古題也寫不好，期末考當然也就爆了； 然後學生 B 把考古題背下來了：第三題選 C、第七題答案是 42，考古題寫了 100 分，但期末考題目換一個數字就不會了； 然後學生 C 是理解題目的觀念，考古題 90 分，期末考也 88 分。

[10:02] 學生 A 就是 Underfitting（欠擬合）：模型太簡單了，連訓練資料都學不會； 學生 B 就是 Overfitting（過擬合）：模型把訓練資料背下來了，裡面的雜訊和巧合都一起背，遇到沒看過的資料就直接破功了； 那學生 C 就是我們要的，叫做泛化（Generalization）：在沒看過的資料上也能表現得好。

[10:28] 看這張圖最清楚：那條亂晃的線確實貫穿了每一個點，Loss 是 0，但你會相信他對下一個點的預測嗎？不會！因為他學到的不是一個趨勢，而是雜訊。

[10:44] 為什麼會這樣？因為旋鈕太多了！模型太靈活的時候，它有能力把每一個細節都記住。而真實的世界裡面，資料是一定有雜訊的：感測器誤差、人工標錯、純粹的運氣。

[11:00] 所以機器學習真正的目標：從來不是把訓練資料學到完美，而是在沒看過的資料上也能預測正確。這句話太重要了！後面每一集講到缺點的時候，你會一直聽到 Overfitting 這個字。那怎麼解決？有很多招數，比如說正規化（Regularization），就是故意不讓模型太放飛自我，那這個我們後面會再細講。

11:27 - 13:23

7. 如何抓出 Overfitting？資料切成三份與分佈偏移

🛡️ 資料切分成三份（嚴防死守） 黃金分割原則
訓練集 (Training ~70%)
驗證 (Val ~15%)
測試 (Test ~15%)
📚 考古題：調旋鈕
📝 模擬考：挑超參數
🔒 期末考：鎖保險箱
🚗❄️
自駕車翻車警告：分佈偏移（Distribution Shift） 如果訓練集與測試集都在「豔陽高照的亞利桑那州」收集，模型測試分數再高，開到「大雪紛飛的匹茲堡」依然會瞬間癱瘓！因為現實世界的資料分佈永遠比資料庫更遼闊。

[11:27] 在解決之前，你得先發現它正在發生。回到剛剛的學生 B，考古題寫了 100 分，如果老師就拿同一份考古題當期末考，你永遠不會發現他其實什麼都不會。

[11:40] 模型也一樣：你不能用它學過的資料來考它。它的標準做法就是在一開始就把資料切成三份：

1. 訓練集 Training set
考古題。模型拿來調旋鈕的。
2. 驗證集 Validation set
模擬考。用來決定學習率多大、模型多複雜等超參數設定。
3. 測試集 Test set
期末考。鎖在保險箱裡，整個專案最後只打開一次。

[12:11] 那怎麼用這三份資料來抓 Overfitting 呢？很簡單：如果「訓練集的分數很高、驗證集的分數很低」，就是學生 B，它在背答案；那如果兩個都很低，就是學生 A，模型太簡單了。

[12:27] 這裡有一個新手很常犯的錯，叫做資料洩露（Data Leakage）：就是期末考的題目不小心混進了考古題。比如說同一個行人的影片，前一秒在訓練集、後一秒在測試集，模型分數好得不可思議，然後一上路就出事了。

[12:44] 最後再講一個有深度的點：就算你切得很完美、測試集分數也很高，還是有可能翻車！如果你的自駕車只在天氣很好的亞利桑那州收集資料，訓練集、測試集都來自那裡，那分數當然很漂亮；但是你把它開到下雪的匹茲堡，它可能就傻了，因為它從來沒看過雪。

[13:06] 這個叫做分佈偏移（Distribution Shift）。測試集只能證明模型在「跟訓練資料很像的世界」裡面有用，而真實世界永遠比資料集更大，這也是為什麼自駕車這麼難。
