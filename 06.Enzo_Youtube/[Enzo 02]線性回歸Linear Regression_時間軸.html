重點精華 · 實務落地
重點整理 (Key Takeaways)
  • 回歸詞源本質：高爾頓父子身高研究之「回歸平庸」，演算法本質是在特徵空間中擬合最優預測直線或超平面。
  • 最小平方法核心：Loss 為殘差正方形面積之和，正負不抵消且大錯重罰；重要心法：Loss 是參數 $w, b$ 的函數，資料是固定常數！
  • 碗形凸曲面保證：MSE 曲面為嚴格凸函數，全域僅有唯一碗底，梯度下降保證收斂至全域最優。
  • 特徵縮放生死攸關：未標準化時 $dw$ 包含特徵乘積使曲面被拉成長橢圓深谷，導致梯度極度懸殊，步長稍大便直接炸飛。
機制說明 (Mechanism & Math)
  • 鏈鎖法則偏微分：$\frac{\partial L}{\partial w} = \frac{2}{n}\sum e_i x_i,\; \frac{\partial L}{\partial b} = \frac{2}{n}\sum e_i$；猜太高逆梯度調小，猜太低調大。
  • 正規方程式解析解：$\boldsymbol{\theta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$；一步求逆，但矩陣求逆計算複雜度為 $O(d^3)$，維度大於數萬時崩潰，而梯度下降僅需 $O(nd)$。
  • 學習率臨界半徑證明：標準化後 Hessian 最大特徵值為 2，收斂半徑 $|1 - 2\eta| < 1 \implies 0 < \eta < 1$。當 $\eta=1.05$ 時誤差每步放大 $1.1$ 倍必引發指數爆炸！
應用在何處 (Industrial Scenarios)
  • 半導體晶圓先進製程控制 (APC)：CVD 薄膜厚度與 CMP 研磨去除率預測補償，維持奈米級良率精準度。
  • 智慧製造能源負載優化：工廠大型冰水主機與空調系統負載預測，依環境溫濕度即時調頻節電 15~20%。
  • 金融量化資產定價模型 (CAPM)：利用多元線性回歸拆解股票系統性風險 $\beta$ 係數與超額 Alpha 收益。

00:00 - 01:04 Concept · 起源歷史

為什麼用一條直線預測數字，要叫做「回歸」？

你是否曾困惑過：用一條直線來預測連續數值，這方法為什麼要叫「回歸（Regression）」？到底是回歸了什麼？難道是韓國女團回歸？

這個名詞實際上源自 19 世紀的英國學者 Francis Galton。他在研究父母與子女身高遺傳關聯時，發現了一個有趣的自然統計現象：極高大的父母，生出的小孩通常也很高，但往往沒有父母那麼高；反之，極矮小的父母生出的小孩雖然也偏矮，但也沒有父母那麼矮。下一代的高度總是不自覺地在朝族群平均值靠近。

Galton 將此現象命名為「向平均回歸（Regression toward the mean）」，而他當時用來分析該趨勢的直線，便一路被稱作「回歸線」。雖然這個名稱和演算法本質關係不大，但這條直線恰巧就是整個機器學習的起點，包含損失函數、梯度下降、訓練集與測試集概念都從這裡展開。

01:05 - 02:14 Intuition · 人腦回歸

房仲情境：如何證明你的線不是隨便畫的？

假設你是房仲，手上有 100 間房屋的歷史成交資料，只知道兩件事：坪數 與 售價。將它們標記在二維坐標系上，一眼就能看出：坪數越大，房價越高。

但資料點並不會完美排成一條直線，因為即便同為 30 坪，其地段、樓層、裝潢與屋齡差異都會導致價格不同。當客戶詢問「我有一間 30 坪的房子大約可以賣多少」時，最直觀的做法就是拿筆在散佈點中間畫一條趨勢線，再找出 30 坪對應的價格。這便是人腦在無意識中完成的「線性回歸」。

核心難題：任何人在圖上都能畫出好幾條看似合理的線。到底哪一條才是數學意義上的「最優解」？要如何說服客戶這條線具有客觀依據？線性回歸要解答的就是：從無限多條候選直線中，用嚴格的數學方法找出最完美的那一條。

02:15 - 03:42 Modeling · 模型架構

直線的數學定義：兩個旋鈕的混音器

中學數學教過一條直線能寫成 $y = ax + b$。在機器學習領域中，為了統一符號規範，習慣改寫為：

$$\hat{y} = w \cdot x + b$$
  • $x$（輸入特徵）：房屋坪數。
  • $\hat{y}$（y-hat，預測標籤）：模型預測出來的房價。戴上「帽子」符號是為了時時提醒：這只是預估值，而非真實成交價。
  • $w$（Weight，權重 / 斜率）：代表特徵每增加 1 單位，預測房價會增加幾萬（每坪單價）。
  • $b$（Bias，偏差 / 截距）：直線通過 Y 軸的截距，可視為該區域不計坪數的基本起步門檻底價。

混音器比喻：線性回歸就像一台只有兩個旋鈕的混音器。轉動 $w$ 會改變直線的傾角斜率；轉動 $b$ 則讓整條線垂直上下平移。如果未來加入「屋齡」或「離捷運站距離」等新維度，只需在混音器上多加幾個對應的旋鈕即可。

可解釋性優勢：權重正負直接傳達邏輯。屋齡權重通常是負數（房越老越便宜），捷運站距離也是負數（越遠越便宜）。你可以透過權重直接讀懂模型的決策邏輯。
w
權重旋鈕 (Weight) 轉動改變直線斜率（傾角陡峭程度）
b
偏差旋鈕 (Bias) 轉動控制整條直線上下垂直位移（基準底價）
03:43 - 05:37 Loss Function · 損失函數

如何衡量誤差？殘差與最小平方法（MSE）

為了比較哪條線最理想，我們需要精準測量每一條直線究竟「錯得有多離譜」。對於每間房子，模型的預測值與真實成交價格之間的差值，稱為 殘差（Residual），在幾何上就是資料點到直線的垂直距離：

$$\text{Loss (MSE)} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$
  • $(\hat{y} - y)$（預測減去真實）：代表垂直誤差的長度。
  • 平方（Square）：保證無論猜太高還是猜太低都會化為正數，同時對「犯大錯」的點施加更重的懲罰。
  • 除以 $n$ 取平均：使得 100 筆樣本與 10,000 筆樣本的損失值能在同一基準線上客觀比較。

幾何本質（最小平方法）：每個殘差平方，相當於以該誤差為邊長所畫出的正方形面積。線性回歸所做的事情，就是轉動直線，直到所有樣本對應的正方形面積總和達到最小。

凸函數（Convex）特性：在固定資料集下，Loss 是 $w$ 與 $b$ 的函數。其在空間中形成一個完美的「碗狀曲面」。這個碗只有唯一的最低底點，沒有局部坑洞陷阱，因此不管從哪裡啟動，終點都是唯一的！

🔥 為什麼線性回歸如此超受歡迎？

深度學習的神經網路曲面充滿成千上萬個局部極小值（Local Minima）與鞍點陷阱，梯度下降很容易迷路卡在半山腰；

但線性回歸是嚴格的凸函數（Convex），整座曲面只有唯一一個最低碗底！這保證了：

  • 沒有局部坑洞：不管初始參數隨機設在哪裡，都能收斂到最佳解。
  • 結果 100% 穩定可重現：跑 100 次程式，算出來的最佳權重都一模一樣。
  • 解析解與數值解殊途同歸：梯度下降一步步走到的碗底，與正規方程式直接算出的答案完全吻合。
05:38 - 07:38 Calculus · 數學推導

梯度下降：用微積分鏈鎖法則算出腳下坡度

為了走到碗底，我們必須知道腳下的切線坡度，這就是微積分中的偏微分。

以單一房屋為例：$\text{Loss} = (wx + b - y)^2$。當微幅旋動旋鈕 $w$，Loss 會變動多少？此時運用微積分的鏈鎖法則（Chain Rule）：

// 對 w 微分 外層導數: $2 \times (\hat{y} - y)$
內層導數: $x$
相乘得: $\frac{\partial L}{\partial w} = 2(\hat{y} - y)x$
// 對 b 微分 外層導數: $2 \times (\hat{y} - y)$
內層導數: $1$
相乘得: $\frac{\partial L}{\partial b} = 2(\hat{y} - y)$

公式白話翻譯：

  • 猜太高時：誤差為正，梯度為正，反方向更新時讓 $w$ 縮小，下次預測就會調低。
  • 錯得越多，調得越猛：梯度正比於誤差。
  • $x$ 越大，$w$ 越該負責：一間 60 坪的房子猜錯，其每坪單價 $w$ 該承擔的責任遠大於 10 坪的房子。
07:39 - 08:45 Pitfall · 新手巨坑

手算一步踩坑：為什麼必須特徵縮放？

若親手推算一步更新，就會發現潛藏的巨大陷阱：

條件：房屋 20 坪 ($x=20$)，實售 1300 萬 ($y=1300$)。初始旋鈕 $w=0, b=0$

1. 模型預估 $\hat{y} = 0$，誤差 $= -1300$

2. $w$ 梯度 $= 2 \times (-1300) \times 20 = \mathbf{-52,000}$

3. $b$ 梯度 $= 2 \times (-1300) = \mathbf{-2,600}$

4. 設學習率 $\alpha = 0.001$，更新後：$w$ 變為 $\mathbf{5.2}$，但 $b$ 僅變為 $\mathbf{0.26}$

問題所在：$w$ 的更新步幅比 $b$ 整整快了 20 倍（正好等於坪數大小）！若房屋為 60 坪，就是 60 倍差距。

這代表損失函數的碗並非圓碗，而是一個被極度壓扁的細長山谷。學習率設大會讓 $w$ 劇烈發散震盪，設小則 $b$ 慢如蝸牛。

必備解法：特徵縮放（Feature Scaling）
事先將坪數標準化為 $\text{Mean}=0, \text{Std}=1$，讓碗的形狀拉回正圓形，確保所有維度以同等節奏收斂。
未縮放：狹長山谷 (極易振盪) 權重梯度過大，更新不平衡
特徵縮放後：正圓形 (平穩收斂) 徑直快速走向最低點
08:46 - 10:26 Analytical Solution · 公式解

秘密武器：正規方程式（Normal Equation）

在碗底最低點，切線坡度剛好等於 0。因此我們可以直接令梯度為 0，利用線性代數一步求得精準解析解：

$$\theta = (X^T X)^{-1} X^T y$$

將資料矩陣代入公式，最佳權重與偏置便瞬間解出！不需要手動調整學習率，也不需要執行迴圈迭代。

既然有直接解法，為什麼還需要學梯度下降？

1. 反矩陣計算極其昂貴 矩陣求逆運算複雜度約為特徵數的立方（$O(d^3)$）。若是 10 萬個特徵，計算量將達到 $1000$ 兆！而梯度下降每一步成本僅與特徵數呈正比。
2. 這是線性回歸的獨家特權 後續的邏輯回歸到深度神經網路，全都不存在解析解，唯一能依靠的只有梯度下降法。
10:27 - 13:00 Pros & Cons · 實戰評估

優劣勢剖析：如何用直線擬合出「曲線」？

三大核心優勢

  • 1. 高度可解釋性：金融與醫療必須解釋決策原因，權重數值即為理由。
  • 2. 運算迅速且穩定：凸函數單一極值，跑幾次結果都一致。
  • 3. 業界 Baseline 基準：評估昂貴複雜的深度學習模型是否真正帶來顯著增益。

三大常見劣勢

  • 1. 害怕極端離群值：平方項會賦予離群點超大面積，直接把整條線拉偏。
  • 2. 多重共線性（Multicollinearity）：同時輸入坪數與平方公尺時，權重會劇烈互飆跳動。
  • 3. 嚴禁任意向外推論：拿 10~60 坪資料訓練的模型去預測百坪豪宅，數字毫無信度。
妙招反轉：如何讓線性回歸畫出曲線？ 例如自駕車煞車距離與「車速的平方」成正比（時速增為 2 倍，煞車距離變 4 倍）。若直接畫直線，高速時會嚴重低估釀成事故。 此時只要把 $x_2 = \text{車速}^2$ 當成一項全新特徵餵入模型： $$\hat{y} = w_1 \cdot (\text{車速}) + w_2 \cdot (\text{車速}^2) + b$$ 這便能畫出漂亮的曲線！而且它依然是線性回歸，因為「線性」指的是對參數旋鈕（$w, b$）呈現線性，而非輸入特徵！
13:01 - 15:10 Implementation · 程式實踐

Python 實作：三種方法求出同一碗底

影片中使用合成數據（真實權重每坪 52 萬、底價 300 萬，保留 20% 測試集），透過三種方法驗證數值收斂：

方法 1：手寫梯度下降 (含特徵縮放) gradient_descent.py 
# 特徵縮放 (Z-Score 標準化)
x_mean, x_std = x_train.mean(), x_train.std()
x_norm = (x_train - x_mean) / x_std

# 梯度下降迴圈
for step in range(epochs):
    y_pred = w * x_norm + b
    error = y_pred - y_train
    # 梯度公式實作
    dw = (2 / n) * np.sum(error * x_norm)
    db = (2 / n) * np.sum(error)
    # 參數更新
    w -= lr * dw
    b -= lr * db

# 還原為真實單位
w_real = w / x_std
b_real = b - (w * x_mean / x_std)
方法 2 & 3：正規方程式 與 Scikit-learn solve_and_sklearn.py 
# 方法 2：正規方程式 (使用 solve 代替 inv 提升數值穩定性)
# X_b 前方多放一排 1 作為 bias 截距項
theta = np.linalg.solve(X_b.T @ X_b, X_b.T @ y_train)

# 方法 3：Scikit-learn (注意 .reshape(-1, 1) 轉成二維表格)
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(x_train.reshape(-1, 1), y_train)
# model.coef_[0] 為斜率，model.intercept_ 為底價
實驗結果：三種方式求得的每坪單價均為 51.46 萬（極度貼近真值 52 萬）、底價約為 323 萬，判定係數 $R^2 = 0.97$，證實三條路徑抵達了同一個碗底！
15:11 - 17:16 Experiment & Summary · 實驗與結論

把演算法玩壞：學習率與標準化終極實測

理解演算法最快的方式就是親手把它弄壞：

實驗 1：學習率調至 1.05 第 73 步 Loss 瞬間發散爆炸！一步跨越山谷越跳越高。有趣的是，學習率在 0.99 時依然安全，剛好超過 1 就崩潰。
實驗 2：直接關閉特徵縮放 相同學習率下，第 3 步就直接溢位報銷。若調小學習率至不爆炸，結果 $w$ 飆到 59、$b$ 卻只有 9.8（$b$ 幾乎沒動，模型硬拉斜率來湊）。

本集核心精髓總結（三句話）：

1. 模型（Hypothesis）：用一條直線 $\hat{y} = wx + b$ 來預測。
2. 損失（Loss）：用所有樣本的正方形面積總和（MSE）衡量錯誤，它是只有單一碗底的凸函數。
3. 學習（Optimization）：用梯度下降法一步步走向碗底，或利用正規方程式一步算完。

這「模型、損失、學習」三步驟就是機器學習後續每一集的通用骨架，其餘演算法大多只是替換這三塊中的某一組件。
