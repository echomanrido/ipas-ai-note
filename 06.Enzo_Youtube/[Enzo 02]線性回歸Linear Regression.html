重點整理 (Key Takeaways)
  • 回歸詞源本質：高爾頓父子身高研究之「回歸平庸」，演算法本質是在特徵空間中擬合最優預測直線或超平面。
  • 最小平方法核心：Loss 為殘差正方形面積之和，正負不抵消且大錯重罰；重要心法：Loss 是參數 $w, b$ 的函數，資料是固定常數！
  • 碗形凸曲面保證：MSE 曲面為嚴格凸函數，全域僅有唯一碗底，梯度下降保證收斂至全域最優。
  • 特徵縮放生死攸關：未標準化時 $dw$ 包含特徵乘積使曲面被拉成長橢圓深谷，導致梯度極度懸殊，步長稍大便直接炸飛。
機制說明 (Mechanism & Math)
  • 鏈鎖法則偏微分：$\frac{\partial L}{\partial w} = \frac{2}{n}\sum e_i x_i,\; \frac{\partial L}{\partial b} = \frac{2}{n}\sum e_i$；猜太高逆梯度調小，猜太低調大。
  • 正規方程式解析解：$\boldsymbol{\theta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$；一步求逆，但矩陣求逆計算複雜度為 $O(d^3)$，維度大於數萬時崩潰，而梯度下降僅需 $O(nd)$。
  • 學習率臨界半徑證明：標準化後 Hessian 最大特徵值為 2，收斂半徑 $|1 - 2\eta| < 1 \implies 0 < \eta < 1$。當 $\eta=1.05$ 時誤差每步放大 $1.1$ 倍必引發指數爆炸！
應用在何處 (Industrial Scenarios)
  • 半導體晶圓先進製程控制 (APC)：CVD 薄膜厚度與 CMP 研磨去除率預測補償，維持奈米級良率精準度。
  • 智慧製造能源負載優化：工廠大型冰水主機與空調系統負載預測，依環境溫濕度即時調頻節電 15~20%。
  • 金融量化資產定價模型 (CAPM)：利用多元線性回歸拆解股票系統性風險 $\beta$ 係數與超額 Alpha 收益。

背景故事

為什麼預測數值的直線要叫「回歸」？

19 世紀英國學者 法蘭西斯·高爾頓（Francis Galton） 研究父母與子女的身高關聯時發現：極高父母的孩子平均偏向矮一點，極矮父母的孩子平均偏向高一點，雙方後代的身高都持續往整體人類的「平均值」靠攏。

高爾頓將此現象稱為 「向平均回歸（Regression toward the mean）」，他拿來分析走勢的直線從此被約定俗成稱為回歸線。

因此，「回歸」之名純屬科學家命名習慣，演算法本質是在從無限條可能的直線中，找出誤差最小的那一條！

凸函數 (Convex) · 絕無局部坑洞

為什麼線性回歸如此受歡迎？

在機器學習中，訓練模型就像是蒙著眼睛下山。 許多複雜模型（例如深度神經網絡）的山路充滿了坑洞、馬鞍面與半山腰的假凹洞（Local Minima），球往往滾到假坑洞就再也出不來。

凸函數（Convex）的巨大幸福：
  • • 兩個水平軸：分別是旋鈕 \(w\)（斜率）和 \(b\)（截距）。
  • • 垂直高度：代表當前參數下的均方誤差（MSE Loss）。
  • • 只有唯一一個最低點：無論你從哪個位置隨機初始化下山，順著坡度走保證一定會抵達同一個全域碗底！
這也是為什麼後續所有機器學習實驗，一定都會先用線性回歸作為無可取代的黃金基準線（Baseline）！

深入微積分核心

梯度下降怎麼算？連鎖律手把手推導

為了知道往碗底的哪個方向走、走多快，我們計算損失函數對兩個旋鈕的偏微分（斜率）。

1

單一資料點的 Loss

假設世界上只有一間房子，真實價格為 \(y\)，預測值為 \(\hat{y} = wx + b\)。

\[ L = (wx + b - y)^2 \]
外層是平方，內層是誤差項 \((wx + b - y)\)。
2

運用連鎖法則 (Chain Rule)

轉動 \(w\) 會使預測值改變，進而改變誤差，連鎖相乘即可求出斜率：

\[ \frac{\partial L}{\partial w} = 2(wx + b - y) \cdot x \]
\[ \frac{\partial L}{\partial b} = 2(wx + b - y) \cdot 1 \]
為什麼 \(b\) 沒有乘 \(x\)？因為偏差 \(b\) 每增加 1，誤差就固定只增加 1。
3

翻譯成白話邏輯

• 猜太高時：誤差為正，梯度為正，反方向更新使 \(w\) 變小。

• 錯越多調越多：梯度大小與誤差成正比。

• \(x\) 越大的樣本越該負責：一間 60 坪房子估錯時，每坪單價 \(w\) 需承擔比 10 坪房子大 6 倍的修正責任！

對所有樣本平均後，套入參數更新：\(\theta \leftarrow \theta - \eta \cdot \nabla L\)。

關鍵細節：為什麼必須做「特徵縮放（Feature Scaling）」？

在手算示範中，20 坪的房子使 \(w\) 的梯度比 \(b\) 大了 20 倍（若為 60 坪則快 60 倍）。這代表損失函數的碗不是圓的，而是一個被嚴重壓扁的狹長山谷！此時若學習率設大，\(w\) 會瞬間震盪爆炸；設太小，\(b\) 則宛如牛步完全不走。透過標準化（均值 0、標準差 1），能讓山谷變回對稱的正圓碗！

閉式解法 (Closed-Form Solution)

既然能直接解方程式，何必辛苦下山？

在碗底最低點，坡度剛好為 0（\(\nabla L = 0\)）。既然是二次多項式，我們能用矩陣代數一步解出最佳權重，這就是著名的 正規方程式（Normal Equation）：

\[ \theta = (X^T X)^{-1} X^T y \]
比較維度 梯度下降法 (Gradient Descent) 正規方程式 (Normal Equation)
超參數需求 需要精心設定學習率 \(\alpha\)，需多次迭代 完全不需要超參數，一步即成
計算時間複雜度 \(O(k \cdot n \cdot d)\)（適合海量特徵維度） 反矩陣計算約為 \(O(d^3)\)，特徵數 10 萬時計算量達 1000 兆！
模型通用性 全能通用（邏輯回歸、Transformer、深度神經網路必備） 僅限於線性回歸（後續非線性模型皆無法直接求逆矩陣）
產業實務選擇 海量數據、線上即時增量更新 中小型數據集（scikit-learn 預設使用矩陣分解求解）
實務工程指南

線性回歸的優劣勢與常見誤區

核心優勢

  • 1. 極佳的可解釋性：可以直接對業務端或審計部門解釋「每增加 1 坪價格增加 51 萬」，在金融與醫療等嚴格監管領域至關重要。
  • 2. 快速且數值穩定：損失函數為嚴格凸函數（Convex），永遠只有一個碗底，絕不會卡在局部極小值（Local Minima）。
  • 3. 不可或缺的 Baseline：任何高階神經網路開發前，必先跑線性回歸作為基準線；若複雜模型只贏一點點，則不具備上線效益。

局限與應對策略

  • 1. 只能畫直線？非也！例如車速與煞車距離呈平方正比，可新增 \(x_2 = x_1^2\) 特徵輸入，模型依然是針對「權重」線性的線性回歸！
  • 2. 極度害怕離群值（Outliers）：因為平方懲罰機制，一間 10 坪卻賣 5000 萬的極端豪宅，會形成超大正方形把整條線硬生生扯偏。
  • 3. 多重共線性陷阱：同時放入「坪數」與「平方公尺」會導致特徵重疊，模型權重會互相抵消亂跳（需透過 Ridge/Lasso 正則化處置）。
  • 4. 切忌任意盲目外推（Extrapolation）：拿 10~60 坪資料訓練的模型去預測 200 坪豪宅，產生的數字毫無可靠根據。
Python 程式碼 (語法高亮)

三種解法完整實現 (NumPy & Scikit-Learn)

import numpy as np
from sklearn.linear_model import LinearRegression

# 1. 生成房價合成資料 (真實規律: 每坪 52 萬, 底價 300 萬)
np.random.seed(42)
X = np.random.uniform(10, 60, size=(100, 1))           # 坪數 (10~60 坪)
noise = np.random.normal(0, 50, size=(100, 1))          # 高斯雜訊
y = 52.0 * X + 300.0 + noise                            # 房價 (萬)

# --- 方法一：手寫梯度下降 (含特徵縮放 Standard Scaling) ---
X_mean, X_std = np.mean(X), np.std(X)
X_scaled = (X - X_mean) / X_std                         # 標準化：避免狹長山谷導致震盪
w_norm, b_norm = 0.0, 0.0
lr, epochs = 0.05, 500

for _ in range(epochs):
    y_pred = w_norm * X_scaled + b_norm
    error = y_pred - y
    dw = (2 / len(X)) * np.sum(error * X_scaled)
    db = (2 / len(X)) * np.sum(error)
    w_norm -= lr * dw
    b_norm -= lr * db

# 將標準化後的參數還原為真實坪數尺度 (w: 萬/坪, b: 萬)
w_gd = w_norm / X_std
b_gd = b_norm - (w_norm * X_mean / X_std)

# --- 方法二：正規方程式 (Normal Equation 閉式矩陣解) ---
X_b = np.c_[np.ones((100, 1)), X]                       # 加入偏置項截距 1
theta_best = np.linalg.solve(X_b.T.dot(X_b), X_b.T.dot(y)) # 求解 (X^T X)^-1 X^T y
b_norm_eq, w_norm_eq = theta_best[0][0], theta_best[1][0]

# --- 方法三：Scikit-Learn 工業級實現 ---
model = LinearRegression()
model.fit(X, y)                                         # 輸入需保證為 2D 矩陣
w_sk, b_sk = model.coef_[0][0], model.intercept_[0]

# --- 結果印出：檢驗三種方法是否收斂至同一個唯一碗底 ---
print(f"【梯度下降解】 w: {w_gd:.2f} 萬/坪, b: {b_gd:.2f} 萬")
print(f"【正規方程解】 w: {w_norm_eq:.2f} 萬/坪, b: {b_norm_eq:.2f} 萬")
print(f"【Sklearn 解】 w: {w_sk:.2f} 萬/坪, b: {b_sk:.2f} 萬")
# 三者解完全一致，精確驗證了 MSE 凸函數（Convex）只有唯一的碗底！
