0_總整理_01

最容易混淆的對比（上）

🧠 深度觀念解析與考點說明

1. Skip-gram vs CBOW CBOW 是用「周圍上下文預測中心詞」，平均化了上下文向量，因此運算快；Skip-gram 是用「中心詞預測周邊詞」，能為低頻/罕見字詞提供多次獨立梯度更新，罕見詞表現更優。
2. Word2Vec vs GloVe Word2Vec 是局部視窗的預測型模型（Local Prediction）；GloVe 是在全域共現矩陣（Global Co-occurrence Matrix）上做因式分解的統計型模型。
3. 實例 (Instance) vs 全景分割 (Panoptic) 實例分割只對感興趣的「前景實體物件」（如：人、車）做個體像素輪廓區分；全景分割則是「實例分割 + 語意分割」，包含天空、道路等背景無差別完全標註。
4. YOLO vs Faster R-CNN YOLO 是單階段（One-stage），直接回歸預測框與類別，超快；Faster R-CNN 是兩階段（Two-stage），先透過 RPN 產生候選區域再分類，精準度高但較耗時。
5. RAG 檢索的核心弱點 向量檢索依賴餘弦相似度，常出現「字面或語意特徵向量很近，但問題意圖完全無關」的假性召回，需透過 Reranker 或混合檢索（BM25+Dense）緩解。
6. 擴散模型：採樣步數 (Steps) vs CFG 採樣步數決定去噪迭代次數（影響畫面細節與清晰收斂度）；CFG（Classifier-Free Guidance）決定模型多嚴格服從提示詞，太高會過度飽和/失真。
7. 聯邦學習 vs 傳統加密傳輸 傳統加密（SSL/TLS）依然是將原始資料傳給伺服器；聯邦學習（Federated Learning）是「資料不出本地設備」，僅將梯度/模型權重聚合上傳。
8. 模態缺失（Multimodal Missing） 若推論時可能缺少圖像或音訊，訓練期就必須主動使用 Dropout 或 Masking 機制隨機抹除模態，強迫模型適應缺失。
0_總整理_02

最容易混淆的對比（下）

🧠 深度觀念解析與考點說明

1. F1-Score vs AUC F1 是調和平均數（Precision 與 Recall），依賴「單一固定閾值（預設0.5）」；AUC 衡量的是分類器對正負樣本的排序能力，掃遍「0到1的所有閾值」。
2. 交叉驗證 vs 早期停止 (Early Stopping) K-Fold 交叉驗證用於客觀評估一組「超參數/模型結構」的泛化能力；早期停止是在單次訓練過程中，監控驗證集 Loss 不再下降時提早中斷，防止過擬合（Overfitting）。
3. 資料漂移 (Data Drift) vs 概念漂移 (Concept Drift) 資料漂移：P(X) 改變，輸入特徵分布變化（如：使用者年齡層變年輕）；概念漂移：P(Y|X) 改變，特徵與答案的對應關係改變（如：通膨後高額消費不再代表詐欺）。
4. 吞吐量 (Throughput) vs 延遲 (Latency) 優化 想要每秒處理更多請求（高吞吐量）適合加大 Batch Size 跑批次推論；想要單次回應更快（低延遲）適合做 INT8 權重降精度量化或剪枝。
L21101 自然語言

自然語言處理一句話記住

📖 重點釋疑

TF-IDF 面對長文本的陷阱 IDF（逆文檔頻率）反映的是整個語料庫中單字的普遍程度，只跟「包含該詞的文件數」有關。長文本導致得分失真純粹是因為文字冗長造成 TF（Term Frequency）次數偏高，解決方法是做長度標準化（如 BM25 演算法的長度懲罰）。
Seq2Seq vs NER (命名實體識別) Seq2Seq（Sequence to Sequence）輸出長度不固定（例如翻譯或摘要，將一串文字轉換為另一串文字）；NER 則是標準的 Token-level 序列標註任務，輸入輸出是一對一貼標籤（例如 [PER]、[LOC]）。

從整張圖到每個像素 (視覺分割階層)

視覺任務辨析對照表：

電腦視覺的粒度演進：分類（無定位） → 偵測（框出位置與個別物體） → 語義分割（全像素類別，但多隻羊連在一起會融合成同一團） → 實例分割（把多隻羊分開，但不管草地和天空） → 全景分割（把羊隻隻分開，同時把草地、天空等背景全數以像素精確塗色標記）。

L21203 風險管理

從源頭防，不是事後抓 (AI生命週期治理)

🛡️ AI 防護機制解讀

事前：版權與清洗

過濾 PII（個人可識別資訊）及無版權授權內容，成本最低且避免模型遭到「毒化（Data Poisoning）」或訴訟。

事中：差分隱私 (DP)

在梯度更新中加入高斯雜訊（DP-SGD），保證攻擊者無法藉由模型輸出逆向推斷特定個人的訓練資料。

事後：溯源與水印

於生成 Token 機率分佈或影像頻域植入不可見數位浮水印，當發生侵權或虛假資訊時可即時鑑識出處。

L21301 數據與模型

差在幾個門檻 (混淆矩陣 vs ROC / AUC)

⭐ 證照與考試必考重點解析

為什麼「無法從混淆矩陣算出 AUC」？
混淆矩陣（Confusion Matrix）是將模型的預測機率，套用單一特定閾值（Threshold，如 0.5）後分類產生的二元結果（TP, FP, TN, FN）。而 ROC 曲線與 AUC 則必須透過變動所有可能的門檻（從 0 到 1）繪製不同 FPR 與 TPR 的動態曲線才能積分出面積。如果你只有一張靜態的混淆矩陣，失去了模型輸出的原始連續分數，就絕對無法回推 AUC！

L21301 數據與模型_02

網格、隨機、貝氏 (超參數調優三劍客)

💡 搜尋策略選擇指引

Grid Search (網格) 參數維度極少（如 1~2 個超參數）且需要地毯式窮舉保證全局最優時使用，參數變多時面臨「維度詛咒」。
Random Search (隨機) 高維度參數空間首選基準。Bengio 等人研究證明，隨機搜尋能更有效覆蓋對損失函數敏感的重要參數維度。
Bayesian Opt (貝氏) 模型訓練成本極其昂貴（如大模型微調）時使用。利用高斯過程與採集函數（Acquisition Function），在 Explore 與 Exploit 間智慧權衡。
L21301 數據與模型_03

數據與模型一句話記住

🔍 演算法關鍵機制精解

ROC 軸向口訣 X 軸是 FPR（假陽性率，越低越好）；Y 軸是 TPR（真陽性率 / 召回率，越高越好）。理想模型曲線應緊貼左上角。
LASSO vs Ridge (L1 vs L2) LASSO 採用 L1 正則化，其菱形約束區容易在座標軸上相交，因此具備壓係數為 0 的稀疏特性，內建特徵選擇效果。
類別不平衡處理 資料層面：SMOTE 利用近鄰插值生成少數類合成樣本；演算法層面：採用 Focal Loss 或調整 Class Weights。
CNN 可解釋性：Grad-CAM 利用最後一層卷積層對目標類別的梯度（Gradient）計算權重，加權求和後生成熱力圖，視覺化神經網絡到底在看哪裡下決策。
L21302 集成與部署

模型漂移與偏差 ＆ 分布監控指標

📊 MLOps 產線實戰監控指標對比

KL 散度 (相對熵) 非對稱度量（$D_{KL}(P \parallel Q) \neq D_{KL}(Q \parallel P)$），用以量化使用新分布 $Q$ 近似真實分布 $P$ 時損失的信息量。若兩分布相同則值為 0。
PSI (群體穩定度指標) 金融風控業界黃金標準！
• PSI < 0.1：變化微弱，穩定
• 0.1 ≤ PSI < 0.25：輕度漂移，需留意
• PSI ≥ 0.25：顯著漂移，必須重新訓練模型
VAE 異常/漂移檢測 面對高維非結構化數據（圖片、聲音），傳統統計檢定（如 KS-test）失效。利用變分自動編碼器的Reconstruction Loss，若還原誤差大幅增加即代表輸入分布偏移。
