自然語言處理 (NLP) 核心觀念辨析

00:00:45

架構辨析互動圖：Word2Vec (預測) vs. GloVe (全域共現統計)

點擊切換查看神經網路滑動視窗與共現矩陣的本質差異

詞向量學習機制 114-2 / 115-1 考題

Word2Vec (預測) vs. GloVe (統計)

核心原理： Word2Vec 是淺層神經網路，透過局部滑動窗口進行猜詞；GloVe 則先掃描全語料庫建立「全域共現矩陣」，再以迴歸優化詞向量。
解題破局點： 資料龐大且需要精準捕捉罕見詞 (Rare Words) 語意時，唯一首選為 Skip-gram。
誘答陷阱與誤判解析：
  • 誤以為 CBOW 能提升罕見詞穩定度（錯！CBOW 的平均計算正好會沖淡罕見詞）。
  • 誘答「Word2Vec 用全域共現矩陣、GloVe 靠神經網路」（完全對調！Global 就是 GloVe）。
  • 誘答「差在即時與靜態資料」（兩者皆採離線靜態語料庫訓練）。
關鍵詞權重統計 114-2 考古題

TF-IDF 原理與長文本偏差

數學定義與公式： $$\text{TF-IDF}(t, d, D) = \text{TF}(t, d) \times \text{IDF}(t, D)$$ 其中 $\text{IDF}(t, D) = \log\frac{|D|}{|\{d \in D : t \in d\}|}$。 TF 衡量詞在該篇出現次數；IDF 衡量詞的跨文章罕見度（越普遍出現，IDF 越低）。
解題破局點： 長文本顧客評論失準，主因是篇幅過長導致詞頻 (TF) 普遍偏高，常見詞被放大而稀釋關鍵字。實務應以文章總詞數進行 TF 正規化。
誘答陷阱辨析： 誤判「長文本會改變 IDF」（錯！IDF 依賴全語料庫的文件集總數，單一文章字數長短完全不影響 IDF）。
序列轉換架構 任務選型

Seq2Seq (編碼器-解碼器)

架構本質： 編碼器將長度可變的輸入文字壓縮為語意向量，解碼器逐步解碼生成全新文字序列。輸入與輸出長度皆自由且伴隨「語意生成」。
適用任務： 機器翻譯、文本自動摘要、對話問答生成。
誘答陷阱辨析：
  • 誤判為命名實體辨識 NER（NER 屬序列標註/為每個字打標籤，不生成新序列）。
  • 誤判為銷量預測（數值時間序列預測，非語意轉換）。
多任務與偏誤 115-1 考題

多任務梯度競爭 & 情感分析資料偏誤

多任務衝突： 以 Transformer 同時做文件分類與 NER，若 NER 變準而分類變差，主因是多任務損失函數相加時未做權重平衡，導致梯度優化互相競爭。
情感分析跨文化誤判： 根本原因在於訓練資料集來源不平衡與隱性偏誤（模型架構救不了骯髒偏差的資料）。
誘答陷阱（選非題）： 錯誤選項為「未對詞嵌入進行正規化」（正規化影響數值收斂，非族群文化誤判主因）。
【NLP 考前一分鐘口訣】：罕見詞用 Skip-gram、全域矩陣是 GloVe；長文本失準在 TF、NER 是貼標籤不是 Seq2Seq！

電腦視覺 (CV) 四大任務與架構辨析

00:07:28

視覺任務層次解析：看得多細？管不管背景？

點擊不同任務階梯，觀察標記維度與代表性考題情境

實例分割：像素級輪廓、可區分同類個體（顧客1號手機 vs 顧客2號手機），但不包含背景道路與天空。

像素級視覺任務 114-2 & 115-1 必考

四大視覺任務終極對決

核心定義：
  • 語意分割：像素級分類，同類別不分個體（路人全塗同色）。
  • 實例分割：像素級分類，分個體、不管背景。
  • 全景分割：像素級分類，分個體 + 管背景（道路/天空）。
解題破局點：
  • 【超市防損題 (115-1)】：購物籃、手機像素遮罩且區分不同顧客 $\rightarrow$ 實例分割。
  • 【自駕車題 (114-2)】：道路、建築及各行人全都要像素分類 $\rightarrow$ 全景分割。
誤判方向： 看到像素就選語意分割（忽略要分個體）；看到分個體就選物件偵測（忽略題目要求像素遮罩而非方框）。
CNN 與偵測架構 115-1 考題

特徵展平 (Flatten) 與偵測階段性

卷積層接全連接層： 卷積層輸出為四維張量 $(B, C, H, W)$，全連接層接收二維 $(B, \text{features})$，標準銜接必須加入 Flatten 層 攤平成一維向量。
單階段 vs. 兩階段偵測：
  • Faster R-CNN (兩階段)：先由 RPN 產生物件候選區，再分類與微調座標。精確但慢。
  • YOLO (單階段)：無候選區域生成，直接整張圖一次預測。適合工廠產線高 FPS 即時瑕疵偵測。
誘答陷阱： 誤選 GAP（全域平均池化是另一種架構，非標準銜接）；誤稱 YOLO 靠增加候選區域提高精度（單階段根本沒有候選區！）。
【CV 考前一分鐘口訣】：要背景選全景、只要物件選實例；卷積攤平用 Flatten；產線即時高 FPS 選單階段 YOLO！

生成式 AI、多代理人容錯與多模態配置

00:10:57
RAG 與 Diffusion 114-2 / 115-1 考題

RAG 檢索挑戰 & 影像去噪調參

RAG 檢索階段最核心挑戰： 「檢索出的文件語意高度相似，但與使用者真實意圖無關」（例如問「年假流程」卻檢索出「年度預算編列」）。
Stable Diffusion 生成清晰度調校： 4K 影像邊緣顆粒模糊，在推論階段唯一的正解是「增加採樣步數 (Sampling Steps) 並選用高品質採樣器」。
常見誘答陷阱： 誤調高 CFG Scale（CFG 控制的是貼近提示詞的強度，過高會造成假影與過度飽和，無法改善去噪解析度）。
Agent & 多模態 115-1 考題

Multi-Agent 容錯 & 模態缺失對策

模態與神經網路配對黃金標準：
  • 空間影像 $\rightarrow$ CNN / ResNet
  • 語意文字 $\rightarrow$ Transformer / BERT
  • 時序訊號 (心率、血氧) $\rightarrow$ LSTM / 1D-CNN
模態缺失與 Agent 容錯最佳實踐：
  • Agent 容錯：協調者 (Orchestrator) 評估不合格時，啟動重試或轉派其他 Worker。
  • 模態缺失：訓練時採用 Modality-Dropout Aware，隨機遮蔽模態動態調整融合權重。
誘答陷阱： 誤選「盲目用 GAN/生成模型補齊缺失模態」（增加系統錯誤串聯風險）；Agent 失敗直接採用或終止整體任務皆違背容錯原則。
【GenAI 考前口訣】：RAG 怕意圖無關、去噪模糊加步數莫調高 CFG；影像配 CNN、文字配 BERT、時序配 LSTM！

AI 導入規劃、法規合規與安全防禦

00:16:35
導入決策管理 114-2 / 115-1 考題

漸進式部署 (Phased Rollout) 與瓶頸處置

試點選擇原則： 醫療輔助導入應選「風險可控且具代表性的單一專科或特定病房」（切忌直接推急診室或非代表性的夜班）。
放量瓶頸決策 (115-1 題)： 推薦模型放量至 30% 轉換率提升但延遲上升，應「暫停擴量，分析並優化延遲瓶頸後再繼續」。
誘答陷阱： 誤選「立即全面回滾 (Rollback)」（放棄商業價值過猶不及）；誤選「直接推到 100%」（擴大災情）。
資安與隱私合規 法規題型

對抗性攻擊、著作權與聯邦學習

對抗性攻擊 (Adversarial Attack)： 防禦手段為「對抗訓練、資料清洗、規則引擎」。網路防火牆無法防禦（因輸入經由合法 HTTP 通道進入）。
HIPAA 醫療資料不出境： 醫院要借用雲端 GPU 但原始影像不能出院外 $\rightarrow$ 聯邦學習 (Federated Learning)（只傳遞模型參數梯度，資料不出院）。
著作權防禦破局： 預防著作權侵權最根本手段為「訓練資料來源篩選與授權驗證」。差分隱私主要是防個人隱私外洩，無法防著作權侵權。
【導入與合規口訣】：防火牆防不住對抗樣本、原始資料不出境選聯邦學習；有商業價值遇瓶頸先暫停優化莫回滾！

數據準備、指標評估與可解釋性 (XAI)

00:21:33

互動實驗室：混淆矩陣指標即時試算機 (可動態調整觀察指標)

動態調整 TP / FP / FN / TN，即時驗證 F1、Precision、Recall 與 ROC 座標

混淆矩陣輸入 (Confusion Matrix)
TP (真陽性) 抓到的真病人
FP (假陽性 / 誤報) 誤判的健康人
FN (假陰性 / 漏報) 漏抓的真病人
TN (真陰性) 放行的健康人
Precision (精確率) 80.0% $\frac{TP}{TP+FP}$
Recall (TPR / 召回) 88.9% $\frac{TP}{TP+FN}$
F1 Score 0.842 調和平均數
FPR (假陽率) 18.2% $\frac{FP}{FP+TN}$
115-1 考點警告：單一混淆矩陣算不出 AUC！ 因為混淆矩陣僅記錄在特定單一門檻下的分類結果；ROC 曲線與 AUC 必須遍歷所有連續門檻值累積計算面積，因此混淆矩陣無法直接計算 AUC。
數據前處理 114-2 / 115-1

SMOTE、交叉驗證與網格搜尋

SMOTE 過採樣： 不改演算法、僅在資料前處理時解決極端不平衡，透過少數類樣本線性內插產生合成樣本。
調參過擬合預防： 使用交叉驗證 (Cross-Validation)；系統化遍歷所有參數組合是網格搜尋 (Grid Search)。
陷阱辨析： 早期停止 (Early Stopping) 只能防止單次訓練 Epoch 過多，防不了超參數選擇帶來的過擬合。
特徵降維與共線性 核心代數原理

Lasso 正則化 & PCA 線性降維

多重共線性 (Multicollinearity)： 特徵高度相關導致迴歸係數跳動不穩定，解法為採用 Lasso (L1 正則化)，自動將冗餘係數壓為 0。
PCA 計算流程： 特徵標準化 $\rightarrow$ 計算協方差矩陣 $\rightarrow$ 特徵值分解 (Eigendecomposition)。非監督、具封閉解。
陷阱辨析： 誤以為 PCA 能讓 SVM 處理非線性資料（PCA 本質是線性旋轉投影，非線性映射全靠 SVM Kernel Trick）。
分群與 XAI 114-2 / 115-1

DBSCAN 空間索引 & Grad-CAM

DBSCAN 海量資料加速： 不改核心演算法邏輯下提升半徑搜索效率，採用 KD-Tree 或 Ball-Tree 距離空間索引。
XAI 醫療影像熱力圖 (<200ms)： 首選 Grad-CAM（反向傳播梯度快速生成，不需重複採樣）。
陷阱辨析： LIME 與 KernelSHAP 需大量擾動重採樣，運算過慢；TreeSHAP 只適用於決策樹，不適用於 CNN。
【數據與模型口訣】：兼顧 P 與 R 用 F1、混淆矩陣算不出 AUC；共線性用 Lasso；PCA 靠特徵值分解且是線性的；影像即時解釋選 Grad-CAM！

MLOps 漂移監控 114-2 / 115-1 超高頻

漂移辨析、KL 散度與 PSI 指數

核心區分：
  • 資料漂移 (Data Drift)：輸入特徵分佈 $P(X)$ 改變。
  • 概念漂移 (Concept Drift)：特徵與標籤的映射關係 $P(Y|X)$ 改變（例：疫情後深夜網購變成常態，風控誤報率遽增）。
統計偵測指標：
  • KL 散度：衡量兩分佈差異 $D_{KL}(P \parallel Q) = \sum P(x) \log\frac{P(x)}{Q(x)}$。
  • PSI 指數：金融風控常態指標，不需即時標籤即可預警（$\text{PSI} > 0.25$ 須警惕）。
  • 分群監控 (Subgroup)：理賠模型大額異常被整體 RMSE 掩蓋，必須做分組分群監控。
誘答陷阱： 「定期重新訓練」是漂移後的處置對策，不是確認與偵測的方法！
推論架構與加速 115-1 實戰架構題

即時串流、INT8 量化與動態批次

架構選型與加速：
  • 低延遲推薦 (<100ms)：Kafka 串流 + Redis 快取，移除批次資料倉儲以防分鐘級延遲。
  • 邊緣影像推論 (<200ms)：不換硬體下降低單張延遲 $\rightarrow$ INT8 量化 (Quantization)。
  • GPU 閒置空轉：Kernel Launch Overhead 過大，採用動態批次處理 (Dynamic Batching)。
API 與故障隔離：
  • 大型影像上傳推論：使用 POST 請求，資料置於 Request Body（`multipart/form-data`）。
  • 防止微服務連鎖癱瘓：架構層面採用斷路器模式 (Circuit Breaker)。
誘答陷阱： 誤選「批次推論加速單張延遲」（批次只增加吞吐量，單張延遲反而惡化！）；防連鎖故障盲目「擴大執行緒池」（只是延緩塞死）。
【MLOps 考前口訣】：Model Registry 管模型、特徵在庫 (Feature Store)；關係變了是概念漂移；單張要快用 INT8 量化，微服務防雪崩掛斷路器！
