
/*********************************************************************************************************************************************/
// 機器學習簡介
/*********************************************************************************************************************************************/


「機器學習」
讓電腦能夠透過數學模型與統計方法, 從大量資料中學習規律,進而完成分類、預測等任務。
機器學習則是讓電腦自己從資料中「學」出這些規則, 進行自我調整與優化。
在這個過程中, 「特徵工程」是一個重要步驟。

機器學習的四種學習方式：監督、非監督、強化與遷移

/*********************************************************************************************************************************************/
// 監督式學習
/*********************************************************************************************************************************************/
[監督式學習]
訓練資料中包含輸入特徵與對應的正確答案（標籤）。模型的任務就是學會如何將輸入對應到正確的輸出。
舉例來說：
○ 在「貓狗圖片分類」任務中，每張圖片都會標註為「貓」或「狗」，模型透過這些資料學會辨別特徵差異。
○ 在翻譯任務中，每句原文對應一個目標語言的翻譯結果，幫助模型學習語言轉換規則。
○ 在物體追蹤任務中，訓練資料會標示物體的邊界框，讓模型能準確識別並追蹤它的移動。

常見的監督式學習演算法包括線性迴歸、邏輯迴歸、決策樹、隨機森林、支援向量機 (SVM)、深度神經網路等，這些方法仰賴高品質的標註資料來提升準確率與穩定性。

/*********************************************************************************************************************************************/
// 非監督式學習
/*********************************************************************************************************************************************/
「非監督式學習」
特點是資料沒有事先標註，模型需自行從中找出隱藏的結構與規律。

常見的應用包含：

*   資料分群 (Clustering) : 例如將顧客行為資料分群，以利行銷策略調整。
*   資料降維 (Dimensionality Reduction) : 例如用 PCA 方法簡化高維資料，利於視覺化或後續分析。
*   特徵提取 (Feature Extraction) : 例如使用自編碼器從圖片中抽取能代表物件特徵的向量。

經典演算法包含 K-means、DBSCAN、主成分分析 (PCA)、Autoencoder (自編碼器) 等。

⚙️ 提示 「分類」與「分群」雖名稱相似，但「分類」依賴標籤 (監督式)，而「分群」則完全無標籤 (非監督式)。

/*********************************************************************************************************************************************/
// 強化學習
/*********************************************************************************************************************************************/
「強化學習」
是一種基於「試錯」與「回饋」的學習機制，模型會與環境互動，
並根據每次行動所獲得的分數（回饋）來調整行為策略。舉例來說，在賽車遊戲中
正常駕駛可得分、撞牆則扣分，這些分數會反映在模型的獎懲系統中，指引它學會何時該加速、減速或轉彎。

這類學習方式也廣泛應用於 AlphaGo 與 ChatGPT 的訓練過程中。

/*********************************************************************************************************************************************/
// 遷移學習
/*********************************************************************************************************************************************/
「遷移學習」
是一種在已有模型基礎上進行微調的技術，能夠有效降低資料與
訓練成本，特別適合中小企業或缺乏大量資料的應用場景，整個流程分為兩個階段：

O 開源模型訓練：使用龐大的資料集訓練出功能強大的模型（例如：GPT-2、BERT）。
O 模型遷移與微調：將這些模型應用於新任務，並使用少量目標資料進行微調，使模型能更貼近特定應用。

例如：只要用幾百筆客服對話資料，就能將 GPT 模型微調成一個專屬客服 AI，
快速實施應用。目前市面上廣為使用的預訓練模型 LLaMA、Gemma、GPT-2、BERT 等這些模型已被應用於語言理解、圖像辨識、甚至跨模態應用（文字結合影像等）等多種任務。
