02

分類四大核心指標與 $F_\beta$ Score 深度推導

全面剖析公式原理、調和平均數的數學真理與不平衡資料陷阱

準確率 (Accuracy)
$$\text{Acc} = \frac{TP + TN}{N}$$

物理意義：全體樣本中，預測正確的比例。

致命缺陷：當正負樣本比例為 1:99 時，模型只要「全部猜負例」，Accuracy 就高達 99%，但對真目標（正例）完全無預測能力！
精確率 (Precision)
$$\text{Precision} = \frac{TP}{TP + FP}$$

物理意義：又稱「查準率」。模型說是正例的當中，到底有多少是真正的正例？

適用時機：誤報成本極高之場景（如垃圾郵件過濾、人臉解鎖、投資推薦）。
召回率 (Recall)
$$\text{Recall} = \frac{TP}{TP + FN}$$

物理意義：又稱「查全率」或「靈敏度 (Sensitivity)」。真正的正例中，被模型成功抓出了多少？

適用時機：漏報代價極其慘重之場景（如惡性腫瘤篩檢、半導體晶圓致命缺陷、地震警報）。
F1 分數 (F1-Score)
$$F_1 = 2 \cdot \frac{P \cdot R}{P + R} = \frac{2TP}{2TP + FP + FN}$$

物理意義：Precision 與 Recall 的「調和平均數 (Harmonic Mean)」。

為何不用算術平均？若 $P=1.0, R=0.0$，算術平均為 0.5（掩蓋致命缺陷），而調和平均為 0！

進階指標：$F_\beta$ Score（權重偏向調整）

在工程實務中，我們很少能同時將 Precision 與 Recall 都提升到 100%（兩者往往存在 Trade-off 蹺蹺板關係）。 $F_\beta$ 分數允許我們透過參數 $\beta$ 來決定更看重哪一方：

$$F_\beta = (1 + \beta^2) \cdot \frac{\text{Precision} \cdot \text{Recall}}{(\beta^2 \cdot \text{Precision}) + \text{Recall}}$$
$\beta = 1$ ($F_1$ Score)

Precision 與 Recall 權重完全相等，常用於標準評估基準。

$\beta = 2$ ($F_2$ Score)

Recall 權重是 Precision 的 2 倍！極端重視召回（如罕見傳染病快篩）。

$\beta = 0.5$ ($F_{0.5}$ Score)

Precision 權重高於 Recall！極端重視準確性（如搜尋引擎首頁推薦、高頻自動交易）。

03

模型全視角：ROC 曲線、AUC 與 PR 曲線

擺脫單一閾值（Threshold）束縛，全方位評估模型分類排序能力

ROC 曲線與 AUC (Area Under Curve) 受試者工作特徵

軸線定義：

  • 橫軸 (X 軸)：$\text{FPR} = \frac{FP}{FP + TN} = 1 - \text{Specificity}$（偽陽性率）
  • 縱軸 (Y 軸)：$\text{TPR} = \frac{TP}{TP + FN} = \text{Recall}$（真正例率 / 靈敏度）

AUC 數值評級：
• AUC = 1.0：完美分類器（曲線上凸至左上角頂點 (0, 1)）
• AUC = 0.5：隨機盲猜（對角線基準線）
• AUC < 0.5：反向預測（顛倒標籤即變成優良模型）

物理機率意義：若從資料集中隨機挑選 1 個正樣本與 1 個負樣本，模型將「正樣本打分高於負樣本」的機率就是 AUC！

PR 曲線 (Precision-Recall Curve) 極不平衡資料首選

軸線定義：

  • 橫軸 (X 軸)：Recall（召回率 / 查全率）
  • 縱軸 (Y 軸)：Precision（精確率 / 查準率）

iPAS 核心必考對比：何時用 PR 代替 ROC？
在正樣本極少（如 0.1% 信用卡盜刷）時，由於負樣本 TN 數量過於龐大，導致 FPR（分母含 TN）即便誤判很多 FP 仍然極低，使 ROC 曲線呈現虛假繁榮（AUC 高達 0.98）。
此時 PR 曲線因為完全不依賴 TN，能真實揭露極端少數類別的真實表現！

04

連續目標度量：迴歸評估指標 (Regression Metrics)

如何衡量「預測數值」與「真實標籤」之間的殘差距離與變異解釋量

評估指標 數學定義公式 單位量綱 對離群值 (Outliers) 敏感度 最佳適用情境
MAE
平均絕對誤差 		$$\text{MAE} = \frac{1}{n}\sum_{i=1}^n |y_i - \hat{y}_i|$$ 與目標 $y$ 相同 低（具強穩健性） 資料含有較多異常噪聲、不希望少數極端值左右模型時。
MSE
均方誤差 		$$\text{MSE} = \frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2$$ 單位平方 ($y^2$) 極高（平方重罰） 作為神經網路損失函數（平滑且處處可微），欲強力遏制大誤差時。
RMSE
均方根誤差 		$$\text{RMSE} = \sqrt{\text{MSE}}$$ 與目標 $y$ 相同 高（懲罰大誤差） 業界最通用基準，兼具大誤差重度懲罰與物理單位可讀性。
MAPE
平均絕對百分比誤差 		$$\frac{100\%}{n}\sum_{i=1}^n \left|\frac{y_i - \hat{y}_i}{y_i}\right|$$ 百分比 (%) 中等（$y_i$ 接近 0 易爆炸） 向非技術高層簡報、跨不同規模產品（如千元與百萬元商品）對比時。
$R^2$ Score
決定係數 		$$1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$ 無量綱 (常態 0~1) 取決於殘差平方和 衡量模型相較於「盲猜平均值 $\bar{y}$」，多解釋了多少目標變異量。

決定係數 $R^2$ 的本質：變異解釋力

總平方和（$\text{SS}_{\text{tot}}$）代表原始資料本身固有的變異量；殘差平方和（$\text{SS}_{\text{res}}$）代表模型尚未解釋的殘餘誤差：

$$R^2 = 1 - \frac{\text{SS}_{\text{res}}}{\text{SS}_{\text{tot}}} = \frac{\text{SS}_{\text{reg}}}{\text{SS}_{\text{tot}}}$$
  • • $R^2 = 1.0$：模型預測完全命中，殘差為 0。
  • • $R^2 = 0.0$：模型的預測力等同於直接猜資料平均值 $\bar{y}$。
  • • $R^2 < 0.0$：模型預測比直接猜平均值還糟糕！常出現在非線性模型或未擬合截距項時。

校正決定係數 (Adjusted $R^2$)：懲罰灌水特徵

陷阱：多元線性迴歸中，每加入一個新特徵（即便該特徵完全是隨機噪音），普通 $R^2$ 只會上升或持平，絕對不會下降！

$$R^2_{\text{adj}} = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - p - 1} \right]$$

其中 $n$ 為樣本數，$p$ 為自變數特徵數量。
👉 若新增特徵對模型的解釋力貢獻無法抵消其增加的自由度懲罰，Adjusted $R^2$ 便會下降！

實戰指南：AI 應用指標挑選決策心法

依據業務目標、損失成本與資料型態，精準選定最適合的衡量標準

分類問題 (Classification) 挑選決策路徑

1. 資料類別是否大致均衡（如 45% vs 55%）？

• 是 👉 可採用 Accuracy（準確率） 作為初步快評指標。
• 否 👉 嚴禁使用單純 Accuracy！進入第 2 步。

2. 誤報 (FP) 與 漏報 (FN) 哪種代價更慘重？

• 漏報 FN 慘重（如醫療、工安）👉 優先採用 Recall (召回率) 或 $F_2$ 分數。
• 誤報 FP 慘重（如合約垃圾郵件、起訴）👉 優先採用 Precision (精確率) 或 $F_{0.5}$ 分數。
• 兩者皆重要 👉 採用 $F_1$-Score。

3. 需要評估排序能力或決定最佳門檻值？

• 一般樣本分佈 👉 繪製 ROC 曲線 並計算 AUC。
• 極度不平衡資料（如 1:999 罕見故障）👉 必須採用 PR 曲線 (Precision-Recall AUC)！

迴歸問題 (Regression) 挑選決策路徑

1. 是否對大誤差極度敏感（大失誤會破產）？

• 是 👉 採用 RMSE 或 MSE（平方放大懲罰大偏差）。
• 否（異常值只是感測器偶發雜訊）👉 採用 MAE（平均絕對誤差）。

2. 需要跨不同維度/尺度的商品相互比較？

• 需要百分比指標 👉 採用 MAPE（無量綱，非技術主管易懂，但注意目標值不可為 0）。

3. 評估整體模型的變異解釋程度與特徵多寡？

• 單純評估擬合優度 👉 檢視 決定係數 $R^2$。
• 進行多元迴歸特徵篩選時 👉 務必檢視 校正決定係數 (Adjusted $R^2$) 避免虛高。

考點：混淆矩陣與指標計算 iPAS 規劃師考古精選

【Q1】某二元分類模型對 100 筆測試資料進行預測，混淆矩陣結果為：真正例 TP = 40，偽正例 FP = 10，真負例 TN = 40，偽負例 FN = 10。請問該模型的精確率 (Precision) 與召回率 (Recall) 分別為何？

正確答案：(A)
深度解析：
• 精確率 Precision = $\frac{TP}{TP + FP} = \frac{40}{40 + 10} = \frac{40}{50} = 0.80$ (80%)
• 召回率 Recall = $\frac{TP}{TP + FN} = \frac{40}{40 + 10} = \frac{40}{50} = 0.80$ (80%)
故兩者皆為 0.80。
考點：極度不平衡資料評估 iPAS 工程師高頻題

【Q2】在金融信用卡交易盜刷偵測系統中，正樣本（盜刷交易）僅佔總交易量的 0.05%。若要客觀評估模型效能，下列哪一項指標「最不適合」作為主要優化指標？

正確答案：(A)
深度解析：
當正樣本極少時，模型就算盲猜「全部正常」，準確率 Accuracy 依然高達 99.95%，但完全無法抓出任何盜刷交易！因此在極度不平衡場景下，Accuracy 會產生嚴重的效能虛假繁榮，最不適合採用。應改用 PR-AUC、Recall 或 F1 分數。
考點：迴歸評估指標與離群值 iPAS 規劃師必考題

【Q3】某工廠訓練溫度預測模型，資料集中偶爾會因傳感器雜訊而產生極端離群值（Outliers）。若希望評估指標「不易受少數極端離群值過度拉抬牽制」，應優先選用下列何者？

正確答案：(B)
深度解析：
MSE 與 RMSE 採用殘差平方 $(y - \hat{y})^2$，會將極端離群值的誤差放大平方倍數，極度敏感；而 MAE 採用絕對值 $|y - \hat{y}|$（L1 範數），誤差隨偏差線性增長，具有極高的強韌性（Robustness），最不易受少數離群值左右。
考點：決定係數 R 平方定義 iPAS 規劃師精選題

【Q4】關於迴歸分析中的決定係數 $R^2$ (R-squared)，下列敘述何者「錯誤」？

正確答案：(D)
深度解析：
$R^2 = 1 - \frac{\text{SS}_{\text{res}}}{\text{SS}_{\text{tot}}}$。當模型預測效果比直接盲猜平均值 $\bar{y}$ 還要差時（即殘差平方和大於總平方和），$R^2$ 便會出現負數！故選項 (D) 敘述錯誤，為本題正解。

Scikit-Learn 實務評估實作範例

一行程式碼搞定完整分類報告與迴歸指標計算

分類評估 (Classification Report & ROC) python 
from sklearn.metrics import (
    classification_report, 
    confusion_matrix, 
    roc_auc_score, 
    f1_score
)

# y_true: 真實標籤, y_pred: 預測類別 (0 or 1), y_prob: 正類預測機率
cm = confusion_matrix(y_true, y_pred)
print("混淆矩陣:\n", cm)

# 一鍵生成 Precision, Recall, F1 與 Support
print(classification_report(y_true, y_pred, target_names=['正常', '異常']))

# 計算 ROC-AUC 分數
auc = roc_auc_score(y_true, y_prob)
print(f"ROC-AUC Score: {auc:.4f}")
迴歸評估 (MAE, MSE, RMSE, R²) python 
from sklearn.metrics import (
    mean_absolute_error, 
    mean_squared_error, 
    r2_score
)
import numpy as np

# 計算 MAE, MSE, RMSE
mae = mean_absolute_error(y_true, y_pred)
mse = mean_squared_error(y_true, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_true, y_pred)

print(f"MAE: {mae:.2f}")
print(f"RMSE: {rmse:.2f}")
print(f"R² 決定係數: {r2:.4f}")

# 計算 Adjusted R²
n, p = len(y_true), X.shape[1]
adj_r2 = 1 - (1 - r2) * (n - 1) / (n - p - 1)
print(f"Adjusted R²: {adj_r2:.4f}")
