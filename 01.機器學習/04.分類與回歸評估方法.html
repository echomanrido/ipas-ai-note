AI 模型評估指標全景指南

分類 (Classification) & 回歸 (Regression) 理論、推導、實務與互動實驗

一句話極致簡介

分類 (Classification) 衡量的是模型「猜得對不對、各類別抓得準不準」（離散空間的判定機率與混淆懲罰）；

回歸 (Regression) 衡量的是模型「數值預測差多少、偏離真實有多遠」（連續空間的幾何殘差與離散程度）。

評估體系核心原理

任何評估方法本質上都是在構建一個「損失/效用度量泛函 (Loss/Utility Functional)」。分類評估以「混淆矩陣 (Confusion Matrix)」為基石，權衡陽性與陰性的判斷成本（Type I 與 Type II Error）；回歸評估以「殘差向量 $e = y - \hat{y}$」為基石，透過 $L_1$ 範數（平移不變、抗離群值）或 $L_2$ 範數（可導、重度懲罰極端誤差）來捕捉模型的方差與偏差。

維度 分類任務 (Classification) 回歸任務 (Regression)
目標輸出空間 離散標籤 $\mathcal{Y} \in \{0, 1\}$ 或 $\{C_1, \dots, C_k\}$（或類別機率） 連續實數域 $\mathcal{Y} \in \mathbb{R}$ 或區間 $[\alpha, \beta]$
核心基石 混淆矩陣 (Confusion Matrix: TP, FP, TN, FN) 殘差向量 ($e_i = y_i - \hat{y}_i$)
標竿指標 Accuracy, Precision, Recall, F1-Score, ROC-AUC, PR-AUC, Cross-Entropy MAE (平均絕對誤差), MSE, RMSE, MAPE, $R^2$ (決定係數)
閥值敏感性 高度依賴決策閥值 $\tau$ (Threshold)，閥值滑移會聯動 Precision 與 Recall 無閥值概念，直接度量真實曲面與預測曲面的空間幾何間距

分類 (Classification) 與回歸 (Regression) 核心範式全景對照

分類與回歸是機器學習監督式學習的兩大核心任務，因預測目標的數學本質迥異（離散類別 vs 連續數值），必須量身選用不同的指標來精確評估模型泛化表現與業務代價。

分類模型評估方法

預測離散類別

任務目標：將資料指派到正確的類別邊界（如是/否二分類、A/B/C 多類別判定）。

準確率 (Accuracy)
預測正確的樣本數佔總樣本數的比例 $\frac{TP+TN}{\text{Total}}$。適合類別分佈均勻的資料集。
精確度 (Precision)
模型預測為正類的樣本中，實際為正類的比例 $\frac{TP}{TP+FP}$（關注預測是否夠準，防 Type I 誤報）。
召回率 (Recall / Sensitivity)
實際為正類的樣本中，被正確捕捉的比例 $\frac{TP}{TP+FN}$（關注是否有漏掉，防 Type II 漏診）。
F1 分數 (F1-Score)
精確度與召回率的調和平均數 $2 \times \frac{P \times R}{P + R}$，在極端不平衡數據下提供更真實的表現。
混淆矩陣 (Confusion Matrix)
以 $2 \times 2$ 矩陣交叉呈現真實與預測類別，一眼看清模型在哪些類別產生誤判。
ROC 曲線與 AUC 值
描繪隨閾值滾動的 TPR vs FPR 曲線，AUC 介於 0.5 到 1.0 之間，衡量整體辨識排序能力。
交叉熵損失 (Cross-Entropy / Log-Loss)
衡量模型輸出機率分佈與真實標籤之資訊距離 $-\sum y \log(\hat{y})$。嚴厲懲罰高信心度誤判。

回歸模型評估方法

預測連續數值

任務目標：預測具有物理量綱的連續數值（如房價、溫度、營收、負載）。

平均絕對誤差 (MAE)
預測值與實際值差的絕對值平均 $\frac{1}{n}\sum |y_i - \hat{y}_i|$，對極端離群點（Outliers）具備高魯棒性。
均方誤差 (MSE)
殘差平方和平均 $\frac{1}{n}\sum (y_i - \hat{y}_i)^2$，會放大較大誤差的懲罰，處處可導利於梯度下降優化。
均方根誤差 (RMSE)
MSE 的平方根 $\sqrt{\text{MSE}}$，量綱單位與原始目標數據相同，數值越小代表擬合越佳。
決定係數 (R² Score)
代表模型解釋變異的比例 $1 - \frac{SS_{res}}{SS_{tot}}$，數值越接近 1 擬合效果越好（劣於均值模型時可為負數）。
💡 實務指標選型原則： 若業務對極端延遲或巨大預測偏差零容忍（如電力負載、航空預估），首選 RMSE / MSE；若感測器有偶發雜訊異常，採 MAE。

分類 (Classification) 評估指標

01. 一句話簡介：評估模型將樣本對應至離散類別決策邊界時的「決策精準度」與「漏失風險容忍度」。

02. 核心原理：建立於混淆矩陣 (Confusion Matrix) 之上，藉由區分真陽性 ($TP$)、假陽性 ($FP$)、真陰性 ($TN$)、假陰性 ($FN$)，透過不同的錯誤代價權衡（Type I 與 Type II Error），量化判準閾值下的敏感度與準確性。

指標群：Accuracy, Precision, Recall, F1-Score, ROC-AUC, Log-Loss (Cross-Entropy)。

回歸 (Regression) 評估指標

01. 一句話簡介：量化模型連續數值預測值與真實觀測值之間的「殘差離散程度」與「方差解釋能力」。

02. 核心原理：基於殘差分析 (Residual Analysis, $e_i = y_i - \hat{y}_i$)，運用 $L_1$ 範數（絕對誤差中位數趨向）或 $L_2$ 範數（平方誤差均值趨向）衡量預測偏差，並以基準均值模型對比得到可解釋變異佔比 ($R^2$)。

指標群：MAE, MSE, RMSE, MAPE, $R^2$, Adjusted $R^2$。

04. 實務特徵與常見陷阱 (Production Reality)

類別極端不平衡 (99:1)

盲目追求 Accuracy 會帶來災難（全猜多數類即可達 99% Accuracy）。實務必須改用 PR-AUC、Macro/Weighted F1 或鎖定特定 Recall/Specificity。

回歸極端值破壞力 (Outliers)

MSE / RMSE 對離群值以平方放大懲罰，若數據存在感測器雜訊，會拉偏整個預測線；此時實務優先採用 MAE 或 Huber Loss。

MAPE 除以零與不對稱懲罰

MAPE 公式分母為 $y_i$，真實值為 0 或極小時直接無窮大；且對低估（最多罰 100%）與高估（可罰數千%）懲罰不對稱，需採用 sMAPE 或 MASE。

05. 歷史與由來

  • ROC 分析 (1940s)： 源於二戰英美雷達訊號檢驗（Receiver Operating Characteristic），用於辨識螢幕雜波中是否藏有敵機。
  • 最小平方法 (1805)： 高斯 (Gauss) 與勒壤得 (Legendre) 為計算天體軌道誤差而創立，演變為現代 MSE 與回歸分析基石。
  • F-Measure (1979)： 由 C.J. van Rijsbergen 在資訊檢索領域提出，旨在平衡召回（找得全）與精確率（找得準）。

06. 生活化直覺例子

  • 分類：火災警報器。
    高 Recall 優先：哪怕煎牛排油煙造成誤報（Precision 低），也不能漏報真正火警（False Negative 代價慘重）。
  • 回歸：外送到達時間預估。
    MAE 告訴你「平均估差幾分鐘」；RMSE 則大幅懲罰「讓顧客苦等 1 小時以上」的毀滅性體驗。

07. 關鍵工業落地實踐

  • 半導體晶圓瑕疵檢測 (AOI)： 嚴重不平衡數據。鎖定 Recall $\ge 99.8\%$ 前提下追求最高 Precision，避免不良品流出或大量假警報停線。
  • 設備預測性維護 (PdM)： 預估渦輪葉片剩餘壽命 (RUL)。常採用非對稱回歸指標（提前估計壽命提早保養懲罰輕，逾期未檢導致爆損懲罰加權百倍）。

09. 嚴謹數學定義與推導

分類核心矩陣與公式

準確率 (Accuracy) 與 精確率 (Precision)：

$$Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$$
$$Precision = \frac{TP}{TP + FP} \quad , \quad Recall = \frac{TP}{TP + FN}$$

$F_\beta$ Score 泛化調和平均：

$$F_\beta = (1 + \beta^2) \frac{Precision \times Recall}{(\beta^2 \times Precision) + Recall}$$

當 $\beta=1$ 即為標準 $F_1$；$\beta=2$ 時召回率權重高於精確率。

二元交叉熵 (BCE) 與 多元交叉熵 (CCE)：

$$\text{BCE} = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \log(\hat{p}_i) + (1 - y_i) \log(1 - \hat{p}_i) \right]$$
$$\text{CCE} = -\frac{1}{n} \sum_{i=1}^n \sum_{k=1}^K y_{i,k} \log(\hat{p}_{i,k})$$

源自 KL 散度，若模型對真實為 1 的樣本給出 $\hat{p} \to 0$ 的預測，損失將趨向 $+\infty$。

回歸殘差與變異數分解

平均絕對誤差 (MAE) 與 均方根誤差 (RMSE)：

$$MAE = \frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i| \quad , \quad RMSE = \sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2}$$

總平方和分解與決定係數 $R^2$：

$$SS_{tot} = \sum (y_i - \bar{y})^2 = SS_{reg} + SS_{res}$$
$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

調整後 $R^2_{adj} = 1 - \left[\frac{(1 - R^2)(n - 1)}{n - p - 1}\right]$，能有效懲罰無用特徵 $p$ 的增加。

1. Scikit-Learn 綜合評估標準範式 

from sklearn.metrics import (
    classification_report, confusion_matrix, roc_auc_score, log_loss,
    mean_absolute_error, mean_squared_error, r2_score
)
import numpy as np

# --- [分類評估範例] ---
y_true_clf = [1, 0, 1, 1, 0, 1, 0, 0, 1, 0]
y_pred_proba = [0.9, 0.1, 0.8, 0.4, 0.2, 0.85, 0.6, 0.1, 0.75, 0.3]
threshold = 0.5
y_pred_clf = [1 if p >= threshold else 0 for p in y_pred_proba]

print("=== 分類報告 ===")
print(classification_report(y_true_clf, y_pred_clf, digits=4))
print("ROC-AUC:", roc_auc_score(y_true_clf, y_pred_proba))
print("Cross-Entropy (Log-Loss):", log_loss(y_true_clf, y_pred_proba))
print("Confusion Matrix:\n", confusion_matrix(y_true_clf, y_pred_clf))

# --- [回歸評估範例] ---
y_true_reg = np.array([25.0, 31.2, 45.0, 18.5, 60.1])
y_pred_reg = np.array([24.2, 33.0, 42.1, 19.8, 55.4])

mae = mean_absolute_error(y_true_reg, y_pred_reg)
mse = mean_squared_error(y_true_reg, y_pred_reg)
rmse = np.sqrt(mse)
r2 = r2_score(y_true_reg, y_pred_reg)

print("\n=== 回歸指標 ===")
print(f"MAE: {mae:.3f} | MSE: {mse:.3f} | RMSE: {rmse:.3f} | R²: {r2:.3f}")

2. PyTorch GPU 張量直接計算指標 ($R^2$、F1-Score 與 交叉熵) 

import torch
import torch.nn.functional as F

class PyTorchMetrics:
    @staticmethod
    def r2_score(y_pred: torch.Tensor, y_true: torch.Tensor) -> torch.Tensor:
        """GPU 批次計算決定係數 R^2"""
        ss_res = torch.sum((y_true - y_pred) ** 2)
        ss_tot = torch.sum((y_true - torch.mean(y_true)) ** 2)
        return 1.0 - (ss_res / (ss_tot + 1e-8))

    @staticmethod
    def binary_f1_score(y_pred_prob: torch.Tensor, y_true: torch.Tensor, threshold: float = 0.5) -> torch.Tensor:
        """GPU 批次計算二分類 F1-Score"""
        preds = (y_pred_prob >= threshold).float()
        tp = torch.sum((preds == 1.0) & (y_true == 1.0)).float()
        fp = torch.sum((preds == 1.0) & (y_true == 0.0)).float()
        fn = torch.sum((preds == 0.0) & (y_true == 1.0)).float()
        
        precision = tp / (tp + fp + 1e-8)
        recall = tp / (tp + fn + 1e-8)
        return 2.0 * (precision * recall) / (precision + recall + 1e-8)

    @staticmethod
    def binary_cross_entropy(y_pred_prob: torch.Tensor, y_true: torch.Tensor) -> torch.Tensor:
        """GPU 批次計算二元交叉熵 (BCE)"""
        return F.binary_cross_entropy(y_pred_prob, y_true)

# 測試用例
y_p = torch.tensor([0.9, 0.2, 0.8, 0.4])
y_t = torch.tensor([1.0, 0.0, 1.0, 0.0])
print("Torch GPU F1:", PyTorchMetrics.binary_f1_score(y_p, y_t).item())
print("Torch GPU BCE Loss:", PyTorchMetrics.binary_cross_entropy(y_p, y_t).item())
