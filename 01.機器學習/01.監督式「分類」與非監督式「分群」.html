開學前教務處已經給了老師一張名冊，每位學生頭上早就貼好標籤（如性別、文理組）。老師訂下明確邊界：「男生坐左邊、女生坐右邊（決策超平面）」。

今天新來了一位轉學生，老師看他名冊上的標籤（是男生），直接指派他：「去左邊坐！」。

🧩 核心特徵：自主聚集，完全依據特徵相似度（頻率投緣、距離近）自然成群，事前無標準答案。

分類演算法 (Classification)

「依據已知標籤尋找最佳決策邊界面，預測未知樣本的離散類別。」

核心任務：學習映射函數 $f: \mathcal{X} \to \mathcal{Y}$，使經驗風險與正規化懲罰最小化。
主要評估指標：Accuracy, Precision, Recall, F1-Score, ROC-AUC, 混淆矩陣。
經典演算法：Logistic Regression, SVM, 決策樹, 隨機森林, XGBoost, CNN。
非監督式學習 (Unsupervised) 無標籤探索 (No Labels)

分群演算法 (Clustering)

「依據特徵相似度或空間距離，探索內在結構並聚集高內聚性子群。」

核心任務：最小化群內變異 (WCSS) 同時最大化群間分離度，無需預先定義答案。
主要評估指標：輪廓係數 (Silhouette Score), 肘部法 (Elbow Method), 戴維斯-鮑丁 (DBI)。
經典演算法：K-Means, DBSCAN (密度分群), 階層分群 (Hierarchical), GMM 高斯混合模型。

K-NN (最近鄰分類) vs K-Means (K-平均分群)

雖然名字都帶有「K」，但在學習範式、K 的本質意涵、計算複雜度與邊界產生機制上有著根本性的天壤之別。

K-NN: 惰性學習 | K-Means: 積極學習
K-NN 的生活比喻：「初來乍到，出門問附近鄰居」

你剛搬進一個新社區，不知道自己屬於哪一個投票里。你平時不用特地去背社區地圖（平時不訓練，惰性學習）。

要投票那天，你走出門看距離你最近的 $K=5$ 位鄰居。若有 4 位說他們在「仁愛里」，只有 1 位說在「和平里」，少數服從多數，你就認定自己也是「仁愛里」。

📌 K 的涵義：你參考的「鄰居人數」（$K=5$ 位鄰居）。
K-Means 的生活比喻：「連鎖超商尋找最佳展店中心」

某總部要在一個居民隨機散落的城市開設 $K=3$ 家分店：

  1. 初始：先隨意選 3 個十字路口擺設攤位。
  2. 指派 (E步)：全市居民各自走到距離自己最近的攤位消費。
  3. 更新 (M步)：三位店長統計今天服務的全部顧客住址，將店面搬遷到所有顧客的「幾何中心點」。
📌 K 的涵義：總共要在這座城市開幾家「分店／群集」（$K=3$ 個群心）。
零售商店加碼比喻：超商無標籤商品結帳 (K-NN) vs 大賣場貨架分區規劃 (K-Means)
K-NN 商店比喻：無條碼未知零食的「鄰近比價」

顧客拿了一包標籤脫落的未知進口零食到櫃檯結帳。店員不需要去考食品檢驗證書（不用預先訓練模型），而是直接轉身在已知貨架上找包裝重量、尺寸材質與它最相近的 $K=3$ 包零食。

若 3 包中有 2 包是「進口洋芋片（60元）」，只有 1 包是「普通餅乾（30元）」，多數決判定這包也是「進口洋芋片」。

💡 本質：有客人問了才拿尺比對貨架上已建檔的商品（$K$ 是比對的相鄰商品件數）。
K-Means 商店比喻：新開大賣場規劃「$K$ 大展示貨架區」

倉庫新進了 3,000 件完全沒有分類標籤的雜貨。老闆要求店長必須在店面規劃出 $K=3$ 個主要陳列貨架：

店長先隨意在賣場東、南、北邊立 3 個架子；接著將性質相近的商品擺到最近的架子（E 步指派）；然後看每個架子累積的商品平均特性，將貨架移動到商品特性的幾何重心（M 步更新），反覆調整後自然劃分出「飲料零食區」、「衛浴日用品區」與「五金工具區」。

💡 本質：從未分類雜貨中自主凝聚出群聚（$K$ 是店長預先規定的貨架專區數）。
校園教室加碼比喻：轉學生入座觀察鄰近同學 (K-NN) vs 全班動態分組換座位 (K-Means)
K-NN 教室比喻：轉學生挑空位「看鄰居社團認同」

開學中途來了一位轉學生，隨便挑了一張空桌子坐下。班長想預測他會加入什麼社團，不需要全班重新大風吹調座位（惰性學習，平時不訓練）。

班長直接看坐在他周圍最靠近的 $K=5$ 位同學：若有 4 位是「熱音社」，只有 1 位是「天文社」，根據少數服從多數原則，班長直接推定這名轉學生也是「熱音社圈子」。

🎓 K 的涵義：轉學生周圍被納入投票的「鄰座同學人數」（$K=5$ 位鄰居）。
K-Means 教室比喻：全班專案分組「動態換座位直至收斂」

導師要在教室將 40 位同學劃分成 $K=4$ 個專案小組，且事先沒有任何既定標籤：

  1. 初始：老師先在教室四個角落隨意放 4 張小組長桌（初始群心）。
  2. 指派 (E 步)：所有同學搬椅子坐到離自己目前最近的那張組長桌旁。
  3. 更新 (M 步)：各組坐定後，大家合力把組長桌搬到「該組所有同學椅子的正中心點（幾何重心）」。
  4. 迭代：桌子換位置後，有些同學發現別組桌子反而更近，於是起身跳槽換桌……反覆重排直到「全班再也沒有人需要更換座位」為止！
🎓 K 的涵義：導師預先規定全班要分成幾組的「組數／群心數目」（$K=4$ 個組別）。
比較維度 K-NN (K-Nearest Neighbors) K-Means Clustering
1. 學習範式 (Paradigm) 監督式學習 (Supervised)：訓練集必須具備 Ground Truth 標籤。 非監督式學習 (Unsupervised)：資料純由特徵組成，無預設標籤。
2. 「K」的數學意涵 鄰居數量 (Number of Neighbors)：待測點周圍要參考的最相近樣本數 $K$。 群集數量 (Number of Clusters)：欲將全體資料劃分出的群心數目 $K$。
3. 訓練階段 (Training Phase) 惰性學習 (Lazy Learning)：訓練時間為 $\mathcal{O}(1)$，基本上僅將資料存入記憶體，不預先建構顯式模型。 積極學習 (Eager Learning)：透過 EM 迭代更新，尋找全域最優群心座標，訓練耗時較長。
4. 推論/預測階段 (Inference) 極慢 $\mathcal{O}(N \cdot D)$：每個新樣本需與所有訓練點計算距離（需透過 KD-Tree / Ball-Tree 提速）。 極快 $\mathcal{O}(K \cdot D)$：新樣本僅需與 $K$ 個群心比對距離即可判定所屬群。
5. K 值調整之偏差/方差權衡 • $K$ 太小（如 $K=1$）：高方差（Variance）、易受噪音干擾、過擬合（Overfitting）。
• $K$ 太大：高偏差（Bias）、邊界過度平滑、欠擬合。 		• $K$ 太小：群內平方和（WCSS）過大、未能捕捉細分結構。
• $K$ 太大（極端 $K=N$ 時 WCSS=0）：過度分割失去聚合意義（常用手肘法決定）。
6. 特徵標準化之必要性 絕對必要！數值範圍大的維度將完全主導歐氏距離計算。 絕對必要！否則群心將被方差大的維度拉偏形成扁平球體。
深度剖析 • 核心觀念澄清

K-NN 和 K-Means 都是用「距離」評估嗎？

答案是：是的，兩者都嚴重依賴距離度量！但距離在兩者中所扮演的「數學角色、目的與可替換性」有著本質上的巨大差異。

幾何度量空間
Metric Space Dynamics
K-NN 中的距離角色 局部拓撲鄰域 (Local Neighbor)

距離是用來「篩選最近投票鄰居」的排序工具

在 K-NN 中，距離只是一個「相似度排序機制」。演算法計算待測點與全體樣本的距離，目的只是為了選出前 $K$ 個最近點（Top-$K$）。

✔ 距離種類彈性高： 可任意更換為曼哈頓距離（L1）、切比雪夫距離（$L_\infty$）、馬氏距離（Mahalanobis，考慮協方差）、甚至文字處理常見的餘弦相似度（Cosine Similarity）。
✔ 距離可以直接做加權投票： 距離越近的鄰居話語權越大，權重常設為 $w_i = \frac{1}{d(\mathbf{x}, \mathbf{x}_i) + \epsilon}$。
K-Means 中的距離角色 全域損失函數 (Objective Loss)

距離被嚴格綁定在「平方誤差和 (WCSS)」最佳化中

在標準 K-Means 中，距離不僅僅是指派依據，它直接構成了演算法的目標損失函數：$J = \sum \|\mathbf{x}_i - \boldsymbol{\mu}_k\|_2^2$。

⚠ 經典 K-Means 嚴格限定「歐氏距離平方」： 因為只有在歐式距離平方下，對群心求偏導 $\frac{\partial J}{\partial \boldsymbol{\mu}_k}=0$ 才能保證群心剛好是「算術平均數 (Mean)」！
⚠ 換了距離，演算法就必須改名： 若改用曼哈頓距離（L1），群心必須改求「中位數 (Median)」，此時演算法稱為 K-Medians；若使用任意非歐度量，則演算法可能無法保證數學收斂。
距離度量本質重點對照表（iPAS / 考試必考）
評估維度 K-NN (最近鄰分類) K-Means (K-平均分群)

底層代數與最佳化推導

核心演算法數學推導

從極大似然估計 (MLE) 到期待最大化 (EM) 思想：深入理解邊界面如何旋轉與群心如何漂移。

分類：邏輯迴歸損失與梯度更新

凸優化

1. 機率假設 (Sigmoid Activation)：

$$\hat{y}_i = \sigma(z_i) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x}_i + b)}}$$

2. 交叉熵損失函數 (Cross-Entropy Loss)：

依據白努力分佈概似函數，取負對數求得凸損失函數：

$$J(\mathbf{w}, b) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln \hat{y}_i + (1 - y_i) \ln(1 - \hat{y}_i) \right]$$

3. 權重梯度偏微分 (Gradient Calculation)：

利用鏈式法則 $\frac{\partial J}{\partial \mathbf{w}} = \frac{\partial J}{\partial \hat{y}} \frac{\partial \hat{y}}{\partial z} \frac{\partial z}{\partial \mathbf{w}}$：

$$\nabla_{\mathbf{w}} J = \frac{1}{N} \sum_{i=1}^N (\hat{y}_i - y_i) \mathbf{x}_i$$

更新法則：$\mathbf{w} \leftarrow \mathbf{w} - \alpha \nabla_{\mathbf{w}} J$（實驗室單步模擬即在計算此向量）。

分群：K-Means 目標函數與群心均值推導

EM 啟發式

1. 群內平方誤差和 (WCSS 目標函數)：

$$J(S, \boldsymbol{\mu}) = \sum_{k=1}^K \sum_{\mathbf{x}_i \in S_k} \|\mathbf{x}_i - \boldsymbol{\mu}_k\|_2^2$$

2. Step E (Expectation)：群集分配 (Voronoi 劃分)

固定群心 $\boldsymbol{\mu}_k$，將各點指派至歐氏距離最近之群心：

$$S_k^{(t)} = \left\{ \mathbf{x}_i : \|\mathbf{x}_i - \boldsymbol{\mu}_k^{(t)}\|^2 \le \|\mathbf{x}_i - \boldsymbol{\mu}_j^{(t)}\|^2, \forall j \right\}$$

3. Step M (Maximization)：更新群心 (幾何質心)

固定群集歸屬，對 $\boldsymbol{\mu}_k$ 求偏導 $\frac{\partial J}{\partial \boldsymbol{\mu}_k} = 0$，得到新群心：

$$\boldsymbol{\mu}_k^{(t+1)} = \frac{1}{|S_k^{(t)}|} \sum_{\mathbf{x}_i \in S_k^{(t)}} \mathbf{x}_i$$

每次迭代皆保證目標函數 $J$ 單調非遞增，並於有限步數內收斂至局部最優。

K-NN：距離度量、加權多數決與維度災難推導

非參數法 (Non-parametric)

1. 閔可夫斯基距離 (Minkowski Distance)

特徵向量 $\mathbf{x}, \mathbf{z} \in \mathbb{R}^D$ 之間的泛化距離定義：

$$D_p(\mathbf{x}, \mathbf{z}) = \left( \sum_{d=1}^D |x_d - z_d|^p \right)^{\frac{1}{p}}$$

$p=1$ 為曼哈頓距離（L1）；$p=2$ 即為標準歐氏距離（L2）。

2. 距離加權多數決 (Distance-Weighted Voting)

為防止遠處鄰居稀釋投票品質，賦予距離倒數之權重 $w_i$：

$$\hat{y} = \arg\max_{c \in \mathcal{Y}} \sum_{i \in \mathcal{N}_K(\mathbf{x})} \frac{1}{d(\mathbf{x}, \mathbf{x}_i) + \epsilon} \cdot \mathbb{I}(y_i = c)$$

距離越近的鄰居，在類別多數決判定中享有更重的話語權。

3. 維度災難 (Curse of Dimensionality)

當特徵維度 $D \to \infty$ 時，高維超立方體空間極其稀疏：

$$\lim_{D \to \infty} \frac{\text{dist}_{\max} - \text{dist}_{\min}}{\text{dist}_{\min}} \to 0$$

所有樣本點間的相對距離趨向一致，導致以「距離」為判斷核心之 K-NN 徹底失效，必須先降維。

import torch
import torch.nn as nn
import torch.optim as optim

# 1. 定義二元分類模型 (單層類神經網路 + Sigmoid 激活函數)
class LogisticRegression(nn.Module):
    def __init__(self, input_dim=2):
        super(LogisticRegression, self).__init__()
        self.linear = nn.Linear(input_dim, 1)

    def forward(self, x):
        return torch.sigmoid(self.linear(x))

# 2. 模擬二維特徵資料集 (N=100)
torch.manual_seed(42)
X = torch.randn(100, 2)
# 真實超平面：x1 + x2 > 0 為 1，反之為 0
y = (X[:, 0] + X[:, 1] > 0).float().unsqueeze(1)

# 3. 初始化模型、二元交叉熵損失 (BCELoss) 與隨機梯度下降 (SGD)
model = LogisticRegression(input_dim=2)
criterion = nn.BCELoss()
optimizer = optim.SGD(model.parameters(), lr=0.1)

# 4. 梯度下降訓練迴圈
for epoch in range(1, 101):
    model.train()
    optimizer.zero_grad()
    
    predictions = model(X)
    loss = criterion(predictions, y)
    loss.backward()  # 反向傳播計算 dLoss/dw 與 dLoss/db
    optimizer.step() # 參數更新: w <- w - lr * grad
    
    if epoch % 20 == 0:
        predicted_cls = (predictions >= 0.5).float()
        acc = (predicted_cls == y).float().mean() * 100
        print(f"Epoch {epoch:03d} | Loss: {loss.item():.4f} | Accuracy: {acc:.1f}%")

print("訓練完成！學得之權重向量 w:", model.linear.weight.data.numpy())
import torch

def pytorch_kmeans(X, k=3, max_iters=30, tol=1e-4):
    """
    純 PyTorch 張量廣播實作之向量化 K-Means 演算法
    X: (N, D) 特徵矩陣
    """
    n_samples, n_features = X.shape
    
    # 隨機選取 K 個點作為初始群心
    random_idx = torch.randperm(n_samples)[:k]
    centroids = X[random_idx].clone()

    for it in range(max_iters):
        # 1. Step E: 計算各點至 K 個群心的歐氏距離平方
        # 廣播維度: (N, 1, D) - (1, K, D) -> (N, K, D) -> sum -> (N, K)
        dist_sq = torch.sum((X.unsqueeze(1) - centroids.unsqueeze(0)) ** 2, dim=2)
        cluster_labels = torch.argmin(dist_sq, dim=1) # 指派給最近群心

        # 2. Step M: 依據指派結果重新計算幾何質心
        new_centroids = torch.stack([
            X[cluster_labels == c].mean(dim=0) if (cluster_labels == c).sum() > 0 else centroids[c]
            for c in range(k)
        ])

        # 3. 檢查收斂條件 (群心漂移量小於閥值)
        shift = torch.norm(new_centroids - centroids)
        if shift < tol:
            print(f"K-Means 在第 {it+1} 次迭代成功收斂！")
            break
        centroids = new_centroids

    # 計算最終 WCSS (群內平方和)
    wcss = sum(torch.sum((X[cluster_labels == c] - centroids[c]) ** 2).item() for c in range(k))
    return cluster_labels, centroids, wcss

# 建立 3 簇合成特徵資料
X_data = torch.cat([torch.randn(50, 2) + 2.5, torch.randn(50, 2) - 2.5, torch.randn(50, 2)])
labels, centers, final_wcss = pytorch_kmeans(X_data, k=3)
print("收斂群心坐標:\n", centers.numpy(), "\n最終 WCSS:", final_wcss)
import torch

def pytorch_knn_predict(X_train, y_train, X_test, k=5):
    """
    純 PyTorch 張量廣播實作之全向量化 K-NN 分類器 (支援 GPU 加速)
    X_train: (N_train, D)
    y_train: (N_train,) 離散標籤
    X_test:  (N_test, D)
    """
    # 1. 利用廣播計算全樣本歐氏距離矩陣: ||x - z||^2 = ||x||^2 + ||z||^2 - 2 x z^T
    # 維度: (N_test, 1, D) - (1, N_train, D) -> (N_test, N_train, D)
    diff = X_test.unsqueeze(1) - X_train.unsqueeze(0)
    dist_matrix = torch.norm(diff, dim=2, p=2) # 形狀: (N_test, N_train)

    # 2. 沿 train 維度選取最小的 K 個距離索引 (topk)
    topk_dists, topk_indices = torch.topk(dist_matrix, k=k, dim=1, largest=False)

    # 3. 取得 K 個最近鄰居的真實標籤
    neighbor_labels = y_train[topk_indices] # 形狀: (N_test, k)

    # 4. 多數決投票 (Majority Voting)
    predictions, _ = torch.mode(neighbor_labels, dim=1)
    return predictions, topk_dists, topk_indices

# 建立模擬二維訓練資料集 (N=200) 與待測點 (N_test=5)
torch.manual_seed(42)
X_train = torch.randn(200, 2)
