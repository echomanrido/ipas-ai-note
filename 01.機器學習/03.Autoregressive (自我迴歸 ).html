01. 權威定義 (AWS / 統計與機器學習) Autoregressive (簡稱 AR)

「一種利用資料自身的過去數值來預測未來或當前數值的統計與機器學習方法。」

更通俗地說：「以自己過去的輸出，作為自己未來的輸入，一步一步遞推生成整個序列。」

⚖️ 核心概念釐清 Autoregressive (自迴歸) vs. Regressive (一般/標準迴歸)
Auto (自我) 的本質差異
⚡
【一句話秒懂兩者本質差異】：

「一般迴歸 (Regressive) 是用別人的特徵預測自己（看坪數預測房價）；
而 自迴歸 (Autoregressive) 則是用過去的自己預測未來的自己（看昨天今天氣溫推測明天氣溫）。」

一般迴歸 (Regressive / Standard Regression) 跨維度特徵映射
輸入變數來源： 來自外部不同維度的特徵自變數 $X$（如：坪數、屋齡、利率）。
數學形式：
$$Y = f(X_1, X_2, \dots, X_k) + \epsilon$$
樣本假設：通常假設樣本間獨立同分佈（i.i.d.），樣本之間無時間依賴與因果回饋。
💡 直觀比喻：「借他山之石」—— 依據外部的多個指標來推測未知結果（例如：看體重與年齡預測血壓）。
自迴歸 (Autoregressive / AR) 時間軸自我反饋
輸入變數來源： 來自目標變數自己過去的歷史數值 $Y_{t-1}, Y_{t-2}, \dots$（時間滯後 Lag）。
數學形式：
$$Y_t = f(Y_{t-1}, Y_{t-2}, \dots, Y_{t-p}) + \epsilon_t$$
樣本假設：高度依賴序列的自我相關性（Autocorrelation），形成「當前輸出即下一步輸入」的閉環。
💡 直觀比喻：「以己為鑑、滾雪球」—— 依據自己剛講過的話接下一句；用前幾天的氣溫推演明天的氣溫。
📌 一句話辨析： 一般迴歸研究的是「變數與外部變數間的因果映射」；自迴歸研究的是「系統隨時間演化與自身的歷史延續性」。
02. 核心數學原理 (Core Principle)

核心在於將序列聯合機率分佈依據條件機率鏈式法則（Probability Chain Rule）做嚴格的自因果分解：

$$P(X_1, X_2, \dots, X_T) = \prod_{t=1}^{T} P(X_t \mid X_1, X_2, \dots, X_{t-1}) = \prod_{t=1}^{T} P(X_t \mid X_{\lt t})$$

在每一個時間步 $t$，模型只能觀察過去已知狀態 $X_{\lt t}$，估計當前狀態 $X_t$ 的條件機率，經採樣或取最大值後將新結果追加進歷史序列中，形成循環遞歸回路。

📘 觀念剖析 什麼是自我迴歸？（三大核心基石）
1 基本概念 (Basic Concept)

序列中的當前值是過去值的函數。 它假設現在的狀態並非憑空產生，而是深受過去一段時間內的歷史數值積累與影響。

$X_t = f(X_{t-1}, X_{t-2}, \dots, X_{t-p}) + \epsilon_t$
2 運作方式 (Operational Flow)

就像文字接龍或預測天氣一樣，模型會根據先前已經發生或生成的內容，一步步預測下一個組件或單字。

[輸入: 天氣晴] $\rightarrow$ [預測: 氣溫高] $\rightarrow$ [反饋輸入] $\rightarrow \dots$
3 核心假設 (Core Hypothesis)

變數在不同時間點之間具有相關性。 模型正是在數學上挖掘並利用這些自我相關性（Autocorrelation, 自相關）來建立穩固的迴歸關係。

$\text{Cov}(X_t, X_{t-k}) \neq 0$（存在跨期依賴）

🤖 人工智慧與生成式模型 (Generative AI & LLMs)

離散 Token 預測

許多大型語言模型（LLM，如 GPT、Llama）採用自迴歸方式，逐字生成語句，使後續生成的文字能夠嚴密依賴前面的輸出。

生成機制特點：
  • Next-Token Prediction：從詞表中計算幾萬個 token 的條件機率分佈。
  • 因果遮罩 (Causal Mask)：阻絕未來訊息洩漏，確保嚴格的自迴歸約束。
  • KV Cache：儲存歷史注意力張量，解決長文本推論的算力浪費。
05. 歷史由來 (Origins & Evolution)

從太陽黑子預測到全能 GPT

1927 年

George Udny Yule 提出 AR 模型

為了解決太陽黑子週期的隨機波動問題，統計學家 Yule 首次構想出「用系統過去的觀測值線性組合來預測當前值」，奠定統計自迴歸 AR($p$) 之基石。

1970 年

Box & Jenkins 時間序列體系

將 AR 與移動平均（MA）及差分整合（I）結合，確立 ARIMA 框架，支配計量經濟學數十年。

2016 年

神經自迴歸爆發 (WaveNet & PixelCNN)

DeepMind 採用因果擴張卷積（Causal Dilated Conv），逐取樣點生成高保真人類語音，證明神經自迴歸的驚人生成潛力。

2018 年~至今

Transformer Causal Decoder 統治生成式 AI

OpenAI 的 GPT 系列捨棄 BERT 的雙向遮蔽式編碼，專注於 Next-Token Autoregressive 預訓練，引爆現代 LLM 與通用人工智慧（AGI）浪潮。

04. 實務特徵 (Practical Characteristics)

工程實踐中的優勢與核心代價

訓練完全並行化

訓練期透過 Teacher Forcing 與因果注意力遮罩（Causal Mask），一次性輸入整段文本同時計算所有 token 損失，算力利用率極高。

推論無法時間並行

生成時每產出一個 token 必須等上一步完成，每次推理需從顯存載入權重，屬於典型記憶體頻寬受限（Memory-bound）。

曝光偏差 (Exposure Bias)

模型訓練時永遠看正確前文（Ground Truth），推論時卻看自己過去產出的可能錯誤，導致小錯誤隨序列滾動放大。

依賴 KV Cache 技術加速

若不儲存前文的 Key 與 Value 張量，生成長度為 $N$ 的句子將產生 $\mathcal{O}(N^2)$ 的自注意力重複計算，需耗費額外顯存。

09. 數學推導 (Mathematical Derivations)

自迴歸的三大數學基石：機率分解、時序平穩性與神經損失函數

一、聯合機率的因果分解（Autoregressive Factorization）

對於任意隨機變數序列 $X = (x_1, x_2, \dots, x_T)$，由條件機率乘法定則，其聯合分佈恆等於條件機率之連乘：

$$P(x_1, x_2, \dots, x_T) = P(x_1) \cdot P(x_2 \mid x_1) \cdot P(x_3 \mid x_1, x_2) \cdots P(x_T \mid x_1, \dots, x_{T-1}) = \prod_{t=1}^T P(x_t \mid x_{\lt t})$$

自迴歸模型將「建模高維聯合分佈」的困難問題，轉化為建模 $T$ 個「一維條件機率分佈」的監督學習問題。

二、古典統計 AR(p) 模型與自我相關（Autocorrelation）推導

階數為 $p$ 的古典自迴歸模型定義為過去 $p$ 個時間點的線性組合加上白噪聲：

$$X_t = c + \sum_{i=1}^p \phi_i X_{t-i} + \epsilon_t, \quad \epsilon_t \sim \text{WN}(0, \sigma^2)$$
💡 深入推導：以一階 AR(1) 模型 $X_t = \phi X_{t-1} + \epsilon_t$ 為例

逐步遞推替換：

$$X_t = \phi(\phi X_{t-2} + \epsilon_{t-1}) + \epsilon_t = \sum_{k=0}^{\infty} \phi^k \epsilon_{t-k}$$

計算方差：

$$\text{Var}(X_t) = \text{Var}\left(\sum_{k=0}^\infty \phi^k \epsilon_{t-k}\right) = \sigma^2 \sum_{k=0}^\infty \phi^{2k} = \frac{\sigma^2}{1 - \phi^2}$$

若要保證方差有限且不隨時間發散（滿足弱平穩條件），幾何級數必須收斂，即： 弱平穩充要條件：$|\phi| \lt 1$（特徵方程的根位於複數單位圓外）。 自相關係數（ACF）呈現指數衰減：$\rho_k = \phi^k$。

🎛️ 互動推演：AR(1) 係數 $\phi$ 數值平穩性試驗台

拖動係數 $\phi$，觀察序列是維持平穩震盪、還是發生指數型發散或單位根隨機遊走。

平穩序列 (|φ| < 1)

白噪聲標準差 $\sigma$: 1.0

三、神經自迴歸模型 (LLM) 的最佳化目標函數

現代 LLM（如 GPT）將每個 token 的預測視為多分類問題，詞表大小為 $V$。目標是最小化整個語料庫的負對數似然（Negative Log-Likelihood, NLL），即交叉熵損失：

$$\mathcal{L}(\theta) = - \sum_{t=1}^T \log P_\theta(x_t \mid x_{\lt t}) = - \sum_{t=1}^T \log \left( \frac{\exp(z_{t, x_t} / \tau)}{\sum_{j=1}^V \exp(z_{t, j} / \tau)} \right)$$

其中 $z_{t}$ 為 Transformer 解碼器在第 $t$ 步輸出的未正規化 Logits，$\tau$ 為溫度係數。因果遮罩矩陣（Causal Mask）在計算注意力權重矩陣時，強制將 $j \gt i$ 處的值設為 $-\infty$，確保數學上嚴格滿足自迴歸條件約束。

11. Python / PyTorch 實作工程

最小自迴歸 Transformer Decoder 引擎 (含 Causal Mask 與採樣迴圈)

autoregressive_transformer.py PyTorch 2.x 
import torch
import torch.nn as nn
import torch.nn.functional as F

class MiniAutoregressiveDecoder(nn.Module):
    """
    極簡因果自迴歸解碼器（GPT 架構原型）
    展示 Causal Mask 如何迫使注意力只能看見過去的 Token
    """
    def __init__(self, vocab_size: int = 1000, d_model: int = 64, n_heads: int = 4, max_len: int = 128):
        super().__init__()
        self.d_model = d_model
        self.token_emb = nn.Embedding(vocab_size, d_model)
        self.pos_emb = nn.Embedding(max_len, d_model)
        
        # 單層 Decoder Transformer
        self.attn = nn.MultiheadAttention(embed_dim=d_model, num_heads=n_heads, batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_model * 2),
            nn.ReLU(),
            nn.Linear(d_model * 2, d_model)
        )
        self.ln1 = nn.LayerNorm(d_model)
        self.ln2 = nn.LayerNorm(d_model)
        self.head = nn.Linear(d_model, vocab_size)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: [batch_size, seq_len] 包含已生成的 tokens
        """
        B, T = x.size()
        positions = torch.arange(0, T, device=x.device).unsqueeze(0)
        
        # 1. 產生因果注意力遮罩 (Causal Mask)
        # 遮蔽未來資訊：上三角矩陣設為 -inf，防止時間穿越
        causal_mask = torch.triu(torch.full((T, T), float('-inf'), device=x.device), diagonal=1)

        # 2. Embedding + Positional Encoding
        h = self.token_emb(x) + self.pos_emb(positions)
        
        # 3. Masked Multi-Head Attention
        norm_h = self.ln1(h)
        attn_out, _ = self.attn(norm_h, norm_h, norm_h, attn_mask=causal_mask)
        h = h + attn_out
        
        # 4. Feed Forward Network
        h = h + self.ffn(self.ln2(h))
        
        # 5. Output Logits: [batch_size, seq_len, vocab_size]
        logits = self.head(h)
        return logits

    @torch.no_grad()
    def autoregressive_generate(self, prompt_tokens: torch.Tensor, max_new_tokens: int = 10, temperature: float = 0.8, top_k: int = 5):
        """
        核心演算法：Step-by-Step 自迴歸循環生成邏輯
        """
        self.eval()
        curr_seq = prompt_tokens.clone() # [1, prompt_len]

        print(f"[*] 初始 Prompt Tokens: {curr_seq.tolist()[0]}")
        for step in range(max_new_tokens):
            # 1. 前向傳播獲取當前完整序列的 Logits
            logits = self.forward(curr_seq)
            
            # 2. 僅取出最後一個時間步的預測 (Next-Token Logits)
            next_token_logits = logits[:, -1, :] / max(temperature, 1e-5)
            
            # 3. Top-k 截斷採樣
            if top_k is not None:
                v, _ = torch.topk(next_token_logits, min(top_k, next_token_logits.size(-1)))
                next_token_logits[next_token_logits < v[:, [-1]]] = -float('Inf')
            
            # 4. Softmax 計算條件機率分佈
            probs = F.softmax(next_token_logits, dim=-1)
            
            # 5. 依機率多項分佈隨機採樣出下一個 Token
            next_token = torch.multinomial(probs, num_samples=1) # [1, 1]
            
            # 6. 【關鍵自迴歸迴路】：將新生成的 Token 追加至序列尾端
            curr_seq = torch.cat([curr_seq, next_token], dim=1)
            print(f" -> Step {step+1:02d}: 生成 Token ID [{next_token.item()}], 當前總長度: {curr_seq.size(1)}")

        return curr_seq

if __name__ == "__main__":
    # 測試最小自迴歸生成
    model = MiniAutoregressiveDecoder()
    prompt = torch.tensor([[101, 45, 88]]) # 假設 Prompt
    final_output = model.autoregressive_generate(prompt, max_new_tokens=6, temperature=0.7, top_k=3)
    print(f"\n[+] 最終自迴歸生成序列: {final_output.tolist()[0]}")
