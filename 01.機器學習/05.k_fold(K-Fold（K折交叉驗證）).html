K-FOLD
01. 一句話簡介

K-Fold（K折交叉驗證）就是把資料平均切成 K 份，輪流拿其中 1 份當驗證集、其餘 K-1 份當訓練集，重複 K 次並將結果平均，來公平且穩定地評估模型好壞。

02. 核心原理

將全體訓練樣本隨機劃分為 $K$ 個大小相等的互斥子集（Folds）。依序輪流以其中的 1 個 Fold 作為驗證集（Validation Set），其餘 $K-1$ 個 Folds 合併作為訓練集（Training Set），總共進行 $K$ 輪獨立的模型訓練與驗證。最後將 $K$ 次的驗證指標求平均，作為模型在未知資料上泛化能力（Generalization Ability）的無偏估計。

06. 生活化例子

這就像高中生為了準備大考，把一本「500 題的題庫」完整刷完 5 遍

你把這本 500 題的題庫平均分成 5 個單元（每單元 100 題，$K=5$），每次模擬考的備戰節奏如下：

第一輪 模擬考

自習讀第 1 到 4 單元（訓練集 400 題），保留第 5 單元作為盲測試卷（驗證集 100 題）。

第二輪 輪替考卷

改讀第 1、2、3、5 單元，換拿第 4 單元作為本次模擬考題。

依此類推（5 輪） 總算無偏

輪流考過每一個單元。算出的 5 次模擬考平均分數，最精準、毫無偏見地反映你的真實應考實力！

傳統一試定生死 (Train/Test Split) vs K-Fold 交叉驗證

本質結構差異讓 K-Fold 成為檢驗真實實力、打破運氣偏誤的標準工具

核心架構對照
比較項目 傳統一試定生死 (Train/Test Split) K-Fold 交叉驗證 (K-Fold CV)
切分方式 資料只切一次，固定比例（如 80% 訓練、20% 驗證）。 資料均分 K 份，輪流當驗證集，重複測試 K 次。
資料利用率 驗證集裡的那 20% 資料，模型永遠沒機會在訓練時讀到。 100% 榨乾價值：每筆資料都既當過訓練集，也當過驗證集。
運算成本 極低，模型只需要訓練 1 次。 較高，模型需重新訓練 K 次（耗時放大為 K 倍）。
結果穩定度 看運氣。若切分時剛好把「簡單的題」分到驗證集，分數就會虛高。 極高。透過 K 次測驗平均，消除了單次切分的運氣成分。

它在防範模型「死記硬背（Overfitting）」上扮演的角色

當模型出現過擬合（Overfitting）時，代表它把訓練集的「雜訊」或「特定規律」死記硬背了下來，導致它遇到沒見過的題目就完全不會寫。K-Fold 在這裡扮演了「最嚴格的模擬考官」角色：

1. 戳破死記硬背的假象

若只用一試定生死，模型可能會針對這固定的 80% 資料進行「特訓」，並在剩下的 20% 資料拿到好分數（可能只是剛好賽到）。但 K-Fold 逼模型要在 $K$ 個完全不同的題目組合中都拿到高分，一旦模型在某個單元是靠死記硬背的，在其他輪的模擬考中就會立刻現形，平均分數就會被拉低。

2. 提供穩定的「停損指標」

在調整模型參數（如決定決策樹要長多深、神經網路要訓練幾輪 Epochs）時，我們需要一個客觀指標判斷模型何時開始死背。K-Fold 提供了一個沒有偏見的平均分數。當這個平均分數開始下降，就代表模型已經開始在死記硬背了，這時就是最佳的停損點（Early Stopping）。

核心警語： 一試定生死像是只做了一份模擬試卷就上考場；而 K-Fold 則是刷遍整本題庫的每個角落，確保模型學到的是「真正的邏輯」，而不是「死背特定題目的答案」。

生命週期角色： 模型評估、超參數選擇 (Tuning)
1 ❌ K-Fold 不在此處

資料清洗 (Cleaning)

包含缺漏值填補、重複值過濾、離群值剃除、文字斷詞清洗等。

⚠️ 嚴禁洩漏： 標準化 (StandardScaler) 等特徵工程不可在清洗時做在全量資料上！必須延後至各 Fold 的 Train Set 做 fit。
2 🔄 深度參與 (手段)

模型學習 (Learning)

演算法透過損失函數最小化與反向傳播（梯度下降 / 決策樹劃分）更新權重參數。

⚙️ K-Fold 角色： 每一輪將 $K-1$ 個 Folds 合併為訓練集，總共執行 $K$ 次全新初始化或擬合，驅動模型的學習。
3 🎯 核心所在 (目的)

驗證評估 (Validation)

評估模型在未見過資料上的泛化指標（Accuracy, ROC-AUC, F1, Loss 等），用於超參數搜尋（GridSearch）與模型篩選。

🏆 K-Fold 角色： 每一輪保留的 1 個 Fold 即為驗證集。5 次指標平均消除隨機偏誤，給出最具公信力的評估分數。

05. 由來與演變

統計學家 Mervyn Stone 與 Seymour Geisser 於 1974 年正式體系化提出 Cross-Validation 與 Leave-One-Out (LOO)；1995 年 Ron Kohavi 發表權威實證論文，證明在偏差與變異數權衡下，$K=10$ 是絕大多數實務場景的最佳折衷。

04. 實務特徵與陷阱

優點：充分榨乾每筆樣本價值，減少抽樣變異。
代價：訓練耗時提高為 $K$ 倍。
致命陷阱（Data Leakage）：特徵縮放（Scaling）或特徵工程必須在每個 Fold 內部獨立 fit，切勿在切分前全量 fit，否則驗證分數將虛高作弊。

07. 工業真實落地

生醫腫瘤良惡性預測：因臨床樣本稀少（常僅數百例），透過 K-Fold 杜絕過度樂觀估計。
晶圓廠瑕疵檢測：採用 Group K-Fold（以晶圓批次 Batch 分組），避免同晶圓圖像同時存在於訓練與驗證集造成模型偷看。

08. 理論簡介 & 09. 數學推導

泛化誤差期望值推導與 Bias-Variance Tradeoff

給定樣本集 $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^N$，將其均等劃分為 $K$ 個互斥子集 $\mathcal{D}_1, \mathcal{D}_2, \dots, \mathcal{D}_K$，滿足：

$\bigcup_{k=1}^K \mathcal{D}_k = \mathcal{D} \quad \text{且} \quad \mathcal{D}_j \cap \mathcal{D}_k = \emptyset \quad (\forall j \neq k)$

設 $f_{-k}$ 代表不在子集 $\mathcal{D}_k$ 上訓練，而是在其餘 $K-1$ 個子集之聯集 $\mathcal{D} \setminus \mathcal{D}_k$ 上擬合出的模型。則第 $k$ 折的評估損失為：

$\hat{R}_k = \frac{1}{|\mathcal{D}_k|} \sum_{i \in \mathcal{D}_k} \mathcal{L}\big(f_{-k}(x_i), y_i\big)$

整體 K-Fold 泛化誤差估計值 $\text{CV}_{(K)}$ 為各折損失的算術平均：

$\text{CV}_{(K)} = \frac{1}{K} \sum_{k=1}^K \hat{R}_k = \frac{1}{N} \sum_{i=1}^N \mathcal{L}\big(f_{-\kappa(i)}(x_i), y_i\big)$
其中 $\kappa(i)$ 表示樣本 $i$ 所隸屬的折數編號。

統計推導關鍵：$K$ 折選取的偏差與變異數權衡

  • 偏差（Bias）： 每輪只使用 $\frac{K-1}{K}N$ 筆資料進行擬合，比實際全量資料少，因此 $\text{CV}_{(K)}$ 對真實誤差估計略偏悲觀（Pessimistically Biased）。當 $K$ 越大（例如 $K=N$ 即 LOOCV），偏差趨近於 0。
  • 變異數（Variance）： 當 $K$ 極大時，各輪訓練集重疊度高達 $\frac{K-2}{K-1}$（例如 10 折重疊 8/9），導致各模型輸出高度正相關；跨資料集採樣時，$\text{CV}_{(K)}$ 估計值的變異數反而會放大。因此實證上 $K=5$ 或 $10$ 能取得均方誤差（MSE）的最佳平衡點。
互動式動態推算 即時折數探索
訓練集資料佔比: 80.0%
估計偏差 (Bias): 適中偏低 (建議區間)
各折模型重疊率: 75.0%
計算開銷倍率: 5 次完整訓練
實務黃金法則： 若資料筆數 $N < 10,000$，通常選 $K=5$ 或 $10$；若樣本具極端群組性質，切記搭配 Stratified / Group K-Fold。

11. 實戰代碼

Scikit-Learn (防洩漏) 與 PyTorch 工業級範例

import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import StratifiedKFold
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.pipeline import Pipeline
from sklearn.metrics import roc_auc_score

# 1. 產生高維度不平衡示範數據 (90% 負樣本, 10% 正樣本)
X, y = make_classification(n_samples=1200, n_features=25, weights=[0.9, 0.1], random_state=42)

# 2. 建立防止資料外洩（Leakage-Free）的 Pipeline
# 注意：StandardScaler 必須包在 Pipeline 內，才能保證各 Fold 僅以 Train Fold 做 fit！
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('model', RandomForestClassifier(n_estimators=100, max_depth=6, random_state=42))
])

# 3. 採用分層 5 折（StratifiedKFold）
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

oof_predictions = np.zeros(len(X))  # 保存 Out-of-Fold 預測
fold_scores = []

for fold, (train_idx, val_idx) in enumerate(skf.split(X, y), start=1):
    X_train, y_train = X[train_idx], y[train_idx]
    X_val, y_val = X[val_idx], y[val_idx]
    
    # 訓練模型 (Scaler 自動嚴格隔離 Train 與 Val)
    pipe.fit(X_train, y_train)
    
    # 產出該折驗證集的預測機率
    val_probs = pipe.predict_proba(X_val)[:, 1]
    oof_predictions[val_idx] = val_probs
    
    fold_auc = roc_auc_score(y_val, val_probs)
    fold_scores.append(fold_auc)
    print(f"Fold {fold} ROC-AUC: {fold_auc:.4f}")

print("-" * 45)
print(f"5-Fold 平均 ROC-AUC: {np.mean(fold_scores):.4f} (±{np.std(fold_scores):.4f})")
print(f"全量 OOF 整合 ROC-AUC: {roc_auc_score(y, oof_predictions):.4f}")
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader, SubsetRandomSampler
from sklearn.model_selection import KFold
import numpy as np

# 1. 簡易分類神經網路
class MLPClassifier(nn.Module):
    def __init__(self, in_features):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_features, 64),
            nn.BatchNorm1d(64),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(64, 1)
        )
    def forward(self, x):
        return self.net(x).squeeze(-1)

# 2. 自定義 Dataset
class TabularDataset(Dataset):
    def __init__(self, X, y):
        self.X = torch.tensor(X, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.float32)
    def __len__(self): return len(self.X)
    def __getitem__(self, idx): return self.X[idx], self.y[idx]

# 3. 5-Fold 交叉驗證訓練循環
X_dummy = np.random.randn(600, 16)
y_dummy = np.random.randint(0, 2, size=600)
dataset = TabularDataset(X_dummy, y_dummy)

kf = KFold(n_splits=5, shuffle=True, random_state=42)
val_losses = []

for fold, (train_idx, val_idx) in enumerate(kf.split(dataset), start=1):
    # 使用 SubsetRandomSampler 避免巨量記憶體深拷貝
    train_loader = DataLoader(dataset, batch_size=32, sampler=SubsetRandomSampler(train_idx))
    val_loader = DataLoader(dataset, batch_size=32, sampler=SubsetRandomSampler(val_idx))
    
    # 關鍵：每一折必須全新實例化模型權重與 Optimizer！
    model = MLPClassifier(in_features=16)
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
    criterion = nn.BCEWithLogitsLoss()
    
    # 單 Fold 訓練循環 (示範 3 Epochs)
    for epoch in range(3):
        model.train()
        for bx, by in train_loader:
            optimizer.zero_grad()
            out = model(bx)
            loss = criterion(out, by)
            loss.backward()
            optimizer.step()
            
    # 驗證循環
    model.eval()
    accum_loss = 0.0
    with torch.no_grad():
        for bx, by in val_loader:
            preds = model(bx)
            accum_loss += criterion(preds, by).item() * len(by)
            
    fold_loss = accum_loss / len(val_idx)
    val_losses.append(fold_loss)
    print(f"[Fold {fold}/5] 驗證損失: {fold_loss:.4f}")

print(f"整體 5-Fold 平均驗證損失: {np.mean(val_losses):.4f}")
