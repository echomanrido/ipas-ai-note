Reinforcement Learning from Human Feedback | 3階段對齊 · 數學推導 · 實戰模擬

一鍵模擬體驗 數學推導 IPAS 考題
01. 一句話簡介

RLHF 是一種透過「人類評分偏好」訓練獎勵模型，並藉由「強化學習演算法 (PPO)」微調大型語言模型，使模型輸出符合人類的有用性 (Helpful)、誠實性 (Honest) 與無害性 (Harmless) 的對齊技術 (Alignment)。

RLHF 標準三大階段流水線 (Three-Stage Pipeline)

階段一 SFT
監督微調 (Supervised Fine-Tuning)

由專業標註員針對大量 Prompt 撰寫高品質示範回應（Demonstration Data），對預訓練基底模型進行監督式訓練，使其從「續寫文字」轉化為「能聽懂指令」的基礎問答模型。

Loss: $\mathcal{L}_{\text{SFT}} = -\log P_\theta(y \mid x)$
階段二 RM
獎勵模型 (Reward Model)

給定同一個 Prompt，讓模型生成多組回應，由人類標註員進行「成對比較排序 ($y_w \succ y_l$)」。以此偏好資料集訓練 RM，使其能將文字回應精準打出實數純量分數 ($r$)。

Bradley-Terry: $P(y_w \succ y_l) = \sigma(r(x,y_w) - r(x,y_l))$
階段三 PPO
強化學習對齊 (PPO Policy Tuning)

將語言模型視為 Agent、Token 生成為 Action。利用 RM 給予的純量獎勵，透過 PPO 演算法更新模型參數；同時引入 KL 散度懲罰，防止模型過度偏離 SFT 模型而崩潰。

$\text{Obj} = \mathbb{E}[r_\phi(x,y) - \beta D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{SFT}})]$
02. 核心原理
  • • 解耦「評估」與「生成」難題： 讓人寫出完美的回答成本極高，但讓人「判斷哪一個回答比較好」卻非常容易且精確。
  • • 客觀化主觀意志： 透過 Bradley-Terry 統計概率模型，將人類的主觀滿意度映射為可連續微積分優化的標量獎勵函數。
  • • 安全錨定 (KL Penalty)： 在探索最大回報的過程中，鎖定基準語言模型的分佈，杜絕「胡言亂語騙取高分」的獎勵黑客 (Reward Hacking)。
04. 實務特徵與挑戰
  • • 對齊稅 (Alignment Tax)： 過度強化無害性 (Harmlessness) 容易導致模型在多樣性與創造力能力上發生衰退，甚至變得過度拒絕回答。
  • • 獎勵黑客現象 (Reward Hacking)： 模型發現 RM 的漏洞（例如：使用冗長且看似禮貌的空話、排版極其複雜的列表），即使內容錯誤也能騙取極高分數。
  • • 四模型併行之顯存痛點： 傳統 PPO-RLHF 在訓練時需在顯存中同時載入 Actor、Critic、Reference 與 Reward 四個大模型，工程調校門檻極高。

09. 核心數學推導：從 Bradley-Terry 到 PPO 與 DPO

深入拆解 RLHF 兩大核心公式：獎勵模型的成對偏好似然函數，以及帶有 KL 懲罰項的策略優化目標。

1. 獎勵模型 (Bradley-Terry) 推導

RM Loss

假設人類對回應 $y$ 的偏好程度取決於隱含的真實回報值 $r^*(x,y)$。根據 Bradley-Terry 成對比較模型，在給定提示詞 $x$ 下，人類偏好 $y_w$ 勝過 $y_l$ 的機率滿足 Logistic Sigmoid 函數：

$$P(y_w \succ y_l \mid x) = \frac{\exp(r_\theta(x, y_w))}{\exp(r_\theta(x, y_w)) + \exp(r_\theta(x, y_l))} = \sigma\big(r_\theta(x, y_w) - r_\theta(x, y_l)\big)$$

給定由標註資料組成的偏好數據集 $\mathcal{D} = \{(x^{(i)}, y_w^{(i)}, y_l^{(i)})\}_{i=1}^N$，藉由極大似然估計 (MLE)，我們最小化負對數似然損失 (Cross-Entropy Loss)：

$$\mathcal{L}_{\text{RM}}(\theta) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma\big(r_\theta(x, y_w) - r_\theta(x, y_l)\big) \right]$$
幾何直覺： 當 $r(y_w) \gg r(y_l)$ 時，差值進入 Sigmoid 飽和區，損失趨近於 0；若預測錯誤 $r(y_w) < r(y_l)$，損失將呈線性急遽上升，驅動梯度更新讓 $y_w$ 得分上升、$y_l$ 得分下降。

2. 策略優化目標與 KL 懲罰項

PPO Objective

在對齊階段，策略模型 $\pi_\theta(y \mid x)$ 旨在最大化來自獎勵模型 $r_\phi(x,y)$ 的分數，同時約束它不可與基準模型 $\pi_{\text{ref}}$ 偏差過大：

$$\max_{\theta} \; \mathbb{E}_{x \sim \mathcal{D}, y \sim \pi_\theta} \left[ r_\phi(x, y) - \beta \mathbb{D}_{\text{KL}}\big(\pi_\theta(y \mid x) \parallel \pi_{\text{ref}}(y \mid x)\big) \right]$$

展開 KL 散度定義，每一步生成之 token 獎勵可被改寫為修訂後的標量綜合 Reward：

$$R_{\text{total}}(x, y) = r_\phi(x, y) - \beta \left( \log \pi_\theta(y \mid x) - \log \pi_{\text{ref}}(y \mid x) \right)$$
KL 正則化超參數 $\beta$ 的物理意義：
• $\beta \to 0$：策略自由度過高，模型發生崩潰 (Reward Hacking)，開始產出重複長冗詞句。
• $\beta \to \infty$：模型完全失去對齊能力，輸出分佈被強制鎖定在原始 $\pi_{\text{ref}}$。

11. 實戰精準代碼：PyTorch 獎勵模型與帶 KL 懲罰之 PPO 步進

包含完整的 Bradley-Terry成對獎勵損失 (Pairwise Loss) 與 PPO Policy Actor 訓練的核心梯度更新實現，邏輯清晰、具備完整註解。

1. Bradley-Terry 偏好獎勵模型 (RewardModel & Loss) PyTorch Implementation 
import torch
import torch.nn as nn
import torch.nn.functional as F

class BradleyTerryRewardModel(nn.Module):
    """
    基於語言模型骨幹的標量打分獎勵模型 (RM)。
    輸入成對文本 (勝者 yw, 敗者 yl)，輸出實數標量回報值 r。
    """
    def __init__(self, backbone_llm, hidden_size):
        super().__init__()
        self.backbone = backbone_llm  # 如 Transformer / Llama / GPT-2
        # 將最終隱藏狀態映射為 1 維標量獎勵
        self.value_head = nn.Linear(hidden_size, 1, bias=False)

    def forward(self, input_ids, attention_mask=None):
        outputs = self.backbone(input_ids=input_ids, attention_mask=attention_mask)
        last_hidden_state = outputs.last_hidden_state  # shape: (B, Seq_len, H)
        
        # 取最後一個有效 token 的隱藏狀態作為序列的整體語義向量
        seq_lengths = attention_mask.sum(dim=1) - 1
        batch_size = input_ids.size(0)
        pooled_states = last_hidden_state[torch.arange(batch_size), seq_lengths]
        
        # 標量分數 r(x, y)
        reward_scalar = self.value_head(pooled_states).squeeze(-1)
        return reward_scalar

class PairwiseRewardLoss(nn.Module):
    """
    Bradley-Terry 成對排序損失函數:
    Loss = -E[log(sigmoid(r_w - r_l))]
    """
    def __init__(self):
        super().__init__()

    def forward(self, rewards_chosen, rewards_rejected):
        """
        rewards_chosen: 人類偏好的回答得分 (batch_size,)
        rewards_rejected: 人類排斥的回答得分 (batch_size,)
        """
        logits_diff = rewards_chosen - rewards_rejected
        loss = -torch.mean(F.logsigmoid(logits_diff))
        accuracy = (logits_diff > 0).float().mean()
        return loss, accuracy
2. 帶有 KL 散度懲罰的 PPO 策略訓練更新核心步 (PPO Step with KL Constraint) PPO Step Engine 
def compute_rlhf_step(
    actor_model,          # 當前被微調的策略模型 pi_theta
    ref_model,            # 凍結的 SFT 基準模型 pi_ref (防止模型漂移)
    reward_model,         # 凍結的獎勵模型 r_phi
    input_ids,            # Prompt token id
    generated_ids,        # 模型生成的 Response token id
    beta_kl=0.1,          # KL 懲罰係數
    clip_eps=0.2          # PPO 裁剪閾值
):
    full_seq = torch.cat([input_ids, generated_ids], dim=-1)
    
    # 1. 取得獎勵模型給予的客觀純量分數
    with torch.no_grad():
        raw_reward = reward_model(full_seq)  # shape: (batch_size,)
        
    # 2. 計算 Actor 與 Reference 模型的對數機率 log P(token)
    logits_actor = actor_model(full_seq).logits[:, -generated_ids.size(-1):, :]
    with torch.no_grad():
        logits_ref = ref_model(full_seq).logits[:, -generated_ids.size(-1):, :]
        
    logp_actor = F.log_softmax(logits_actor, dim=-1).gather(2, generated_ids.unsqueeze(-1)).squeeze(-1)
    logp_ref = F.log_softmax(logits_ref, dim=-1).gather(2, generated_ids.unsqueeze(-1)).squeeze(-1)
    
    # 3. 計算逐 Token 的 KL 散度近似懲罰: log(pi_actor / pi_ref)
    kl_divergence = logp_actor - logp_ref  # shape: (batch_size, seq_len)
    
    # 4. 融合 KL 懲罰項形成總獎勵獎懲信號 (KL-penalized reward)
    # 獎勵只在最後一個 token 加上原始環境獎勵，每步均扣除 KL 漂移
    rewards_with_kl = -beta_kl * kl_divergence
    rewards_with_kl[:, -1] += raw_reward
    
    # 5. 計算 PPO 剪裁損失 (Surrogate Objective)
    # ratio = exp(logp_actor - logp_old)
    # loss_ppo = -min(ratio * Adv, clip(ratio, 1-eps, 1+eps) * Adv)
    # (此處省略 Critic 優勢值 Adv 估計之 GAE 模組，專注展示核心對齊邏輯)
    mean_kl = kl_divergence.sum(dim=-1).mean().item()
    mean_net_reward = rewards_with_kl.sum(dim=-1).mean().item()
    
    return {
        "raw_reward": raw_reward.mean().item(),
        "kl_penalty": mean_kl,
        "net_reward": mean_net_reward
    }

在主流 RLHF 獎勵模型中，常採用 Bradley-Terry 模型來對成對比較進行建模。若勝者回應為 $y_w$、敗者為 $y_l$，其被人類偏好的預測機率公式為何？

正確答案：(B)

近年提出的直接偏好優化 (Direct Preference Optimization, DPO) 相比於傳統 PPO-RLHF，最主要的工程與理論突破為何？

解析：DPO 在數學上巧妙地將最優策略解反解回獎勵函數，直接以簡單的二元交叉熵微調策略本身，避免了顯存需常駐四個模型的極高成本及強化學習訓練不穩定的缺點。
