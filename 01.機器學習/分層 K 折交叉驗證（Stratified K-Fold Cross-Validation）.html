【分層 K 折交叉驗證 (Stratified K-Fold)】核心精華與產業實務應用

Key Takeaways · Sampling Constraint · Imbalanced Industrial Scenarios

重點精華 · 實務落地
重點整理 (Key Takeaways)
  • 分層等比例抽樣：確保每個 Fold 的標籤比例嚴格等於母體比例（例如正負樣本比 1:99，每折訓練與驗證集皆保持 1:99）。
  • 防禦極端評估偏差：徹底根除標準 K-Fold 在少數類別上可能發生的「零陽性樣本折」或「少數類過度集中折」，消除評估分數的大幅震盪。
  • 分類專用 vs 迴歸限制：本質為針對離散分類標籤設計；連續型目標迴歸無法直接使用（需改採自定義分箱 Continuous Stratified 或標準 K-Fold）。
  • 非採樣合成技術：僅改變「數據劃分方式」以客觀評估泛化性能，不生成虛擬樣本（區別於 SMOTE/ADASYN 等數據擴增技術）。
核心機制與原理說明

演算法首先將母體數據依據目標標籤 $y$ 進行層化分組（Stratification），對各個獨立類別子集合分別執行打散與 $K$ 等分切分，最後再將每個折中各類別的等分區塊對齊合併成 $K$ 個完整折。數學上強制滿足條件： $$\forall k \in \{1,\dots,K\}, \quad P(y=c \mid \text{Fold}_k) = P(y=c \mid \mathcal{D})$$ 在 Scikit-Learn 中呼叫 StratifiedKFold(n_splits=5, shuffle=True, random_state=42)，迭代器 .split(X, y) 必須傳入標籤 y 方能按類別比例分配索引。

應用在何處 (產業與落地實務)
  • 金融防盜刷與洗錢防制 (AML)：盜刷率通常低於 0.01%，標準隨機切分極易讓驗證折完全沒有盜刷樣本，分層交叉驗證確保每折穩定評估 PR-AUC 與 Recall。
  • 半導體晶圓瑕疵篩檢 (Wafer AOI)：良率 99.5% 時瑕疵僅 0.5%，透過 Stratified K-Fold 驗證缺陷分類模型（如致命刮痕、顆粒污染），避免誤殺或漏檢模型過擬合。
  • 醫療罕見疾病與癌症病理快篩：陽性病患極度稀缺（< 1%），分層保證每輪驗證集皆能客觀考核對少數類陽性病患的靈敏度 (Sensitivity)。
01. 一句話簡介

「按標籤比例切分，確保每折都是母體的完美縮影」

分層 K 折交叉驗證（Stratified K-Fold Cross-Validation）是機器學習模型評估的重要工具，也是標準 K 折交叉驗證的改良版本。在將資料分割成 $K$ 個折時，增加了一個關鍵約束：確保每個折中各類別的樣本比例與原始資料集嚴格保持一致。

這對於處理類別不平衡（Class Imbalance）的分類問題尤為重要，能有效避免某個折中缺乏少數類別樣本而導致評估結果產生偏誤與極端變異。

重要觀念釐清：分層 K 折是「評估工具」，而非「不平衡學習方案」

分層 K 折解決的是評估過程中的類別分佈問題，但它本身並不解決類別不平衡的學習問題。

若需要讓模型更好地學習少數類別，仍需要配合過採樣（如 SMOTE）、欠採樣、調整類別損失權重（如 class_weight='balanced' 或 Focal Loss）等針對不平衡學習的技術。分層 K 折確保的是我們在「公平且一致的條件下」，客觀評估這些技術的真實效益與泛化能力。

IPAS 避坑警語： 若搭配 SMOTE，必須在每個 Fold 內部對訓練集採樣，切忌在分折前對母體全域進行過採樣（避免資料洩漏 Data Leakage）！

02. 核心原理

1

類別獨立子分組

先將整體樣本依標籤 $Y$ 分組（例如分為多數類群與少數類群），避免類別在混洗時隨機聚集。

2

組內等分 K 份

在每個類別內部獨立打散，並平均均分為 $K$ 等份。確保每一份中少數類的數值皆為 $\lfloor N_c / K \rfloor$。

3

交叉對齊組裝

將每個類別的第 $k$ 等份合併形成 Fold $k$。徹底杜絕一般 K-Fold 可能發生「某個 Fold 根本抽不到少數類別」的致命評估偏誤。

03. IPAS AI 應用工程師經典考題

證照考題模擬與深入拆解

評估指標與驗證策略單元
[單選題] 考題 1

某金融防偽團隊正在訓練交易詐欺（Fraud Detection）預測模型。在收集到的 100,000 筆刷卡紀錄中，只有 200 筆為盜刷詐欺交易（正類樣本佔比 0.2%）。工程師若採用標準 10-Fold 交叉驗證（Standard K-Fold），最常面臨的根本性評估問題為何？

(A) 模型訓練時間會增加 10 倍以上
(B) 某些 Fold 的驗證集中可能完全不包含正類詐欺樣本，導致評價指標（如 Recall/AUC）產生極端變異
(C) 模型會自動將所有特徵正規化而遺失尺度資訊
(D) 會引發嚴重反向傳播梯度爆炸
常見度：★★★★★ | 難度：中等
正確答案：(B)
深度解析： 正類僅 200 筆，若完全隨機切分為 10 份，由二項分布可知部分 Fold 分配到的正樣本數可能極低甚至為 0。當驗證集正類為 0 時，召回率（Recall = TP / (TP+FN)）的分母為 0 無法計算，且模型在該折的評估分數會產生強烈雜訊，導致平均估計的變異數（Variance）過高。此題最佳解即為採用 Stratified K-Fold，保證每一折均有剛好 20 筆正類。
[觀念判斷題] 考題 2

關於 Stratified K-Fold 與其他交叉驗證技術的適用情境，下列敘述何者「錯誤」？

(A) Stratified K-Fold 主要適用於二元與多元「分類任務」，無法直接原封不動套用在連續值的「回歸任務」
(B) 在樣本類別極度平衡（如 50:50）時，Stratified K-Fold 與 Standard K-Fold 的表現差異會顯著收斂
(C) 面對金融股價等時間序列預測任務時，Stratified K-Fold 依然是最佳推薦方案
(D) Kohavi (1995) 的實證研究表明，Stratified K-Fold 相較普通 CV 能有效降低評估偏差與變異數
考點：驗證方法適用邊界與時間洩漏
正確答案：(C)
深度解析： (C) 錯誤。時間序列（Time-Series）資料具備強烈時序相依性（Temporal Dependency）。若使用 Stratified K-Fold 隨機打散後切分，會造成「未來的資訊被用來訓練過去的模型」，產生致命的資料外洩（Data Leakage / Look-ahead bias）。時間序列應使用 TimeSeriesSplit 或前向滾動驗證（Walk-Forward Validation）。
09. 嚴謹數學推導與配額演算法

KL 散度最小化目標與 Hamilton 最大餘數分配法

動態數學推導

數學優化目標：各折類別分布對齊

設資料集樣本總數為 $N$，類別集合為 $\mathcal{C}$，類別 $c$ 的真實母體比例為 $P(Y=c) = \frac{N_c}{N}$。分層交叉驗證劃分為 $K$ 個互相獨立的折 $\mathcal{S}_1, \dots, \mathcal{S}_K$，其最佳化目標為最小化各折與母體分布之 **Kullback-Leibler (KL) 散度**：

$$\min_{\{\mathcal{S}_k\}} \sum_{k=1}^K D_{\mathrm{KL}}\left( P_{\mathcal{S}_k}(Y) \,\parallel\, P(Y) \right)$$
約束條件：$\bigcup_{k=1}^K \mathcal{S}_k = \mathcal{D}$，且當 $i \ne j$ 時 $\mathcal{S}_i \cap \mathcal{S}_j = \emptyset$。

離散整數分配：Hamilton 最大餘數法

因為樣本數必須為整數，當 $N_c$ 無法被 $K$ 整除時，各折樣本數需滿足嚴格約束：

$$n_{k, c} \in \left\{ \left\lfloor \frac{N_c}{K} \right\rfloor, \; \left\lceil \frac{N_c}{K} \right\rceil \right\}, \quad \sum_{k=1}^K n_{k, c} = N_c$$

計算基本商數 $q_c = \lfloor N_c / K \rfloor$ 與餘數 $r_c = N_c \bmod K$。前 $r_c$ 個 Fold 分配 $q_c + 1$ 筆，其餘折分配 $q_c$ 筆。

04. 實務特徵 & 08. 理論架構

理論與實務的核心優勢與限制

實務優勢 (Pros)
  • 變異數顯著降低 (Variance Reduction)： 各折驗證分數震盪幅度小，超參數調優更加穩定可靠。
  • 避免零樣本陷阱： 杜絕特定 Fold 少數類樣本為 0 造成 Recall、F1-Score 無法定義的問題。
  • 公正檢驗不平衡演算法： 為 SMOTE、Focal Loss、Threshold-Moving 等演算法提供無偏差的公平測試基準。
  • 高覆蓋率： 每一筆樣本既是 $K-1$ 次訓練資料，又恰好擔任 1 次驗證資料。
使用邊界與注意事項 (Cons & Pitfalls)
  • 連續回歸無法直接用： 連續型標籤需先進行分箱（Binning）轉為離散分位數，方可執行分層。
  • 不適用獨立群組： 若同病患有多筆切片或同使用者有多筆評論，應使用 StratifiedGroupKFold 避免同群組跨折洩漏。
推薦實務標準：Scikit-Learn 的分類器 cross_val_score 預設即為 StratifiedKFold
05. 由來 ＆ 歷史背景

統計學與機器學習的演進

交叉驗證概念由 Seymour Geisser (1975) 等統計學家奠定。然而在 1995 年的國際人工智慧聯合會議 (IJCAI) 上，史丹佛學者 Ron Kohavi 發表了劃時代的經典論文 "A Study of Cross-Validation and Bootstrap for Accuracy Estimation and Model Selection"，透過大規模實驗證明：Stratified Cross-Validation 在平衡偏差與變異數表現上，全面優於普通交叉驗證與 Bootstrap，自此成為分類模型評估的黃金準則。

關鍵決策：折數 K 的奧秘

$K$ 值的選擇權衡：偏差（Bias）與變異數（Variance）的拉鋸戰

IPAS 高頻重點觀念

在交叉驗證中，$K$ 代表將資料集分割成的子集（折）數量。「$K$ 不是愈大就愈好」，選擇 $K$ 本質上是在估計偏差（Bias）、估計變異數（Variance）與計算資源消耗（Computational Cost）三者之間進行最佳折衷（Trade-off）。

指標維度 小 $K$ 值 (如 $K=2, 3$) 中等 $K$ 值 (推薦 $K=5 \sim 10$) 留一法 $K=N$ (LOOCV)
模型估計偏差 (Bias) 高（訓練樣本過少，容易低估模型性能） 低至適中（80%~90% 資料訓練） 極低（近乎使用整體樣本訓練）
評估變異數 (Variance) 較低（各折訓練集重疊度低，相互獨立） 平衡穩定（經 Kohavi 實證最具穩定度） 極高（各折訓練集重疊率達 $(N-2)/(N-1)$，高度正相關）
運算負擔 (Compute) 極低（僅需訓練 2 次） 可接受（訓練 5~10 次） 極巨大（需重新訓練模型 $N$ 次）
IPAS 建議適用情境 海量大數據（大於數百萬筆）快速原型驗證 絕大多數分類/回歸實務與競賽標準 樣本極度珍稀且昂貴時（如罕病醫學幾十筆資料）
10. 屬於哪個範疇？跨領域關鍵互動實務

機器學習、深度學習與 LLM 中的分層交叉驗證

在傳統結構化資料中，極度不平衡分類（如 XGBoost、LightGBM、CatBoost）依賴 StratifiedKFold 進行早停（Early Stopping）監控與超參數搜尋（Bayesian Optimization）。若未分層，驗證折的少數類樣本震盪會讓提早停機策略誤判過擬合時機。

最佳實務： 搭配 scale_pos_weight 或 Focal Loss，並以 StratifiedKFold(n_splits=5, shuffle=True, random_state=42) 作為內外層驗證。

在電腦視覺與醫學影像分類中（如 CNN, Vision Transformer），影像通常以資料夾分類。我們不可直接做隨機 random_split，而是利用 StratifiedKFold 獲取 Indices，再傳入 PyTorch torch.utils.data.Subset 與 DataLoader。

PyTorch 關鍵字： 使用 Subset(dataset, train_idx) 與 WeightedRandomSampler 結合。

在大語言模型領域中，長尾意圖分類（Long-tail Intent Classification）與有害內容安全過濾（Guardrail Moderation）極度依賴分層切分。罕見的安全越獄指令（Jailbreak Prompts）佔比可能低於 1%，若微調評估驗證集未分層，會造成基準評測（Benchmark）出現虛假的高安全性假象。

LLM 應用細節： 針對 Prompt 意圖標籤分層切分訓練 / 驗證 LoRA Adapter，確保評估時各少數攻擊類別均被嚴格檢驗。

圖例高亮標示： 核心 API 函式 (Red Highlight) 類別結構 (Cyan) 重要超參數 (Amber) 語法關鍵字 (Purple) 
import numpy as np
import torch
from torch.utils.data import Dataset, DataLoader, Subset
from sklearn.model_selection import StratifiedKFold

# ==========================================
# 1. 模擬高不平衡資料集 (1000 筆，正類僅 5%)
# ==========================================
np.random.seed(42)
X = np.random.randn(1000, 16)
y = np.random.choice([0, 1], size=1000, p=[0.95, 0.05])

# ==========================================
# 2. 宣告 StratifiedKFold 分層交叉驗證器
# ==========================================
skf = StratifiedKFold(
    n_splits=5, 
    shuffle=True, 
    random_state=42
)

print(f"母體資料集類別分布: Class 0={np.sum(y==0)}, Class 1={np.sum(y==1)}")

# ==========================================
# 3. 執行分層切割並整合 PyTorch DataLoader
# ==========================================
for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    y_train_fold, y_val_fold = y[train_idx], y[val_idx]
    
    # 驗證每個 Fold 的正類比例是否一致
    val_pos_ratio = np.mean(y_val_fold == 1) * 100
    print(f"[Fold {fold+1}] 驗證集樣本: {len(val_idx)} 筆 | 正類比例: {val_pos_ratio:.2f}%")
    
    # 轉換為 PyTorch DataLoader (適用於深度學習訓練迴圈)
    train_tensor_x = torch.tensor(X[train_idx], dtype=torch.float32)
    train_tensor_y = torch.tensor(y[train_idx], dtype=torch.long)
    
    val_tensor_x = torch.tensor(X[val_idx], dtype=torch.float32)
    val_tensor_y = torch.tensor(y[val_idx], dtype=torch.long)
    
    val_loader = DataLoader(
        torch.utils.data.TensorDataset(val_tensor_x, val_tensor_y),
        batch_size=32,
        shuffle=False
    )
