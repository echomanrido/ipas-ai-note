重點精華 · 實務落地
重點整理 (Key Takeaways)
  • 回歸的詞源與本質：高爾頓研究遺傳身高之「回歸平庸 (Regression to mediocrity)」，本質即是在空間中尋找一條最能表徵輸入特徵與輸出連續標籤的超平面。
  • 最小平方法的幾何直覺：Loss 是以殘差為邊長之「正方形面積總和」，平方消除正負抵消且「大錯重罰」；重要心法：Loss 是參數 $w, b$ 的函數，資料是固定常數！
  • 凸函數 (Convex Bowl) 的唯一碗底：線性回歸 MSE 曲面為嚴格凸函數，全域僅有唯一最低點，絕無局部極小值陷阱，梯度下降必定收斂至全域最優。
  • 特徵縮放 (Feature Scaling) 生死攸關：未標準化時因 $dw$ 包含特徵乘積使曲面被拉成長橢圓深谷，導致梯度懸殊，步長稍大便直接炸飛。
機制說明 (Mechanism & Math)
  • 鏈鎖法則偏微分： $$\frac{\partial L}{\partial w} = \frac{2}{n}\sum e_i x_i,\quad \frac{\partial L}{\partial b} = \frac{2}{n}\sum e_i$$ 猜太高 ($e>0$) 則梯度為正，參數往小更新；猜太低則往大調整。
  • 正規方程式 (Normal Equation) 解析解： $$\boldsymbol{\theta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$ 一步求逆得最優解，但求逆計算複雜度為 $O(d^3)$，維度大於數萬時崩潰，而梯度下降僅需 $O(nd)$。
  • 學習率臨界半徑證明：標準化後 Hessian 矩陣最大特徵值 $\lambda_{\max}=2$。收斂條件 $|1 - \eta \lambda| < 1 \implies 0 < \eta < 1$。因此當 $\eta=1.05 > 1$ 時，誤差每步放大 $1.1$ 倍必引發指數爆炸！
應用在何處 (Industrial Scenarios)
  • 半導體晶圓先進製程控制 (APC)：在薄膜沉積 (CVD) 與化學機械研磨 (CMP) 中，利用線性回歸實時預測厚度去除率與機台研磨墊損耗，達成奈米級精度回饋補償。
  • 智慧製造與電力能源負載預測：工廠冰水主機與空調系統依據外界氣溫、濕度與稼動率，以極佳可解釋性之線性模型即時調控變頻輸出，節電 15~20%。
  • 金融量化資本資產定價模型 (CAPM)：利用多元線性回歸計算單一股票與大盤之 $\beta$ 敏感度與 $\alpha$ 超額收益，為各大量化基金風險對沖之絕對核心基準。
MODULE 01 & 02

房仲問題：$y = wx + b$ 與兩個物理旋鈕

從無限多條直線中，挑出最有憑有據的那一條

收音機雙旋鈕直覺比喻

給定 100 筆過往房屋成交資料（坪數 $x$，價格 $y$），當新客戶走進房仲店詢問 30 坪房價時，我們透過方程式 $\hat{y} = wx + b$ 建立模型：

旋鈕 1：權重 / 斜率 ($w$)

代表「每多買 1 坪，預期加價多少萬元」。控制直線的傾斜仰角。

旋鈕 2：偏置 / 截距 ($b$)

代表「0 坪時的基礎地段門牌溢價」。控制直線整體的垂直升降。

💡 多特徵擴展：當加入屋齡 $x_2$、捷運距離 $x_3$ 時，超平面公式擴展為 $\hat{y} = \mathbf{w}^T \mathbf{x} + b$。

平面直線擬合與垂直殘差正方形幾何

紅色方塊代表 $(\hat{y}_i - y_i)^2$ 的面積。所謂「最小平方法」，就是轉動直線讓所有紅色正方形面積之和最小！

MODULE 03

損失函數 MSE 與碗形曲面 (Convex Bowl)

為什麼 Loss 是參數的函數？為什麼凸函數絕對不卡住？

1

為什麼誤差要取平方？

單純相加誤差會正負相消（猜高 100 萬 + 猜低 100 萬 = 0）；取絕對值在原點不可導；取平方能保證非負、處處光滑可微，且具備大錯重罰特性。

2

神級觀念：變數 vs 常數

在訓練階段，資料點 $(x_i, y_i)$ 是固定已知常數！真正改變的是旋鈕 $(w, b)$！因此 Loss 是以 $w, b$ 為自變數的三維地形曲面。

3

碗形曲面：凸函數優勢

二次曲面呈現完美「向上開口的碗」。它只有唯一全域最低點，沒有局部極小值（Local Minima），從任何位置起步都能滑落碗底！

MODULE 04

手撕微積分：鏈鎖法則推導梯度公式

站在碗壁上，如何精確感知哪裡是下山坡度？

對斜率 w 偏微分 (dw)

$$\frac{\partial L}{\partial w} = \frac{1}{n} \sum_{i=1}^n 2(\hat{y}_i - y_i) \cdot \frac{\partial (\hat{y}_i - y_i)}{\partial w}$$

因為 $\hat{y}_i = w x_i + b$，內層對 $w$ 微分剩下 $x_i$：

$$\frac{\partial L}{\partial w} = \frac{2}{n} \sum_{i=1}^n (\hat{y}_i - y_i) \cdot x_i$$

💡 猜太高時 $\text{error}>0$，梯度為正，更新時減去學習率乘梯度，讓 $w$ 變小。

對截距 b 偏微分 (db)

$$\frac{\partial L}{\partial b} = \frac{1}{n} \sum_{i=1}^n 2(\hat{y}_i - y_i) \cdot \frac{\partial (\hat{y}_i - y_i)}{\partial b}$$

內層對 $b$ 微分只有 $b$ 變成 $1$，其餘常數為 $0$：

$$\frac{\partial L}{\partial b} = \frac{2}{n} \sum_{i=1}^n (\hat{y}_i - y_i)$$

💡 截距梯度僅為平均誤差乘 2，直觀反映整體猜測高估或低估的中心偏差。

參數更新法則： w = w - lr * dw b = b - lr * db
（$\text{lr}$ 即學習率 $\eta$，決定邁出步伐大小）
MODULE 05

手算踩坑：為什麼特徵縮放 (Feature Scaling) 生死攸關？

從正圓形碗底，到被拉扯成狹長橢圓深谷的災難

對比 $dw$ 與 $db$ 的公式可以發現關鍵魔鬼細節：

• $dw$ 包含每個點乘上特徵值：$\frac{2}{n} \sum e_i \cdot \mathbf{x_i}$

• $db$ 沒有乘特徵值：$\frac{2}{n} \sum e_i$

在房仲範例中，坪數 $x \in [10, 60]$，這代表 $dw$ 天生就是 $db$ 的 30 到 50 倍大！

如果沒有經過標準化，Loss 等高線會變成極度扁長的「橢圓峽谷」： 在 $w$ 的軸向上山壁陡峭如刀削，在 $b$ 的軸向上平緩如平原。 如果學習率稍大，$w$ 就會在兩壁之間瘋狂震盪跳躍甚至爆炸；如果學習率調小遷就 $w$，$b$ 在平原上一萬步也走不到碗底！

解方：Z-score 標準化 $x_{\text{scaled}} = \frac{x - \mu}{\sigma}$，讓曲面復原為正圓對稱碗！

MODULE 06

正規方程式 (Normal Equation)：一步登頂的解析解

既然有一步算出答案的公式，為什麼現代深度學習非學梯度下降不可？

令矩陣損失導數等於 0：$\nabla_{\boldsymbol{\theta}} L = 2 \mathbf{X}^T (\mathbf{X} \boldsymbol{\theta} - \mathbf{y}) = 0 \implies \mathbf{X}^T \mathbf{X} \boldsymbol{\theta} = \mathbf{X}^T \mathbf{y}$，直接得閉式解：
$$\boldsymbol{\theta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$
在 Python 裡只需一行：np.linalg.solve(X.T @ X, X.T @ y)。
比較維度 梯度下降 (Gradient Descent) 正規方程式 (Normal Equation)
運算複雜度 $O(n \cdot d \cdot \text{epochs})$ $O(d^3)$ 或 $O(d^{2.376})$（矩陣求逆極其昂貴）
特徵數量 d 很大時 ✅ 仍舊非常快（如 $d=100,000$ 仍能順暢運算） ❌ 運算量與記憶體爆炸 (OOM)
樣本數 n 巨大時 ✅ 支援 Mini-batch / SGD 批次讀取串流學習 ❌ 必須一次性全載入 RAM
超參數調校 需要選擇合適學習率 $\eta$ 與迭代次數 ✅ 零超參數，直接解析得解
非線性模型擴展 ✅ 深度學習、Transformer、擴散模型通用核心 ❌ 非線性神經網絡無閉式解

未標準化時，坪數直接乘入梯度，使 $dw$ 被放大數十倍，原本收斂的 $0.01$ 步長在峭壁上瞬間失控炸裂！

--no-scale --lr 0.0005 參數跛腳

現象：w 迅速就位，b 紋絲不動

步長遷就 $w$ 不爆炸，但平緩軸向的 $b$ 步履蹣跚，200 步跑完 $b$ 還在原點，強迫 $w$ 歪斜補償出畸形直線。

--lr 0.01 牛步爬行

現象：收斂過慢，200 步遠未到底

邁出步伐太保守，像蝸牛在碗壁上爬行，需要將 Epoch 提高到 2000 步以上才能勉強抵達碗底。

★

留言挑戰題深度解析：為什麼學習率剛好超過 1 就會爆炸？

考慮標準化後的單變數損失函數 $L(w) = (w - w^*)^2$。 其對 $w$ 的二階導數（Hessian）為 $H = \frac{d^2 L}{dw^2} = 2$。

梯度更新式為：$w_{t+1} = w_t - \eta \cdot 2(w_t - w^*)$。兩邊減去最優解 $w^*$ 得： $$(w_{t+1} - w^*) = (1 - 2\eta)(w_t - w^*)$$

若要使誤差 $|w_{t+1} - w^*|$ 每步縮小，必須滿足收斂半徑條件： $$|1 - 2\eta| < 1 \iff -1 < 1 - 2\eta < 1 \iff 0 < \eta < 1$$ 因此，只要 $\eta > 1$（例如 $1.05$），放大係數 $|1 - 2(1.05)| = |-1.1| = 1.1 > 1$！每走一步誤差就擴大 $10\%$，呈幾何級數發散爆炸！這就是純粹而美麗的數值分析法則！
