重點精華 · 實務落地
重點整理 (Key Takeaways)
  • 監督式降維核心思想：透過標籤資訊尋找最佳投影軸，達成「類間間距最大化（Maximize Between-class Variance $S_B$）」與「類內離散最小化（Minimize Within-class Variance $S_W$）」的雙重平衡。
  • Fisher 準則數學解算：最大化 Rayleigh 商 $J(\mathbf{w}) = \frac{\mathbf{w}^T S_B \mathbf{w}}{\mathbf{w}^T S_W \mathbf{w}}$，轉化為廣義特徵值問題求解 $S_W^{-1} S_B \mathbf{w} = \lambda \mathbf{w}$。二分類最佳投影方向正比於 $S_W^{-1}(\mu_1 - \mu_2)$。
  • 維度上限與分佈假設：降維後維度上限嚴格受限於 $\min(d, C-1)$（$C$ 為類別數）；假設各類別服從常態分佈且具備相同的協方差矩陣（若協方差不同則需使用 QDA 二次判別分析）。
核心機制與原理說明

與非監督式 PCA 僅關注全域方差不同，LDA 將分類判別資訊內嵌於幾何投影中。投影後樣本點的緊湊度由類內散佈矩陣 $S_W = \sum_c \sum_{x \in C_c} (x - \mu_c)(x - \mu_c)^T$ 刻劃，類別分離度由類間散佈矩陣 $S_B = \sum_c N_c (\mu_c - \mu)(\mu_c - \mu)^T$ 刻劃。當面臨「小樣本問題（$d > N$）」導致 $S_W$ 奇異無法求逆時，工程實務常串聯 PCA 先降維去除奇異性，或引入正則化平滑項（Regularized LDA: $S_W + \gamma I$）維持數值求逆之穩定度。

應用在何處 (產業與落地實務)
  • 工業與半導體製造：化學氣相沉積（CVD）與蝕刻多腔體感測訊號的特徵分離與故障模式診斷；旋轉沖壓產線聲學頻譜之刀具磨損階段線性判別。
  • 智慧商業與生醫醫療：經典 Fisherfaces 人臉特徵向量降維識別；臨床腦電波（EEG）運動想像信號特徵提取與腦機介面（BCI）即時運動意圖解碼。
  • 系統維運與通訊資安：通訊協定多維封包特徵降維，區分正常商業連線、惡意掃描與 DDoS 異常流量，提供具備高度線性可解釋性的即時判別邊界。
01. 一句話簡介 (One-Line Summary)

尋求投影方向，最大化類別間間距，最小化類別內離散。

LDA（Linear Discriminant Analysis）是一種監督式降維與線性分類技術。其核心思想是將高維空間資料投影至低維軸線（如 1D 或 2D），使投影後達到「類間距離最大化（Between-class Variance Maximize）」同時「類內分散最小化（Within-class Variance Minimize）」，從而為後續分類器保留最高判別力。

降維視角：LDA 與 PCA 的核心承接與關鍵差異

在降維度的方法上，LDA 是 PCA 延伸的一種方法。PCA 目標是希望找到投影軸讓資料投影下去後分散量最大化，但 PCA 不需要知道資料的類別。而 LDA 也是希望資料投影下去後分散量最大，但不同的是這個分散量是希望「不同類別之間的分散量」越大越好。

所以 LDA 和 PCA 差異的部份，PCA 是無監督式（unsupervised learning）方法，LDA 多了這四個字（「不同類別」）是一種監督式（supervised learning）方法。

關鍵不同 1：有無標籤（非監督 vs 監督）

PCA 視全部點為同色同群，僅計算整體協方差；LDA 掌握各點所屬類別標籤，分別計算各類中心 $\mu_k$ 與類內離散 $S_W$。

關鍵不同 2：投影幾何目標（全體方差 vs 類間可分）

PCA 盲目追求「整體延伸最長」，常使不同類別擠在同一直線上；LDA 專門尋找「讓不同類別中心拉得最遠、同類抱得最緊」的黃金投影軸。

02. 核心原理

透過定義類間散布矩陣 $S_B$ 與類內散布矩陣 $S_W$，構建廣義瑞利商（Generalized Rayleigh Quotient）： $$J(w) = \frac{w^T S_B w}{w^T S_W w}$$ 轉化為求解廣義特徵值問題：$S_W^{-1} S_B w = \lambda w$。

04. 實務特徵與限制
  • 降維維度上限：最多降至 $C - 1$ 維（$C$ 為類別數）。
  • 基本假設：各類別特徵服從多元常態分佈且共變異矩陣相等。
  • 維度災難：樣本數小於特徵數時 $S_W$ 不可逆（小樣本問題）。
05. 由來 (History)

1936 年由現代統計學之父 Ronald A. Fisher 於其論文中提出，最初用於二分類問題（Fisher's Linear Discriminant），用以區分三種鳶尾花（Iris Dataset）。1948 年由 C. R. Rao 推廣為多類別（Multiclass LDA）。

PCA 生活比喻：全景側拍照相

一群高矮胖瘦各不相同的人聚集在廣場，攝影師希望拍出一張最能看清所有人輪廓的照片（訊息量最大）。

攝影師不在意誰是老師、誰是學生（無標籤），他只找能讓隊伍站位「展開幅度最寬」的角度按下快門，避免所有人疊在同一條線上。
核心：抓住全體最大的幾何伸展方向
LDA 生活比喻：水果分類斜坡槽

果農要將「檸檬」與「萊姆」分流，已貼好標籤進行測試。雖然兩者重量有重疊，但檸檬較橢圓、萊姆較圓。

LDA 不在意整體水果大小的自然離散，而是專門尋找一條能夠「最完美切開檸檬與萊姆」的傾斜通道，讓投影落點分成兩堆毫不重疊。
核心：利用已知標籤，最大化分離度
t-SNE 生活比喻：跨國社群聚會繪圖

上千位來自世界各地的專家在多度社交維度（語言、興趣、專業、居住國）中互動，要把關係畫在一張 2D 園遊會海報上。

t-SNE 像彈簧系統：讓平常最聊得來的好朋友緊緊聚成一小群（保留局部鄰域結構），不同圈子之間各自散開，哪怕非線性扭曲也無所謂。
核心：保留局部微觀結構，專門用於 2D 視覺化

工業實務選型指南 (Industrial Practical Guide)

PCA 工業現場：感測器去相關與無損壓縮
  • 高科技廠房機台：監控機台 500 個溫度、震動、電流感測器，因物理鄰近有極高共線性，PCA 萃取前 10 主成分即保留 98% 資訊並降噪。
  • 特徵臉辨識 (Eigenfaces)：在深度學習普及前，將千維人臉影像正交壓縮至幾十個維度。
LDA 工業現場：帶標籤的即時分類前處理
  • 半導體瑕疵分類 (Defect Binning)：刮痕、顆粒、薄膜厚度異常等 6 類缺陷，LDA 直接壓至 $6-1=5$ 維空間，後接超輕量分類器毫秒級推論。
  • Fisherfaces 人臉辨識：利用類別標籤消除光照角度與陰影變化（類內干擾），辨識度顯著超越 PCA。
t-SNE 工業現場：高維探索與生物特徵叢集
  • 單細胞基因定序 (scRNA-seq)：面對 20,000 個基因維度，生醫團隊使用 t-SNE 繪製 2D 細胞群落圖，發掘未知免疫細胞亞型。
  • 大型語言模型 (LLM) 語義空間除錯：將 4096 維的 Token Embedding 投影在 2D 圖上，快速檢視詞意偏見與同義詞群聚現象。

06. 生活化比喻：三大降維直覺 Step-by-Step

用日常直覺拆解演算法思維歷程：果園分揀、團體照攝影、社群聚會分桌

果園採收數萬顆「檸檬」與「萊姆」。果農要設計一條旋轉滑道，讓水果自然滾落進入各自的果籃：

量測多維特徵（重量 vs. 粗糙度）

每顆水果記錄「重量（克）」與「表面粗糙度」，在 2D 平面上散落為兩大團點。

發現單一維度困境（PCA 盲點）

只看重量（變異最大的軸），大顆萊姆和小顆檸檬重量相同，堆在同一直線上難以區分！

3
利用標籤找出中心與自身離散（$\mu$ 與 $S_W$）

依據人工標籤計算檸檬中心 $\mu_1$、萊姆中心 $\mu_2$ 與兩堆各自向外膨脹的形狀。

4
旋轉最優傾斜滑道（求最佳投影軸 $w^*$）

依據 $w^* \propto S_W^{-1}(\mu_1-\mu_2)$ 旋轉角度，讓投影間距最大化、各自團塊最緊實。

5
重力 1D 投影落箱（零延遲分揀完成）

水果沿傾斜軸滾落，在分界線左右自動落入檸檬籃與萊姆籃，完成高效分類！

LDA 心法：已知標籤，刻意挑選能讓「類與類最遠、各自最緊實」的黃金傾斜角。

運動會上一百位高矮胖瘦不同的同學在操場自由交談。攝影師要在 2D 照片中保留最豐富的身形多樣性與姿勢資訊（不看身分是誰）：

1
統計全員中心位置（去平均中心化）

攝影師先走到人群的正中心點，將相機視野的基準原點對準全體學生的中心重心。

2
觀察隊形的主要伸展方向（計算共變異）

觀察同學是沿著東北-西南方向排成長列，還是橫向散開？找出人潮「拉得最長、分得最開」的主軸。

3
架設第一主相機角度（PC1 最大變異方向）

沿著最長的主軸正面拍攝，此視角下大家的站位展開最寬，遮擋最少，捕捉到最多的姿勢訊息！

4
正交垂直架設第二相機（PC2 次要獨立視角）

在與第一相機完全垂直 90 度處拍第二張（零冗餘資訊），補充第一張無法看到的側面深度。

5
捨棄雜訊維度（保留前幾張最有價值的照片）

微小的腳趾擺放、手指微動等變異極小的微觀細節直接忽略，用少數幾張大景照片保留 95% 全貌。

PCA 心法：不問身分與標籤，只找能讓全體數據「幾何展開幅度最大」的正交視角。

全球跨國校友園遊會上，上千名校友在「母語、主修、興趣、工作產業」等多度關係中互動。要把大家安排到一張 2D 大草坪野餐墊上：

1
測量高維社交緊密度（高維條件機率）

問卷調查每兩個人之間「是否聊得來」的機率。平常同實驗室、講同種語言的人互動機率極高。

2
隨機分發草坪初始座次（低維初始隨機分佈）

一開始把每位校友隨機丟在草坪 2D 地圖的任意座標上，此時熟人彼此可能離得極遠。

3
安裝虛擬彈簧系統（拉力：引力引向好友）

在好友之間綁上橡皮筋彈簧，聊得來的人若距離太遠，會產生強大拉力將他們拉到同一張野餐桌。

4
換上長尾排斥力墊片（Student-t 分佈解擁擠）

若大家都擠在一起會坐不下（擁擠問題）。改用長尾分佈，讓不熟的群體之間產生溫和推力自動分開。

5
彈簧平衡收斂成社群小島（完美呈現群聚關係）

彈簧振動平衡後，草坪上自然浮現出一個個分明的聚落小島：生醫組、AI組、文創組各自成群！

t-SNE 心法：不在意全域直線投影，專注讓局部好友緊密相聚，哪怕非線性扭曲也甘之如飴。
三大演算法直覺總結： LDA 依標籤調角度切開果實； PCA 找最寬拍照視角保留輪廓； t-SNE 靠彈簧聚攏知心好友。

07. 工業現場與尖端應用：三大降維演算法 Step-by-Step

標準生產管線：解析 LDA、PCA 與 t-SNE 在現代工業生產端的逐步落地實施流程

【LDA 監督式現場】半導體晶圓瑕疵分級 (Wafer Defect Binning)： 利用已知 6 類缺陷標籤（刮痕、空洞、短路等），尋找判別力最強的正交空間，將計算負擔壓至極限以滿足百萬級晶片即時分選。
1
高維特徵萃取（光學 AOI 影像） 128 維特徵向量

光學檢測機台即時擷取灰階紋理、邊緣梯度、輪廓曲率、色度差等 128 項幾何與頻域特徵，組成原始特徵向量 $x \in \mathbb{R}^{128}$。

2
PCA 預先降維（抗奇異與去相關） 128 維 → 30 維

為避免小樣本問題（$N < D$ 導致類內散布矩陣 $S_W$ 奇異無法求逆），先以無監督 PCA 消除共線性雜訊並壓縮至 30 維前置特徵空間。

3
LDA 監督式判別矩陣求解 降至 5 維空間

結合品管工程師標記的 6 類缺陷標籤，計算類間散布 $S_B$ 與類內散布 $S_W$，求解廣義特徵值問題，求出投影矩陣 $W \in \mathbb{R}^{30 \times 5}$，降至 $6-1 = \mathbf{5}$ 維。

4
邊緣運算極速推論（0.8 ms 毫秒決策） 延遲 < 1 ms

將 5 維投影座標送入輕量線性判別式或最近質心距離比對（Nearest Centroid），單顆晶片瑕疵分類耗時僅 0.8 ms，完全跟上機台產能節奏。

5
產線異常警報與持續自我閉環 MLOps 閉環

若投影落點距離已知 6 類中心皆超過馬氏距離門檻，標記為「新型缺陷」，通報產線警報，並自動收集新樣本加入每週定期重新訓練排程。

【PCA 非監督現場】高科技廠房 500 感測器去相關與 MSQC 統計製程管制： 蝕刻與薄膜沉積機台擁有數百個高共線性感測器（無標籤）。透過主成分萃取去除冗餘並建立 $T^2$ 與 SPE 雙指標監控。
1
多通道感測訊號採集與 Z-score 標準化 500 物理通道

每秒同步收集機台 500 個溫度、氣體流量、射頻功率與腔體壓力數值。因各感測器物理單位懸殊，先進行 $z = \frac{x-\mu}{\sigma}$ 標準化消除量綱干擾。

2
共變異矩陣計算與特徵值正交分解 特徵分解 $\Sigma = V \Lambda V^T$

計算歷史正常運轉批次的樣本共變異數矩陣 $\Sigma \in \mathbb{R}^{500 \times 500}$，透過特徵分解或 SVD 求得相互正交的主成分載荷向量矩陣 $P$。

3
碎石圖評估與 95% 累計解釋方差截斷 500 維 → 12 主成分

依據解釋變異比例 $\frac{\sum_{i=1}^k \lambda_i}{\sum \lambda} \ge 95\%$ 截斷，前 12 個主成分即涵蓋 95% 產線物理動態，將維度由 500 驟降至 12 維。

4
線上雙統計量監控（Hotelling's $T^2$ 與 SPE） 即時製程管制

在主成分空間計算 $T^2$ 監控系統變異；在殘差空間計算平方預測誤差 SPE（Q 統計量）監控物理關聯破壞，任何一項超越 $99\%$ 管制上限即觸發警報。

5
異常貢獻圖（Contribution Plot）根因追溯 根因定位

觸發警報瞬間，系統將超標的殘差反向投影回原始 500 維感測器，產生長條貢獻圖，維修工程師在 30 秒內即可鎖定是哪一支電磁閥或溫度計發生漂移故障。

【t-SNE 非線性流形現場】單細胞基因定序 (scRNA-seq) 與 LLM 語意空間探索： 面對數萬維非線性流形，以機率分佈為核心，保留局部微觀結構，在 2D/3D 平面上呈現細胞亞群分化路徑或語言模型潛在偏見。

08. 理論架構 & 09. 嚴謹數學推導

Fisher 判別準則與廣義特徵值問題解析

二類別經典推導：從投影方差比值到最優投影向量 $w^* \propto S_W^{-1}(\mu_1 - \mu_2)$。

步驟 1 · 資料投影定義

給定樣本 $x \in \mathbb{R}^D$ 與單位投影向量 $w$，投影值為純量：

$$y = w^T x$$

類別均值向量 $\mu_1, \mu_2$ 投影後中心為：

$$\tilde{\mu}_1 = w^T \mu_1, \quad \tilde{\mu}_2 = w^T \mu_2$$
目標：使 $|\tilde{\mu}_1 - \tilde{\mu}_2|$ 最大
步驟 2 · 散布矩陣定義

定義類內散布矩陣 (Within-class)：

$$S_W = \sum_{x \in C_1}(x-\mu_1)(x-\mu_1)^T + \sum_{x \in C_2}(x-\mu_2)(x-\mu_2)^T$$

定義類間散布矩陣 (Between-class)：

$$S_B = (\mu_1 - \mu_2)(\mu_1 - \mu_2)^T$$
注意：$S_B$ 的秩 (Rank) 恆為 1
步驟 3 · 瑞利商目標函數

Fisher 判別準則定義投影後「類間方差」除以「類內方差」：

$$J(w) = \frac{(\tilde{\mu}_1 - \tilde{\mu}_2)^2}{\tilde{s}_1^2 + \tilde{s}_2^2} = \frac{w^T S_B w}{w^T S_W w}$$

目標是求得最佳向量 $w^*$ 使得 $J(w)$ 取得極大值。

尺度不變性：J(cw) = J(w)
步驟 4 · 微分求極值與解析解

對 $w$ 偏微分令其為零 $\frac{\partial J}{\partial w} = 0$：

$$(w^T S_W w) S_B w = (w^T S_B w) S_W w$$

因 $S_B w = (\mu_1-\mu_2)\beta$ 是純量倍數，化簡可得解析閉合解：

$$w^* = S_W^{-1} (\mu_1 - \mu_2)$$
多類別則求解特徵向量

試題 1 · 核心觀念比較

關於主成分分析（PCA）與線性判別分析（LDA）之比較，下列敘述何者最為正確？

(A) 兩者皆為非監督式特徵萃取演算法
(B) PCA 尋求最大化總方差的方向，LDA 尋求最佳化類別分離度的方向
(C) LDA 降維後的維度最多可以達到特徵數 $D$ 維
(D) 兩者皆假設特徵之間具有高度非線性分佈
正確答案：(B)

【IPAS 考點詳解】：

(A) 錯誤：PCA 為非監督式（不使用 Label），LDA 為監督式（必須使用 Label）。

(B) 正確：PCA 目標在於保留整體資料的最大變異量；LDA 旨在最大化類間散布並最小化類內散布。

(C) 錯誤：若有 $C$ 個類別，類間散布矩陣 $S_B$ 的秩最大為 $C-1$，故 LDA 降維後維度最多僅為 $C-1$。

(D) 錯誤：兩者本質皆為線性變換方法（Linear Projection）。

試題 2 · 數學與矩陣限制

一資料集包含 5 個不同的目標分類類別（$C = 5$），原始特徵為 100 維（$D = 100$）。若採用標準多類別線性判別分析（Multiclass LDA）進行降維，則投影後的子空間最大維度為何？

(A) 100 (B) 5 (C) 4 (D) 1
正確答案：(C)

【IPAS 考點詳解】：

在多類別 LDA 中，類間散布矩陣定義為 $S_B = \sum_{k=1}^C N_k (\mu_k - \mu)(\mu_k - \mu)^T$。因為全體中心 $\mu$ 是各類均值向量 $\mu_k$ 的線性組合，因此這 $C$ 個差值向量中只有 $C-1$ 個是線性獨立的。因此 $\text{Rank}(S_B) \le C - 1$。由此推得非零特徵值最多只有 $C - 1$ 個，本題 $C = 5$，最大維度為 $5 - 1 = 4$。

試題 3 · 實務工程瓶頸與處理

在人臉識別應用中，輸入影像維度為 $10000$（$100 \times 100$ 畫素），但訓練樣本僅有 $200$ 張人臉。此時直接套用 LDA 會面臨類內散布矩陣 $S_W$ 奇異（Singular）無法求逆的問題，此現象稱為什麼？工程上標準解法為何？

考點名稱：小樣本問題 (Small Sample Size Problem, SSS)

【IPAS 考點詳解】：

1. 原因：當訓練樣本數 $N$ 小於特徵維度 $D$ 時，矩陣 $S_W$ 的秩最多為 $N - C < D$，因此 $S_W$ 必定為奇異矩陣（Det = 0），無法直接求逆矩陣 $S_W^{-1}$。

2. 工業界標準解法：

  • PCA + LDA 組合法 (Fisherfaces 經典管線)：先利用 PCA 將維度壓縮至 $N - C$ 以下，再執行 LDA。
  • 正規化 LDA (Regularized LDA / Shrinkage)：在對角線加入微小擾動 $\tilde{S}_W = S_W + \gamma I$（類似 Ridge 正則化）確保可逆。

import numpy as np

def fisher_lda_two_class(X, y):
    """手刻 Fisher 經典二類別線性判別分析 (Linear Discriminant Analysis)"""
    X1 = X[y == 0]
    X2 = X[y == 1]
    
    # 1. 計算兩類別平均向量 μ1, μ2
    mu1 = np.mean(X1, axis=0)
    mu2 = np.mean(X2, axis=0)
    
    # 2. 計算類內散布矩陣 Sw = S1 + S2
    S1 = np.dot((X1 - mu1).T, (X1 - mu1))
    S2 = np.dot((X2 - mu2).T, (X2 - mu2))
    Sw = S1 + S2
    
    # 3. 求解最佳投影向量 w* ∝ Sw^(-1) * (mu1 - mu2)
    # 使用 solve 求解線性方程 Sw @ w = (mu1 - mu2)，數值穩定性高於直接求逆 inv
    w = np.linalg.solve(Sw, (mu1 - mu2))
    
    # 正規化單位向量
    w = w / np.linalg.norm(w)
    
    # 4. 計算線性決策門檻 (投影中心點)
    threshold = 0.5 * np.dot(w, (mu1 + mu2))
    return w, threshold

# 測試推導結果
X_toy = np.random.randn(100, 2)
y_toy = (X_toy[:, 0] + X_toy[:, 1] > 0).astype(int)
w_opt, b_opt = fisher_lda_two_class(X_toy, y_toy)
print(f"LDA 最佳投影方向向量: {w_opt}, 門檻: {b_opt:.3f}")
        

from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

# 1. 載入經典鳶尾花資料集 (3 類別, 4 特徵)
iris = load_iris()
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, stratify=y, random_state=42)

# 2. 初始化 LDA 模型
# n_components 最多為 C - 1 = 3 - 1 = 2
lda = LinearDiscriminantAnalysis(
    n_components=2, 
    solver='eigen',       # 支援特徵分解，亦可選 'svd' 或 'lsqr'
    shrinkage='auto'      # 自動 Ledoit-Wolf 正則化防止 Sw 矩陣奇異
)

# 3. 擬合並執行降維
X_train_lda = lda.fit_transform(X_train, y_train)
X_test_lda = lda.transform(X_test)

# 4. 評估分類成效
y_pred = lda.predict(X_test)
print(f"各成分解釋變異比例: {lda.explained_variance_ratio_}")
print(classification_report(y_test, y_pred, target_names=iris.target_names))
        

import torch
import torch.nn as nn

class LDALossLayer(nn.Module):
    """結合深度學習骨幹 (Backbone) 的神經網絡特徵 LDA 正則化損失函數"""
    def __init__(self, in_features, num_classes):
        super().__init__()
        self.in_features = in_features
        self.num_classes = num_classes

    def forward(self, z, labels):
        # z: [Batch_Size, Feature_Dim] 特徵嵌入向量
        total_mean = torch.mean(z, dim=0)
        Sw = torch.zeros(self.in_features, self.in_features, device=z.device)
        Sb = torch.zeros(self.in_features, self.in_features, device=z.device)
        
        for c in range(self.num_classes):
            zc = z[labels == c]
            if zc.shape[0] > 1:
                mean_c = torch.mean(zc, dim=0)
                diff_within = zc - mean_c
                Sw += torch.matmul(diff_within.T, diff_within)
                
                diff_between = (mean_c - total_mean).unsqueeze(1)
                Sb += zc.shape[0] * torch.matmul(diff_between, diff_between.T)
        
        # 最大化 Trace(Sb) / Trace(Sw) 即最小化 -Tr(Sb)/Tr(Sw)
        lda_objective = torch.trace(Sb) / (torch.trace(Sw) + 1e-5)
        return -lda_objective  # 梯度下降目標
