01. 一句話簡介 & 02. 核心原理剖析

三大降維巨頭：看見資料的本質維度

從無標籤的能量最大化、有標籤的類別分離，到高維曲面的拓撲攤平。

非監督式 · 線性

PCA (主成分分析)

Principal Component Analysis

【01. 一句話簡介】

「不看標籤，尋找能讓資料投影後變異數（方差）最大的正交方向，以最少維度保留全域整體能量。」

生活化比喻

就像從各個角度拍一張全家福，目的是找一個最好的角度，讓照片能拍到最多的人、保留最多畫面細節。

【02. 核心原理】

透過計算資料的協方差矩陣 $\Sigma$，進行特徵值分解或奇異值分解 (SVD)，取前 $k$ 個最大特徵值對應的正交特徵向量作為新坐標軸。

關鍵目標：$\max_w w^T \Sigma w \quad \text{s.t. } w^T w = 1$
監督式 · 線性

LDA (線性判別分析)

Linear Discriminant Analysis

【01. 一句話簡介】

「緊盯標籤，尋找能讓類間距離最大化且類內散布最小化的投影軸，使各類別影子分得最開。」

生活化比喻

就像在學校園遊會分類攤位，目的是把賣「飲料」和「炸物」的攤位徹底隔開，讓想買的人一眼就能分清楚。

【02. 核心原理】

利用類間散布矩陣 $S_B$ 與類內散布矩陣 $S_W$，最大化 Fisher 判別準則（廣義瑞利商），轉換為求解 $S_W^{-1} S_B$ 的廣義特徵值問題。

關鍵目標：$\max_w \frac{w^T S_B w}{w^T S_W w}$（上限維度 $C-1$）
非監督式 · 非線性流形

t-SNE (t-分布隨機鄰居嵌入)

t-Distributed Stochastic Neighbor Embedding

【01. 一句話簡介】

「不靠筆直投影，將高維歐氏距離轉為機率，在低維利用 t-分布長尾效應像攤平橘皮般保留微觀鄰域拓撲。」

生活化比喻

就像把立體地球儀畫成平面世界地圖，雖然遠處的面積變形了，但原本住得近的鄰居在平面上依然會挨在一起。

【02. 核心原理】

高維使用高斯分布對稱聯合機率 $p_{ij}$，低維使用自由度為 1 之 Student-t 分布 $q_{ij}$，透過梯度下降最小化兩者之 KL 散度。

關鍵目標：$\min_Y KL(P || Q) = \sum_{i,j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$

05. 演算法由來與歷史脈絡

PCA 的誕生 (1901 / 1933)

1901 年由現代統計學之父 Karl Pearson 提出，作為力學中「主軸定理」在幾何空間的類比；1933 年 Harold Hotelling 獨立發展並正式確立了隨機變數主成分分析的數學架構。

LDA 的誕生 (1936 / 1948)

1936 年英國遺傳統計大師 Ronald Fisher 在處理鳶尾花（Iris）品種分類時提出「Fisher's Linear Discriminant」；後由 C. R. Rao 於 1948 年推廣至多元分類，成為現代判別分析基石。

t-SNE 的誕生 (2002 / 2008)

圖靈獎得主 Geoffrey Hinton 與 Sam Roweis 於 2002 年提出 SNE；2008 年 Laurens van der Maaten 與 Hinton 共同發表改良版 t-SNE，引入 Student-t 分布一舉破解流形擠迫問題（Crowding Problem）。

08. 理論簡介 & 09. 核心數學嚴密推導

PCA：以拉格朗日乘子法求解變異數最大化

設中心化（零均值）後的資料矩陣為 $X \in \mathbb{R}^{n \times d}$，樣本協方差矩陣為 $\Sigma = \frac{1}{n} X^T X$。尋找一個單位投影向量 $w \in \mathbb{R}^d$ ($w^T w = 1$)，使得投影後的純量標量 $z_i = w^T x_i$ 之樣本變異數最大。

1. 目標函數：

$$\sigma^2_z = \frac{1}{n} \sum_{i=1}^n (w^T x_i)^2 = \frac{1}{n} w^T \left( \sum_{i=1}^n x_i x_i^T \right) w = w^T \Sigma w$$

2. 建立帶有限制條件的拉格朗日函數：

$$\mathcal{L}(w, \lambda) = w^T \Sigma w - \lambda (w^T w - 1)$$

3. 對 $w$ 微分並令其為零：

$$\frac{\partial \mathcal{L}}{\partial w} = 2 \Sigma w - 2 \lambda w = 0 \implies \Sigma w = \lambda w$$

4. 結論：

$$w^T \Sigma w = w^T (\lambda w) = \lambda (w^T w) = \lambda$$

欲最大化變異數，投影方向 $w$ 必須是協方差矩陣 $\Sigma$ 的特徵向量，且投影變異數大小正好等於對應的特徵值 $\lambda$。取前 $k$ 個最大特徵值對應的正交特徵向量，即構成降維矩陣 $W = [w_1, w_2, \dots, w_k]$。

LDA：Fisher 判別準則與廣義特徵值問題

以二分類為例，類別 $C_1, C_2$ 的樣本均值為 $\mu_1, \mu_2$。定義類內散布矩陣 $S_W$ 與類間散布矩陣 $S_B$。

1. 散布矩陣定義：

$$S_W = \sum_{x \in C_1} (x - \mu_1)(x - \mu_1)^T + \sum_{x \in C_2} (x - \mu_2)(x - \mu_2)^T$$ $$S_B = (\mu_1 - \mu_2)(\mu_1 - \mu_2)^T$$

2. Fisher 準則（廣義瑞利商 Generalized Rayleigh Quotient）：

$$J(w) = \frac{w^T S_B w}{w^T S_W w}$$

3. 對 $w$ 求導並令其為零：

$$\frac{\partial J}{\partial w} = \frac{2 S_B w (w^T S_W w) - 2 S_W w (w^T S_B w)}{(w^T S_W w)^2} = 0$$ $$S_B w (w^T S_W w) = S_W w (w^T S_B w) \implies S_W^{-1} S_B w = \left( \frac{w^T S_B w}{w^T S_W w} \right) w = \lambda w$$

因此最優投影軸 $w$ 是矩陣 $S_W^{-1} S_B$ 的特徵向量。在多類別情境下，若類別數為 $C$，則 $S_B$ 的秩最多為 $C-1$，故最多僅能解出 $C-1$ 個非零特徵值，這正是 LDA 最多只能降至 $C-1$ 維的根本數學原因！

t-SNE：高維高斯分布、低維 Student-t 與 KL 散度梯度

t-SNE 將距離轉化為條件機率，以對稱聯合機率分布衡量樣本點之間的鄰近相似度。

1. 高維空間相似度（對稱高斯機率）：

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}, \quad p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}$$

2. 低維空間相似度（自由度為 1 之 Student-t 分布 / 柯西分布）：

$$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k} \sum_{l \neq k} (1 + \|y_k - y_l\|^2)^{-1}}, \quad q_{ii} = 0$$

3. 損失函數與梯度下降公式：

$$KL(P || Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$ $$\frac{\partial KL}{\partial y_i} = 4 \sum_{j} (p_{ij} - q_{ij})(y_i - y_j)(1 + \|y_i - y_j\|^2)^{-1}$$

梯度具有彈簧力學直觀：當 $p_{ij} > q_{ij}$（高維親近但低維太遠）產生引力；當 $p_{ij} < q_{ij}$ 產生排斥力。

10. 四大機器學習範疇中之應用深潛

傳統機器學習 (Machine Learning)

在高維特徵工程中，「維度災難」會導致距離度量失效與過擬合。

  • PCA：消除特徵間多重共線性，提升線性模型泛化速度。
  • LDA：直接作為 Bayes 最適線性分類器，具閉式解析解。

深度學習 (Deep Learning)

CNN 或 Transformer 隱藏層表徵（Latent Representation）通常是數百至數千維稠密向量。

  • t-SNE：視覺化瓶頸層特徵圖，檢查神經網路是否正確分群。
  • PCA：作為神經風格遷移中的白化濾波或權重低秩矩陣分解（LoRA 原理）。

強化學習 (Reinforcement Learning)

RL 智能體面臨連續環境的巨量狀態空間爆炸。

  • t-SNE 軌跡視覺化：分析 DQN 狀態價值網絡是否能有效辨識「危險」與「安全」狀態。
  • PCA 狀態壓縮：在邊緣嵌入式晶片上即時壓縮高維感測訊號，加速 Policy 決策。

LLM 與檢索增強生成 (LLM & RAG)

當代 Embedding 模型（如 1536 或 3072 維）維度極高。

  • 向量資料庫除錯：利用 t-SNE 繪製知識庫 Chunk 向量，排查語意孤島與聚類不均。
  • Matryoshka 階層表徵 (MRL)：以類似 PCA 階層能量概念，保留前少數維度大幅節省儲存。

import torch

def pytorch_pca(X: torch.Tensor, k: int = 2):
    """
    純 PyTorch SVD 實作 GPU 加速 PCA
    X: (n_samples, n_features)
    k: 目標維度
    """
    # 1. 中心化 (Zero-center)
    X_mean = torch.mean(X, dim=0)
    X_centered = X - X_mean
    
    # 2. 奇異值分解 (SVD: X = U S V^T)
    # V 的前 k 欄即為協方差矩陣的前 k 個特徵向量
    U, S, V = torch.linalg.svd(X_centered, full_matrices=False)
    
    # 3. 投影至前 k 個主成分方向
    W = V[:k, :].T  # (d, k)
    X_projected = torch.mm(X_centered, W) # (n, k)
    
    # 4. 計算各主成分解釋變異數比例
    explained_variance = (S ** 2) / (X.size(0) - 1)
    explained_variance_ratio = explained_variance[:k] / explained_variance.sum()
    
    return X_projected, W, explained_variance_ratio

# 示範於 GPU 執行 (若支援)
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
X_tensor = torch.randn(10000, 128, device=device)
X_proj, W, evr = pytorch_pca(X_tensor, k=2)
print(f"PyTorch 降維完成，輸出形狀: {X_proj.shape} on {device}")
print(f"前兩軸解釋變異數比率: {evr.cpu().numpy()}")
