NumPy 的多維陣列核心物件為 ndarray。記憶體連續存放同質元素，屬性反映維度結構與數據型態，為資料預處理與矩陣運算的基石。

① ndim 軸維度數量② shape 各維度大小元組③ size 總元素數量④ dtype 元素資料型態
NumPy 程式重點 
import numpy as np
arr = np.zeros((2, 3, 4), dtype=np.float32)
print(arr.ndim)   # 3 (維度數量)
print(arr.shape)  # (2, 3, 4)
print(arr.size)   # 24 (2*3*4 總元素數)
print(arr.dtype)  # float32
易混淆考點 / 陷阱辨析：
  • •一維向量 (N,) 與二維矩陣 (1, N) 或 (N, 1) 在 scikit-learn 中完全不同，大多數 Estimator 要求二維特徵矩陣 (n_samples, n_features)。
  • •arr.size 等於 shape 中所有數值的連乘積；len(arr) 僅代表第 0 維（最外層）的長度。

有考古題 (2)

reshape 在不改變元素總數的前提下重塑陣列形狀。參數中的 -1 代表由 NumPy 自動根據其他指定維度與總元素數守恆來推算。

① 元素總數絕對守恆② -1 自動推算未知維度③ 僅允許一個維度設為 -1
NumPy 程式重點 
arr = np.arange(12)  # [0, 1, ..., 11]，size = 12
arr_2d = arr.reshape(3, -1)   # 自動推算出 (3, 4)
arr_col = arr.reshape(-1, 1)  # 自動推算出 (12, 1) 欄向量
易混淆考點 / 陷阱辨析：
  • •不能同時出現兩個或以上的 -1（例如 arr.reshape(-1, -1) 會拋出 ValueError）。
  • •總元素數量無法被其他指定維度整除時會拋出 ValueError: cannot reshape array of size X into shape Y。

有考古題 (1)

NumPy 的 axis 指定沿著哪一個軸向折疊壓縮運算。對於二維陣列：axis=0 沿著列折疊（得出每欄統計值）；axis=1 沿著欄折疊（得出每列統計值）。

① axis=0 沿垂直跨列折疊 (欄統計)② axis=1 沿水平跨欄折疊 (列統計)③ keepdims=True 保留二維維度
NumPy 程式重點 
m = np.array([[1, 2, 3],
              [4, 5, 6]])
print(m.sum(axis=0))  # [5, 7, 9] (每欄總和，壓縮列)
print(m.mean(axis=1)) # [2., 5.] (每列平均，壓縮欄)
print(m.sum(axis=0, keepdims=True)) # shape: (1, 3)
易混淆考點 / 陷阱辨析：
  • •許多人直覺誤以為 axis=0 是「在第 0 列算」，實際上 axis=0 是「消除第 0 維」，也就是垂直往下壓，結果長度等於欄數！
  • •在標準化時，若計算每特徵欄平均值，必須指定 axis=0！

有考古題 (1)

NumPy 基礎切片 (Slicing) 回傳的是原陣列的視圖 (View)，共享底層記憶體，修改切片會直接污染原陣列！欲獨立必須調用 .copy()。

① 基礎切片 arr[1:3] 共享記憶體 (View)② 花式索引/布林遮罩 產生新副本 (Copy)③ 明確複製務必呼叫 .copy()
NumPy 程式重點 
a = np.array([10, 20, 30, 40])
sub_view = a[1:3]   # 視圖 View
sub_view[0] = 999
print(a)  # [10, 999, 30, 40] -> 原陣列被意外篡改！

sub_copy = a[1:3].copy()  # 獨立副本
sub_copy[0] = 777
print(a)  # a 不受影響
易混淆考點 / 陷阱辨析：
  • •使用 arr[arr > 20] 布林索引或 arr[[0, 2]] 整數陣列索引時，NumPy 會自動建立 Copy 副本，但基礎切片 a[1:3] 一定是 View！
  • •若要避免資料預處理時原特徵被不可逆篡改，請養成使用 .copy() 的習慣。

有考古題 (1)

不同形狀的陣列運算時，NumPy 從末端維度（最右側）向左逐一比對：兩個維度相等，或其中一個為 1，即可自動廣播展開運算。

① 從最右側（末端維度）向左比對② 維度大小相等，或其中一方為 1③ 缺少的維度視為 1 補齊擴展
NumPy 程式重點 
# A: (3, 4)
# B: (   4) -> 廣播為 (1, 4) -> (3, 4) -> 相容！
A = np.ones((3, 4))
B = np.arange(4)
C = A + B  # 成功，形狀為 (3, 4)

# 無法相容範例：(3, 4) 與 (3, ) -> 末端 4 與 3 不符！
# 解決方案：B.reshape(3, 1)
易混淆考點 / 陷阱辨析：
  • •形狀 (3, 4) 與 (3,) 不能直接相加！因為 (3,) 對應的是末端維度的 4，4 與 3 不相等且皆不為 1，會報錯。必須將 (3,) 轉為 (3, 1)。

有考古題 (1)

在 NumPy 中，符號 * 代表元素逐項相乘 (Element-wise)，而符號 @ 或 np.dot 才是真正的線性代數矩陣乘法 (Matrix Multiplication)。

① * 元素對位相乘 (形狀須相容)② @ / np.matmul 現代矩陣乘法語法③ np.dot 向量內積或二維矩陣乘法
NumPy 程式重點 
A = np.array([[1, 2], [3, 4]])
B = np.array([[2, 0], [1, 2]])

# 逐元素相乘
print(A * B)  # [[1*2, 2*0], [3*1, 4*2]] = [[2, 0], [3, 8]]

# 真正的矩陣相乘 (列乘行累加)
print(A @ B)  # [[4, 4], [10, 8]]
易混淆考點 / 陷阱辨析：
  • •考試中看到 A * B 時，請千萬不要套用高中矩陣列乘行公式！那是 @ 的結果，* 只是單純相同位置數字相乘。

有考古題 (2)

loc 是以標籤名稱 (Label) 為依據選取，切片時包含結束邊界！iloc 則是以整數位置 (Position) 為依據選取，切片符合 Python 前包後不包慣例。

① loc 依標籤切片 (包含最後一個標籤)② iloc 依整數索引 (不包含結尾索引)③ 格式統一為 [列範圍, 欄範圍]
pandas 程式重點 
import pandas as pd
df = pd.DataFrame({'age': [20, 25, 30], 'score': [80, 90, 85]},
                  index=['a', 'b', 'c'])

# loc 包含 'c'！回傳 a, b, c 三列
print(df.loc['a':'c', 'age'])

# iloc 不含 2！僅回傳 index 0, 1 兩列
print(df.iloc[0:2, 0])
易混淆考點 / 陷阱辨析：
  • •當 DataFrame 的 Index 本身就是整數時（如 0, 1, 2），df.loc[0:2] 會包含標籤 2（共 3 列）；但 df.iloc[0:2] 只有前 2 列！這是最致命的考古題陷阱。

資料清洗第一步：使用 isna().sum() 統計各欄缺失量；dropna() 刪除缺失列/欄；fillna() 填補預設值或統計量（均值、中位數、眾數）。

① isna() / isnull() 判別 NaN② dropna(axis=0, subset=['重要欄'])③ fillna(val, inplace=True) 填補
pandas 程式重點 
# 檢查缺失數量
print(df.isna().sum())

# 刪除特定欄位為空的列
df.dropna(subset=['target'], inplace=True)

# 偏態數值特徵以中位數填補
median_val = df['income'].median()
df['income'].fillna(median_val, inplace=True)
易混淆考點 / 陷阱辨析：
  • •dropna() 與 fillna() 預設不會修改原 DataFrame，必須接收回傳值 (df = df.dropna()) 或設定 inplace=True！
  • •有離群值或偏態分佈的特徵，填補缺失值應優先選用「中位數 (median)」而非均值 (mean)。

在 pandas 進行多條件篩選時，必須使用位元運算子 & (AND)、| (OR)、~ (NOT)，且「每個條件子句必須以小括號 () 完整包裹」。

① 必須使用位元運算子 & | ~② 嚴格禁止使用 Python 原生 and / or③ 每個條件子句強制加小括號 ()
pandas 程式重點 
# 正確語法：每個條件都有括號
cond = (df['age'] >= 18) & (df['city'] == 'Taipei')
filtered_df = df[cond]

# 反向條件 (NOT)
not_taipei = df[~(df['city'] == 'Taipei')]

  • •若寫成 df[df['age'] >= 18 and df['city'] == 'Taipei'] 會報錯 ValueError: The truth value of a Series is ambiguous！
  • •若忘記加括號 df[df['age'] >= 18 & df['city'] == 'Taipei'] 會因運算子優先權導致語法錯誤。

combined = pd.concat([df_2023, df_2024], ignore_index=True)

map 專精於 Series 的單一欄位字典或數值映射；apply 能對 Series 套用函數，或在 DataFrame 上依軸向套用跨欄運算；replace 則替換特定數值。

① Series.map(dict) 標籤快速轉數值② Series.apply(lambda x: ...) 複雜自定義運算③ DataFrame.apply(func, axis=1) 逐列計算

# 類別文字轉數字 (二分類)

有考古題 (1)

使用 describe() 查看數據摘要。Tukey 盒鬚圖離群值判定：四分位距 IQR = Q3 - Q1；正常範圍界限為 [Q1 - 1.5*IQR, Q3 + 1.5*IQR]。

① Q1 = df['x'].quantile(0.25)② Q3 = df['x'].quantile(0.75)③ IQR = Q3 - Q1④ 異常界限 = Q3 + 1.5*IQR
pandas 程式重點 
Q1 = df['fare'].quantile(0.25)
Q3 = df['fare'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
outliers = df[(df['fare'] < lower_bound) | (df['fare'] > upper_bound)]
易混淆考點 / 陷阱辨析：
  • •Tukey 離群值倍數是 1.5 倍的 IQR，而不是 1.5 倍標準差！若使用常態分佈 3-Sigma 原則才是平均值加減 3 倍標準差。

所有 scikit-learn 演算法均遵循統一物件介面：fit 學習數據參數、transform 特徵工程轉換、predict 預測標籤、score 輸出評估指標。

① fit(X) 學習資料統計特徵 (均值/權重)② transform(X) 套用學得規則做轉換③ fit_transform(X) 合併計算 (僅限訓練集)④ predict(X) 產生預測標籤

scaler = StandardScaler()
X_train_sc = scaler.fit_transform(X_train) # 學參數並轉換

  • •測試集 (Test Set) 絕對嚴禁使用 fit() 或 fit_transform()！否則會產生資訊洩漏 (Data Leakage)，模型分數虛高失真。

train_test_split 用於切割訓練與測試集。在類別不平衡問題中，設定 stratify=y 能確保切分後的兩集合具有完全相同的類別比例。

① test_size=0.2 (20% 作為測試集)② random_state=42 (確保可重現性)③ stratify=y (依標籤比例分層抽樣)

有考古題 (1)

StandardScaler 計算 Z-score，特徵轉為均值 0、標準差 1；MinMaxScaler 將特徵壓縮至 [0, 1] 區間。樹狀模型無需縮放，但基於距離/梯度演算法必備！

① StandardScaler: (X - μ) / σ② MinMaxScaler: (X - min) / (max - min)③ 適用於 KNN, SVM, Logistic, NN
scikit-learn 程式重點 
# 數值近似常態分佈且有離群值時首選
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()

# 特徵有明確上下邊界（如影像像素 0~255）首選
from sklearn.preprocessing import MinMaxScaler
minmax = MinMaxScaler()
易混淆考點 / 陷阱辨析：
  • •決策樹 (Decision Tree)、隨機森林 (Random Forest)、XGBoost 等樹狀模型不需要做特徵縮放，因為分割點只看數值排序大小！

無大小順序名義變數（如紅/藍/綠）應使用 OneHotEncoder 展開為虛擬變數；有等級順序變數（如小/中/大）使用 OrdinalEncoder；LabelEncoder 僅供目標標籤 y 使用。

① OneHotEncoder 展開獨立 0/1 欄位② 避免線性模型誤判等級大小③ handle_unknown='ignore' 防測試集未知值
scikit-learn 程式重點

X_cat = ohe.fit_transform(df[['city']])

confusion_matrix 輸出 2x2 或 NxN 矩陣；classification_report 一次印出 Precision (精準率)、Recall (召回率)、F1-score 與 Support 樣本數。

① confusion_matrix(y_true, y_pred)② classification_report 綜合報表③ macro avg (無權重平均) vs weighted avg
scikit-learn 程式重點 
from sklearn.metrics import confusion_matrix, classification_report
cm = confusion_matrix(y_true, y_pred)
print(cm)
print(classification_report(y_true, y_pred))
易混淆考點 / 陷阱辨析：
  • •scikit-learn 的 confusion_matrix 排列慣例：列為真值 (y_true)、欄為預測值 (y_pred)，若標籤是 0 與 1，左上角預設是 TN (負類真值判為負類)！

有考古題 (1)

ROC 曲線衡量不同分類門檻下的真正率 (TPR) vs 假正率 (FPR)。AUC 為曲線下面積，範圍 [0, 1]，0.5 為隨機猜測，1.0 為完美分類器。

① 橫軸: FPR (FP / FP+TN 冤枉好人率)② 縱軸: TPR / Recall (TP / TP+FN 抓壞人率)③ 傳入參數必須是正類機率 y_prob
scikit-learn 程式重點 
from sklearn.metrics import roc_auc_score
# predict_proba 取出第 1 欄 (正類機率)
y_prob = model.predict_proba(X_test)[:, 1]
auc = roc_auc_score(y_test, y_prob)
print('ROC-AUC:', auc)
易混淆考點 / 陷阱辨析：
  • •呼叫 roc_auc_score 時，第二個引數務必傳入「預測機率」model.predict_proba(X)[:, 1]，若誤傳 model.predict(X) 標籤會算成階梯折線導致數值大幅失真！

有考古題 (1)

GridSearchCV 窮舉所有參數網格組合並配合交叉驗證；RandomizedSearchCV 則從指定分佈中隨機取樣固定次數，計算速度更快且更易探索寬廣參數空間。

① cv 交叉驗證折數 (如 cv=5)② scoring 評估指標 ('f1', 'roc_auc')③ n_jobs=-1 開啟全 CPU 核心平行運算
scikit-learn 程式重點 
from sklearn.model_selection import GridSearchCV
param_grid = {'n_estimators': [50, 100], 'max_depth': [3, 5, None]}

print(grid.best_params_)
易混淆考點 / 陷阱辨析：

若 Tensor 標註 requires_grad=True，PyTorch 會在背景建構動態計算圖。對最終標量損失呼叫 loss.backward() 時，自動依鏈式法則計算各參數梯度並存於 .grad。

① x = torch.tensor(..., requires_grad=True)② loss = (y_pred - y_true)**2③ loss.backward() 自動反推微分④ x.grad 讀取偏微分斜率
PyTorch 程式重點

y = x ** 2 + 2 * x + 1  # y = x^2 + 2x + 1, dy/dx = 2x + 2
y.backward()
print(x.grad)  # 2*3 + 2 = 8.0
易混淆考點 / 陷阱辨析：
  • •只有純量（Scalar，單一數值純量）能直接無參數調用 .backward()！若 loss 是向量或多維張量，必須先算 sum() 或 mean() 轉成純量。

有考古題 (1)

自定義模型必須繼承 nn.Module。在 __init__() 中調用 super().__init__() 並宣告各神經網路層；在 forward(self, x) 中實作前向傳播資料流線路。

① 繼承 class MyNet(nn.Module):② 構造函式第一行: super().__init__()③ 定義層結構 self.fc = nn.Linear(in, out)④ 在 forward(self, x) 串接運算
PyTorch 程式重點 
import torch.nn as nn
import torch.nn.functional as F

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(20, 64)
        self.fc2 = nn.Linear(64, 2)
        
    def forward(self, x):
        x = F.relu(self.fc1(x))
        return self.fc2(x)  # 回傳 raw logits
易混淆考點 / 陷阱辨析：
  • •推論時調用模型應寫 output = model(x)，切勿寫 output = model.forward(x)！直接呼叫 model(x) 才會正確觸發 PyTorch 的 Hook 監聽回呼與上下文機制。
直擊考古題：
有考古題 (2)

PyTorch 訓練迴圈必須遵守四部順序： 1. optimizer.zero_grad() (清空歷史梯度) 2. outputs = model(inputs) (前向計算預測) 3. loss.backward() (反向傳播求梯度) 4. optimizer.step() (更新參數權重)。

① optimizer.zero_grad() 清除累積梯度② outputs = model(inputs) 前向計算③ loss = criterion(outputs, y); loss.backward() 反向求導④ optimizer.step() 梯度下降更新
PyTorch 程式重點 
for inputs, labels in dataloader:
    # 1. 清空上一個 step 的梯度（必做！）
    optimizer.zero_grad()
    # 2. 前向傳播
    outputs = model(inputs)
    # 3. 計算損失並反向傳播
    loss = criterion(outputs, labels)
    loss.backward()
    # 4. 根據梯度更新權重參數
    optimizer.step()
易混淆考點 / 陷阱辨析：
  • •若漏寫 optimizer.zero_grad()，PyTorch 預設會將新計算的梯度與舊梯度持續「累加」，導致梯度爆衝、模型訓練徹底發散崩潰！

① model.train() 訓練模式 (啟用 Dropout)② model.eval() 評估模式 (停用 Dropout)③ with torch.no_grad(): 關閉自動求導省顯存
