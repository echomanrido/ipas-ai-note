一句話解說

協方差矩陣是用來衡量多維資料中「各維度自身離散程度（方差）」與「維度兩兩之間協同變動趨勢（協方差）」的對稱半正定方陣。

協方差矩陣（Covariance Matrix，又稱共變異數矩陣）是一張用來記錄「多個項目各自的波動程度」以及「項目彼此之間如何連動」的統計表格。它能幫助我們一眼看穿多組數據是同漲同跌、此消彼長，還是完全不相干。

Real-World Intuition

生活化例子：拆解協方差矩陣的運作邏輯

以下透過「日常購物支出」與「投資理財」兩個生活例子，帶你輕鬆直觀看懂數值背後的意義。

1

生活例子一：每週超市購物籃

假設你記錄了連續幾週去超市買「咖啡豆」與「牛奶」的花費，並整理出一張 $2 \times 2$ 的協方差矩陣：

項目 咖啡豆花費 牛奶花費
咖啡豆花費 100 （咖啡豆變異數） 60 （兩者協方差）
牛奶花費 60 （兩者協方差） 80 （牛奶變異數）
● 對角線數字（變異數 Variance）

左上角的 100 代表咖啡豆每週花費的波動幅度。數值越大，代表你買咖啡豆的金額越不固定（有時買特價品，有時買高單價莊園豆）。右下角的 80 則是牛奶花費的波動幅度。

● 非對角線數字（協方差 Covariance）

右上與左下都是 60（正數），代表兩者呈現正向連動。因為你習慣喝拿鐵，只要這週多買了咖啡豆，通常也會順手多買幾瓶牛奶。

● 如果加入「衛生紙」

若矩陣加入第三項「衛生紙」，它與咖啡豆的協方差可能會接近 0。這代表買不買衛生紙，跟這週有沒有買咖啡豆完全沒有關係。

2

生活例子二：投資組合的風險分散

在理財規劃中，協方差矩陣是「雞蛋不要放在同一個籃子裡」的數學依據。假設你同時觀察「科技股」、「雨傘工廠股票」與「黃金」：

● 正協方差（同漲同跌）

科技股與半導體設備股的協方差是很大的正數。景氣好時兩者一起大漲，景氣差時也一起暴跌，同時持有無法有效分散風險。

● 負協方差（此消彼長）

「冰淇淋店」與「雨傘工廠」的協方差通常是負數。大太陽時冰淇淋大賣、雨傘滯銷；連續豪雨時雨傘大賣、冰淇淋沒人買。把這兩者放進同一個投資組合，整體收益就會變得非常平穩。

● 零協方差（互不干擾）

「黃金價格」與「本地餐飲業營收」的協方差接近 0。兩者受不同的市場因素影響，各自獨立波動。

快速判讀口訣

1. 看對角線（左上到右下） 數字越大，代表該項目自己越不穩定（波動幅度大）。
2. 看其他格子（非對角線）
正數 > 0 好兄弟，一起變大或一起變小。
負數 < 0 蹺蹺板，一個變大、另一個就變小。
接近 0 陌生人，各走各的路、互不干擾。
核心定義精要

捕捉多維隨機變數的「分散度」與「聯動趨勢」

協方差矩陣 $\mathbf{\Sigma} \in \mathbb{R}^{d \times d}$ 是機器學習與特徵工程的幾何基石。對角線反映單特徵自身的變異數（Variance），非對角線則刻劃兩特徵間的共變異（Covariance）。在 PCA 降維、馬氏距離與異常檢測中扮演中樞角色。

矩陣對稱性 $\mathbf{\Sigma} = \mathbf{\Sigma}^T$ (對稱)

兩兩變數間的關聯方向對等

幾何定性 半正定 (Positive Semi-Definite)

特徵值 $\lambda_i \ge 0$，無負方差

PCA 物理意義 特徵向量 = 主軸方向

特徵值對應投影方差大小

樣本協方差矩陣公式

設資料矩陣 $\tilde{\mathbf{X}} \in \mathbb{R}^{n \times d}$ 為已經過中心化（Zero-centered）之樣本矩陣：

$$\mathbf{\Sigma} = \frac{1}{n - 1} \tilde{\mathbf{X}}^T \tilde{\mathbf{X}}$$
$$\Sigma_{ij} = \frac{1}{n-1} \sum_{k=1}^n (x_{ki} - \mu_i)(x_{kj} - \mu_j)$$
  • • $n - 1$：貝塞爾校正（Bessel's correction），確保無偏估計。
  • • 若特徵經 Z-score 標準化，則協方差矩陣即等同相關係數矩陣 (Correlation Matrix)。
維度：$d$ 個特徵時為 $d \times d$ iPAS 常用 2D & 3D 運算

Machine Learning Applications

機器學習核心三大演算法應用

協方差矩陣在降維、機率生成分類模型與異常偵測的關鍵作用與數學原理：

主成分分析 (PCA)

對協方差矩陣進行特徵分解（Eigendecomposition），可找出資料方差最大的方向（即主成分）。

$$\mathbf{\Sigma} \mathbf{w} = \lambda \mathbf{w}$$
$\max_{\|\mathbf{w}\|=1} \operatorname{Var}(\mathbf{Xw}) = \lambda_{\max}$
📌 特徵向量即為保留最大資訊量的正交投影基底。

線性與高斯判別分析 (LDA / GDA)

作為多變量常態分布的核心參數，用來決定各類別的幾何分佈形狀與分類決策邊界。

$$p(\mathbf{x}|y) \sim \mathcal{N}(\boldsymbol{\mu}_k, \mathbf{\Sigma})$$
等方差時為線性邊界 (LDA)，不等時為二次邊界 (QDA)
📌 共用協方差矩陣決定類別內分散度（Within-class scatter）。

馬哈拉諾比斯距離 (Mahalanobis Distance)

在異常值偵測中，利用協方差矩陣的逆矩陣 $\mathbf{\Sigma}^{-1}$，計算考慮到特徵尺度與維度相關性的統計距離。

$$D_M(\mathbf{x}) = \sqrt{(\mathbf{x}-\boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x}-\boldsymbol{\mu})}$$
消除維度相關性與各向異性
📌 形成等機率橢球面，精準偵測常態多維分佈的離群點。

實戰程式碼對比：NumPy vs PyTorch Tensor 
import numpy as np
import torch

# 建立 5 筆樣本、3 個特徵的資料矩陣 (n=5, d=3)
X = np.array([
    [2.5, 2.4, 0.5],
    [0.5, 0.7, 0.2],
    [2.2, 2.9, 0.8],
    [1.9, 2.2, 0.6],
    [3.1, 3.0, 0.9]
])
n = X.shape[0]

# 步驟 1: 計算特徵中心化 (Zero-center)
X_mean = np.mean(X, axis=0)
X_centered = X - X_mean

# 步驟 2: 向量化外積相乘，除以自由度 (n - 1)
cov_manual = (X_centered.T @ X_centered) / (n - 1)

# 步驟 3: PyTorch GPU 特徵分解 (PCA 降維核心)
X_tensor = torch.tensor(X_centered, dtype=torch.float32)
cov_torch = torch.mm(X_tensor.t(), X_tensor) / (n - 1)
eigenvalues, eigenvectors = torch.linalg.eigh(cov_torch)

print("協方差矩陣:\n", cov_manual)
print("特徵向量 (主軸):\n", eigenvectors)

題號 01 ｜ 主成分分析 (PCA)

在對零均值化的高維資料集進行主成分分析（PCA）降維時，資料投影後方差最大的方向是透過求解協方差矩陣的何種屬性獲得？

正確解答：(B)

解析：投影後方差目標函數為 $\max_{\mathbf{w}} \mathbf{w}^T \mathbf{\Sigma} \mathbf{w}$ 滿足 $\|\mathbf{w}\|=1$。透過拉格朗日乘子法可得 $\mathbf{\Sigma}\mathbf{w} = \lambda\mathbf{w}$，目標最大方差即為協方差矩陣的最大特徵值 $\lambda$，其方向為對應之特徵向量 $\mathbf{w}$。

題號 02 ｜ 矩陣基本性質

若有一組實數隨機變數計算所得的協方差矩陣為 $\mathbf{\Sigma}$，下列敘述何者錯誤？

正確解答：(C)

解析：主對角線元素 $\Sigma_{ii} = \operatorname{Var}(X_i) = \mathbb{E}[(X_i - \mu_i)^2] \ge 0$，變異數為平方期望值，永遠不可能為負數，故 (C) 敘述錯誤。
