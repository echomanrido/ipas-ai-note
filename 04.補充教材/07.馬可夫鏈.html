📌 00. 一句話總結定義

什麼是馬可夫鏈？

「未來只取決於當前狀態，與過去歷史無關（無記憶性）——它是將系統時序演化解構為『狀態空間』與『條件躍遷機率矩陣』的隨機動態模型，更是強化學習 MDP 與生成式序列模型的核心基石。」

核心原理 (Core Principle)
  • 1. 馬可夫性（條件獨立／無記憶性）： 給定當前狀態 $X_t$，未來 $X_{t+1}$ 的分佈與過去軌跡 $\{X_0, \dots, X_{t-1}\}$ 條件獨立。歷史被完整編碼入「現態」。
  • 2. 隨機躍遷矩陣與線性運算： 以列隨機矩陣 $P$ 表徵跳轉機率（每列和為 1），機率向量演化遵循 $v_{t+1} = v_t P$，$n$ 步機率即為矩陣乘方 $P^n$。
  • 3. 遍歷收斂（動態定點）： 滿足「不可約」且「非週期」之鏈，必存在唯一平穩分佈 $\pi = \pi P$，系統長程分佈收斂且消除初態敏感性。
IPAS AI 考題特徵 (Certification Focus)
  • 1. 強化學習 MDP 五元組與 Bellman 方程： IPAS 考題極常考查強化學習基礎：$\langle S, A, P, R, \gamma \rangle$，詢問「狀態轉移機率 $P(s' \mid s, a)$ 是否滿足馬可夫性」及折現因子 $\gamma$ 對決策長短期的影響。
  • 2. NLP 序列模型演進（N-gram $\to$ HMM $\to$ Transformer）： 學習指引評量重點：比較統計機率模型（隱馬可夫模型 HMM、CRF 於詞性標註/語音辨識之應用與局限）與現代自注意力機制的長程依賴差異。
  • 3. 轉移矩陣運算與狀態辨別： 單選題常出現「給定轉移機率矩陣 $P$ 計算 2 步後的機率分佈」或辨識何謂「無記憶性（Memoryless Property）」觀念題。
實務特徵 (Production & Systems)
  • 1. 稀疏性與大規模圖計算 (PageRank)： 超大規模狀態（如巨量網頁或用戶行為圖）轉移矩陣達十億維度，實務使用稀疏矩陣儲存並搭配冪迭代法 (Power Iteration)。
  • 2. 狀態特徵化 (State Featurization)： 真實世界資料常非嚴格一階馬可夫，工程上透過「滑動視窗拼接」或「RNN 隱藏狀態 $h_t$」將時序歷史強行壓縮入單一狀態向量。
  • 3. 採樣技術 (MCMC & 投機解碼)： 高維積分無法封閉求解時仰賴馬可夫鏈蒙地卡羅採樣；在 GenAI 端側推理時，則用輕量馬可夫草稿模型加速 Transformer 解碼。
01. 誕生背景與歷史典故

學術論戰下的產物：打破「大數法則必然依賴獨立性」的神話

神學與數學的交鋒

20世紀初，俄國數學家帕維爾·涅克拉索夫 (Pavel Nekrasov) 聲稱：大數法則只適用於相互獨立的事件，並以此論證人類「自由意志」在統計規律中的神聖性。

馬可夫的有力反擊

安德烈·馬可夫 (Andrey Markov, 1856–1922) 為了駁斥此論調，於 1906 年構造了一種「強烈依賴前一個狀態、但依然遵守大數法則與中央極限定理」的鏈狀隨機變數序列。

普希金詩集的統計實驗

1913年，馬可夫親手統計了普希金著名長詩《尤金·奧涅金》前兩萬個字母，計算出俄語中「母音接子音」與「子音接母音」的轉移機率，成為歷史上第一個實際文字的馬可夫模型！

01-B. 深度探索：什麼是大數據獨立性？如何打破獨立性枷鎖？

從「獨立同分佈 (i.i.d.)」到「時序相依」：統計學與 AI 的範式轉移

在馬可夫之前，古典機率統計學主要奠基於**獨立性假設（Independence Assumption, i.i.d.）**。然而在 AI 領域的大數據（文本串流、金融高頻交易、機器人感測軌跡）中，相鄰觀測數據幾乎必然高度相關。

✕ 什麼是傳統的「獨立性假說」？為何在大數據與 AI 中失效？

1. 數學本質（i.i.d.）： 變數間互不干涉，聯合機率等於邊際機率的乘積： $$P(X_1, X_2, \dots, X_n) = \prod_{i=1}^n P(X_i)$$ 這意味著過去發生的任何事，對未來的機率分佈毫無任何影響。

2. 現實大數據與 AI 任務的真實樣貌： 在 NLP、物聯網感測器、強化學習序列決策中，「純粹獨立」幾乎不存在！

  • 語意大數據： 「卷積」後面接「神經網路」的機率極高，文字前後高度相依。
  • 強化學習決策： 機器人當前關節角度直接受前一微秒動作影響。
  • 若盲目誤用獨立假設： 模型會嚴重低估連續偏差的累積風險，導致預測全面失準。
✓ 馬可夫如何突破獨立性限制？

1. 結構化相依（一階條件獨立）： 馬可夫提出革命性的精簡約束：允許變數間強烈相依，但相依性僅透過當前狀態單步傳遞，既打破了獨立性束縛，又避免了全歷史建模導致的維度爆炸。

2. 馬可夫大數定理 (Markov's LLN)： 馬可夫嚴格證明：只要鏈的記憶衰減滿足混合條件，即使樣本高度時序自相關，其樣本平均仍依機率收斂於全域期望值！ $$\lim_{n \to \infty} P\left( \left| \frac{1}{n} \sum_{t=1}^n f(X_t) - \mathbb{E}_\pi[f] \right| > \epsilon \right) = 0$$

3. 遍歷性定理（Ergodicity）： 允許以「單一系統長時間軌跡的平均」替代「百萬個獨立平行試驗的均值」，為強化學習體驗回放（Replay Buffer）與 MCMC 採樣提供堅實理論支撐。

04. 核心理論簡介

核心性質與四大定理要素

1

馬可夫性 (無記憶性)

已知目前狀態 $X_t$ 的條件下，未來狀態 $X_{t+1}$ 與歷史條件獨立：

$P(X_{t+1}=s \mid X_t, \dots, X_0) = P(X_{t+1}=s \mid X_t)$
2

狀態轉移矩陣 (P)

轉移矩陣每列和為 1 (隨機矩陣, Stochastic Matrix)。元素 $P_{ij}$ 代表自狀態 $i$ 跳至狀態 $j$ 的機率。

$P_{ij} \ge 0, \quad \sum_{j} P_{ij} = 1$
3

平穩分佈 (Stationary)

當系統運行足夠久，狀態機率分佈向量不再隨時間改變：

$\pi P = \pi, \quad \sum_i \pi_i = 1$
4

遍歷性定理 (Ergodicity)

若馬可夫鏈是「不可約 (Irreducible)」且「非週期 (Aperiodic)」的有限鏈，則無論初態為何，最終必收斂至唯一平穩分佈。

07. 完整 Python 與 PyTorch 實作代碼

工程級別代碼：平穩分佈求解與 GPU 批量模擬

包含 NumPy 線性代數求解特徵向量，以及 PyTorch 張量批量矩陣並行採樣。

import numpy as np
import torch

# =====================================================================
# 1. NumPy 經典解析解：特徵值分解求解平穩分佈 (π P = π)
# =====================================================================
P = np.array([
    [0.80, 0.20],  # 晴天 -> [晴天, 雨天]
    [0.40, 0.60]   # 雨天 -> [晴天, 雨天]
])

# 轉置求特徵值，使 P^T * v = 1 * v 成立
eigenvalues, eigenvectors = np.linalg.eig(P.T)
# 尋找特徵值最接近 1 的對應特徵向量
stationary_idx = np.argmin(np.abs(eigenvalues - 1.0))
stationary_vec = np.real(eigenvectors[:, stationary_idx])
pi_numpy = stationary_vec / np.sum(stationary_vec)

print(f"[NumPy 解析解] 平穩分佈 π = {pi_numpy}")

# =====================================================================
# 2. PyTorch GPU 向量化批量蒙地卡羅步進模擬 (Batch Markov Chain)
# =====================================================================
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
P_tensor = torch.tensor([
    [0.80, 0.20],
    [0.40, 0.60]
], dtype=torch.float32, device=device)

num_chains = 100_000  # 同時模擬 10 萬條獨立平行世界軌跡
steps = 50

# 初始狀態全設為雨天 (State 1)，驗證不論初態為何都會收斂至平穩分佈
current_states = torch.ones(num_chains, dtype=torch.long, device=device)

for step in range(steps):
    # 根據每個 chain 當前狀態提取對應的躍遷機率分佈 [N, 2]
    probs = P_tensor[current_states]
    # 使用 torch.multinomial 進行 GPU 並行採樣
    current_states = torch.multinomial(probs, num_samples=1).squeeze(-1)

# 計算經驗分佈 (Empirical Distribution)
empirical_dist = torch.bincount(current_states, minlength=2).float() / num_chains
print(f"[PyTorch 10萬樣本模擬] 50步後狀態分佈: {empirical_dist.cpu().numpy()}")
