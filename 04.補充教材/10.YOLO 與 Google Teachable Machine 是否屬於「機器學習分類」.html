重點精華 · 實務落地
重點整理 (Key Takeaways)
  • Google Teachable Machine：本質上是「基於遷移學習的監督式機器學習分類器」。以預訓練 MobileNet 萃取特徵向量，用戶在上層以 KNN 或微調 Softmax 分類頭完成多類別影像/音訊分類。
  • YOLO (You Only Look Once)：屬於「端到端物件偵測 (Object Detection)」框架，它「包含分類，但遠大於純分類」。YOLO 同步完成「Bounding Box 邊界框迴歸定位」與「類別機率多標籤分類」。
  • 單一任務 vs 複合任務：傳統分類回答「這張圖是什麼？」（全局單一標籤）；物件偵測則回答「圖中有哪些東西、在什麼幾何位置？」（多物件、位置座標 + 類別機率）。
  • iPAS 檢定核心思辨：在標準 AI 檢定分類體系中，兩者底層均深深植根於監督式學習與損失反向傳播，但其網路輸出頭（Output Head）設計與損失函數構造有著根本級的維度躍遷。
核心機制與原理說明

Teachable Machine 運用遷移學習，凍結 MobileNet 骨幹卷積層，僅將輸入圖像映射為高維特徵 Embedding，用戶自定義的類別樣本在特徵空間透過餘弦相似度 KNN 或輕量線性層訓練交叉熵損失，屬於純粹的影像分類任務。反觀 YOLO，將輸入影像劃分為 $S imes S$ 網格，每個網格同時預測 $B$ 個邊界框座標 $(x, y, w, h)$、框內是否存在物件的置信度得分（Confidence Score，本質為二元分類或 IoU 迴歸），以及該物件所屬的 $C$ 個類別條件機率。其總損失函數是定位損失（CIoU/GIoU 迴歸）、置信度損失（BCE）與類別分類損失（BCE）的複合加權總和。

應用在何處 (產業與落地實務)
  • 製造產線無代碼快速驗證 (PoC)：廠端產線工程師以 Teachable Machine 於 10 分鐘內訓練簡單的合格/不良料盤分類原型，評估 AI 導入可行性。
  • 智慧工廠與智慧安防即時監控：YOLO 廣泛部署於邊緣端 Jetson 模組，即時追蹤未戴安全帽人員、叉車路徑障礙、產線輸送帶異物入侵（30+ FPS 即時回饋）。
  • 農業科技與零售無人結帳：利用 YOLO 實時定位並分類水果瑕疵等級，以及零售貨架商品拿取自動辨識與無感結帳系統。

YOLO 與 Google Teachable Machine 是否屬於「機器學習分類」？

釐清「純影像分類（Classification）」與「多物件偵測（Object Detection）」的任務界線與技術底層

Teachable Machine：標準分類 YOLO：主體為物件偵測

Google Teachable Machine

任務範疇：純影像分類 (Classification)
100% 分類任務

【結論：是，完全屬於分類】
Teachable Machine 旨在回答整張影像「是什麼（What）」。使用者上傳多種類別圖片（例如「良品」與「瑕疵」），系統學習將整張圖片歸入對應標籤，輸出各類別機率分佈，不包含任何物體座標位置回歸。

⚙️ 底層技術機制：
• 預訓練骨幹：基於 TensorFlow.js 載入 ImageNet 預訓練之 MobileNet。
• 遷移學習：凍結全部卷積層特徵提取器，僅微調最頂層的全連接分類頭（Dense + Softmax）。
• 輸出形態：純類別機率向量 $\mathbf{p} = [p_1, p_2, \dots, p_K]$，滿足 $\sum p_i = 1$。
支援類型：影像分類 / 音訊頻譜分類 / 人體姿態分類 No-Code 遷移學習

YOLO (You Only Look Once)

任務範疇：物件偵測 (Object Detection)
偵測 > 純分類

【結論：嚴格來說是「物件偵測」，但內部包含分類子分支】
YOLO 旨在同時回答「是什麼（What）」與「在哪裡（Where）」。它一次性對全圖進行網格劃分，不僅辨識物體類別，更同時精準回歸物體的邊界框（Bounding Box: $x, y, w, h$）。

⚙️ 底層技術機制：
• 單階段架構：端到端多任務回歸（Backbone + FPN Neck + Detection Head）。
• 複合損失函數：邊界框回歸損失（$\mathcal{L}_{box}$: CIoU）+ 物件置信度損失（$\mathcal{L}_{obj}$）+ 類別分類損失（$\mathcal{L}_{cls}$: BCE/CE）。
• 衍生延伸：現代 YOLO 程式庫（如 YOLOv8/v11）亦擴展提供獨立的純 Classification 模式。
支援類型：物件偵測 / 實例分割 / 姿態估計 / 旋轉框 Multi-task Regression

01. 一句話簡介

「影像分類是讓神經網路透過特徵提取與機率對映，回答輸入影像『是什麼（What）』的監督式學習任務；而遷移學習（Transfer Learning）則是站在預訓練巨人的肩膀上，以極少資料在數秒內微調出高精度專屬分類器。」

02 核心原理 (Core Principle)

1. 分層表徵萃取 (Feature Extraction)

利用卷積層（CNN）或 Vision Transformer (ViT) 將百萬像素影像由淺入深轉換為低維語意向量（淺層抓邊緣紋理，深層辨識部件器官結構）。

2. Logits 與 Softmax 機率轉換

全連接分類頭將抽象特徵映射為無邊界的得分值（Logits $z_k$），經由標準化指數函數（Softmax）壓縮為總和等於 1 的多類別機率分佈。

3. 遷移學習骨幹凍結 (Weight Freezing)

如 Google Teachable Machine：凍結在巨量數據（ImageNet）訓練好的通用骨幹網路（如 MobileNet），僅重新訓練頂層極少參數的分類頭，避免過擬合且大幅提速。

04 實務特徵 (Practical Characteristics)

  • 端到端特徵表徵（End-to-End Representation）： 擺脫傳統機器學習需人工抽取 SIFT/HOG 特徵的繁瑣，讓神經網路自主學習最具鑑別度的過濾器。
  • 資料極度不平衡問題（Class Imbalance）： 實務上正常樣本往往佔 99%，瑕疵樣本不足 1%，需透過 Focal Loss、Weighted Cross-Entropy 或資料擴增（Mixup、CutMix）解決。
  • 推論延遲與邊緣部署（Edge Deployment）： 著重 FLOPs 與參數平衡，常以 MobileNetV3、ShuffleNet、EfficientNet-Lite 或 TensorRT 量化（INT8）部署於產線邊緣設備。

05 由來與演進里程碑 (Origin & History)

1998：LeNet-5 雛形誕生

Yann LeCun 提出經典 CNN 架構，成功商用於美國郵政手寫郵遞區號分類。

2012：AlexNet 席捲 ImageNet

利用 GPU 平行運算搭配 ReLU 與 Dropout，一舉引爆全球深度學習大爆炸。

2015-2017：ResNet 殘差連接與 MobileNet 輕量革命

解決梯度消失讓網路深度突破千層；深度可分離卷積促使邊緣設備與瀏覽器端遷移學習成真。

2020~至今：ViT 與零樣本分類（CLIP / Multimodal LLM）

自注意力機制擴展至圖像領域，影像分類邁入多模態零樣本提示工程（Zero-Shot Classification）時代。

08 理論簡介：正向傳播、Softmax 與交叉熵損失

影像分類本質上是尋找一個參數化對映函數 $f_\theta(\mathbf{x}): \mathbb{R}^{C \times H \times W} \to \Delta^{K-1}$，將高維輸入轉換為 $K$ 個離散類別的機率分佈。整個過程由 卷積特徵提取、線性層轉換為 Logits、Softmax 機率歸一化、以及評估預測與真實分佈差距的 交叉熵損失（Cross-Entropy Loss） 組成。

09 數學推導（互動式實驗室）

動態滑動調整未歸一化對數得分（Logits $z_i$）與溫度係數（Temperature $T$），即時觀察梯度與機率分佈變化

互動式公式渲染
Step 1: Softmax 函數

將任意實數 $z_i \in (-\infty, \infty)$ 壓縮為 $(0, 1)$ 且總和為 1 的有效機率。

Step 2: 交叉熵損失 (Cross-Entropy)

當真實標籤為 One-Hot 向量時，損失等價於目標類別對數機率的負值 $-\ln(\hat{y}_c)$。

Step 3: 梯度反向傳播 (優雅的差值)

反向傳播傳回 Logits 的梯度恰好等於「預測機率」減去「真實 One-Hot 標籤」！

調整模型 Logits 輸出 ($z_1, z_2, z_3$) 目標真值: 類別 1 (One-Hot [1, 0, 0])

類別 1 Logit ($z_1$) 2.5
類別 2 Logit ($z_2$) 1.0
類別 3 Logit ($z_3$) -0.5
溫度係數 Temperature ($T$) 1.0

$T \to 0$ 趨近於 Argmax；$T \to \infty$ 機率均勻平滑。

11 Python / PyTorch 實作：標準遷移學習分類器

重點核心函式以不同顏色標明（凍結權重、替換分類頭、損失函數、優化器）

transfer_learning_classifier.py
PyTorch 2.x + TorchVision 
import torch
import torch.nn as nn
import torchvision.models as models
from torchvision import transforms
from torch.utils.data import DataLoader

# =====================================================================
# 1. 載入 ImageNet 預訓練骨幹網路 (MobileNetV2: Teachable Machine 常見骨幹)
# =====================================================================
model = models.mobilenet_v2(weights=models.MobileNet_V2_Weights.DEFAULT)

# =====================================================================
# 2. 關鍵步驟：【凍結骨幹網路全部參數】(鎖定特徵提取層，防止過擬合)
# =====================================================================
for param in model.features.parameters():
    param.requires_grad = False  # 💥 重要：不計算梯度，不更新權重

# =====================================================================
# 3. 替換頂層分類頭 (Classification Head) 為我們的自訂類別數 (例如 3 類)
# =====================================================================
in_features = model.classifier[1].in_features  # MobileNetV2 為 1280 維
num_classes = 3  # 假設任務為: [瑕疵A, 瑕疵B, 良品]

model.classifier = nn.Sequential(
    nn.Dropout(p=0.2),
    nn.Linear(in_features, num_classes)  # 💥 僅此層權重 requires_grad=True
)

# =====================================================================
# 4. 定義損失函數與優化器 (僅優化未凍結的分類頭參數)
# =====================================================================
# 💥 CrossEntropyLoss 內部已整合 LogSoftmax + NLLLoss，輸入直接傳入原始 Logits
criterion = nn.CrossEntropyLoss()

# 💥 傳入 model.classifier.parameters()，避免將凍結層加入優化計算
optimizer = torch.optim.Adam(
    model.classifier.parameters(), 
    lr=1e-3
)

# =====================================================================
# 5. 訓練單步步驟 (Forward, Loss, Backward, Step)
# =====================================================================
def train_step(images, labels):
    model.train()
    optimizer.zero_grad()              # 清空歷史梯度
    logits = model(images)             # 正向傳播獲取未歸一化分數 Logits
    loss = criterion(logits, labels)   # 計算交叉熵損失
    loss.backward()                    # 反向傳播計算梯度
    optimizer.step()                   # 更新分類頭權重
    
    # 計算當前預測類別與機率
    probabilities = torch.softmax(logits, dim=1)
    predictions = torch.argmax(probabilities, dim=1)
    return loss.item(), predictions
