為什麼不「只用蒙地卡羅」？為什麼不「只用馬可夫鏈」？

MCMC = Markov Chain (解決如何探索) + Monte Carlo (解決如何估計)
單獨用：蒙地卡羅 致命瓶頸 ✘

無法處理「未知分母」與「高維維度詛咒」

  • 需要能直接獨立抽樣 (i.i.d.)： 傳統蒙地卡羅要求我們能直接從目標分佈 $p(x)$ 抽樣（如逆變換採樣），但在多維或複雜問題中這根本辦不到。
  • 分母配分函數不可解： 在貝氏推論中 $p(\theta \mid D) = \frac{p(D \mid \theta)p(\theta)}{Z}$，分母 $Z = \int p(D \mid \theta)p(\theta)d\theta$ 是百維積分，數值積分直接崩潰。
  • 拒絕/重要性採樣在高維失效： 提議分佈在高維空間與目標分佈重合度極低，採樣接受率以指數級 $\mathcal{O}(e^{-D})$ 暴跌歸零。
結論：高維未知正規化常數下，單靠傳統蒙地卡羅「根本抽不出樣本」。
單獨用：馬可夫鏈 局限所在 ✘

它只是一種「狀態轉移動態」，缺乏估計目的

  • 只是隨機過程的數學描述： 馬可夫鏈本質僅說明「下一個狀態僅與當前狀態相關（無記憶性）」，它本身並不是數值計算或統計推論工具。
  • 漫無目的的遊走： 若未特別人為設計轉移機率，隨機漫步可能發散、週期循環或滯留在低價值區域，無法對應到特定的複雜後驗分佈。
  • 沒有數值估計機制： 馬可夫鏈生成的是一條時序相依的狀態軌跡，如何從這條軌跡轉化為「參數期望值、信賴區間、數值積分」？這超出馬可夫鏈原本的定義範疇。
結論：馬可夫鏈提供的是「局域移動機制」，但缺乏目標引導與統計推論功能。
兩者結合：MCMC 完美破局 ✔

1 + 1 > 2：巧借漫步解高維，再用經驗算期望

  • 馬可夫鏈解決「怎麼抽」： 設計細緻平衡轉移核，以「兩點機率比值 $\frac{\tilde{p}(x')}{\tilde{p}(x)}$」做局域探索，未知的可怕分母 $Z$ 被直接分子分母約分消去，完全不需要全域資訊！
  • 蒙地卡羅解決「怎麼算」： 依據遍歷定理（Ergodic Theorem），當馬可夫鏈遍歷平穩分佈後，我們用蒙地卡羅平均值 $\frac{1}{N}\sum f(x_t)$ 直接計算高維期望值。
  • 擺脫維度詛咒： 抽樣估計誤差的收斂速率恆為 $\mathcal{O}(1/\sqrt{N})$，與空間維度大小無關！
本質：以馬可夫鏈突破「無法抽樣」的死局，用蒙地卡羅實現「高維精確推論」。
01. 核心簡介與觀念總覽 Statistical Computing Framework

馬可夫鏈蒙地卡羅（Markov Chain Monte Carlo, MCMC）

一種利用馬可夫鏈進行隨機抽樣的統計計算方法。當目標機率分佈的狀態空間太大、維度太高或形式過於複雜而無法直接抽樣時，MCMC 能夠精準建構隨機漫步路徑，以經驗樣本逼近高維幾何分佈。

主要目的
目標分佈狀態空間巨大、高維度且無法直接解析抽樣時的破局關鍵。
馬可夫鏈（無記憶性）
序列隨機變數的下一個狀態僅與當前狀態相關，與歷史路徑無關。
平穩分佈收斂
人為構造轉移機率核，確保長時間漫步後極限狀態精確匹配目標分佈。
蒙地卡羅積分
自收斂後的鏈獲取樣本，透過大數法則以樣本均值估算高維積分與推斷。
支柱 01 Purpose

主要目的與痛點

當目標機率分佈的狀態空間太大、維度太高且複雜（如多參數聯立分佈或分母常數無法解析積分）而無法直接均勻抽樣或逆變換時，MCMC 提供了解析高維幾何的隨機路徑解法。

克服高維積分不可解困境
支柱 02 Markov Chain

馬可夫鏈（無記憶性）

構建一系列序列隨機變數 $X_0, X_1, \dots, X_t$，其下一個狀態 $X_{t+1}$ 的產生機率僅取決於當前所在狀態 $X_t$，與過去歷史無關： $$P(X_{t+1} \mid X_t, \dots, X_0) = P(X_{t+1} \mid X_t)$$

狀態轉移機率核 $T(x \to x')$
支柱 03 Stationary

平穩分佈收斂

MCMC 刻意設計特定的轉移機率核，保證馬可夫鏈經過多次隨機漫步更新後，其長期的極限狀態分佈能精確收斂並匹配到目標機率分佈 $\pi(x)$（Ergodic 遍歷性）。

細緻平衡：$\pi(x)T(x \to x') = \pi(x')T(x' \to x)$
支柱 04 MC Integration

蒙地卡羅數值積分

當順利從收斂後的鏈中取得大量樣本 $\{x_1, \dots, x_N\}$ 後，利用大數法則以樣本均值直接逼近任意複雜函數的統計期望值： $$\mathbb{E}[f(X)] = \int f(x)\pi(x)dx \approx \frac{1}{N}\sum_{i=1}^N f(x_i)$$

誤差收斂率 $\mathcal{O}(1/\sqrt{N})$ 不受維度影響
演算法核心演進

常見 MCMC 演算法比較與機制剖析

Metropolis-Hastings vs. 吉布斯抽樣 (Gibbs Sampling)
1. Metropolis-Hastings (M-H) 演算法 最通用基礎架構

透過提議分佈 $q(x^* \mid x_t)$ 先提出一個候選樣本點，再透過接受機率 $\alpha(x_t, x^*)$ 裁定是否跳躍：

$$\alpha(x_t, x^*) = \min\left(1, \frac{p(x^*)q(x_t \mid x^*)}{p(x_t)q(x^* \mid x_t)}\right)$$
  • 優勢： 幾乎適用於任何已知分子非正規化形式的高維分佈。
  • 局限： 若提議步長不佳，容易出現大量拒絕（留在原地）或遍歷緩慢現象。
2. 吉布斯抽樣 (Gibbs Sampling) 特殊特例・100% 接受

M-H 的特殊特例。將多維變數 $\mathbf{x} = (x_1, \dots, x_D)$ 拆開，每次固定其他變數，沿單一維度的全條件機率直接抽樣：

$$x_i^{(t+1)} \sim p\left(x_i \mid x_1^{(t+1)}, \dots, x_{i-1}^{(t+1)}, x_{i+1}^{(t)}, \dots, x_D^{(t)}\right)$$
  • 優勢： 接受率恆為 100%，無需手動微調提議分佈標準差。
  • 適用條件： 必須能夠推導出每個變數在給定其他變數下的閉式條件機率（Conjugacy）。

08 & 09. 理論剖析與數學推導

為什麼 MCMC 能在不知道分母的情況下精確抽樣？

貝氏定理中後驗機率 $p(\theta \mid D) = \frac{p(D \mid \theta)p(\theta)}{\int p(D \mid \theta')p(\theta')d\theta'}$。分母的積分稱為「邊際概似度（Marginal Likelihood）」或「配分函數（Partition Function）」。當參數空間高達數十或上百維時，數值網格積分在計算上是不可行的（$O(N^d)$ 爆炸）。

設目標平穩分佈為 $p(x)$，轉移機率核為 $T(x \to x')$。細緻平衡條件表述為：

$$p(x) T(x \to x') = p(x') T(x' \to x)$$

證明平穩性：若對所有可能的前一狀態 $x$ 進行積分：

$$\int p(x) T(x \to x') dx = \int p(x') T(x' \to x) dx = p(x') \int T(x' \to x) dx = p(x') \cdot 1 = p(x')$$

這證明了只要滿足細緻平衡，以 $T$ 進行轉移後的機率分佈依然是 $p(x')$，代表 $p(x)$ 必然是該馬可夫鏈的平穩分佈（Stationary Distribution）。

任意提議分佈 $q(x' \mid x)$（例如從當前點為中心的高斯隨機擾動）通常不滿足細緻平衡：

$$p(x) q(x' \mid x) \neq p(x') q(x \mid x')$$

我們引入一個接受機率因子 $\alpha(x, x') \in [0, 1]$，使得整體轉移機率為 $T(x \to x') = q(x' \mid x) \alpha(x, x')$。細緻平衡要求：

$$p(x) q(x' \mid x) \alpha(x, x') = p(x') q(x \mid x') \alpha(x' \to x)$$

移項整理得到比值：

$$\frac{\alpha(x, x')}{\alpha(x' \to x)} = \frac{p(x') q(x \mid x')}{p(x) q(x' \mid x)}$$

為了使採樣效率最高（盡量少拒絕、最大化採樣移動），Metropolis 與 Hastings 採取了極限解法：令較大的一端接收率為 $1$，因此得到經典的 Metropolis-Hastings 接受準則：

$$\alpha(x, x') = \min\left(1, \frac{p(x') q(x \mid x')}{p(x) q(x' \mid x)}\right) = \min\left(1, \frac{\tilde{p}(x') / Z \cdot q(x \mid x')}{\tilde{p}(x) / Z \cdot q(x' \mid x)}\right) = \min\left(1, \frac{\tilde{p}(x') q(x \mid x')}{\tilde{p}(x) q(x' \mid x)}\right)$$

★ 關鍵結論：未知的分母配分函數 $Z$ 在比值中被精準消去！我們只需能夠計算非正規化分子 $\tilde{p}(x)$，就能完成正確抽樣。

10. 領域範疇與跨領域深度應用

MCMC 在現代機器學習、深度學習與 LLM 中的定位

貝氏統計與不確定性量化 (Bayesian Statistics & ML)

貝氏統計中，參數後驗分佈為 $p(\theta \mid D) \propto p(D \mid \theta)p(\theta)$。當模型參數複雜時，分母配分函數無法封閉求解，MCMC 成為估計後驗機率分佈、信賴區間（Credible Interval）的核心支柱。

貝氏邏輯斯與層次模型 (Hierarchical Models) 透過 Gibbs 採樣或 Metropolis-Hastings 對高維階層參數抽樣，獲得完整的後驗不確定性估計，適用於小樣本高風險醫療與流行病學預測。
潛在狄利克雷分配 (LDA 主題模型) 透過 Collapsed Gibbs Sampling 解析海量文章集合中單詞與隱含主題（Topics）的聯合後驗分佈。

深度能量模型 (Energy-Based Models, EBM) 與朗之萬動力學

定義資料分佈為 $p_\theta(x) = \frac{e^{-E_\theta(x)}}{Z(\theta)}$，其中 $E_\theta(x)$ 是神經網路輸出的純量能量值。最大概似訓練需要計算對數梯度的負相位（Negative Phase）： $$\nabla_\theta \log p_\theta(x) = -\nabla_\theta E_\theta(x_{data}) + \mathbb{E}_{x \sim p_\theta}[\nabla_\theta E_\theta(x)]$$

SGLD (Stochastic Gradient Langevin Dynamics)：結合神經網路自動微分梯度的 MCMC 方法。採樣時在像素空間進行迭代： $$x_{t+1} = x_t - \frac{\epsilon}{2}\nabla_x E_\theta(x_t) + \sqrt{\epsilon} z_t, \quad z_t \sim \mathcal{N}(0, I)$$ 這正是當代擴散模型（Diffusion Models）逆向生成去噪過程的物理與數學前身！

最大熵強化學習與軌跡規劃 (Maximum Entropy RL)

在連續動作空間中，傳統 RL 容易陷入次優解。最大熵 RL（如 SAC, Soft Actor-Critic）將策略最佳化轉換為後驗機率採樣問題： $$p(\tau) \propto \exp\left(\sum_t r(s_t, a_t) + \alpha \mathcal{H}(\pi)\right)$$

以 MCMC 進行動作空間採樣：在機器人軌跡規劃（Trajectory Optimization）中，將報酬最高且動作平滑的軌跡視為高機率分佈，利用 MCMC 在動態環境障礙物中抽樣出多條可行避障路徑。

大型語言模型（LLM）推理、對齊與推測解碼

1. 推測解碼 (Speculative Decoding) 小型草稿模型（Draft model）快速提議 $K$ 個 Token，目標大模型（Target model）並行驗證。其接收機制本質就是 Metropolis-Hastings 抽樣的變形，精確保證輸出 Token 分佈與大模型單獨自回歸解碼嚴格一致，同時加速 2-3 倍！
2. 蒙地卡羅樹搜尋 (MCTS) 與複雜推理 (System-2 Reasoning) 如同 OpenAI o1、DeepSeek-R1 的思維鏈搜索，使用隨機模擬（Rollout）評估推理路徑的價值，於潛在推理狀態樹中導航最優解題步驟。
3. 受控文字生成 (Energy-Guided Controlled Generation) 將語氣、安全性、事實性定義為能量評分函數 $E(y)$，在 Token 潛在空間中透過 MCMC 採樣約束自回歸機率，使 LLM 無需重新微調即可生成符合特定條件的文本。

計算科學：計算物理、生物學與機率圖形模型

計算物理：統計力學與易辛模型 (Ising Model) 模擬自旋磁矩陣列的相變現象。高溫/低溫下的玻爾茲曼分佈 $p(s) \propto e^{-E(s)/kT}$ 透過 M-H 或 Wolff 集團抽樣模擬巨量自旋微觀態的宏觀磁化強度。
計算生物學：系統親緣演化樹與蛋白質摺疊 利用 MCMC（如 MrBayes 軟體）在數百萬種可能的基因譜系樹拓撲空間中遊走，計算生物演化枝後驗機率；並在三維構型空間抽樣分子能階分佈。
機率圖形模型 (Graphical Models & MRF) 馬可夫隨機場（Markov Random Field）及條件隨機場（CRF）中，全域配分函數計算複雜，吉布斯抽樣（Gibbs Sampling）利用節點的馬可夫毯（Markov Blanket）進行高效邊際推論。

04. 實務特徵與調校秘訣

演算法實務超參數與收斂診斷

  • 燃燒期 / 暖機期 (Burn-in)： 初始點可能位於目標分佈的低機率深淵，前 $N_{burn}$ 步是「尋路期」，應全部丟棄，僅保留收斂至平穩分佈後的樣本。
  • 稀疏抽樣 (Thinning)： 連續馬可夫樣本間存在強烈自相關（Autocorrelation）。每隔 $k$ 步抽取一個樣本，能降低自相關，提升「有效樣本數（Effective Sample Size, ESS）」。
  • 黃金接收率法則 (Optimal Acceptance Rate)： 理論證明，高維隨機遊走 Metropolis 演算法的最優漸進接收率約為 23.4%；一維情況則約在 44% 左右。
  • 收斂檢驗 ($\hat{R}$ Gelman-Rubin 統計量)： 同時運行多條隨機初始化的馬可夫鏈，當鏈間方差與鏈內方差比值 $\hat{R} < 1.05$ 時，通常判定鏈已充分收斂混合。
05. 歷史由來

曼哈頓計畫中的中子擴散之謎

1940 年代洛斯阿拉莫斯國家實驗室中，Stanislaw Ulam 在生病休養玩西洋單人紙牌（Solitaire）時，思考算出勝率太困難，不如「玩 100 次看贏幾次」！他與 John von Neumann 合作在 ENIAC 計算機上實作，並以著名賭場「蒙地卡羅」命名。1953 年 Nicholas Metropolis 等人發表重要論文；1970 年加拿大統計學家 W.K. Hastings 將其推廣至非對稱分佈，奠定現代 M-H 架構。

06. 生活化例子

國王巡視群島記 (The King of Islands)

國王要在一串島嶼巡遊，希望在各島停留時間正比於該島人口。國王不知道總人口，每天只能擲硬幣決定是否提議前往相鄰島嶼：
1. 信鴿向鄰島詢問人口 $P_{neighbor}$。
2. 若鄰島人口更多，國王立刻啟程 ($100\%$ 接受)。
3. 若鄰島人口較少，國王擲一枚偏向骰子，以機率 $\frac{P_{neighbor}}{P_{current}}$ 決定前往，否則留在原地。
長此以往，國王在各島停留的時間比例完美等於各島人口比！這正是 Metropolis 演算法的核心機制。

# 1. 定義未正規化的目標對數機率分佈 (避免數值下溢)
def unnormalized_target_log_prob(x: torch.Tensor) -> torch.Tensor:
    # 雙峰分佈混合: 40% N(-2.5, 1.0) + 60% N(2.5, 0.5)
    p1 = 0.4 * torch.exp(-0.5 * ((x + 2.5) / 1.0) ** 2)
    p2 = 0.6 * torch.exp(-0.5 * ((x - 2.5) / 0.707) ** 2)
    return torch.log(p1 + p2 + 1e-12)

# 2. Metropolis-Hastings 抽樣演算法實作
def metropolis_hastings(num_samples=10000, proposal_std=1.2, burn_in=2000, thin=2):
    # 隨機初始化起點
    current_x = torch.randn(1)
    samples = []
    accepted_count = 0
    total_steps = num_samples * thin + burn_in

    for step in range(total_steps):
        # 對稱高斯提議分佈: x_prop ~ N(current_x, proposal_std^2)
        proposal_x = current_x + torch.randn(1) * proposal_std

        # 計算對數接受率: log_alpha = log p(x') - log p(x)
        log_prob_curr = unnormalized_target_log_prob(current_x)
        log_prob_prop = unnormalized_target_log_prob(proposal_x)
        log_alpha = log_prob_prop - log_prob_curr

        # Metropolis 接受準則
        # u ~ Uniform(0, 1) => log(u) <= log_alpha
        u = torch.rand(1)
        if torch.log(u) < log_alpha:
            current_x = proposal_x
            if step >= burn_in:
                accepted_count += 1

        # 捨棄暖機期樣本，並按 thin 步數稀疏存檔
        if step >= burn_in and (step - burn_in) % thin == 0:
            samples.append(current_x.item())

    acceptance_rate = accepted_count / (num_samples * thin)
    print(f"MCMC 完成! 接受率: {acceptance_rate:.2%} (理想範圍: 20%~50%)")
    return np.array(samples)

# 執行抽樣
if __name__ == "__main__":
    samples = metropolis_hastings(num_samples=8000, proposal_std=1.5, burn_in=1000)
    print(f"採集樣本均值: {samples.mean():.4f}, 方差: {samples.var():.4f}")
