理論推導與公式結構

從標準二元交叉熵 (BCE) 演繹至 $\alpha$-Balanced Focal Loss

深度學習基礎
Step 1 • 基礎交叉熵

標準 Binary Cross Entropy

$$ \text{CE}(p_t) = -\log(p_t) $$

其中 $p_t = p$（若真值為前景），$p_t = 1-p$（若真值為背景）。
痛點： 當 $p_t = 0.99$ 時，損失雖僅約 $0.01$，但乘上數十萬個簡單背景框後，累積梯度直接淹沒關鍵前景。

缺陷：無法區分「好學的樣本」與「棘手的樣本」。
Step 2 • 引入調節因子

加入動態權重 $(1-p_t)^\gamma$

$$ \text{FL}(p_t) = -(1 - p_t)^\gamma \log(p_t) $$

當樣本容易分類（$p_t \to 1$）時，$(1-p_t)^\gamma \to 0$，損失被強烈打壓！
當樣本難分類（$p_t \to 0$）時，調製因子趨近於 1，完整保留其懲罰力道。

突破：自動抑制已收斂良好樣本的梯度貢獻。
Step 3 • 終極平衡形態

$\alpha$-Balanced Focal Loss

$$ \text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t) $$

加入 $\alpha_t$ 同步調節正負樣本基底比例。
實務經典推薦超參數組合：
$\alpha = 0.25, \gamma = 2.0$（兼顧樣本難易動態與正負比例靜態平衡）。

PyTorch 工業級實作 (重點函式彩色標明)

數值穩定（Logits-Based）且支援自定義 $\alpha$ 與 $\gamma$ 的完整 Module

focal_loss.py
Python 3.8+ / PyTorch 1.10+ 
import torch
import torch.nn as nn
import torch.nn.functional as F

class FocalLoss(nn.Module):
    """
    Focal Loss for Dense Object Detection & Imbalanced Classification
    公式: FL(p_t) = -alpha_t * (1 - p_t)^gamma * log(p_t)
    """
    def __init__(self, alpha: float = 0.25, gamma: float = 2.0, reduction: str = 'mean'):
        super(FocalLoss, self).__init__()
        self.alpha = alpha
        self.gamma = gamma
        self.reduction = reduction

    def forward(self, inputs: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        # inputs: 模型輸出之未經 Sigmoid 的 Logits 矩陣
        # targets: 0 或 1 二元標籤

        # 1. 計算數值穩定的基礎 BCE Loss (保持 element-wise, 不降維)
        bce_loss = F.binary_cross_entropy_with_logits(
            inputs, targets, reduction='none'
        )

        # 2. 取得預測機率 p_t (True Class Probability)
        probs = torch.sigmoid(inputs)
        p_t = probs * targets + (1.0 - probs) * (1.0 - targets)

        # 3. 計算動態衰減調製因子 Modulating Factor: (1 - p_t)^gamma
        modulating_factor = torch.pow((1.0 - p_t), self.gamma)

        # 4. 取得類別平衡因子 alpha_t
        alpha_t = self.alpha * targets + (1.0 - self.alpha) * (1.0 - targets)

        # 5. 組合最終 Focal Loss
        focal_loss = alpha_t * modulating_factor * bce_loss

        # 6. 依據 reduction 策略聚合損失值
        if self.reduction == 'mean':
            return focal_loss.mean()
        elif self.reduction == 'sum':
            return focal_loss.sum()
        else:
            return focal_loss
實務工程注意事項 1：避免數值溢位 永遠優先使用 binary_cross_entropy_with_logits 搭配 torch.sigmoid，切勿在模型尾端自帶 Sigmoid 後再計算 log()，否則容易發生浮點下溢（Underflow / NaN）。
實務工程注意事項 2：Bias 初始化秘訣 RetinaNet 論文特別指出，最後一層分類卷積的偏置（Bias）建議初始化為 $b = -\log((1-\pi)/\pi)$（如 $\pi=0.01$），防止剛開始訓練時大量背景產生巨大震盪。
