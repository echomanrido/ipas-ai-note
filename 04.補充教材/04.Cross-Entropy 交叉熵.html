Cross-Entropy 交叉熵 互動教學

一句話核心定義

「交叉熵是用來度量『AI 模型預測的機率分佈』與『真實標籤分佈』之間差距的尺標；模型預測越自信且越正確，交叉熵就越接近理論極限，一旦預測錯誤且過度自信，將承受無限大的懲罰代價。」

生活化比喻：氣象預報員與降雨懲罰

想像今天真實情況是「必定會下雨」（真實機率 $y=1$）。兩位氣象專家給出預報：

  • 專家 A 說：「今天下雨機率 99%」 損失 $-\ln(0.99) \approx 0.01$ (極低懲罰)
  • 專家 B 拍胸脯：「今天下雨機率只有 1%」 損失 $-\ln(0.01) \approx 4.61$ (暴增 460 倍!)

若預報員給出 0% 卻下了雨，損失值趨近於 $\infty$。這促使模型誠實、精確地朝向真實分佈校準。

直覺小實驗：感受 Log 懲罰的威力 損失: 0.105

假設真實答案為「是 (Label = 1)」，拖動滑桿調整模型的預測信心：

模型預測機率 $\hat{p}$: 90.0%
✓ 預測良好，只有微小處罰 Formula: $-\ln(\hat{p})$

理論簡介：從夏農資訊論看交叉熵

探索資訊量、夏農熵、KL 散度與交叉熵的數學連帶關係

1. 自資訊量 (Information)
$I(x) = -\log_2 P(x)$

事件發生的機率越小，一旦發生所帶來的「震驚度/資訊量」就越大。例如「明天太陽升起」毫無驚喜，「明天彗星撞地球」帶來極高資訊。

2. 夏農熵 (Shannon Entropy)
$H(P) = -\sum_{x} P(x) \log P(x)$

真實系統本身不可消除的「平均不確定性」。如果已知一個硬幣公正，其夏農熵最大（1 bit）；若硬幣兩面皆為正面，夏農熵為 0。

3. KL 散度 (相對熵)
$D_{KL}(P \parallel Q) = \sum_{x} P(x) \log \frac{P(x)}{Q(x)}$

衡量用預測分佈 $Q$ 去逼近真實分佈 $P$ 時所產生的「額外浪費位元數」。恆有 $D_{KL}(P \parallel Q) \ge 0$。

核心黃金等式 (The Golden Equivalence)
$H(P, Q) = H(P) + D_{KL}(P \parallel Q)$
在機器學習中，真實標籤分佈 $P$ 是固定的常數，因此它的夏農熵 $H(P)$ 是不可變的常數。因此：最小化交叉熵 $H(P, Q) \iff$ 最小化預測與真實的 KL 散度 $D_{KL}(P \parallel Q)$！

Python / PyTorch 實作對照

學會手刻公式與工程級 `torch.nn.CrossEntropyLoss()` 的數值穩定秘密

# PyTorch 官方標準最佳實踐
import torch
import torch.nn as nn

# 1. 模擬神經網路未經 Softmax 的原始輸出 Logits (批次大小 2, 類別數 3)
logits = torch.tensor([[2.0, 0.5, 0.7], 
                       [0.2, 3.1, 0.1]], dtype=torch.float32, requires_grad=True)

# 2. 真實標籤 (類別索引，非 One-Hot): 第0筆為 Class 0，第1筆為 Class 1
targets = torch.tensor([0, 1], dtype=torch.long)

# 3. 實例化損失函數 (底層自動整合 LogSoftmax + NLLLoss，具備數值穩定優化)
criterion = nn.CrossEntropyLoss()

# 4. 計算損失
loss = criterion(logits, targets)
print(f"標準 CrossEntropy 損失: {loss.item():.4f}")

# 5. 反向傳播計算梯度
loss.backward()
print("Logits 梯度 (p - y):\n", logits.grad)
工程避坑重點： 千萬不要在 PyTorch 網路的最後一層加上 nn.Softmax() 後再去接 nn.CrossEntropyLoss()！因為 PyTorch 的 CrossEntropyLoss 內部已經把 LogSoftmax 與 NLLLoss 合併，採用了 Log-Sum-Exp 技巧來杜絕數值溢位 (Numerical Overflow / Underflow)。
